백경필 대표님 1:1 컨설팅 정리

3개프로그램 설치 완료
1단계스토어 심사 후 API 연동
백경필 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

처음부터 설치를 못 하신 상태여서, 원격으로 연결해 프로그램 세 개를 한 번에 깔고 계정·결제·키 발급까지 마쳤습니다. 남은 건 스마트스토어 심사가 끝난 뒤 API 연동 하나입니다.

오늘 끝낸 것

크롬 업데이트, 원격 연결, 셀러들의 수다 · 자동 카탈로그 · 상품 자동등록 세 프로그램 설치와 회원가입, 이미지용 AI 결제 등록과 API 키 발급까지 완료했습니다.

남은 것

스마트스토어가 심사 중(목요일 신청)이라 API 연동은 아직입니다. 심사가 끝나면 아이디와 시크릿 키를 받아 프로그램에 넣으면 됩니다.

막히면

전화보다 셀수다 질문하기가 가장 빠릅니다. 하루 100개까지, 보통 3시간~하루 안에 답변드립니다. 오래 걸릴 일은 1:1 컨설팅을 신청해 주세요.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1크롬 정리와 원격 연결“패스키 보안 안 하셔도 돼요. 건너뛰기 하세요.”▾
  • 크롬 비밀번호를 다시 설정했는데 ‘이 기기에서 사용할 수 없다’고 떠서 크롬을 먼저 업데이트했습니다.
  • 업데이트 후 나오는 패스키 보안은 건너뛰기로 넘어가셔도 됩니다.

원격 연결 순서

  1. 크롬 리모트 데스크톱 설치
  2. 코드 생성을 눌러 나온 숫자를 코치에게 불러 주기
  3. 연결 요청이 오면 공유 누르기
  • 원격 중에 뜨는 “이 앱이 디바이스를 변경하도록 허용하시겠습니까?” 같은 확인창은 코치 화면에는 보이지 않고, 뜨면 코치가 마우스를 못 움직입니다. 화면이 멈춘 것 같으면 대표님 화면에 확인창이 떠 있는지 보고 ‘예’를 눌러 주세요.
  • 대표님 방에서 통화가 가끔 끊길 수 있습니다. 안 들리시면 지금처럼 불러 주시면 됩니다.
2프로그램 세 개 설치와 회원가입“한꺼번에 다 깔다 보니까 어려우셨을 거예요.”▾
프로그램하는 일
셀러들의 수다질문하기, 1:1 컨설팅 신청
자동 카탈로그카탈로그 작업
상품 자동등록상품 등록 (이미지용 AI 키·네이버 API 연결 필요)
  • 대표님이 주로 쓰실 것은 크롬 즐겨찾기에 넣고, 셀러들의 수다는 작업 표시줄에 고정해 두었습니다. 꺼져도 작업 표시줄 아이콘을 누르면 다시 열립니다.
  • 각 프로그램 회원가입은 휴대폰 번호로 했고, 비밀번호도 모두 같은 규칙으로 맞췄습니다. 꼭 바꾸실 필요는 없고, 원하시면 나중에 바꾸셔도 됩니다.
  • 닉네임은 한글로 적어도 됩니다.
3이미지용 AI(구글 제미나이) 결제와 키 발급“월이 아니고, 16,000원이 다 쓰이면 다시 충전되는 거예요.”▾
  • 상세페이지 썸네일 같은 이미지를 만들어 주는 구글 AI입니다. 처음 쓰실 때 구글에 카드 정보를 등록해야 합니다.
  • 주소는 선택 항목이라 다 안 적어도 됩니다. 이름 입력 후 휴대폰 문자 인증(6자리)을 거쳤습니다.
  • 카드 비밀번호 앞 두 자리를 한 번 잘못 눌러 오류가 났고, 다시 넣어 저장했습니다. 앞으로 이 카드로 계속 결제됩니다.
  • 결제 방식: 16,000원어치 크레딧을 사 두고 쓰는 방식입니다. 매월 빠지는 돈이 아닙니다. 상품 하나 등록에 약 200~300원이 쓰입니다.
  • 자동 충전은 크레딧이 거의 다 쓰이면 16,000원을 다시 결제하는 기능입니다. 켜도 되고 안 켜도 됩니다. 안 켜면 다 쓰였을 때 결제 → 크레딧 구매하기에서 직접 충전하시면 됩니다.
  • 결제 후 나온 API 키는 상품 자동등록 프로그램에 저장해 두었습니다.
4스마트스토어 심사 끝나면 할 일: API 연동남은 일“아이디랑 시크릿 키가 나오면 여기에다 넣어 주시면 돼요.”▾
  • API 센터에서 계정 생성을 누르니 ‘통합 매니저 권한이 아니거나 스토어 심사 중’이라고 떴습니다. 목요일에 심사를 신청하셔서 아직 심사 중입니다.
  • 영업일 기준이라 늦어도 화요일이나 수요일쯤 끝날 것으로 보입니다(확정 아님).
  • 스마트스토어 로그인이 한 번 안 됐는데 네이버 아이디로 로그인하니 들어가졌습니다.

심사가 끝나면

  1. 네이버 커머스 API 센터에서 시작하기
  2. 계정 생성 → 강의에서 안내한 대로 뷰셀 항목 확인 후 생성
  3. 나온 아이디 · 시크릿 키를 상품 자동등록 프로그램에 입력 (들어갈 때마다 입력창이 뜨고, 안 보이면 설정에서 입력)
  • 자세한 순서는 뷰셀님이 전자책이나 강의에서 한 번 더 보여 주실 예정입니다. 하다가 막히면 컨설팅을 다시 신청해 주세요.
5질문하기와 1:1 컨설팅 쓰는 법“그나마 빠른 게 질문하기예요.”▾
  • 질문하기: 셀러들의 수다에서 ‘질문하기’를 누르고 상황을 적거나, 캡처·사진을 붙여 보내시면 됩니다. 처음에 이름을 한 번 적습니다.
  • 하루 100개까지 올릴 수 있고, 보통 3시간~하루 안에 답변드립니다. 사업과 함께 하다 보니 바로 답이 못 갈 때도 있습니다.
  • 급한 전화는 코치들이 컨설팅 중이라 받기 어려운 경우가 많습니다. 질문하기가 가장 빠릅니다.
  • 1:1 컨설팅: 셀러들의 수다에서 1:1 선택을 눌러 신청합니다. 코치들이나 뷰셀님이 보고 잡아 드립니다.
  • 컨설팅은 10회로 안내되어 있고 오늘도 1회 차감됩니다. 다만 딱 10회로 끊지는 않고, 열심히 하시는 분은 20회 가까이 받으신 경우도 있습니다.
6컴퓨터는 바꾸지 않아도 됩니다“원격 걸면 보통 버벅거리는데, 대표님 거 진짜 빨라요.”▾
  • 2017년쯤 산 데스크톱 PC인데 원격으로 봐도 새 컴퓨터 수준으로 빠릅니다. 노트북보다 지금 PC로 하시는 게 낫습니다.
  • 쓰실 만큼 쓰시고, 수익으로 강의비를 먼저 회수한 다음에 바꾸셔도 됩니다.
  • 컴퓨터를 바꾸면 프로그램을 다시 세팅해야 합니다. 그때 컨설팅으로 한 번에 깔아도 되고, 하나씩 깔면 혼자서도 어렵지 않습니다.
7앞으로의 흐름: 상품 등록 → 발주“발주는 2주차 때 진행돼요.”▾
  • 오늘 세팅은 질문할 때, 상품 등록할 때 쓰는 도구를 준비한 것입니다. 당장 집중할 것은 상품 등록입니다.
  • 판매가 되면 하는 발주는 2주차 강의에서 다룹니다. 그 전에 주문이 들어오면 질문하기나 컨설팅으로 알려 주세요.
  • 강의는 뷰셀님이 시작 5분 전까지 카톡방에 링크를 올립니다. 그 링크로 들어가시면 됩니다.

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 스마트스토어 심사 결과 확인 백경필목요일 신청, 화~수 예상
  • 심사 끝나면 API 아이디 · 시크릿 키 발급 후 프로그램에 입력 백경필시작하기 → 계정 생성 → 키 입력, 막히면 컨설팅 신청
  • 이미지용 AI 자동 충전 켤지 정하기 백경필안 켜면 다 쓰였을 때 결제 → 크레딧 구매하기
  • 궁금한 건 셀수다 질문하기로 백경필캡처 첨부, 하루 100개, 3시간~하루 내 답변
  • 강의는 카톡방 링크로 입장 백경필시작 5분 전까지 링크 올라옴
  • 발주 전에 주문이 들어오면 바로 문의 백경필발주는 2주차 강의에서
