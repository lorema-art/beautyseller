하루 2시간작업 가능 시간
백지선 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

“계속 찾아도 안 나온다”는 고민으로 시작해, 원격으로 대표님 화면에서 베스트 소싱을 같이 돌려 보고 실제로 마진 남는 상품 두 개를 찾아 시트에 정리하는 데까지 진행했습니다.

지금 상태

마스크팩·앰플·색조를 오가며 찾다 보니 결과가 안 나왔습니다. 확인해 보니 상품 하나 보는 속도(30~40초)는 충분히 빠릅니다. 문제는 카테고리를 자주 옮겨 다닌 것입니다.

이번에 찾은 것

네베소에서 블랑네이처 어성초 토너 300ml(네이버 적립 반영, 위탁 시 약 1,700원 마진), 오늘의 할인에서 엘바이오 건기식(쿠팡 5개 묶음 → 1개 카탈로그, 약 2,000원 마진).

앞으로

하루 2시간 안에서 베스트 소싱 + 꼬리물기를 하고, 안 나오는 날엔 오늘의 할인을 섞어 등록 흐름을 끊지 않습니다. 숙제는 꼬리물기 5개.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1안 나올 때는 카테고리를 고정하기핵심“카테고리는 여기 안에서만 움직이시는 게 좋아요.”▾
  • 대표님은 마스크팩, 앰플, 색조까지 넘나들며 보셨는데, 이렇게 왔다 갔다 하면 더 힘들어집니다.
  • 2차 카테고리 하나 안에서만 계속 보시면 보통 서너 시간에 하나는 나옵니다. 베스트는 원래 3시간에 1개 나올까 말까라, 안 나오는 날엔 인내심이 필요합니다.
  • 스킨케어 › 스킨/토너를 기준으로 잡고 80개 카탈로그를 끝까지 본 뒤, 찾은 상품 하나로 꼬리물기를 시작하면 됩니다.
  • 스킨케어에서 안 나오면 다음은 크림, 그다음 토너 패드·앰플 패드 순으로 들어가면 한두 개씩 나옵니다.
2베스트 소싱 한 바퀴 (같이 해 본 순서)“1개짜리는 안 될 것 같아요. 그러면 패스해 주시고요.”▾

묶음이면 개당 가격 환산

안 되면 바로 패스
  • 묶음 상품은 나누기로 개당 가격을 낸 뒤 배송비 3,000원을 더해 1개짜리 카탈로그 가격과 비교합니다. 예: 3개 51,000원 → 개당 약 17,000원 + 3,000원 = 2만 원이라 1개 카탈로그와 차이가 없어 패스.
  • 에누리에서는 배송비 포함을 체크하고, 카탈로그 기준 가장 저렴한 곳을 기준점으로 봅니다. 상품명이 길면 뒤쪽을 지워 짧게 검색합니다.
  • 판매처가 하나뿐인 카탈로그는 에누리에서만 확인하면 됩니다.
  • 상담 중 여러 후보는 마진이 안 나와 넘겼고, 카탈로그가 안 보일 땐 네이버 로그인 상태를 확인했습니다.
3찾은 상품: 블랑네이처 어성초 토너 300ml“이걸로 소싱이 가능해요, 위탁으로 하면.”▾

포인트까지 넣은 실구매가 계산

  • 네이버 카탈로그 최저가 약 21,680원. 공식몰로 보이는 판매처 가격 약 21,700원에서 기본 적립 + 멤버십 추가 적립만 뺍니다.
  • 리뷰 적립·네이버페이 머니 결제 적립은 빼지 않습니다(우리는 안 하니까). 멤버십 전용 카드 적립은 한 번만 적용되는 일회성이라 불안정해서 제외합니다.
  • 이렇게 계산하면 실구매가 약 18,445원입니다. (네이버 멤버십은 월 4천 원대 비용이 있습니다.)

마진

  • 위탁으로 고객에게 바로 배송되는 조건이면, 카탈로그보다 10원 싸게 올려도 약 1,700원이 남습니다. → 소싱 가능.
4오늘의 할인 활용법주의“오늘 올려도 내일 당장 할인이 풀릴 수 있거든요.”▾
  • 네베소·꼬리물기에 시간을 많이 못 쓰는 대표님들이 빠르게 수익을 내도록 만든 기능입니다. 말 그대로 그날 할인이라 금방 끝날 수 있습니다.
  • 상품 옆 돈 모양 아이콘을 누르면 예상 마진이 보입니다. 1,000원도 안 남는 건 하지 않는 게 낫습니다.
  • 쿠팡 등 매칭은 프로그램이 찾는 거라 100% 같은 상품이 아닐 수 있습니다. 직접 들어가서 확인합니다.

꼭 보는 두 가지

① 마진 1,000원 이상 남는지
+
② 공식 판매처인지

예시: 엘바이오 건기식 (대표님 건기식 판매 가능)

  • 쿠팡 5개 묶음 약 25,900원, 상세페이지에서 주식회사 엘바이오 공식 판매처 확인.
  • 5개를 사서 1개짜리 카탈로그(약 9,880원)로 올리면, 배송비 3,000원을 붙여도 약 2,000원이 남습니다. → 소싱 가능.
5등록과 가격 설정“프로그램이 자동으로 카탈로그 기준 10원 저렴하게 들어가거든요.”▾
마진 확인된 카탈로그 열기
→
확장 프로그램 ‘카탈로그 담기’
→
모아서 등록
  • 소싱되는 즉시 카탈로그 담기를 해 두면 목록에 쌓입니다. 카탈로그 페이지를 켠 상태에서 담는 게 정석입니다.
  • 금액 설정은 따로 하지 않습니다. 자동 등록 프로그램이 카탈로그 최저가보다 10원 싸게 넣습니다.
  • 등록 후 10원 싸게 안 보였다면, 다른 판매자가 그 뒤에 다시 가격을 내린 경우입니다.
  • ‘판매처 링크 직접 지정’ 기능은 실장님도 잘 쓰지 않습니다. 카탈로그 담기로 하시면 됩니다.
6꼬리물기 시트 적는 법“네베소에서 찾은 거니까 ‘네베소’라고 적어 주시고.”▾
  • 구분: 네베소에서 찾았으면 ‘네베소’, 오늘의 할인이면 ‘오늘의 할인’.
  • 지칭 단어: 꼬리물기 할 때 적으면 되니 지금은 비워 둡니다.
  • 제조사·브랜드: 상품 페이지 ‘제품 정보’에서 복사해 넣습니다. 카테고리도 함께(예: 스킨/토너).
  • 오늘의 할인 상품만 예외로 구매 사이트 링크(예: 쿠팡 링크)를 같이 적어 둡니다. 할인이 금방 사라지기 때문입니다.
  • 오늘의 할인 상품은 잘 팔리는 카탈로그가 아니라서 꼬리물기는 하지 않습니다. 등록만 합니다.
7꼬리물기 복습2주차“지칭하는 단어는 두 단어로 적어 주시면 되거든요.”▾

지칭 단어 · 카테고리

  • 메인 단어(예: 토너)를 중심으로 브랜드명은 빼고 두 단어로 만듭니다. 예: ‘9배 토너’, ‘고농축 토너’, ‘어성초 토너’, ‘토너 300ml’.
  • 왼쪽부터 순서대로 검색합니다. ‘스킨/토너’처럼 슬래시가 있으면 스킨, 토너를 따로 검색합니다.
  • 지칭 단어와 카테고리는 검색 결과 1페이지만 보면 됩니다.
