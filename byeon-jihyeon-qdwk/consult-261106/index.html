변지현 대표님 컨설팅 정리 (2회차)

2026년 11월 6일 · 변지현 대표님, 뷰셀 · 전화 + 원격 (화면 녹화 포함)
39분상담 시간
하루 3개오늘의 할인 찜·등록
24시간톡톡 답변 기한
변지현 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

혼자 따라 하는 교육자료

오늘의 할인 상품, 혼자서 올려 보기 →이번 상담 화면 녹화를 단계별 영상·캡처로 나눴습니다. 가격관리 켜기부터 찜 → 마진 확인 → 자기 전 등록, 톡톡 답변, 프로그램 새 버전 설치까지 순서대로 따라 하시면 됩니다.

한눈에 보기

카톡으로 길게 남겨 주신 “안 된다”는 문제들을 원격으로 하나씩 확인했습니다. 대부분 컴퓨터 고장이 아니라 프로그램이 예전 버전이거나, 정상인데 정상인 줄 모르셨던 경우였습니다. 진도를 나가기보다 전체 사용법을 다시 짚었습니다.

지금 상태

등록 상품 8개. 혼자서 하루 종일 네배소·꼬리물기를 해 보셨지만 마진 상품을 못 찾으셨고, 노마진 주문 취소 승인을 못 찾아 고객 문의가 5일 밀렸습니다. 스스로를 많이 탓하고 계셨는데, 실제로는 다 잘 해 두셨고 확인하는 법만 모르셨던 겁니다.

오늘 정리한 것

자동등록·셀러들의 수다를 새 버전으로 바꾸고, IP를 고정했습니다. 오늘의 할인 찜 → 마진계산기 → 담기 흐름을 함께 해 보고, 톡톡 문의 답변까지 마쳤습니다. 자동 소싱 프로그램(토끼)도 설치해 드렸습니다.

앞으로

급하게 갈 수 없는 상황이니, 컨설팅 때마다 하나씩 해결하는 느낌으로 갑니다. 숙제는 오늘의 할인 매일 3개, 네배소 1개 → 꼬리물기. 다음 주에 같이 봅니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1가격관리 프로그램 — 안 뜨는 게 정상핵심“컴퓨터가 문제가 아니라 가격관리 프로그램을 켜셔서 그래요.”▾
  • “눌러도 안 뜨고 자꾸 머문다”고 하셨던 건 가격관리 프로그램이 이미 켜져 있어서였습니다. 한 번 켜면 크롬 창이 하나 따로 떠서 혼자 돌아가고, 다시 눌러도 새로 안 켜집니다(강의에서 안내드린 내용).
  • 컴퓨터를 켤 때마다 꼭 켜 두고, 끌 때는 따로 만질 필요 없이 전원만 끄면 됩니다.
2프로그램 새 버전으로 교체“그것도 대표님 새로고침 안 해서 그래요. 신규 버전 안 받아서.”▾
  • 자동등록 프로그램: 새 버전 다운로드 → 압축 풀기 → 설치 파일 실행(추가 정보 → 실행 → 허용) → 크롬 확장 프로그램 관리에서 기존 것 삭제 후 폴더 다시 로드.
  • 셀러들의 수다: 설치 파일만 실행하면 위로 덮어씌워져 자동으로 새 버전이 됩니다.
  • “온라인 사무실이 없었는데 생겼다”, “오늘의 할인에서 찜했는데 상품이 안 열린다”도 예전 버전이라서였습니다.
  • 컴퓨터를 어려워하셔서 화면을 녹화해 교육자료로 정리해 드렸습니다.
3IP가 켤 때마다 바뀌는 문제 — 고정“와이파이가 바뀌지 않는 이상 IP는 안 바뀌어요.”▾
  • 업무는 거의 사무실에서만 보시는데(집에서는 잠만), 등록된 IP가 너무 많았고 켤 때마다 바뀌고 있었습니다.
  • 뷰셀이 대표님 PC의 IP를 고정하고 커머스 API에 다시 등록했습니다. 한 번만 하면 되는 작업이라 따로 배우실 필요는 없습니다.
  • 웬만하면 이제 안 바뀌겠지만, 조금 더 지켜봅니다.
4오늘의 할인 → 마진계산기 → 담기핵심“이렇게 했을 때도 천 원 이상의 마진이 남는가를 보는 거예요.”▾

마진계산기
→
1,000원↑이면 담기 → 자기 전 등록
  • 셀수다 오늘의 할인에서 하루 3개까지 찜할 수 있습니다. 찜하고 상품 보기를 누르면 왼쪽(옥션 등)은 사는 사이트, 오른쪽 네이버 가격비교 보기는 카탈로그가 열립니다. 예상 마진 400원짜리는 건너뛰었습니다.
  • 실습(쿠쿠 6인용 밥솥): 사는 가격 233,980원, 카드 할인 9%, 판매가 242,400원(카탈로그 최저가보다 조금 싸게), 택배비는 뷰셀 사무실 경유 사람 머리만 한 크기라 5,000원 → 1건 순이익 약 8,200원.
  • 마진이 확인되면 카탈로그 링크를 자동등록 프로그램에 바로 넣고, 자기 전에 등록만 누르면 됩니다.
  • 주문을 받고 나서 사는 것을 권합니다. 미리 사려면 이번 주 강의에서 기준을 들은 뒤에.
5묶음은 개당으로 계산“이게 다 개당 가격으로 계산되는 거니까 그렇게 보시면 돼요.”▾
  • 3개 묶음을 사서 1개씩 팔 때 택배비를 3,000원 × 3 = 9,000원으로 넣어 “남는 게 없다”고 판단하셨습니다.
  • 마진계산기는 1건 팔 때 남는 돈 기준입니다. 예) 판매가 15,000원 − 수수료 약 1,005원 − 택배비 3,000원 − 원가 10,000원 = 1개에 995원, 3개 다 팔면 995 × 3.
  • 한 번에 이해가 안 되는 게 당연합니다. 강의를 천천히 다시 보세요.
6톡톡 문의는 24시간 안에 답변주의“전화로 했더라도 이분이 여기다가 문의를 남겼잖아요.”▾
  • 노마진 주문을 날짜를 바꿔 취소를 권했고 고객이 취소를 요청했는데, 취소 승인 위치를 몰라 5일이 지났습니다. 고객 전화를 받고 유튜브를 찾아 오후 5시쯤 승인하셨고, 카드 환불은 바로 됐습니다.
  • 그런데 오늘 아침 네이버에서 ‘고객 문의에 응대하지 않았다’는 문자가 왔습니다. 전화로 처리해도 톡톡에 남긴 글에는 따로 답변해야 합니다(원칙상 24시간 안).
  • 상담 중 함께 답변했습니다: 글의 상품 주문번호를 눌러 취소 완료 확인 → 답변 작성 → 답변하기. 같은 내용 여러 건은 똑같이 답하면 끝.
7꼬리물기 양식 · 자동 소싱 프로그램“대표님 아직 우리가 4배속도 안 했잖아요.”▾
  • “엑셀 파일(꼬리물기 양식)이 안 된다”고 하셨는데 잘 받아 두셨습니다. 찾기 쉽게 크롬 즐겨찾기에 고정해 드렸습니다.
  • 거인의 도구 공방 사이트 로그인이 안 돼 비밀번호를 새로 정했고, 셀수다 자동 소싱 프로그램(토끼 아이콘)을 설치했습니다. 셀러들의 수다 비밀번호도 초기화해 드렸으니, 새로 정한 비밀번호들은 휴대폰 메모장에 적어 두세요.
  • 자동 소싱 프로그램으로 꼬리물기를 할 수도 있지만, 아직 네배소도 강의대로 익히지 않은 단계라 지금은 손으로 먼저 합니다.
  • 네배소는 뷰셀도 1시간에 하나, 못 찾을 땐 3시간에 하나 찾습니다. 중요한 건 강의에서 보여 드린 방법 그대로 했는지입니다. 그래서 컨설팅 때 질문보다 진도를 나갑니다.
8‘가격 변경하라’ 알림은 무시“무시하세요.”▾
  • 처음에 올린 상품 8개 중 7개에 ‘금액이 변경됐으니 변경하라’는 알림이 뜬다고 하셨는데, 무시해도 됩니다. 처음 올린 상품도 그대로 두면 됩니다.
9급하게 가지 않기“현 상황에서 차분히 하나씩 해결하는 느낌으로.”▾
  • 몸으로 하는 일만 해 오셔서 컴퓨터가 낯설다고 하셨습니다. 방법은 하나, 컨설팅을 받으며 하나씩 해결하는 것입니다.
  • 못 찾는 건 대표님 잘못이 아닙니다. 모르면 혼자 오래 붙잡지 말고 바로 물어보세요.

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 컴퓨터 켜면 가격관리 프로그램 켜기 변지현창은 그대로 두고, 끌 때는 전원만
  • 오늘의 할인 매일 3개 찜 → 마진 확인 → 등록 변지현1개 기준 1,000원 이상 · 자기 전 대량등록
  • 네배소 1개 찾아 꼬리물기 양식 정리 → 꼬리물기 → 등록 변지현맞든 틀리든 해 보기 · 강의 방법 그대로
  • 톡톡 문의·취소 요청 24시간 안에 처리 변지현전화로 처리해도 톡톡에 답변
  • 이번 주 강의 보고 선사입 기준 확인 변지현그 전까지는 주문 받고 구매
  • IP 고정 유지되는지 지켜보기 뷰셀바뀌면 다시 점검
