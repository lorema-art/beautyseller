최경림 대표님 컨설팅 정리

2026년 11월 10일 · 최경림 대표님, 뷰셀 · 사무실 대면
65분상담 시간
매일 3개오늘의 할인 등록
1개첫 4배수 상품 찾기
최경림 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

2주차 진도를 나가기보다, 대표님이 혼자서 상품을 올릴 수 있게 되는 것을 오늘의 목표로 잡았습니다.

지금 상태

10월 31일 이후 등록된 상품이 없습니다. 역마진이 날까 겁나서 올렸던 상품도 모두 내리셨습니다. 2주차(소싱) 강의는 보셨지만 아직 직접 해 보지는 못하셨고, 월요일 특강도 아직 못 보셨습니다. 디지털·가전 상품은 인증 정보 입력에서 막히셨습니다.

오늘 한 것

사무실에서 대표님 노트북으로 직접 실습했습니다. KC 인증 찾기 → 카탈로그 담기 → 대량 등록 → 마진 계산 → 상품조회 확인까지 한 바퀴 돌았고, 네이버·에누리 가격 비교와 화장품 판매자(정품) 확인 방법도 함께 연습했습니다.

이번 주

집에서 오늘의 할인 매일 3개 등록을 반복하며 손에 익히고, 4배수 상품 1개를 찾아 등록한 뒤 뷰셀 카톡으로 알려 주세요. 꼬리물기는 그다음 단계입니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1오늘 목표 — 진도보다 ‘혼자 올리기’핵심“급하게 생각하시면 안 되고, 지금 2주차보다 얘가 익숙해져야 돼요.”▾
  • 10월 31일 이후 등록 상품이 없는 걸 보면, 강의 때 드린 숙제를 어려워서 못 하고 계셨을 가능성이 큽니다.
  • 1주차에 시간을 길게 드린 이유도 같습니다. 프로그램을 편하게 다루는 것이 먼저입니다.
  • 2주차(소싱) 내용은 “조금 이해는 됐는데 해 보지는 못했다”고 하셨습니다. 이해만으로는 안 되고 직접 여러 번 해 봐야 손에 익습니다.
  • 다른 수강생 속도에 맞추지 말고 대표님 속도로 따라오시면 됩니다. 녹음보다 직접 해 보는 게 중요합니다.
2역마진 걱정에 내리지 말고, 1만 원 올려 두기핵심“겁은 내실 필요 없어요.”▾
  • 대표님은 올린 상품에 역마진이 날까 봐 모두 내리셨습니다. 주문 들어온 역마진 건은 배운 대로 발주 지연 3개월 처리를 하셨습니다.
  • 온라인 가격은 주 단위로 바뀝니다. 할인 행사가 보통 주 단위라 이번 주에 없어도 다음 주에 다시 돌아옵니다.
  • 그래서 미리 판매 중단하지 말고 가격을 1만 원만 올려 두는 겁니다. 다시 할인이 돌아오면 그때 맞추면 됩니다.
  • 구분해서 기억하세요: 이미 올린 상품은 1만 원 올려 두기, 새로 찾는 상품은 마진이 안 나면 처음부터 패스.
3가전·디지털 상품 인증 정보(KC) 찾기“한국에서 유통되는 가전제품은 전기가 들어가면 다 KC 인증을 받아야 돼요.”▾
  • 오늘의 할인에서 고른 상품이 대부분 디지털·가전이라, 등록할 때 인증 번호를 몰라 막히셨습니다.
  • 건전지로 움직이는 제품도 전기를 쓰므로 KC 인증 대상입니다. 법적으로 정해져 있으니 찾아서 넣어 주면 됩니다.
  • 찾는 곳: 프로그램 화면보다 네이버 상품 페이지가 빠릅니다. 아래로 내려 보고, 안 보이면 ‘상세정보 펼쳐보기’ → 맨 아래까지 내립니다. 공식 판매처에 없으면 다른 네이버 판매자 페이지도 참고합니다(같은 상품인지 꼭 확인).
  • 실습 때 R로 시작하는 방송통신기자재 번호, 전기용품 인증 정보를 예로 봤습니다. 인증 유형·번호·제조사·인증기관을 맞춰 넣고, 선택지가 여러 개여도 등록은 됩니다.
4카탈로그 담기 → 대량 등록, 돌아갈 땐 손대지 않기주의“몇 개든 몇 백 개든 다 넣을 수 있어요.”▾

  • ‘자동 상품 등록’으로 하나씩 하면 매번 지켜봐야 합니다. 카탈로그 담기로 여러 개 담고 대량 등록 시작을 누르면 차례대로 올라갑니다. 등록가는 카탈로그 최저가로 자동 설정됩니다.
  • 담긴 게 맞는 상품인지 숫자로 비교할 수는 있지만, 대표님이 켜 둔 창이 들어가는 것이라 굳이 확인 안 해도 됩니다.
  • 카탈로그 담기 칸에 문구나 영어를 직접 입력하지 마세요. 예전에 복사해 붙여 넣은 내용 때문에 담기가 됐다 안 됐다 했을 수 있습니다.
  • 등록이 도는 동안에는 컴퓨터를 만지지 않는 게 좋습니다. 노트북은 화면이 하나라 다른 창을 보면 멈추거나 오류가 날 수 있습니다. 창이 닫혀 보여도 아직 돌아가고 있을 수 있습니다. 뷰셀도 모니터 4대를 쓰지만 웬만하면 퇴근할 때 돌립니다.
  • 다 올라갔는지는 스토어 상품관리 → 상품조회에서 확인합니다.
  • 오늘의 할인은 하루 3개까지 등록할 수 있습니다. IP는 장소마다 바뀌지만, 집 와이파이는 웬만하면 그대로라 집에서는 다시 바꿀 필요가 없을 겁니다.
5마진 계산 — 가전은 마진보다 스토어 활성화“가전제품은 마진을 보는 용도가 아니에요. 얘는 스토어가 활성화가 되도록 하는 거예요.”▾

  • 쿠쿠 밥솥으로 실습: 판매가 196,610원, 쿠폰 적용 구매가 202,490원, 카드 할인 9%, 적립금 포함 → 약 4,181원 마진(배송비 5,000원 가정).
  • 카드가 없어도 카드 할인까지 넣은 가격으로 계산합니다. 카드가 없으면 구매대행을 신청하면 뷰셀이 대신 사 드립니다.
  • 배송비 어림: 주먹 크기 3,000원 · 머리 크기 5,000원 · 몸통 크기 10,000원.
  • 가전은 큰 마진을 보려는 게 아니라 스토어 매출을 늘려 네이버가 더 밀어주게 하는 용도입니다. 2·3주차에 설명드린 내용입니다.
  • 밥솥 등록은 대기 시간이 길어 집에서 해 보시기로 했습니다.
6네이버 ↔ 에누리 가격 비교 순서핵심“배송비 포함은 매번 확인하세요.”▾
  • 네이버 상품명에서 브랜드명 + 흔히 부르는 상품명만 남겨 에누리에서 검색합니다. 예: ‘토리든 다이브인 앰플’. 세럼과 앰플은 같은 뜻으로 쓰이기도 합니다.
  • 배송비 포함 설정을 매번 켜고, 광고 영역은 지나서 카탈로그와 옵션을 봅니다. 더 싼 옵션이 숨어 있는지, 카드 할인이 있는지도 확인합니다. 파란색 표시가 최저가입니다.
  • 네이버 상품과 에누리 상품이 용량·수량·증정품까지 같은 구성인지 대조합니다. 예: 100ml+20ml 증정 → 같은 구성을 찾았지만 카드 할인이 없고 마진이 안 나서 패스.
  • 수량 구성은 총액 ÷ 수량으로 개당 가격을 냅니다(2개면 ÷2, 4개면 ÷4). 낱개 포장 마스크처럼 1개 단위면 나눌 필요가 없습니다. 어려우면 계산기·셀수다 마진계산기를 쓰세요.
  • 4개 구성 실습: 개당 약 43,930원, 약 1,600원 마진. 다만 1개 옵션이 먼저 노출되는 상품이면 4개 구성은 덜 팔릴 수 있으니 마진이 나도 팔릴지 한 번 더 봅니다.
  • 프로그램이 수량·가격이 다른 엉뚱한 상품을 비교해 보여 주면 프로그램 오류입니다. 그냥 패스하고 뷰셀에 알려 주시면 프로그램을 손보겠습니다.
  • 마진이 안 나거나 역마진이면 패스.
7화장품은 판매자부터 확인 — 가품 조심주의“가품을 유통하는 거는 굉장히 조심해야 돼요.”▾
  • 싼 곳을 찾았으면 그 판매자가 정품을 파는 곳인지 먼저 봅니다. 화장품 가품 유통은 법적 문제와 네이버 제재로 이어질 수 있습니다.
  • 확인 기준 세 가지: ① 브랜드명과 스토어명이 같은지 ② 홈쇼핑 관련 판매처인지 ③ 공식 인증(네이버 ‘판매자의 공식’ 표시 등)이 있는지. ‘공식’ 표시는 네이버가 본사로 인정한 판매자라는 뜻입니다.
  • 옥션·G마켓은 플랫폼이 판매자가 아니므로, 목록만 보지 말고 판매처에 들어가 판매자 정보를 확인합니다.
  • 실습 사례: 판매처가 본사가 아니고 상품 이미지도 흐릿해서, 싸더라도 고르지 않는 편이 좋다고 판단했습니다(가품이라고 확정한 것은 아님).
8작업 속도 — 창 배치와 단축키“키보드는 왼손, 마우스는 오른손.”▾
  • 노트북 한 화면이면 네이버는 왼쪽, 에누리는 오른쪽에 두고 화면을 나눠 씁니다. 창 찾느라 왔다 갔다 하는 시간을 줄입니다.
  • 집 데스크톱에 설치해도 되고, 듀얼 모니터가 편한지는 사람마다 달라서 직접 써 보시면 됩니다. 밖에서는 노트북, 집에서는 데스크톱으로 나눠 써도 됩니다.
  • 단축키: Ctrl+A 전체 선택 · Ctrl+C 복사 · Ctrl+V 붙여넣기 · Ctrl+W 창 닫기(X 대신). 검색어는 필요한 부분만 드래그해 복사합니다.
  • 키보드는 왼손, 마우스는 오른손으로 같이 쓰는 습관을 들이면 빨라집니다.
9숙제 — 4배수 상품 1개 찾기핵심“4배수 하나를 우선 찾는 게 숙제예요.”▾
  • 네이버 가격비교 화장품 카테고리에서 비건 → 스킨케어 → 바디케어 → 샴푸 → 핸드케어 순으로 차근차근 봅니다. 설정은 해외직구 제외 · 80개 보기, 각 카테고리는 첫 페이지만 봅니다.
  • 첫 상품은 찾는 데 1시간, 길면 3시간도 걸립니다. 조급해하지 않으셔도 됩니다.
  • 찾으면 일단 등록하고, 뷰셀 카톡으로 알려 주세요. 뷰셀이나 코치가 한 번 더 봐 드립니다.
  • 찾은 상품에서 잘 팔리는 상품·브랜드로 이어가는 꼬리물기는 지금 배우면 헷갈리니, 검색·등록이 익숙해진 다음에 알려 드립니다.
10수익 기대와 도움받는 방법“이해가 안 되면 꼭 이해가 안 된다고 말씀해 주세요.”▾
  • “꾸준히 하면 정말 수익이 나느냐”는 질문에: 지금 속도라면 한 달 안에는 어렵고, 월 50만 원 정도를 먼저 바라볼 수 있다고 답했습니다. 연세 있는 수강생은 보통 3개월을 잡고, 60~70대 수강생이 두 달쯤 뒤 월 100만 원 정도 버는 경우도 있었습니다(경험담이며 보장은 아닙니다).
  • 온라인 교육이 사기처럼 끝나는 경우가 많다는 걱정에는, 연락이 끊기지 않고 컨설팅 일정을 잡아 계속 확인할 수 있다고 말씀드렸습니다.
  • 동업자에게 일부를 맡기는 건 그분이 진짜 관심과 의지가 있어야 가능합니다. 권해서 끌어들이는 방식은 어렵습니다.
  • 막히면 원격 지원: 설치해 둔 원격 프로그램에서 접속 코드를 만들어 뷰셀에 알려 주시면 됩니다. 코치는 매뉴얼대로 빠르게 진행할 수 있으니, 모르는 건 꼭 바로 말씀해 주세요.
