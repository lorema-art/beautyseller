꼬리물기 1개+이번 숙제

최희정 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

지난 숙제(베스트 1개)는 중간에 막혀 못 해 오셨습니다. 그래서 이번에는 베스트 소싱 한 바퀴를 화면 녹화하면서 처음부터 다시 함께 했고, 마지막에 마진계산기 쓰는 법까지 익혔습니다.

막혔던 곳

지난번 녹화가 카탈로그 찾는 장면까지만 찍혀 있어, 그 뒤 순서가 헷갈리셨습니다. Ctrl+클릭으로 새 탭 열기, 복사·붙여넣기, 탭 끄기가 아직 손에 덜 익었습니다.

이번에 익힌 것

에누리 묶음 단가 계산으로 역마진 걸러내기, 공식 판매처 3가지 기준, 같은 상품·소분 판매 확인, 멤버십 적립을 뺀 실구매가로 마진계산기 돌리기.

앞으로

2주차 강의를 다시 보고, 베스트 상품에서 꼬리물기 1개 이상을 찾아 옵니다. 맞든 틀리든 직접 해 봐야 빨리 흡수됩니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1녹화하면서 처음부터 다시“그 장면을 안 찍었더라고요… 오늘 하면서 찍어볼까요?”▾
  • 지난번엔 설명을 들으며 알 것 같아서 카탈로그까지만 녹화하셨는데, 혼자 하니 그다음부터 막히셨습니다. 이번에는 Ctrl+클릭 장면부터 다시 녹화했습니다.
  • 녹화 중간중간 녹화가 실제로 되고 있는지 꼭 확인합니다. 한 번 끊겨서 다시 찍었습니다.
  • 네이버 가격비교 창과 에누리 창은 양옆에 나란히 띄웁니다. 메뉴가 이상하게 보이면 창이 작아서 그런 것이니 창을 키우면 제대로 보입니다.
  • 네베소: 화장품/미용 › 스킨케어 › 크림 · 해외직구 제외 · 80개씩. 중간에 나오는 사진 퀴즈(번호 입력)는 적힌 대로 넣으면 됩니다.
2Ctrl+클릭과 탭 정리핵심“컨트롤 누르면 이 창은 그대로 있고 클릭만 열어주거든요.”▾

  • 그냥 클릭하면 베스트 목록이 사라져 다시 찾아야 합니다. Ctrl을 누른 채 클릭하면 목록은 그대로 두고 상품만 새 탭으로 열립니다.
  • 상품명은 길면 50자(최대 80자) 정도까지만 드래그해 복사합니다.
  • 에누리 검색창 옆 다른 버튼은 누르지 마세요. 상품명이 바뀝니다. 엔터 또는 돋보기만 누릅니다.
  • 안 되는 상품은 네이버 쪽 그 상품 탭만 끕니다. 베스트 목록 탭이나 에누리 창을 끄면 처음부터 다시 해야 합니다.
  • 실수로 껐다면 Ctrl+Shift+T로 방금 닫은 탭을 되살릴 수 있습니다.
3묶음 단가로 역마진 걸러내기“한 개당 8천 원인데 6천 원에 팔아야 하니까 마진 안 남잖아요.”▾

네이버 쪽에서 먼저

  • 상품 페이지에서 수량별 가격을 내려 보고, 개당 가장 싼 구성을 찾습니다.

에누리에서

  • 항상 ‘배송비 포함’ 체크 → 카탈로그가 있는지 확인 → 왼쪽 파란색 최저가를 눌러 카드 할인이 되는지 봅니다.
  • 카탈로그가 안 나오면 검색어 뒤쪽을 지워 핵심 3~4단어(용량까지)만 남기고 다시 검색합니다. 파란색이 안 보이면 다른 옵션(수량)을 눌러 찾습니다.

암산법

묶음 가격 ÷ 수량
+
배송비 3,000원
vs
1개 판매가
  • 예) 50ml 5개 27,000원 → 개당 약 5,400원 + 3,000원 ≈ 8,000원인데, 1개짜리 판매가가 6,000원 → 역마진, 패스.
  • 9개 묶음, 5개 묶음 상품들도 같은 방식으로 계산해 모두 역마진이라 넘겼습니다.
  • 사무실을 거쳐 보내면 개당 배송비 3,000원이 붙고, 고객에게 바로 보내면 배송비는 0원입니다. 수수료까지 생각하면 몇백 원 차이는 남지 않습니다.
4공식 판매처 3가지 기준핵심“이렇게 저렴한 거는 해외 직구 상품일 확률이 높거든요.”▾
①마켓명 옆 ‘공식’ 딱지
②홈쇼핑 채널
③상세페이지 ‘○○ 공식판매처입니다’
✕셋 다 없으면 패스
  • 홈쇼핑은 본사 정품 위주로만 들어가서 믿을 만합니다.
  • 유난히 싸면 “왜 이렇게 싸지?” 하고 들어가 봅니다. 해외직구 상품은 개인이 재판매할 수 없어 바로 끕니다.
  • 롯데온처럼 개인 판매자도 입점하는 곳은 공식 여부를 꼭 확인합니다. 이번에 본 롯데온 상품은 판매 중이 아니어서 패스했습니다.
  • 이번 실습의 라로슈포제·피지오겔은 마진은 맞을 것 같았지만 마켓명이 브랜드가 아니고, 공식 딱지·문구도 없어 모두 넘겼습니다.
  • 올리브영 세일처럼 싸게 사 두었다가 주문 때 보내는 선사입은 가능하지만, 가격이 바뀔 수 있어 익숙해지고 수익이 난 뒤에 하시기로 했습니다.
5같은 상품인지, 소분은 아닌지주의“이런 거는 그냥 보지도 말고 뿌세요. 공홈이어도 안 돼요.”▾
  • 검색 결과가 비슷해 보여도 형태·용량·구성이 같아야 같은 상품입니다. 이번에 본 상품은 원래 단지형인데 에누리 결과는 스포이드형이라 다른 상품 → 패스.
  • 한 통(큰 박스)에 6개가 들어 있고 낱개 박스가 없는 상품은 나눠 팔 수 없습니다. 화장품은 박스 하나에 제품 하나가 들어 있어야 합니다.
6멤버십 적립 빼고 마진계산기 돌리기“카탈로그보다 10원 저렴하게 들어가야 대표님께 판매가 돼요.”▾

실구매가 구하기 (바이오더마 예시)

  • 공식 딱지 있는 판매처, 결제 금액 28,880원에서 기본 적립·슈퍼 적립을 뺍니다.
  • 리뷰 적립(안 쓸 것)과 멤버십 전용 카드 적립(일회성)은 빼지 않습니다. → 실구매가 약 24,550원.
  • 네이버플러스 멤버십은 월 이용료보다 적립이 훨씬 많아 가입하시는 걸 권했습니다(현금 인출은 안 되고 포인트 결제용).

배송비: 사무실 경유 3,000 / 직배송 0
  • 바이오더마는 카탈로그 27,130원 → 판매가 27,120원, 고객 직배송(배송비 0)으로 넣으니 마진 약 700원. 1,000원이 안 되니 패스입니다.
  • 판매가는 10원만 낮춥니다. 100원은 너무 많이 내리는 겁니다.
  • 내려오는 길에 얼추 될 것 같은 상품만 계산기로 확인하고 넘어가면 됩니다.
  • 셀수다는 이미 가입돼 있었고, 로그인 정보가 헷갈렸던 부분은 실장님이 정리해 드렸습니다. 셀수다는 크롬 확장 프로그램에 고정해 두어 누르면 바로 열립니다.
7마음가짐 — 이 단계를 넘어가야 합니다응원“천원이 힘이 되게 커요.”▾
  • 안 나올 때는 3시간에 1개도 안 나올 때가 있습니다. 나올 때까지 계속 찾는 게 포인트입니다.
  • 베스트에서 하나를 찾아야 꼬리물기가 됩니다. 꼬리물기가 되면 베스트보다 훨씬 많이 나옵니다. 대부분 이 단계에서 힘들어하시는데, 인내가 필요한 구간입니다.
  • 천 원짜리도 있고, 하다 보면 5천 원·만 원짜리도 나옵니다. 천 원씩 쌓이는 게 큽니다.
  • 처음이라 어려운 것이고, 상담 후반엔 손이 많이 느셨습니다. “헷갈리니까 재밌네요”라고 하셨습니다.
  • 하다가 막히면 어디서 막혔는지 셀수다로 문의 주세요.
8숙제“맞든 틀리든 한번 해보시고 나와야 이게 좀 더 흡수가 빨라지거든요.”▾

  • 베스트 상품으로 소싱해서 꼬리물기 상품 1개 이상을 찾아 옵니다.
