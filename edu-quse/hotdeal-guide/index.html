오늘의 할인 상품, 혼자서 올려 보기

컴퓨터를 켜서 가격관리 프로그램을 돌리고, 셀러들의 수다 ‘오늘의 할인’에서 하루 3개를 찜해 마진을 확인하고, 자기 전에 등록하는 과정까지 실제 원격 실습 화면 그대로 정리했습니다. 위에서부터 순서대로 따라 하시면 됩니다. 프로그램이 이상할 때 보는 부분은 아래쪽에 따로 모았습니다.

영상 재생 속도

원격 연결 코드, 로그인·비밀번호 입력 장면, 고정 IP 설정 화면, 스토어 이름·사서함 번호·이름이 보이는 부분은 영상에서 빼거나 가렸습니다. 영상은 소리 없이 화면만 담았습니다.

컴퓨터 켜기→ 가격관리 프로그램 켜기→ 오늘의 할인에서 찜 (하루 3개)→ 사는 곳·카탈로그 확인→ 마진계산기

매일 하는 일

01컴퓨터를 켜면 가격관리 프로그램부터

  1. 컴퓨터를 켤 때마다 가격관리 프로그램을 꼭 켜 주세요. 켜 두어야 대표님 컴퓨터에서 자동으로 돌아가며 가격을 맞춥니다.
  2. 켜면 크롬 창이 하나 따로 뜹니다. 이 창에서 혼자 알아서 일하고 있는 겁니다. 그대로 두세요.
  3. 한 번 켜 둔 뒤에는 아이콘을 다시 눌러도 새 창이 안 뜹니다. 이미 돌아가고 있어서 그렇고, 고장이 아닙니다.
  4. 끝낼 때 따로 끌 필요 없이 컴퓨터 전원만 끄면 됩니다.
위쪽에 ‘새 버전이 나왔어요’가 보이면

노란 띠의 다운로드로 새 버전을 받으면 됩니다. 이번 상담에서 ‘누르면 안 뜬다’, ‘찜했는데 상품이 안 열린다’, ‘온라인 사무실이 없다’ 같은 증상은 모두 예전 버전이라서 생긴 것이었습니다. 이상하면 먼저 아래 9~11번으로 새 버전을 받아 보세요.

02오늘의 할인에서 하루 3개 찜하기

  1. 셀러들의 수다를 열고 왼쪽 메뉴의 오늘의 할인을 누릅니다.
  2. 목록 위쪽 탭에서 마진 남는 것이나 초보 추천을 고르면 고르기 쉽습니다.
  3. 마진이 남는 상품은 찜한 사람(선착순 3명)에게만 상품명과 링크가 열립니다. 상품을 누르고 찜하고 상품 보기를 누릅니다.
  4. 찜은 하루 3개까지입니다. 예상 마진이 400원처럼 너무 적은 건 건너뛰고 다른 걸 고르세요.
찜을 풀어도 오늘 찜 개수는 돌아오지 않습니다.

확인해 봤는데 안 맞으면 찜 풀기를 하면 되지만, 오늘 쓸 수 있는 새 찜 개수는 그대로 줄어 있습니다. 그래서 예상 마진이 넉넉한 것부터 고르세요.

03왼쪽은 사는 곳, 오른쪽은 카탈로그

찜하면 ‘이 상품 올려보기’ 창이 열립니다. 맨 위 ① 확인에 버튼이 두 개 있습니다.

버튼열리는 곳여기서 보는 것
옥션에서 보기 (왼쪽, 사이트는 상품마다 다름)내가 사 오는 사이트실제 결제 가격, 카드 할인, 배송비
네이버 가격비교 보기 (오른쪽)네이버 카탈로그지금 최저가 → 내가 팔 가격의 기준
묶음 구매가는 몇 개짜리인가요?

사는 페이지에서 고른 그대로입니다. 1개짜리를 산다면 1개 가격, 묶음이 더 싸면 묶음 가격을 쓰고 아래 마진계산기에 묶음 수량을 적습니다. 묶음과 상관없이 저렴하게 살 수 있는 쪽으로 사면 됩니다.

04마진계산기로 1,000원 이상 남는지 확인

예상 마진이 적혀 있어도, 실제로 남는지는 꼭 마진계산기로 한 번 더 봅니다. 셀러들의 수다 왼쪽 메뉴 마진 계산기.

  1. 묶음 구매가: 사는 사이트에서 본 가격. 예) 233,980원
  2. 묶음 수량: 1개짜리면 1.
  3. 카드 할인 (%): 사는 페이지에 ‘이 카드로 9% 할인’ 같은 안내가 있으면 그 숫자. 예) 9 → 자동으로 빼서 계산됩니다.
  4. 판매가: 네이버 카탈로그 최저가보다 조금 싸게. 예) 최저가 242,410원 → 242,400원
  5. 택배비: 기본은 3,000원. 이 밥솥처럼 뷰셀 사무실로 받았다가 보내는 사람 머리만 한 상자는 5,000원으로 바꿉니다.
  6. 오른쪽 초록 칸 1건 순이익이 1,000원 이상이면 등록합니다.
묶음 구매가233,980
카드 할인9%
판매가242,400
택배비5,000
수수료6.7%
1건 순이익8,237원
주문을 받고 나서 사는 걸 권합니다.

미리 사 두는 건(선사입) 이번 주 강의를 본 다음에 하세요. 강의에서 미리 사도 되는 기준을 알려 드립니다.

05묶음으로 사도 마진은 ‘1개’ 기준으로

3개 묶음을 사서 1개씩 판다고 택배비를 3,000원 × 3 = 9,000원으로 넣으면, 한 번 팔 때마다 9,000원이 빠지는 것으로 계산돼 마진이 거의 없어 보입니다. 마진계산기는 1건(1개) 팔 때 남는 돈으로 계산합니다. 택배비는 한 번 보낼 때 드는 3,000원만 넣으세요.

예시: 1개 원가 10,000원, 판매가 15,000원금액
판매가15,000
− 수수료 (약 6.7%)1,005
− 택배비 (한 번 보낼 때)3,000
− 원가 (1개)10,000
1개 팔 때 남는 돈995
3개 다 팔면995 × 3 = 2,985

마진계산기 오른쪽에도 ‘1건에 남는 돈’이라고 적혀 있습니다. 묶음 전체로 얼마 남는지는 그 아래 ‘이 묶음 하나를 다 팔면’에서 따로 보여 줍니다.

06담아 두고, 등록은 자기 전에

  1. ‘이 상품 올려보기’ 창 ③ 등록의 세 칸을 확인하고 체크합니다: 네이버 상품과 같은 상품·같은 용량 / 구성 수량(몇 개입·몇 개 묶음) / 오픈마켓 배송비·실제 결제가.
  2. 카탈로그 링크 복사를 누릅니다. (세 칸을 다 체크해야 눌립니다.)
  3. 크롬 오른쪽 위에서 자동등록 프로그램을 열고, 대량등록 목록 칸에 붙여넣기(Ctrl+V)합니다. 네이버 카탈로그 화면을 연 상태라면 이 카탈로그 담기를 눌러도 똑같이 들어갑니다.
  4. 하루 동안 담아 두고, 밤에 자기 전에 대량등록 시작을 누릅니다. 돌아가는 동안에는 컴퓨터를 만지지 않습니다.
등록이 안 되면

목록에 실패 사유가 나옵니다. 그 화면을 캡처해서 질문하기나 카톡으로 보내 주세요.

고객 응대

07톡톡 문의는 24시간 안에 답변

전화로 이미 처리했더라도, 고객이 톡톡(문의)에 글을 남겼으면 거기에도 답변해야 합니다. 원칙적으로 24시간 안에 답해야 하고, 답이 없으면 네이버에서 ‘응대가 늦다’는 안내 문자가 옵니다.

  1. 스마트스토어센터에 들어가 알림·문의에 남아 있는 고객 글을 엽니다.
  2. 글 안의 상품 주문번호를 누르면 그 주문이 취소됐는지 바로 보입니다.
  3. 답변 칸에 처리 내용을 적고 답변하기를 누릅니다. 답한 글은 목록에서 사라집니다.
  4. 같은 고객이 같은 내용을 여러 번 남겼다면 같은 내용으로 하나씩 다 답변하면 끝입니다.
고객님, 불편을 드려 정말 죄송합니다. 요청하신 주문은 취소 처리가 완료되었고, 결제하신 카드로 환불이 진행되었습니다. 이용해 주셔서 감사합니다.

위 문장은 취소 건 답변 예시입니다. 상황에 맞게 고쳐서 쓰세요.

취소 요청은 빨리 승인해 주세요.

고객이 취소를 요청하면 승인을 눌러야 환불이 됩니다. 마진이 안 남아 먼저 취소를 권한 경우라면 더더욱, 요청이 들어오는 대로 바로 승인하세요. 위치를 못 찾겠으면 혼자 오래 찾지 말고 바로 질문하기나 카톡으로 물어보세요.

08‘가격이 바뀌었으니 변경하라’ 알림은 무시

등록해 둔 상품 위로 ‘금액이 변경됐다, 변경하라’는 알림이 떠도 무시하셔도 됩니다. 가격은 가격관리 프로그램이 맞춥니다.

프로그램이 이상할 때만

09자동등록 프로그램 새 버전 설치

  1. 자동등록 프로그램에 ‘새 버전 다운로드’가 뜨면 눌러서 내려받습니다.
  2. 받은 압축 파일의 압축을 풉니다(마우스 오른쪽 → 압축 풀기).
  3. 안에 있는 설치 파일을 두 번 클릭합니다. 파란 ‘Windows의 PC 보호’ 창이 뜨면 추가 정보 → 실행.
  4. “게시자를 알 수 없는 앱이… 허용하시겠어요?”가 뜨면 예. 검은 창이 세 번쯤 꺼졌다 켜졌다 하면 설치가 끝납니다.
  5. 완료 창의 확인. 이어서 뜨는 안내 페이지가 설명서입니다.

10크롬 확장 프로그램 다시 넣기

  1. 크롬 오른쪽 위 퍼즐 모양 → 확장 프로그램 관리.
  2. 기존 [셀수다] 자동등록 프로그램을 삭제합니다.
  3. 압축해제된 확장 프로그램 로드 → 내 PC → 로컬 디스크 (C:) → 셀수다 자동등록 → 확장프로그램 폴더 → 폴더 선택.
  4. 목록에 다시 들어오면 끝입니다.

11셀러들의 수다 새 버전 설치

  1. 공유 문서함 프로그램 → 셀러들의수다 폴더에서 설치 파일(.exe)을 내려받습니다.
  2. 두 번 클릭 → (PC 보호 창이 뜨면 추가 정보 → 실행). 기존 버전 위로 그대로 덮어씌워지니 지울 필요가 없습니다.
  3. 새 버전에는 왼쪽 메뉴에 온라인 사무실이 생기고, 오늘의 할인에서 찜하면 상품이 정상으로 열립니다.

12셀수다 자동 소싱 프로그램 (토끼 아이콘)

이번 상담에서 함께 설치해 드렸습니다. 꼬리물기를 도와주는 프로그램이지만, 지금은 쓰지 않아도 됩니다. 강의 순서(네배소 → 꼬리물기)대로 손으로 먼저 익히고, 그다음에 씁니다. 다시 깔아야 할 때만 보세요.

  1. 거인의 도구 공방 사이트(giantstoolbox.com)에 로그인합니다. 아이디·비밀번호는 1:1 과외 신청 앱과 같습니다.
  2. 무료 자료 설치 페이지 → ② 자동소싱프로그램 설치 버튼으로 설치 파일을 받습니다.
  3. 받은 파일을 두 번 클릭 → “허용하시겠어요?”는 예. 설치 창에 초록 체크 5개가 다 뜨면 닫기.
  4. 크롬 확장 프로그램 관리 → 오른쪽 위 개발자 모드 켜기 → 압축해제된 확장 프로그램 로드 → C: → 셀수다자동소싱 → 확장프로그램 폴더 선택.
  5. 크롬 오른쪽 위 토끼 아이콘을 눌러 전화번호와 셀러들의 수다 비밀번호로 로그인합니다.
비밀번호가 기억나지 않으면

여러 번 틀리게 넣지 말고 바로 카톡으로 알려 주세요. 초기화해 드립니다. 새로 정한 비밀번호는 휴대폰 메모장에 적어 두세요.
