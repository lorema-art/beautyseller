주문이 들어왔을 때, 발주처리 따라하기

신규 주문 확인부터 마진 판단, 셀러들의 수다 입고·배송요청, 배송비 충전까지 실제 원격 실습 화면을 그대로 따라가며 정리했습니다. 처음엔 낯설어도 한두 번만 해보면 금방 손에 익습니다.

화면 속 스토어명, 고객 이름·연락처·주소, 주문번호, 개인 사서함 번호는 모두 가렸습니다.

전체 흐름

주문 한 건은 마진이 남느냐 아니냐에 따라 두 갈래로 나뉩니다.

신규 주문 확인→ 엑셀 다운로드·정리→ 판매장부에 기록→ 네이버 → 에누리 마진 확인

마진이 남는다 → 발주

상품 구매 (배송지 = 창고 + 내 사서함번호) 셀러들의 수다 입고 등록 배송요청 엑셀 대량등록 배송비 예치금 충전

마진이 안 남는다 → 보류

스토어 판매가 1만 원 인상 발송지연 처리 (최장 3개월 뒤) 장부 ‘배송지연’ 탭으로 이동 주말·월초 할인 때 다시 확인
가격 인상과 발송지연은 한 세트입니다.

발주를 못 하는 주문은 가격만 올리고 끝내면 안 됩니다. 가격을 올려 추가 주문을 막고, 이미 들어온 주문은 반드시 발송지연 처리까지 해야 합니다.

01신규 주문 엑셀로 받기

  1. 스마트스토어센터에서 신규주문을 누릅니다.
  2. 주문을 전체 선택하고 엑셀다운을 누릅니다.
  3. 엑셀 비밀번호는 0 또는 1234처럼 아주 간단하게 정합니다. 평소 쓰는 비밀번호가 아니라 잠깐 열어볼 용도라서 간단해도 됩니다.
  4. 다운로드 후 발주확인을 눌러 둡니다.

02엑셀에서 필요한 정보만 남기기

엑셀을 열고 편집 사용을 누른 뒤, 맨 위 안내 문구와 필요 없는 열(아직 보내지도 않았으니 택배사 같은 칸)은 지웁니다. 남길 열은 아래 정도입니다.

  • 수취인명, 상품명, 옵션, 수량, 주문금액
  • 수취인 연락처, 배송지 주소 (배송 보낼 때 필요)

그다음 상품명 열을 오름차순 정렬합니다. 같은 상품이 여러 건 들어왔을 때 한데 모여서 한 번에 발주하기 쉬워집니다.

2주차에 더 편해집니다.

필요한 정보만 앞으로 빼서 보는 정렬 설정은 2주차 강의에서 따로 알려드립니다. 지금은 손으로 지워도 충분합니다.

03판매장부(구글 스프레드시트)에 옮기기

  1. 판매장부는 가능하면 구글 스프레드시트로 씁니다. 어느 컴퓨터에서든 열 수 있어 USB로 들고 다닐 필요가 없습니다.
  2. 엑셀에서 수취인명 · 상품명 · 옵션 · 수량 · 주문금액을 복사해 장부에 붙여넣습니다.
  3. 붙여넣으면 서식이 깨집니다. 아래쪽 빈 줄을 복사한 뒤 붙여넣은 칸을 선택하고 선택하여 붙여넣기 → 서식만을 고르면 원래 모양으로 돌아옵니다.

04마진이 남는지 확인하기 (네이버 → 에누리)

할인이 가장 많은 두 가격비교 사이트, 네이버 가격비교와 에누리를 봅니다. 에누리는 로딩이 오래 걸리니 검색은 먼저 걸어두고 네이버부터 봅니다.

검색어 만드는 법

  • 주문 상품명에서 브랜드명부터 용량 숫자까지 복사해 검색합니다. (예: “롯데칠성음료 게토레이 레몬 600”)
  • 검색이 잘 안 되면 불필요한 단어를 빼고, 브랜드명 + 제품을 특정할 수 있는 성분·라인명 하나 정도만 남깁니다.
  • 마스크팩처럼 낱장 포장 제품은 매수(5매 등)까지 꼭 넣지 않아도 됩니다.

① 네이버 가격비교

  1. 검색 결과에서 내가 등록한 카탈로그를 엽니다. (상품명이 같아도 “5매×1개”와 “1매×5개”는 서로 다른 카탈로그일 수 있으니 내 카탈로그를 정확히 고릅니다.)
  2. 아래로 내려 수량별 구성 가격을 보고 내 판매 구성보다 더 싸게 살 수 있는 구성이 있는지 찾습니다.
  3. 여러 개 묶음은 개당 가격으로 나눠 봅니다. 암산이 어려우면 계산기를 쓰고, 뒷자리를 잘라내고 나누면 훨씬 쉽습니다. (12,220원 → 12,000원 ÷ 2 = 개당 6,000원)
묶음을 사서 나눠 보낼 때는 배송비를 더하세요.

1개 주문에 2개 묶음을 사서 창고로 받은 뒤 고객에게 다시 보내면 3,000원 정도 배송비가 한 번 더 듭니다. 개당 가격이 싸 보여도 배송비를 더하면 역마진이 되는 경우가 많습니다.

② 에누리 가격비교

  1. 검색 후 배송비 포함을 반드시 먼저 켭니다. 에누리는 무조건 이걸 켜고 봅니다.
  2. 상단 광고 영역을 지나 나오는 것이 에누리 카탈로그입니다. 구성 중 파란색으로 표시된 것이 현재 가장 저렴한 구성입니다.
  3. 그 구성의 가격을 누르면 오른쪽에 가격비교 창이 뜹니다. 여기서 카드할인을 켭니다.
  4. 카드할인을 켠 뒤의 최저가가 실제로 살 수 있는 가격입니다. 이 가격을 마진계산기에 넣어 마진이 남는지 확인합니다.

실제 판단 사례 (주문 4건)

실습 날 들어온 주문 4건을 위 방법으로 확인한 결과입니다. 판매가와 최저가가 10~20원 차이여도 수수료를 떼면 마진이 남지 않습니다.

상품내 판매가확인한 최저가판단이유
게토레이 레몬 600ml 20개16,960원16,970원발주 불가네이버에 더 싼 구성 없음, 에누리 최저가가 판매가보다 높음
메디힐 티트리 마스크 10매 4개35,140원10매당 약 1만 원발주 불가10매당 8,780원 이하여야 하는데 시중가가 더 비쌈. 애초에 1개짜리 구성으로 등록했어야 마진이 남는 상품
오리온 황치즈칩 쿠키 256g6,240원6,260원발주 불가네이버 2개 묶음 개당 6,000원이지만 재발송 배송비 3,000원을 더하면 역마진. 에누리도 판매가보다 높음

등록할 때 구성을 꼭 골라서 등록하세요.

셀러들의 수다에서 상품을 등록할 때 처음 뜨는 구성(예: 4개 묶음)을 그대로 등록하면 마진이 안 남을 수 있습니다. 목록에 “낱개로 팔면 +○○원”처럼 마진이 남는 구성이 따로 표시되니, 원하는 구성을 눌러 바꾼 뒤 등록하세요.

05마진이 안 남을 때: 가격 인상 + 발송지연

① 판매가 1만 원 올리기

  1. 상품관리 → 상품 조회/수정에서 해당 상품을 체크합니다.
  2. 판매가 변경을 누르고 10,000원 / 인상으로 바꾼 뒤 변경을 누릅니다.
  3. 가격을 올려 두면 같은 상품으로 손해 보는 주문이 더 들어오지 않습니다. 중간에 뜨는 안내 팝업은 무시해도 됩니다.

② 발송지연 처리

  1. 판매관리 → 발주확인/발송관리로 들어가 해당 주문을 찾습니다. 이름은 구매자명이 아니라 수취인명으로 찾으세요. 둘이 다를 수 있습니다.
  2. 주문을 체크하고 발송지연 처리를 누릅니다.
  3. 발송지연 사유는 상품준비중, 발송기한은 주문일로부터 3개월 뒤 같은 날짜로 정합니다. (예: 10월 28일 주문 → 다음 해 1월 28일)
  4. 상세 사유 칸에 아래 안내 문구를 붙여넣고 확인을 누릅니다. 목록에서 발송기한이 늘어났는지 확인합니다.
안녕하세요 고객님 :)
먼저 배송에 불편을 드려 죄송합니다.

현재 공급사측 사정으로 인하여 출고가 지연되고 있는것으로 확인됩니다.
가능한 빠른 출고 진행을 도와드릴 수 있도록 노력하고 있으나
최대 1 ~ 2개월가량 지연될 수 있을것으로 사료됩니다.

취소를 원하실경우 취소요청 주시면 빠른 환불조치 도와드리겠습니다.
최대한 빠른 출고가 될 수 있도록 더욱 신경써서 확인하겠습니다.
다시한번 불편을 드려 죄송합니다.
처리 전에 한 번 더 확인하세요.

발송지연은 결제일 이후 최대 90일 이내로 주문당 1회만 할 수 있고, 입력한 내용은 나중에 고칠 수 없습니다. 바뀐 발송기한까지 발송하지 못하면 고객 취소 요청 시 바로 환불되고 지연 페널티가 붙습니다.

③ 지연 건 관리하기

  • 발송지연 처리한 주문은 판매장부의 ‘배송지연’ 탭으로 잘라서 옮겨 둡니다. (잘라내기 Ctrl+X, 붙여넣기 Ctrl+V)
  • 그 사이 고객이 취소 요청을 하면 스토어의 취소요청 메뉴에 뜹니다. 발송지연한 주문이면 그냥 승인해 주세요. 환불이 끝나면 장부에서도 그 줄을 지웁니다.
  • 취소가 안 들어와도 걱정하지 않아도 됩니다. 온라인 가격은 계속 바뀌고, 주말과 월초에 할인이 가장 많습니다. 그때 다시 검색해서 마진이 남으면 발주합니다.

06마진이 남을 때 ① 상품 구매와 입고 등록

발주할 상품은 뷰셀 창고로 받은 뒤 창고에서 고객에게 출고합니다. 셀러들의 수다의 재고&배송요청 메뉴를 씁니다.

상품을 살 때 배송지 적는 법

  • 이름: 본인 성함 / 연락처: 본인 연락처
  • 주소: 셀러들의 수다 재고관리 탭에 안내된 창고 주소
  • 주소 맨 뒤에 내 사서함번호를 꼭 붙입니다. 송장에는 이름 일부가 별표로 가려지고 동명이인도 많아서, 사서함번호가 없으면 창고에서 누구 물건인지 알 수 없습니다.
(창고 주소 전체) 내사서함번호
예) 경기도 ○○시 ○○로 12, 3층 가000
사서함번호는 평소엔 바뀌지 않습니다.

물량이 많아지면 정식 코드 번호와 전용 칸을 따로 드리는데, 그때 한 번 바뀔 수 있습니다. 그 전까지는 지금 번호를 계속 쓰면 됩니다.

입고 등록하기

  1. 재고관리 → 입고 등록 (사무실로 보낼 물건)으로 내려갑니다.
  2. 카탈로그명: 스토어 상품명을 그대로 복사해 붙여넣습니다. (상품명을 카탈로그명과 똑같이 쓰기 때문)
  3. 옵션: 색상·사이즈처럼 나뉘는 상품만 적습니다. 용량은 카탈로그명에 들어 있으니 비워 둡니다.
  4. 수량: 내가 구매한 수량을 적습니다.
  5. 공급가·구매사이트: 산 가격과 구매한 곳(링크)을 적습니다.
  6. 메모: 물류 담당자가 보고 처리할 수 있게 필요한 내용을 적습니다. (예: 택배 3박스로 발송 / 송장번호)
  7. 입고 등록을 누르면 창고에서 실시간으로 확인합니다.

07마진이 남을 때 ② 배송 요청 (엑셀로 한 번에)

창고가 고객에게 보내려면 주문 정보를 받아야 합니다. 배송요청 탭에서 한 건씩 손으로 입력할 수도 있지만, 주문이 적어도 엑셀 대량등록으로 하는 습관을 들이세요. 주문이 갑자기 늘었을 때 그대로 쓸 수 있습니다.

  1. 엑셀로 여러 건 한번에 등록 → 1) 엑셀 템플릿 받기를 누릅니다.
  2. 템플릿에 주문 엑셀의 정보를 붙여넣습니다. 받는사람 · 카탈로그명 · 옵션 · 수량 · 연락처 · 주소 · 배송메시지 순서입니다. 마우스보다 Ctrl+C / Ctrl+V가 빠릅니다.
  3. 카탈로그명은 입고 등록한 이름과 똑같이 적어야 접수됩니다. 템플릿의 ‘예시’ 줄은 지웁니다.
  4. 파일을 내 컴퓨터에 저장합니다.
  5. 2) 주문을 채운 엑셀 파일 선택 → 파일 선택으로 방금 저장한 파일을 고르고 등록하기 → 확인.
  6. 배송요청 현황 목록에 들어왔는지 확인합니다.
출고 시간

창고는 오전 9시에 들어온 상품을 검수하고, 오후 3시 전까지 들어온 배송요청은 당일 발송합니다. 단, 창고에 내 재고가 들어와 있어야 합니다. 출고되면 스토어에는 자동으로 발송처리됩니다.

08배송비 예치금 충전

배송비는 선불 차감 방식이라 잔액이 있어야 발송됩니다.

  1. 셀러들의 수다에서 충전하기 → 확인을 누르면 충전 사이트가 열립니다.
  2. 1만 원 단위로 수량을 정합니다. (2만 원이면 수량 2)
  3. 구매하기 → 로그인(처음이면 회원가입) → 이름·연락처 입력.
  4. 결제는 무통장 입금만 됩니다. 택배비는 택배사에 그대로 전달되는 비용이라 카드 결제가 안 됩니다.
  5. 입금하면 매일 오전 10시에 확인 후 충전 처리됩니다.
얼마나 넣어야 하나요?

딱 맞게 넣어도 되고 여유 있게 넣어도 됩니다. 남은 금액은 원하면 확인 후 환불해 드리니, 너무 과하지 않게 적당히 충전하세요.

09판매장부 마무리

  • 날짜: 발송처리한 날짜를 적습니다.
  • 도매단가 · 배송비: 실제로 산 가격과 배송비를 넣으면 원가합, 수수료, 마진이 자동으로 계산됩니다.
  • 판매처: 물건을 직접 산 경우 사입이라고 적습니다.

판매중지 요청을 받았을 때

브랜드나 권리자에게서 “판매를 중지해 달라”는 문자나 메일이 오면 아래처럼 처리합니다.

  1. 상품관리 → 상품 조회/수정에서 해당 상품을 체크합니다.
  2. 판매변경에서 판매중지로 바꿉니다.
  3. 전시변경에서 전시중지도 합니다. 판매중지와 전시중지는 둘 다 해야 하는 세트입니다.
  4. 중지 처리만 하면 됩니다. 메일 회신을 요구해도 따로 답장할 필요는 없습니다.
스토어 고객센터 번호는 070으로 바꿔 두세요.

개인 휴대폰 번호를 그대로 쓰면 광고 전화와 고객 연락이 계속 와서 번거로워집니다. 바꾸는 방법은 단톡방 공지를 참고하세요.
