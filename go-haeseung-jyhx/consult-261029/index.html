고해승 대표님 첫 주문 발주처리 실습

2026년 10월 29일 · 고해승 대표님, 뷰셀 · 원격 상담
38분상담 시간
4건신규 주문 점검
1건 출고3건 발송지연
고해승 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

마진계산기까지는 아시는데 그다음 무엇을 눌러 어떻게 보내야 하는지를 몰라 멈춰 있던 상태였습니다. 원격으로 신규 주문 4건을 같이 보면서 엑셀 정리 → 판매장부 → 네이버·에누리 마진 확인 → 발주 또는 가격 인상+발송지연까지 한 바퀴 돌았습니다. 3건은 역마진이라 발송지연 처리했고, 1건은 사무실 보유 재고로 오늘 출고합니다.

오늘 처리한 것

주문 4건 마진 점검 → 3건 발송지연(3개월 뒤), 역마진 상품 판매가 1만 원 인상. 프리메라 마스크 1건은 셀러들의 수다 입고 등록 + 배송요청 엑셀 등록까지 완료. 판매중지 요청 상품은 판매중지·전시중지 처리.

대표님이 하실 것

배송비 예치금 무통장 입금 충전(오늘 출고 건 포함), 스토어 고객센터 번호 070으로 변경. 지연 3건은 주말·월초 할인 때 다시 확인.

앞으로

아직 강의 전이라 낯선 게 당연합니다. 2주차에 소싱법과 발주 처리를 정식으로 배우고, 그 전까지는 아래 교육자료를 보며 한 번 따라 해 보세요.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1주문 엑셀 받아서 판매장부로 옮기기“비밀번호는 최대한 간단하게, 0 아니면 1234로 하시고요.”▾

엑셀다운 (비번 0/1234)
→
발주확인
→
필요 열만 남기고 상품명 오름차순
→
판매장부 붙여넣기
  • 엑셀은 편집 사용 누르고 안내 문구·택배사 등 필요 없는 열은 지웁니다. 수취인명·상품명·옵션·수량·주문금액·연락처·주소만 남깁니다.
  • 상품명을 오름차순으로 정렬하면 같은 상품이 모여 한 번에 발주하기 좋습니다.
  • 판매장부는 가능하면 구글 스프레드시트로 — 장소를 옮겨도 USB 없이 열 수 있습니다.
  • 붙여넣은 뒤 서식이 깨지면 아래 빈 줄을 복사해 선택하여 붙여넣기 → 서식만.
  • 필요한 정보만 앞으로 빼는 정렬 방법은 2주차에 알려 드립니다.
2네이버 → 에누리로 마진 확인핵심“에누리는 무조건 배송비 포함을 켜고 보는 거예요.”▾
  • 할인이 많은 네이버 가격비교와 에누리 두 곳을 봅니다. 에누리는 로딩이 오래 걸리니 검색을 먼저 걸어 둡니다.
  • 검색어: 상품명에서 브랜드명부터 용량 숫자까지. 안 나오면 불필요한 단어를 빼고 브랜드 + 특정 성분 정도만 남깁니다.
  • 네이버: 내가 등록한 카탈로그를 열어 수량별 구성 중 더 싼 구성이 있는지 확인. 묶음은 개당으로 나눠 보고(뒷자리 잘라 암산), 받아서 다시 보낼 땐 배송비 3,000원을 더합니다.
  • 에누리: 배송비 포함 ON → 광고 지나 에누리 카탈로그 → 파란색이 최저 구성 → 가격 눌러 카드할인 ON → 그 최저가로 마진계산.

오늘 주문 4건 결과

  • 게토레이 레몬 600ml 20개: 판매 16,960원 / 최저 16,970원 → 발주 불가
  • 메디힐 티트리 마스크 10매×4: 35,140원, 10매당 8,780원 이하여야 하는데 시중 약 1만 원 → 발주 불가
  • 오리온 황치즈칩 쿠키 256g: 판매 6,240원 / 에누리 6,260원, 네이버 2개 12,000원도 배송비 더하면 역마진 → 발주 불가
  • 프리메라 비타티놀 마스크 5매: 시중 최저 20,110원이지만 사무실 재고(14,000원 + 배송비 3,000원)로 보내면 마진 → 오늘 출고
3메디힐은 1개짜리로 등록했어야주의“켰을 때 네 개짜리가 먼저 떴는데, 원하는 걸 누르고 나서 등록을 해야 돼요.”▾
  • 메디힐 마스크는 오늘의 할인 기준 낱개(1개)로 팔아야 마진이 남는 상품인데, 처음 뜬 4개 구성 그대로 등록된 것으로 보입니다.
  • 셀러들의 수다에서 등록할 때는 “낱개로 팔면 +○○원”처럼 마진이 남는 구성을 눌러서 바꾼 뒤 등록하세요. 1개·4개 두 개 다 등록됐을 수 있으니 한번 확인해 보세요.
4역마진 주문: 가격 인상 + 발송지연은 한 세트“금액을 올리는 거와 별개로 배송지연 처리를 꼭 해줘야 돼요.”▾
  • 첫째, 상품 조회/수정 → 판매가 변경 10,000원 인상으로 추가 주문을 막습니다.
  • 둘째, 발주확인/발송관리에서 주문 체크(이름은 수취인명으로 찾기) → 발송지연 처리 → 사유 상품준비중, 발송기한은 주문일 3개월 뒤(28일 주문 → 1월 28일), 안내 문구 붙여넣기 → 확인.
  • 지연 처리한 주문은 판매장부 ‘배송지연’ 탭으로 옮겨 둡니다.
  • 그 사이 취소 요청이 오면 바로 승인, 환불되면 장부에서 삭제. 취소가 없어도 걱정 마세요 — 주말·월초에 할인이 가장 많고 곧 월초입니다. 그때 다시 보고 마진이 나오면 발주합니다.
5셀러들의 수다 입고 등록·배송요청“주문이 적더라도 수기로 입력하시지 마시고요.”▾
창고로 상품 구매
→
입고 등록
→
배송요청 엑셀 템플릿
→
파일 등록
  • 상품을 살 때 배송지는 대표님 성함·연락처 + 창고 주소, 주소 맨 뒤에 사서함번호 가051을 꼭 붙이세요. 송장 이름이 별표로 가려지고 동명이인이 많아 번호가 없으면 찾을 수 없습니다. 물량이 늘면 정식 코드로 한 번 바뀔 수 있습니다.
  • 입고 등록: 카탈로그명(스토어 상품명 그대로) · 옵션(색상·사이즈만) · 수량(구매한 수량) · 공급가 · 구매사이트 · 메모(물류 담당자용).
  • 배송요청: 엑셀 템플릿 받기 → 받는사람·카탈로그명·옵션·수량·연락처·주소·배송메시지 붙여넣기(Ctrl+C/V) → 저장 → 파일 선택 → 등록하기.
  • 창고는 오전 9시 입고 검수, 오후 3시 전 들어온 배송요청은 당일 발송합니다. 출고되면 스토어에 자동 발송처리됩니다.
  • 판매장부에는 발송처리한 날짜, 도매단가·배송비, 판매처 ‘사입’을 적습니다. (오늘 건: 14,000원 + 3,000원 → 마진 약 420원)
6배송비 예치금 충전“택배비를 제가 가지는 게 아니라 택배사에 전달을 하잖아요.”▾
  • 선불 차감 방식이라 잔액이 있어야 발송됩니다. 오늘 출고 건도 포함해서 충전해 주세요.
  • 셀러들의 수다 충전하기 → 충전 사이트에서 1만 원 단위 수량 선택 → 구매하기 → 로그인(회원가입) → 이름·연락처.
  • 카드 결제 불가, 무통장 입금만 됩니다. 매일 오전 10시에 확인 후 처리합니다.
  • 남은 금액은 원하면 환불해 드리니 너무 많지 않게 적당히 넣으세요.
7판매중지 요청·070 번호“판매중지랑 전시중지, 이 두 개는 세트예요.”▾
  • 어제 문자로 받은 판매중지 요청 상품(로세양 관련)은 판매변경 → 판매중지, 전시변경 → 전시중지 둘 다 처리했습니다. 메일 회신 요구는 답장하지 않아도 됩니다.
  • 스토어 고객센터 번호가 아직 개인 휴대폰입니다. 광고 전화·고객 연락이 계속 와서 번거로우니 070으로 변경하세요. 단톡방 공지를 카톡으로 다시 보내 드렸습니다.

교육자료

오늘 실습 화면을 그대로 담아 단계별로 정리했습니다. 보면서 한 번 따라 해 보세요.

발주처리 따라하기 →

주문 엑셀 → 판매장부 → 마진 확인 → 발송지연 / 입고·배송요청 → 배송비 충전까지

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 배송비 예치금 무통장 입금 충전 고해승오늘 출고 건 포함 · 매일 오전 10시 반영
  • 프리메라 마스크 1건 당일 출고 뷰셀사무실 보유 재고로 발송
  • 스토어 고객센터 번호 070으로 변경 고해승단톡방 공지 참고
  • 메디힐 마스크 등록 구성 확인 고해승1개짜리 카탈로그로 등록됐는지, 4개짜리가 중복 등록됐는지
  • 발송지연 3건 월초·주말 가격 다시 확인 고해승마진 나오면 발주, 취소 요청 오면 바로 승인
  • 교육자료 보며 발주처리 한 번 따라 하기 고해승다음 주문부터 직접
