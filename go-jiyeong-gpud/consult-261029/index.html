고지영 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

오래 전에 만든 스마트스토어가 휴면 해제 후 통합 계정 권한이 없는 상태라 자동등록 프로그램 연결이 막혀 있었습니다. 상담 중 네이버에 권한 부여를 요청했고, 네이버가 빠르게 해결해 줘서 그 자리에서 프로그램 세팅과 첫 등록 실습까지 마쳤습니다. 이번 주 과제는 프로그램 사용에 익숙해지기 — 하루 2~10개씩 등록 연습입니다.

대표님 상황

주얼리(악세사리·은·금) 온라인 판매 중. 홈쇼핑·GS샵 등에 입점해 직접 만들거나 남대문에서 사입해 팔고, 직접 주얼리 케이스에 포장해 발송합니다. 포토샵으로 하나하나 올리는 방식이 너무 힘들어 몇 년째 신상품을 못 올린 상태라 새 방법이 필요해 신청하셨습니다.

오늘 해결한 것

네이버 통합 계정 권한 → 해결. 자동등록 프로그램 연결·실행 → 완료. 오늘의 할인 → 가격비교 → 카탈로그 담기 → 대량 등록 순서로 직접 등록까지 해 보셨습니다.

앞으로

1주차는 프로그램 숙련, 메인인 2주차는 소싱입니다. 가까이 사시니 컨설팅은 사무실 방문을 권해 드렸고(어려우면 원격), 강의 끝날 때까지 매주 받는 것이 좋습니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1통합 계정 권한 문제 — 네이버 문의로 해결해결“통합 계정으로 되어 있어야 이 앱을 생성할 수 있거든요.”▾
  • 예전에 만든 스토어가 판매가 없어 휴면 상태였고, 이번에 휴면을 풀면서 통합 계정으로 전환했습니다. 너무 오래 전에 만든 스토어라 통합 계정 권한이 비어 있어 API 앱을 만들 수 없는 상태였습니다.
  • 네이버 문의에 담당자명(대표님 성함)과 함께 “네이버 API 센터에 가입하려는데 통합 매니저 권한이 없어 부여해 달라”고 요청 → 상담 중 네이버가 빠르게 처리해 줬습니다. (같은 상황인 다른 분은 아직 해결 전일 만큼 운이 좋은 경우였습니다.)
  • 예전 판매자 아이디(LOOP)는 비밀번호를 알아도 ‘없는 계정’으로 나와 로그인이 되지 않습니다. 이 부분은 네이버에 따로 확인해야 합니다.
  • 스토어 사업자 주소지가 예전에 살던 구리로 되어 있습니다(현재 별내 거주). 필요하면 사업자 정보 변경을 확인해 보세요.
  • 구글 결제 시 사업자등록증을 입력한 기억이 없다고 하셨는데, 기존 개인 구글 계정이라 그럴 가능성이 높고 결제는 정상으로 보입니다.

대량 등록 시작
  • 프로그램은 크롬 오른쪽 위 초록색 카메라 아이콘을 누르면 켜집니다. 저희 프로그램은 대부분 크롬 기반이라 네이버도 크롬으로 들어가세요.
  • 오늘의 할인에서 플러스(+)로 표시된 금액이 남는 돈입니다. 낱개로 팔 때 남는다고 나오면, 카탈로그에서 1개짜리를 골라 담아야 합니다.
  • 스마트스토어 관리자(판매자) 창은 꼭 열어 둘 필요 없습니다.
  • 프로그램이 돌아가는 동안에는 컴퓨터를 만지지 마세요. 여러 개 담아 두고 자기 전에 대량 등록을 돌려 두면 편합니다.
  • 상품마다 ‘완료’가 뜰 때까지 기다립니다. X는 오류로 안 올라간 것 — 오류 내용이 표시되니 캡처해서 물어봐 주세요.
  • 마진 계산기는 지금은 쓰지 않습니다. 집중할 부분만 알려 드리니, 혼자 이것저것 눌러 보지 말고 알려 드린 대로만 따라오세요.
3이번 주 등록 가능·제외 품목“딱 제가 안 된다고 하는 것만 안 되는 거예요.”▾

올려도 되는 것

  • 화장품뿐 아니라 식품·음료(예: 제로슈거 음료)도 괜찮습니다.
  • 단, 냉장·냉동 보관이 필요한 식품은 사무실 냉장고가 작아 재고로 쌓아 둘 수 없습니다. 잠깐 받아 바로 보내는 정도는 가능하고, 그 외에는 위탁으로 보냅니다(위탁 주의점은 2주차 안내).

이번 주 제외

  • 의류·잡화(패션)
  • 향수 — 가품이 많습니다.
  • 건강기능식품·영양제 — 아직 허가·신고가 나지 않았습니다.
4배송 — 직접 해도 되지만, 물량이 늘면 맡기기“그 시간을 소싱에 더 투자하는 게 낫기는 할 것 같아요.”▾
  • 직접 포장·발송해도 상관없습니다. 다만 택배 계약 단가 2,600원이면 박스·부자재까지 약 3,000원입니다.
  • 주얼리는 사서 재포장해 보내면 끝이지만, 이 사업은 소싱을 해야 합니다. 예전처럼 하루 100~200개씩 포장하면 하루 종일 걸리니, 그 시간을 소싱에 쓰는 게 낫습니다. 처음엔 직접 하다가 결국 맡기시는 분이 대부분입니다.
  • 맡기면: 주문 시 여러 개 구성으로 싸게 사서 사무실로 받고 → 1개 출고 → 남은 재고는 다음 주문 때 출고. 직원이 포장·검수하고, 대표님은 셀러들의 수다 프로그램에 입력만 하면 됩니다.
  • 재고 관리: 대표님마다 섹션을 나누고 코드 번호를 따로 발행해 섞이지 않습니다. 프로그램 입력으로 관리하고, 주기적으로 재고 조사도 합니다.
  • 반품·교환: 프로그램에서 신청하면 택배 접수·포장(본사 반송 포함)까지 처리합니다.
  • 한 스토어에서 주얼리(대표님 출고)와 이 상품(대행 출고)을 같이 팔아도 출고지·반품지가 달라도 문제없습니다. 위탁 상품은 본사에서 바로 가는 것과 같은 원리입니다.
5공부·컨설팅 방법“수익 잘 나시는 분들은 강의를 보통 세 번 정도는 돌려봐요.”▾
  • 하루 최대 4시간 투자 예정 — 결코 적은 시간이 아니고, 정확한 방법으로 하면 수익이 빨리 나옵니다. 더 하면 그만큼 더 나옵니다.
  • 강의는 세 번 보세요: 토요일 첫 시청 → 3일~일주일 뒤 모르는 부분 생길 때 → 약 3주 뒤. 아는 만큼 들리는 게 달라집니다.
  • 알려 드린 대로 곧이곧대로 따라 하는 게 가장 빠릅니다. 힘든 점은 무엇이 힘든지 말씀해 주시면 답을 드립니다.
  • 컨설팅은 강의가 끝날 때까지 매주. 잘 따라오시면 진도를 빨리 뺍니다.
  • 사무실이 육교 하나 건너면 되는 거리라 방문 컨설팅을 권합니다. 매주 일요일에 예약 일정이 열리니 거기서 예약하고, 맞는 시간이 없으면 가능한 날짜·시간을 많이 알려 주세요. 정말 안 맞으면 원격으로 합니다.

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 하루 2~10개 등록 연습 고지영오늘의 할인 마진 1,000원↑ → 가격비교 → 낱개 선택 → 카탈로그 담기 → 대량 등록
  • 제외 품목 지키기 고지영의류·잡화, 향수, 건강기능식품·영양제 빼고 — 식품·음료는 OK
  • 대량 등록은 자기 전에, 돌아가는 동안 PC 만지지 않기 고지영X 오류가 나면 캡처해서 문의
  • 예전 아이디(LOOP) 네이버에 확인 고지영로그인 안 되는 이유 문의
  • 사업자 주소지(구리) 변경 필요 여부 확인 고지영현재 별내 거주
  • 배송 방식 결정 고지영직접 포장 vs 물류 대행 — 물량 늘면 대행 권장
  • 방문 컨설팅 예약 고지영일요일 열리는 일정 확인, 안 맞으면 가능한 시간 전달
