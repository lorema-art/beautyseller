고지영 대표님 컨설팅 정리

2026년 11월 11일 · 고지영 대표님, 뷰셀 · 원격 상담
40분상담 시간
80개+1시간에 봐야 할 상품 수
1시간 3개꼬리물기 소싱 목표
고지영 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

지난주는 수~금 일정 때문에 거의 못 하셨고, 토요일부터 하셨지만 자동등록 프로그램이 안 깔려서 등록은 못 한 상태였습니다. 오늘 원격으로 자동등록·가격관리 프로그램을 다시 세팅했습니다. 꼬리물기가 막혔던 가장 큰 이유는 카탈로그가 아닌 상품까지 다 보느라 시간만 쓰고 못 찾은 것. 이번 주는 1시간에 몇 개 보고 몇 개 찾는지 기록하면서 꼬리물기를 최대한 많이 하고, 오늘의 할인 하루 3개는 꼭 올립니다.

오늘 해결한 것

자동등록 프로그램 재설치(이제 자동 업데이트), 가격관리 프로그램 바탕화면에 꺼내 두고 로그인·세팅 완료, 카탈로그 구분법, 본사 판단 기준, 판매장부 취소·반품 처리.

지금 문제

찾은 상품이 아직 적어서 판단하기엔 이릅니다. 카탈로그 아닌 상품까지 보느라 오래 걸렸고, 지칭 단어·카테고리·제조사 기록에 실수가 있었습니다. 상품 하나 판단할 때 마우스가 멈칫하는 부분이 있습니다.

앞으로

질문은 컨설팅 때 모아서 하지 말고 생길 때마다 바로 프로그램 질문하기·카톡에 남겨 주세요. 지금 상품의 4방향 키워드를 다 본 뒤 연락 주시면 찾은 상품을 보고 점검해 드립니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1카탈로그만 본다핵심“얘가 헷갈리면 우리가 뭐를 할 수가 없어요.”▾
  • 하나의 상품에 여러 판매처가 붙어 있는 것이 카탈로그입니다. 판매처 수가 몇 개인지, ‘브랜드 카탈로그’ 같은 표시는 따지지 말고 이것만 보세요.
  • 카탈로그가 아닌 상품은 리뷰 수가 10개 이상이어도 우리가 할 수 없는 상품입니다. 꼬리물기 할 때도 마찬가지입니다. (오늘 본 달바 상품이 카탈로그가 아니라 기준에서 벗어난 사례)
  • 눌렀을 때 쿠팡이나 다른 브랜드 페이지가 뜨는 건 카탈로그가 아니라서 그런 겁니다.
  • 카탈로그로 들어가면 옵션이 따로 나뉜 화면은 나오지 않습니다. 그런 화면이면 잘못 들어간 겁니다.
  • 카탈로그 최저가보다 현저히 싼 곳에서 2개 사서 1개로 판다는 계산이 나오면, 그곳이 가품일 수 있습니다.
2구매처는 ‘사이트’가 아니라 ‘판매자’로 판단“판매자가 본사냐 아니냐 기준으로만 보셔야 돼요.”▾
  • 무신사·롯데온 같은 사이트 이름이 아니라 판매자가 본사인지를 봅니다. 개인사업자든 법인이든 상관없습니다.
  • 본사 기준 3가지 중 하나: 공식 표시 / 스토어명 = 브랜드명 / 홈쇼핑.
  • 홈쇼핑(SK스토아 등)은 판매자 정보가 안 보이지만, 일반 판매자 입점은 1% 정도로 드물어 본사로 봐도 됩니다. 롯데온·무신사는 홈쇼핑이 아니라 일반 사이트입니다.
  • 브랜드 자체 사이트는 본사입니다. ‘리셀러 판매 금지’ 같은 문구는 무시해도 됩니다.
  • 해외 사업자·해외 배송 구매는 불법이라 절대 안 됩니다(지마켓 등).
3꼬리물기 — 보는 순서와 기록“카테고리가 바뀔 때마다 첫 페이지 보셔야 돼요.”▾
  • 검색 → 첫 페이지 보기 → 1,000개 이상 카테고리 누르고 첫 페이지 → 다음 카테고리도 첫 페이지. 카테고리가 바뀔 때마다 첫 페이지를 봅니다.
  • 지칭 단어는 사람들이 부르는 이름을 고정합니다. 예: 크림 상품이면 ‘미드나잇 크림’, ‘블루 크림’, ‘카밍 크림’, ‘크림 60ml’처럼. 크림을 스킨·토너 카테고리에서 찾은 건 카테고리도 잘못된 경우였습니다.
  • 제조사로 찾았다면 상품의 제조사도 같아야 합니다. 다르면 잘못 찾았거나 잘못 적은 것 — 기록을 정확히 하세요.
  • 찾은 날짜를 정확히 적어야 확인이 됩니다. 파란색(이미 본 것)은 3개월 동안 패스합니다.
  • 4방향 키워드를 다 봤는데 못 찾으면 다음 위치로 넘어가 꼬리물기를 이어 갑니다.
4속도 — 1시간 80개 이상숙제“시간을 많이 투자하는 거랑은 상관없어요.”▾
  • 상품 하나를 20~30초 안에 판단하는 게 목표 → 1시간에 80개 이상 봐야 합니다. 속도는 나쁘지 않지만 마우스가 멈칫하는 구간이 있습니다.
  • 안 되는 상품도 에누리에서 가격 부분을 눌러 카드할인까지 확인하고, 그래도 안 되면 상품명을 줄여 보고, 그래도 없으면 패스.
  • 에누리에서 개수당 최저가가 보이는 에누리 카탈로그가 나와야 비교가 됩니다.
  • 오래 앉아 있는 것보다 집중한 시간이 중요합니다. 다른 수강생도 6시간 했다고 했지만 실제로 집중한 건 1시간 정도였습니다.
  • 초보자 평균은 1시간 3개(많으면 7개). 이번 주는 1시간에 몇 개 보고 몇 개 찾는지를 기록해 주세요.
5프로그램 세팅 — 자동등록·가격관리해결“냅두면 알아서 다 됩니다.”▾

자동등록 프로그램

  • 오늘 다시 넣어 두었고, 이제 자동으로 업데이트되니 따로 할 일 없습니다.
  • 다시 넣어야 할 때: 크롬 확장 프로그램 → 압축 해제된 확장 프로그램 로드 → 로컬 디스크 C → 셀수다 자동 등록 확장 프로그램 폴더 선택. (압축 푼 폴더 안으로 한 번 더 들어가면 안 될 수 있습니다.)

가격관리 프로그램

  • 바탕화면에 꺼내 두었습니다. ‘셀수다 가격관리’를 실행하면 됩니다. 스토어 등록이 안 잡혀 있던 것을 세팅 완료했습니다.
  • 컴퓨터를 켤 때 크롬 창이 하나 따로 뜨면 로그인만 해 주세요. 로그인된 상태면 창이 안 뜨는 게 정상이고, 뒤에서 알아서 돌아갑니다.
  • ‘반영 실패’ 표시는 확인용이며, 지금 보이는 건 이전 것이라 무시해도 됩니다.
  • 사이트에서 직접 가격을 고치는 건 3주차 주말 업무로 따로 하셔야 합니다.
6오늘의 할인 — 하루 3개는 무조건“하루에 3개씩 올리면 한 달이면 90개잖아요.”▾
  • 찜하면 보이는 사이트(예: 옥션)가 구매할 곳이고, 그 위에서 등록합니다.
  • 지난 찜 상품은 ‘기록’을 누르면 다 볼 수 있습니다.
  • 하루 3개 × 한 달 = 90개. 매일 빠짐없이 올리세요.
7주문·장부·배송“기록적으로 남겨 놓으려고 하는 거예요.”▾
  • 판매장부: 반품은 금액만 0으로 바꾸고 줄은 남겨 둡니다. 취소는 빼도 됩니다. 취소했다고 생각했는데 안 된 경우를 대비한 기록입니다.
  • 운송장은 셀수다에서 대표님 스토어에 자동 입력됩니다.
  • 사무실은 매일 아침 9시까지 입고된 제품을 검수해 출고합니다. 9시 이후 입고분은 다음 날 검수·출고됩니다. (오늘 오후 1시 반에 배송 완료된 지마켓 주문 → 내일 출고)
8질문은 바로바로 남기기“새벽이든 언제든 우선 남겨 주세요.”▾
  • 컨설팅 시간은 한정적이라 질문을 받다 보면 진도를 못 나갑니다. 다음부터는 컨설팅 때 질문을 받지 않습니다.
  • 모아 두지 말고 생길 때마다 캡처해서 프로그램 질문하기(가장 빠름)나 카톡에 남겨 주세요. 답변이 이해가 안 되면 한 번 더 남기시면 됩니다. 뷰셀이나 코치분들이 답변드립니다.
  • 강의는 몇 번 다시 보시거나, 직접 많이 해 보셔야 익숙해집니다. 일정을 비우지 마세요.

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 꼬리물기 최대한 많이 — 1시간 3개 이상 찾기 고지영카탈로그만, 카테고리 바뀔 때마다 첫 페이지
  • 1시간에 몇 개 보고 몇 개 찾는지 기록 고지영목표: 1시간 80개 이상 보기(1개 20~30초)
  • 오늘의 할인 매일 3개 등록 고지영지난 찜은 ‘기록’에서 확인
  • 지칭 단어·카테고리·제조사·날짜 정확히 기록 고지영사람들이 부르는 이름 고정, 찾은 날짜 명확히
  • 현재 상품 4방향 키워드 다 본 뒤 연락 고지영찾은 상품 보고 뷰셀이 점검
  • 컴퓨터 켜면 가격관리 크롬 창 로그인 고지영바탕화면 ‘셀수다 가격관리’, 뒤에서 자동 실행
  • 질문은 바로 프로그램·카톡에 남기기 고지영모아 두지 말고 캡처해서
