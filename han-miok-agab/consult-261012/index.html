한미옥 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

프로그램은 깔려 있지만, 처음 하나를 올려 본 뒤로 혼자 찾고 올리는 단계에서 멈춰 있었습니다. 오늘은 연동과 등록 방법을 정리하고, 함께 소싱해서 마진 남는 상품을 하나 찾았습니다.

오늘 해결한 것

네이버 커머스 API 연동 완료, 자동등록 프로그램 사용법 확인, 닥터 브로너스 상품으로 마진 계산과 본사 확인을 처음부터 끝까지 해 봤습니다.

지금 필요한 것

강의를 따라 할 수 있을 만큼 반복. 여러 번 봐도 잊어버린다면, 빨리감기 없이 차근차근 다시 보는 수밖에 없습니다.

걸림돌

원격에서 인터넷 창 클릭이 안 됨. 말로만 안내하다 보니 속도가 나지 않아, 다음은 직접 방문해서 함께 실습합니다.

관리 방식

엑셀 파일 대신 구글 스프레드시트로 바꾸고 링크를 한 번 공유해 주시면, 방문 전까지 중간중간 실시간으로 보고 첨삭해 드립니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1지금 상황“그 다음부터는 제가 찾아서 어떻게 올리는지 잘 모르겠더라고요.”▾
  • 예전에 원격으로 프로그램을 깔고 뿌요 교육실장이 상품 하나를 함께 올려 드렸는데, 그 뒤로 혼자 찾아 올리는 단계에서 멈춰 있는 상태입니다.
  • 강의는 2회차를 3번 이상 보셨지만 보고 나면 자꾸 잊어버리신다고 했습니다. 3회차는 근무 때문에 아직 다 못 보셨습니다.
  • 에누리에서 2개짜리로 되어 있는데 막상 보면 1개 가격인 경우가 많아 잘 안 맞는다고 하셨는데, 이건 강의대로 누르지 않았을 확률이 높습니다.
  • 이번 원격에서도 대표님 마우스는 움직이지만 코치 쪽 클릭이 인터넷 창에서는 먹히지 않아(지난번 뿌요 실장 때도 동일), 설명 위주로 진행했습니다.
2네이버 커머스 API 연동완료“얘는 해결됐고요.”▾
  1. 새 창에서 네이버 커머스 API 센터 접속
  2. 왼쪽 내 스토어 애플리케이션 → 보기 → ID 복사 → 셀러들의 수다(셀수다) ID 칸에 붙여넣기
  3. 다시 API 센터로 돌아와 ID 밑 시크릿 ‘보기’ → 퀴즈 풀고 복사 → 셀수다에 붙여넣기
  4. 연동하기
3자동등록 프로그램 쓰는 법“이거 까먹으시면 안 돼요.”▾
초록색 카메라 아이콘 켜기
→
마진 남는 네이버 카탈로그에서 ‘카탈로그 담기’
→
자기 전 ‘대량 등록 시작’
  • 화면 맨 아래 작업표시줄의 초록색 카메라 모양이 자동등록 프로그램입니다.
  • 하루 동안 찾은 상품을 ‘카탈로그 담기’로 모아 두고, 자기 전에 대량 등록 시작을 누르면 프로그램이 돌아갑니다. 아래에 링크가 들어가 있으면 담긴 것입니다.
  • 단, 담기 전에 꼬리물기 정리는 먼저 하셔야 합니다. 이 프로그램은 등록만을 위한 것입니다.
  • 연습으로 담은 건 비우기로 비워 두었습니다.
4‘오늘의 할 일’ 추천 상품은?“동기분들이 다 같이 올리니까 마진이 빨리 깎이겠죠.”▾
  • 할인 있는 제품을 프로그램이 자동으로 찾아 드리는 것이라 올리셔도 괜찮습니다.
  • 다만 동기분들이 같은 상품을 함께 올리기 때문에 경쟁이 붙어 마진이 금방 줄어듭니다. 그래서 시간이 없는 분에게만 권하고, 시간이 되시면 직접 소싱하는 걸 권합니다.
  • 추천 상품도 자동이라, 실제로 마진이 남는지와 본사인지는 대표님이 직접 검증해야 합니다.
5화면 배치와 검색어 줄이기“중요한 단어를 지워 버리셨어요.”▾

화면 배치

  • 불필요한 창은 바로바로 끕니다. 원격 중에는 맨 오른쪽 창만 남기면 됩니다.
  • 네이버는 왼쪽, 에누리는 오른쪽. 에누리 창 오른쪽 끝(X 버튼)을 화면 오른쪽 맨 위에 맞추고, 가격이 잘리지 않게 폭은 3분의 2 정도로 줄입니다. 그러면 두 창을 오가기만 하면 됩니다.
  • 복사 Ctrl+C, 붙여넣기 Ctrl+V. 에누리 검색창은 초기화하지 않고 그대로 붙여넣어도 됩니다.

카탈로그가 안 나올 때

  • 카탈로그는 항상 맨 위에 뜹니다. 안 보이면 단어를 더 지워 봅니다.
  • 향 이름 같은 수식어는 지우되, 메인 키워드는 남겨야 합니다. 예: 바디워시인데 상품명엔 ‘솝’(영어로 비누)이라고 되어 있다면 ‘솝’이 핵심이고, 티트리는 성분, ‘퓨어’ 정도는 지워도 됩니다.

에누리에서 볼 것

  • 배송비 포함, 카드 할인을 켭니다.
  • 판매처에 들어가는 건 본사인지 확인하기 위해서입니다. 마진이 안 남는 상품은 굳이 누를 필요가 없습니다.
  • 에누리가 네이버보다 비싸면 볼 필요도 없습니다. 봐야 할 것만 딱딱 보고 넘어가세요.
6암산으로 빠르게 거르기“이렇게 판단하면 굳이 안에 안 들어가도 되죠.”▾
  • 먼저 네이버 가격비교에서 메인 구성이 몇 개짜리인지 봅니다. 메인이 1개짜리면 우리도 1개짜리만 팔 수 있습니다.
  • 예: 에누리 2개 46,000원 → 개당 23,000원 + 택배비 3,000원 = 26,000원. 네이버 판매가보다 높으니 역마진, 패스.
  • 2로 나누는 건 암산으로 충분하지만, 3 이상으로 나눌 땐 계산기(작업표시줄 검색 → 계산기, 휴대폰도 OK)를 씁니다.
7본사 확인 기준 3가지꼭 기억“모든 사이트는 판매자가 입점할 수 있어요.”▾
  1. 플랫폼이 인정한 ‘공식’ 마크가 붙은 스토어
  2. 브랜드명 = 스토어명인 곳 (예: 브랜드도 스토어도 ‘닥터 브로너스’)
  3. 홈쇼핑 채널
  • 롯데온 같은 곳도 일반 판매자가 입점할 수 있어서, 사이트 이름만으로 공식몰로 보면 안 됩니다. 2주차에 알려 드린 이 기준선 안에서만 움직입니다.
  • 롯데온·숲이 싸 보이는 건 아직 본 상품이 적어서이고, 비율로 보면 오히려 비싼 편입니다. 그 밖의 경우는 소싱이 손에 잡힌 뒤에 판단할 수 있습니다.
8실습: 닥터 브로너스 마진 계산“1,000원 이상 남죠?”▾
  • 에누리 쪽은 안 됐지만, 네이버의 닥터 브로너스 코리아 스토어 아래 보라색 슈퍼적립을 봤습니다. 53,500원에 사면 적립금이 8,025원 쌓입니다.
  • 메인 구성이 2개라 2개짜리와 1개짜리를 팔 수 있습니다.

마진 계산기 입력

  1. 묶음 구매가: 할인가 53,500원
  2. 포인트: 8,025원 사용으로 반영
  3. 판매가: 최저가로 선점, 2개짜리 50,240원
  4. 본사에서 바로 보내는 위탁이라 택배비는 빼고 계산 → 1,000원 이상 마진 확인
  • 공식 마크가 있고 브랜드명과 스토어명이 같으니 본사 조건도 충족합니다. → 꼬리물기 시트에 기록.
9꼬리물기 시트 기록과 공유“링크를 한 번만 공유해 주시면 계속 볼 수 있어요.”▾

찾은 상품 적는 법

  • 상품명을 붙여넣고, 카테고리·제조사·브랜드를 카탈로그에서 찾아 먼저 적습니다.
  • 지칭 단어는 지금 적지 않습니다. 상품명만 있으면 나중에 만들 수 있고, 그 상품으로 꼬리물기를 할 때 씁니다.

엑셀 → 구글 스프레드시트

  • 지금은 컴퓨터에 저장된 엑셀 파일이라 코치가 볼 수 없습니다. 카톡으로 보내 드린 스프레드시트 공유 방법을 따라 만들고, 공유를 열어 링크를 보내 주세요.
  • 링크는 한 번만 보내시면 됩니다. 저장해 두고 실시간으로 보며 첨삭해 드립니다.
10숙제와 방문 컨설팅“익숙하지 않으니까 더 많이 해 봐야 돼요.”▾
