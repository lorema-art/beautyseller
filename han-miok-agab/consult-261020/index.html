한미옥 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

지난 상담 뒤 공식몰 적립금으로 마진을 내는 방법이 손에 잡히면서 소싱이 되기 시작했습니다. 이번에는 직접 오셔서 업로드를 막던 API 문제를 짚고, 가격관리·발주·꼬리물기를 처음부터 끝까지 함께 했습니다.

업로드가 안 되던 이유

자동등록 9개가 “정확한 API 주소가 아니다”로 실패했습니다. 사무실 IP를 등록하자 바로 올라갔으니, 집 IP가 커머스 API에 등록되지 않은 것이 원인일 확률이 높습니다. 오늘 집에서 꼭 등록해 주세요.

잘하고 계신 것

역마진 주문 6건을 문자로 지연 처리해 두셨고, 단축키도 금방 익히셨습니다. 실습 마지막엔 상품 하나를 1분 안에 판단하셨어요.

바로잡을 것

브랜드로 바로 들어가 순서 없이 찾다 보니 같은 걸 또 찾는 일이 생겼습니다. 다 본 키워드는 빨간색, 중복은 파란색으로 표시하고 순서대로 갑니다.

앞으로

하루 2~3시간, 하루 10개 등록을 목표로 3개월 바짝. 다만 지치지 않게 5개라도 꾸준히가 우선입니다. 다음 컨설팅에서 등록한 상품을 점검한 뒤, 더 빨리 매출을 내는 다음 단계로 넘어갑니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1API 연동: IP 등록하기오늘 집에서“아마 대표님 집에 있는 IP가 아니라서 인식이 안 됐을 확률이 높아요.”▾
  • 자동등록에서 9개가 올라가지 않았고, 실패 사유가 “정확한 API 주소가 아니다” 식으로 떴습니다. 셀러들의 수다 연동 때도 같은 메시지가 계속 떴다고 하셨습니다.
  • 사무실 IP를 등록하고 1개를 테스트하니 정상 업로드됐습니다.

집에서 할 순서

  1. 네이버에서 ‘내 IP’(영어로 ip도 됨) 검색 → 뜨는 IP 복사
  2. 네이버에서 ‘커머스 API 센터’ 검색해 접속
  3. 내 스토어 애플리케이션 → 뷰셀 앱 클릭 → 수정
  4. IP 칸에 붙여넣고 저장. 최대 3개까지 넣을 수 있으니, 안 쓰는 IP는 지우고 다시 저장

그래도 안 되면

  • 실패 화면 전체를 캡처해서 보내 주세요. 사유를 보고 확인합니다. → 원격 → 그래도 안 되면 다시 방문.
  • 직장에서 열면 IP가 달라 등록이 안 될 수 있습니다. 직장에서는 ‘담기’까지만, 등록은 집에서 하세요.
  • 지난번 원격 때 인터넷 창 클릭이 안 됐던 건 집 와이파이 쪽 문제일 수도 있는데, 원인은 아직 모릅니다.
  • 자동등록 프로그램이 크롤링하는 동안에는 마우스를 쓰지 않습니다.
2가격관리 프로그램과 북마크“컴퓨터 켤 때마다 뜰 거예요.”▾

가격관리 프로그램

  • 컴퓨터를 끄면 프로그램도 꺼집니다. 그래서 PC 켤 때 자동 시작을 켜 두었습니다.
  • 시작을 누르면 크롬 창이 뜨고, 거기서 스마트스토어에 로그인합니다(새 IP면 인증번호를 한 번 더 받을 수 있음).
  • 조금 지나 ‘1사이클 시장 진입 성공’이 뜨면 정상입니다. ‘자세한 기록 보기’에서 확인할 수 있고, 이후 정시마다 자동으로 돕니다.

크롬 북마크

  • 매번 카톡에서 링크를 찾아 들어가지 않도록, 주소창 별표 → 완료로 북마크바에 추가해 두었습니다(스마트스토어, 가격관리, 네이버 가격비교 등).
31,000원 넘는 차이는 금·토·일에 직접“평소에는 프로그램 돌리면 되고요.”▾
  • 프로그램은 최저가와 1,000원 이하로 차이 나는 상품만 맞춰 줍니다.
  • 1,000원 넘게 차이 나는 건 금·토·일에 하나씩 직접 합니다. 소싱할 때처럼 검색하고 에누리를 붙여 두고 왔다 갔다 하며 확인합니다. (3주차 강의 내용)
  • 위치: 스마트스토어 상품관리 → 카탈로그 가격관리. 최저가 1위인 상품은 초록색, 나머지는 최저가와의 차액이 보입니다. API가 안 돼서 그동안 이 화면을 못 보셨습니다.
  • 12일쯤 찾은 상품들은 일주일이 지나 대부분 가격이 올라 역마진입니다. 그래서 주말 관리가 꼭 필요합니다.
4발주 순서와 역마진 처리“발주가 돈과 직결되기 때문에 후딱후딱 해 주는 게 좋아요.”▾
  • 발주는 수시로 하지 말고 시간을 정해 두고 그 안에 끝냅니다.
  • 발주 확인 전에는 고객이 취소하면 바로 취소되고, 발주 확인 후에는 고객이 마음대로 취소할 수 없습니다.

순서

  1. 신규 주문 엑셀 다운로드 → 바탕화면에 저장
  2. 발주 확인으로 넘기기
  3. 엑셀에서 배송 합계까지 복사 → 판매장부에 Ctrl+Shift+V(서식 맞춰 붙여넣기), 날짜 입력
  4. 실제로 보낼 수 있는지(마진이 남는지) 확인

역마진일 때

  • 판매장부에서 빨간색으로 칠하고 ‘역마진’ 메모. 고객이 취소하면 그때 지웁니다.
  • 상품명을 한 번 더 확인하고 배송 지연 3개월 설정 + 안내 멘트 발송.
  • 그 상품이 더 팔리지 않게 막아 둡니다. 역마진 처리 방법은 가격 1만 원 인상 외에는 따로 없습니다.
  • 안내 멘트를 매번 카톡에서 찾지 말고, Win+V(클립보드 기록)에 넣어 두면 바로 꺼내 쓸 수 있습니다.
  • 초반엔 역마진 주문이 많아도 괜찮습니다. 취소되기 전까지는 매출로 잡혀 스토어 지수가 오르고, 다른 상품 노출도 늘어나는 예열 기간입니다.
5멤버십 적립으로 마진 계산하기“전용카드 적립은 일회성이라 우리는 거의 안 할 거예요.”▾
  • 공식몰 판매가에서 구매 적립을 빼서 실구매가를 잡습니다. 기본 적립과 멤버십 추가 적립이 있으면 둘 다 뺍니다.
  • 리뷰 적립, 멤버십 전용카드 적립은 빼지 않습니다. 전용카드 적립은 한 번 쓰면 없어지는 일회성이 많기 때문입니다.
  • 바깥 화면에 멤버십 할인이 안 적혀 있으면 굳이 들어가 볼 필요 없습니다. 실습에서도 들어가 봤지만 적립 합계가 700원 남짓이라 안 됐습니다.
6꼬리물기 규칙꼭 기억“가장 최근에 찾은 날 것부터 꼬리물기 해 주시는 거예요.”▾

시트 표시

  • 다 본 키워드는 빨간색. 순서대로 내려오다 이미 찾은 게 또 나오면 파란색(중복)으로 칠하고 보지 않고 넘어갑니다. (2주차 강의 내용)
  • 한 달 안에 검색한 키워드는 결과가 비슷하니 다시 볼 필요 없습니다.

지칭 단어 만들기

  • 브랜드는 빼고 두 단어로. 예: 닥터지 선크림 라인 → ‘브라이트닝 썬’, ‘모이스처 썬’ … 있는 건 다 합니다.
  • 사람들은 ‘선크림’으로 찾지만 제조사가 ‘썬’이라고 붙여 놨으니, 상품명에 쓰인 대로 ‘썬’으로 검색해 봅니다.
  • 지칭 단어 검색은 베스트와 달리 해외직구 제외·80개 설정 없이 바로 내려가 카탈로그를 봅니다.

진행 순서

  • 매일 가장 최근 날짜에 찾은 상품의 키워드부터 꼬리물기 합니다. 하루에 다 못 봤으면 다음 날 새 상품이 아니라 그 자리부터 이어서, 다 물고 나서 다음 상품으로.
  • 찾은 상품은 날짜, 카테고리·제조사·브랜드를 적고, 지칭 단어는 꼬리물기 할 때 적습니다.
  • 지금 진행 중인 닥터지(한국콜마 베스트에서 나옴)는 순서가 조금 어긋났지만 할인이 많아 그대로 이어 가도 됩니다.
  • 할인 상품이 더 이상 안 나오거나 규칙이 깨졌다면 어디서 꼬인 것이니, 그때 4배수홀을 새로(크림 다음 카테고리부터) 합니다.

남으면 본사 확인
  • 에누리가 로딩되는 동안 네이버를 봅니다. 에누리가 네이버보다 비슷하거나 비싸면 바로 끕니다.
  • 몰 여러 개가 묶여 있으면 1개짜리라도 카탈로그입니다. 파란 글자(최저가)만 눌러 카드 할인을 확인합니다.
  • Ctrl+클릭으로 상품 5개 정도를 미리 열어 두고, 본 건 Ctrl+W로 닫습니다. 끝에서부터 닫는 게 편합니다.
  • 처음엔 오래 걸려도 괜찮습니다. 정확하게 보는 게 먼저, 속도는 같이 줄여 갑니다.

걸러야 하는 판매처

  • ‘유한회사’ 등 중국 판매자는 제외. 설화수 같은 브랜드는 가품 이슈가 많으니 특히 주의.
  • 판매처 이름이 홈쇼핑처럼 보여도 상세페이지 아래 사업자를 확인합니다. 실습에선 개인사업자라 제외했습니다.
  • ‘공식’ 딱지가 없어도 가격이 비슷하거나 더 싸면 들어가서 본사인지 봅니다.

헷갈릴 때

  • 카탈로그 이미지가 달라 보이면(튜브형 vs 퍼프형) 리뷰로 실제 많이 팔리는 상품을 확인합니다. 맞는 카탈로그가 없으면 불필요한 단어를 빼 세 단어 정도로 다시 검색, 그래도 없으면 패스.
  • 2개짜리로 올렸는데 1개짜리 카탈로그도 있으면, 1개 카탈로그로도 들어갈 수 있는지 봐 두면 나중에 다시 볼 필요가 없습니다. 다른 옵션을 누르면 뜨기도 합니다. 지금 어렵다면 뜨는 것만 봐도 됩니다.

  • 순익 100만 원까지가 제일 힘든 구간입니다. 엄청난 노력보다 성실하게 매일 해야 할 것을 하는 것이 중요합니다.
