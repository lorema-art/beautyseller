허진구 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

첫 주문이 들어왔는데, 하필 브랜드 쪽에서 판매 중지를 요청한 상품이었습니다. 상품은 내리고, 들어온 주문은 뷰셀 재고로 보낼 수 있는지 확인하는 중입니다.

이번 주문

‘킹스파워 염색샴푸’ 주문 1건. 브랜드 대표 측이 톡톡으로 판매 중지를 요청해, 상담 중에 스마트스토어에서 판매 중지 처리를 마쳤습니다.

뷰셀님 재고가 있으면

뷰셀님께 알려 주시는 가격으로 사서 대표님 재고로 넘겨받고, 사입 절차로 고객에게 배송 요청합니다.

재고가 없으면

해당 주문을 3개월 발송 지연 처리합니다. 이때는 엑셀을 받을 필요가 없습니다.

서두르지 않아도 되는 이유

처리 기한은 영업일 3일입니다. 토·일은 빠지므로 사실상 10월 13일(화) 밤 12시까지 처리하면 됩니다. 그 전에 일요일 12시 컨설팅에서 함께 봅니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다. 상담 때 쓴 메모장도 바탕화면에 저장돼 있습니다.

1판매 중지 요청이 왔을 때“상품 중지하고 해당 상품 배송 지연해 주시면 되고요.”▾

원칙

  • 브랜드 측에서 연락이 왔다는 건 가격·판매처를 관리하는 곳이라는 뜻입니다. 상품은 바로 내립니다.
  • 이미 들어온 신규 주문은 보낼 수 있으면 보내고, 못 보내면 배송 지연 처리합니다.

톡톡 확인과 답장

  • 스마트스토어 메인 화면을 아래로 내리면 톡톡 알림이 보입니다. ‘자세히 확인하기’를 누르면 톡톡 창으로 들어갑니다.
  • 답장은 “안녕하세요, 확인했습니다.” 정도만 남기면 됩니다.

판매 중지하는 법

  1. 상품관리 → 상품조회/수정
  2. 상품명 칸에 제품명을 넣고 검색 (하나씩 눌러 찾지 말고 검색으로 조회하면 훨씬 빠릅니다)
  3. 목록에서 상품 선택 → 판매상태 변경 → 판매중지
  4. 다시 팔려면 같은 곳에서 ‘판매중’으로 돌리면 됩니다.
2주문이 들어오면: 발주 확인과 엑셀 정리“먼저 선택해야 엑셀 다운이 가능하거든요.”▾

발주 확인

  1. 판매관리에서 신규 주문 건 전체 선택
  2. 엑셀 다운로드 (비밀번호는 0)
  3. 받은 엑셀을 열어 둔 상태에서 스토어의 발주확인 클릭 → 주문이 ‘신규주문’에서 ‘발주 후’로 넘어갑니다.

엑셀 정리

  1. 맨 위 1번 행(노란색)을 오른쪽 클릭 → 삭제
  2. 택배사·송장번호 열(B, C)을 삭제 (Ctrl 누른 채 둘 다 선택하거나 하나씩 삭제)
  3. 상품명을 복사해 둡니다. 이 엑셀은 고객 주소·이름·연락처를 옮겨 적을 때 계속 씁니다.

최저가 확인

  • 크롬에서 네이버 가격비교 창과 에누리 창을 열고, 복사한 상품명을 양쪽에 붙여 넣습니다.
  • 카탈로그에 들어가 살 수 있는지, 마진이 1,000원 이상 남는지, 본사(공식) 판매처인지 봅니다.
  • 묶음 구성이 더 싸면 그걸 삽니다(예: 4개짜리보다 3개짜리가 유리한 경우).
  • 이 과정은 2주차 강의에 그대로 나옵니다.
3위탁 배송: 고객에게 바로 보내기“복사 붙여넣기 하면 되기 때문에 어려운 건 아니거든요.”▾

주문·결제

  1. 구매처(네이버·에누리에서 찾은 곳) 결제 화면에서 배송지 수정 → 신규 입력
  2. 엑셀에 있는 고객 주소, 고객명, 휴대폰 번호를 복사해 붙여 넣고 결제

송장 입력

  1. 상품이 출고되면 구매처의 마이쇼핑 → 주문/배송내역에서 택배사와 운송장 번호를 확인 (네이버라면 네이버 홈 → 쇼핑 → 마이쇼핑, G마켓에서 샀다면 G마켓에서 확인)
  2. 스마트스토어 판매관리 → 발송관리 → ‘발주 후’ 주문 선택
  3. 배송방법 ‘택배·등기·소포’ 선택 → 택배사 선택 → 송장번호 입력

짚어 둘 점

  • 택배사는 아무거나 고르면 안 됩니다. 구매처 주문내역에 뜬 택배사(CJ대한통운, 롯데택배 등)를 그대로 골라야 합니다. 송장이 아직 안 나왔으면 입력하지 않고 기다립니다.
  • 네이버에서 주문한 건은 송장이 중복으로 인식될 수 있습니다.
  • 결제 때 휴대폰 칸에 고객 번호를 넣을지 대표님 번호를 넣을지는 녹음상 표현이 엇갈립니다. 일요일 컨설팅 때 한 번 더 확인해 주세요.
4사입 배송: 재고로 잡고 배송 요청하기이번 주문“입고 등록을 하면 대표님 앞으로 재고가 잡히거든요.”▾

직접 사입할 때 결제

  • 배송지는 고객 주소가 아니라 뷰셀 사무실 주소, 수취인은 대표님 성함(허진구)으로 넣습니다.

① 재고관리 → 입고 등록

  1. 카탈로그명: 상품명을 붙여 넣고 뒤에 붙은 수량 표시만 지웁니다.
  2. 수량: 실제로 산 개수 (3개 묶음을 샀다면 3)
  3. 구매 사이트: 산 곳 (예: 네이버)
  4. 공급가: 개당 단가 (6만 원에 3개면 2만 원)
  5. 입고 등록 클릭 → 대표님 재고로 잡힙니다.

② 배송요청

  1. 배송요청 메뉴에서 재고로 잡힌 상품 선택 (목록에서 고르게 되어 있습니다)
  2. 엑셀을 보고 고객명, 수량, 주소, 배송 메시지, 휴대폰 번호 입력
  3. 배송요청 클릭하면 끝
  • 여러 건을 엑셀로 한 번에 올리는 방법도 있지만, 지금은 한 건씩 입력하는 방법부터 익힙니다.
  • 이번 염색샴푸는 뷰셀님 재고를 넘겨받으면 대표님 재고에 바로 뜨므로, ②배송요청부터 하면 됩니다.
5이번 주문 처리 계획“사셔가지고 배송을 요청해서 발송하고 이득 보시는 게 낫지 않을까 싶어서요.”▾

진행 상황

  • 뿌요 실장이 상담 중에 대표님 카카오톡으로 뷰셀님께 재고 문의를 보내 두었습니다. 뷰셀님께 카톡이 많이 쌓여 있어 순서대로 답이 올 예정입니다(오늘 또는 내일).
  • 재고가 있으면 뷰셀님이 가격을 알려 주십니다. 입금하고 재고를 넘겨받는 방식입니다.
  • 상담 중 본 가격으로는 마진이 600원 정도 남습니다. 뷰셀님 가격을 받으면 다시 계산해 보세요.

재고가 없을 때: 발송 지연

  1. 발송관리에서 주문 선택 → 발송지연처리
  2. 발송 기한을 3개월 뒤로 지정

기한

  • 영업일 3일 이내 처리. 주말은 빠지므로 10월 13일(화) 밤 12시까지면 됩니다.
6익히는 법과 도움 받는 법“해보면 별거 아니거든요.”▾

연습

  • 강의를 세 번 보셨어도 손으로 해 보는 건 다릅니다. 주문이 들어왔다고 생각하고 2주차 강의를 하나씩 따라 눌러 보세요.
  • 보통 3~5번 해 보면 이해되고, 어려워하는 분도 6~10번이면 익숙해집니다. 대표님만 어려운 게 아닙니다.
  • 소싱이 가장 어렵고, 발주는 그에 비하면 훨씬 쉽습니다.

막힐 때

  • 셀스타(셀수다) 프로그램 ‘질문하기’로 남기면 코치들이 확인합니다. 급한 건은 일정을 당겨서라도 봐 드립니다.
  • 대표님은 1기라 컨설팅 횟수 제한이 없습니다(2·3기는 10회).
  • 뿌요 실장은 휴가로 10월 12~14일(월~수) 자리를 비웁니다. 그 사이엔 강사님이나 다른 코치가 도와 드립니다.

소싱

  • 소싱을 많이 해야 지금처럼 주문이 들어옵니다. 잘하고 계시니 조금만 더 해 주세요.
  • 소싱은 많이 했는데 등록은 하나밖에 못 했다고 하셨습니다. 원인은 일요일 컨설팅에서 함께 봅니다.

  • 셀스타 ‘질문하기’로 일요일 12시 컨설팅 요청 남기기 허진구“뷰셀님 재고 확인됨, 일요일 12시 컨설팅 부탁” 식으로
  • 재고 있으면 배송요청, 없으면 3개월 발송 지연 허진구10/13(화) 밤 12시까지
  • 2주차 강의 따라 하며 발주 연습 허진구바탕화면 메모장과 이 리포트를 옆에 띄워 두고
  • 일요일 컨설팅 예약 뿌요10/11 12시, 발주와 미등록 소싱 상품 점검
