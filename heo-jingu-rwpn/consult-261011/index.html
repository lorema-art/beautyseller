한눈에 보기

입고 등록과 배송 요청까지 혼자 해내셨습니다. 이제 남은 건 송장이 뜨면 스마트스토어에 넣는 일 하나, 그리고 다시 소싱입니다.

지금까지 한 것

뷰셀 재고로 입고 등록 → 셀수다에 파일로 배송 요청까지 완료. 판매장부에는 단가만 아직 비어 있습니다(뷰셀님이 단가를 알려 주시면 입력).

송장이 뜨면 ①

셀수다 ‘재고 배송요청’에서 운송장 발송처리 지금 실행을 누릅니다. 스마트스토어에 송장이 자동으로 들어갑니다.

안 들어갔으면 ②

송장번호를 복사해 스마트스토어 배송준비에서 한 건씩 직접 입력하고 발송처리합니다.

언제까지

물건이 이미 사무실에 있어 월요일(10/12) 오후 4~5시쯤 송장이 뜰 것으로 봅니다. 연휴 물량으로 늦으면 화요일. 발송 기한은 10월 14일이고, 그때까지 송장만 입력돼 있으면 됩니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다. 상담 때 함께 적은 메모장(바탕화면)과 같은 내용입니다.

1판매장부 입력“까먹지 않기 위해서 저 같은 경우에는 색깔을 칠해 놔요.”▾
  • 판매장부는 바탕화면 ‘실거래’ 폴더의 엑셀 파일입니다.
  • 주문이 들어와 발주할 때 받은 엑셀 내용을 바로 판매장부에 옮겨 적는 게 좋습니다. 실제 순이익이 얼마인지 여기서 계산합니다.
  • 이번 건은 뷰셀님께 받을 단가만 비어 있습니다. 빈 칸에 색을 칠해 두고, 단가를 받으면 채웁니다.
  • 셀수다에 파일로 배송 요청한 것, 상품명 뒤 수량을 빼고 입력한 것 모두 잘하셨습니다.
2송장 자동 입력: 운송장 발송처리 지금 실행먼저 할 것“한 번 누르면 스토어에 자동으로 입력되거든요.”▾

흐름

  • 배송 요청이 들어가면 물류 담당자가 사무실에 있는 물건을 포장해 내놓습니다. 그러면 셀수다에 운송장 번호가 자동으로 뜹니다.

하는 법

  1. 셀수다 → 배송관리 탭 → 재고 배송요청
  2. 운송장 번호가 뜬 것을 확인
  3. 운송장 발송처리 지금 실행 클릭 → 스마트스토어에 송장이 자동 입력되고 발송처리까지 됩니다.
  • 원래는 송장을 복사해 스토어에 하나씩 넣어야 하는데, 이 작업을 어려워하는 분이 많아 뷰셀님이 만든 기능입니다. 지금까지 오류가 난 경우는 거의 없었습니다.
  • 송장이 뜰 만한 때 종종 눌러 주셔도 됩니다.
3자동이 안 될 때: 직접 입력“고객명은 잘 확인해 주셔야 돼요.”▾
  1. 셀수다 재고 배송요청에서 해당 고객 건의 운송장 번호만 복사 (옆의 복사 버튼)
  2. 스마트스토어 판매자센터 → 배송준비 클릭 (송장을 아직 안 넣은 주문만 보입니다)
  3. 아래 목록에서 고객명을 확인하고 해당 주문 체크
  4. 배송방법 택배·등기·소포 선택
  5. 택배사 CJ대한통운 선택
  6. 송장번호 붙여넣기 → 선택건 적용 (목록에 송장이 들어간 것 확인)
  7. 위쪽 발주확인 옆 ‘발송처리’ 클릭 → 끝
  • 여러 건이면 1~7을 한 건씩 반복합니다.
  • 뷰셀 물류는 CJ대한통운을 씁니다. 다른 택배사를 고르면 안 됩니다.
4잘 들어갔는지 확인하기“운송장이 입력되면 배송중으로 넘어가요.”▾
  • 자동으로 넣든 직접 넣든, 송장이 들어가면 주문이 ‘배송준비’에서 사라지고 ‘배송중’으로 넘어갑니다.
  1. 스마트스토어 판매자센터 → 배송중 클릭
  2. 목록에서 해당 주문이 있는지 확인
  3. 상품주문번호(숫자)를 누르면 상세 정보가 열리고, 거기서 송장번호를 확인할 수 있습니다.
  • 배송중에 없으면 입력이 안 된 것입니다. ‘지금 실행’을 한 번 더 눌러 보고, 그래도 안 되면 3번 방법으로 직접 넣습니다.
  • 버벅거리면 셀수다 ‘질문하기’에 남겨 주세요.
5꼬리물기 다시 잡기“브랜드가 나오면 어차피 안 올리면 되잖아요.”▾

판매 중지된 상품도 꼬리물기는 계속

  • 킹스파워 염색샴푸는 내린 게 맞습니다. 하지만 그 상품명에 쓰인 키워드로는 계속 꼬리물기를 합니다.
  • 같은 키워드(예: ‘샴푸 블랙’)를 상품명에 쓰는 다른 브랜드들이 할인할 확률이 높기 때문입니다. 킹스파워 상품이 나오면 그것만 안 올리면 됩니다.
  • 판매 중지 요청은 그 상품 하나에 대한 것입니다. 같은 브랜드의 다른 상품도 마진이 나오면 올리고, 내려 달라고 하면 그때 내립니다.

시트 고치기

  • 꼬리물기 키워드는 두 단어로 씁니다. ‘샴푸’ 대신 샴푸 블랙, 샴푸 앤, 샴푸 볼륨, 샴푸 300ml처럼 나눕니다.
  • 제조사가 안 나와 있고 브랜드만 있는 경우가 있습니다. 일부러 안 쓴 것일 수 있으니 물음표로 두고 넘어갑니다.
  • 찾은 상품은 시트 아래로 쌓이고, 마지막 상품을 기준으로 다시 꼬리물기를 이어 갑니다.

→
나오면 거기서 꼬리물기

안 나오면 베스트부터 새로
  • 시트 위쪽 기록은 9월 14일 것이라 한 달 가까이 지났습니다. 그 사이 할인은 대부분 끝났을 테니, 위로 더 올라가지 말고 베스트 소싱을 새로 시작합니다.
6숙제와 다음 상담“대표님만의 속도로 한 단계 한 단계 나아가고 있으니까요.”▾

숙제

  • 다음 컨설팅까지 하루 5개 찾기. 꼬리물기에서 안 나오면 베스트 상품 소싱에서 5개.
  • 참고로 2시간이면 꼬리물기로 보통 3~7개가 나옵니다. 대표님은 하루 2시간 이상 앉아 계시니 충분히 가능한 양입니다.

수집 프로그램

  • 설치가 안 되는 수집 프로그램(거인의 공방)은 뿌요 실장도 써 본 적이 없어, 휴가에서 돌아온 뒤 함께 보기로 했습니다.

다음 상담

  • 다음 주 예약은 오늘(10/11) 오후에 열립니다. 목·금·토·일 중 편한 시간으로 신청해 주세요.
  • 뿌요 실장은 10월 12~14일(월~수) 휴가입니다. 그 사이 막히면 셀수다 ‘질문하기’로 남겨 주세요.

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 송장 뜨면 ‘운송장 발송처리 지금 실행’ 누르기 허진구10/12(월) 오후 4~5시쯤 예상, 늦으면 화요일
  • ‘배송중’에서 송장 입력 확인, 안 됐으면 직접 입력 허진구10/14(수)까지, CJ대한통운
  • 단가 받으면 판매장부 입력 허진구실거래 폴더 엑셀, 빈 칸 색칠해 두기
  • 꼬리물기 시트 키워드 두 단어로 고치고 이어 가기 허진구샴푸 블랙·앤·볼륨·300ml → 킹스파워 브랜드 → 없으면 베스트
  • 하루 5개 소싱 허진구다음 상담까지 매일
  • 다음 주 컨설팅 신청 허진구오늘 오후 예약 오픈, 목·금·토·일 중
  • 수집 프로그램(거인의 공방) 설치 함께 보기 뿌요휴가 복귀 후
