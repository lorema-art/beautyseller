한눈에 보기

사정이 있어 시간을 많이 못 내신 한 주였습니다. 그래서 프로그램 설치는 미루고, 그 시간에 함께 상품을 찾았습니다.

오늘 정한 것

샴푸 꼬리물기 줄은 10월 6일 것이라 3~4주가 지나 거의 나오지 않습니다. 오늘부터 베스트로 새로 소싱합니다. 베스트 세팅 순서는 손이 이미 기억하고 계셨습니다.

새로 배운 것

상품명이 너무 길어 검색이 안 되면 앞의 회사명과 중간 단어를 지우고 브랜드 + 핵심 단어 3개 정도만 남겨 검색합니다. 이미 판 상품은 다시 올리지 않습니다.

숙제

다음 상담까지 모두 합쳐 5개 소싱. 무리하지 말고 하실 수 있는 만큼, 상품 찾기를 끊기지 않게 이어 가는 게 목표입니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1소싱 프로그램(거인의 공방)은 보류“필요하시면 깔아 드리고, 아니면 상품 소싱하는 게 나을 것 같아요.”▾
  • 거인의 공방 무료자료 쪽으로 들어가 봤지만 로그인 단계에서 막혀 설치하지 못했습니다. 들어가는 페이지는 저장해 두었습니다.
  • 소싱할 시간이 없을 때 돌려 보는 용도로는 쓸 수 있지만, 프로그램이 찾은 상품도 결국 직접 다시 확인해야 합니다.
  • 그래서 오늘은 설치 대신 직접 소싱을 하기로 했습니다. 필요해지면 그때 다시 요청해 주세요.
2위탁 처리 흐름 다시 확인“일단 상품을 판매해 봐서, 그걸 하면서 여쭤봐야 될 것 같아요.”▾
  • 위탁은 산 사이트의 마이쇼핑 → 주문/배송내역에서 송장을 찾아 스마트스토어에 입력하면 끝입니다(10/18 리포트 4번 참고).
  • 실제 위탁 주문이 들어오면 그때 한 번 해 보면서 막히는 곳을 셀수다로 물어보시면 됩니다.
3이미 판 상품은 다시 올리지 않기“중복으로 들어가서 네이버에서 싫어하거든요.”▾
  • 3개짜리 8,500원으로 마진이 될 것 같아 소싱 리스트에 올리려다 확인해 보니, 이미 두 개 팔고 브랜드 요청으로 내린 킹스파워 상품이었습니다. 아직 할인이 계속되고 있었습니다.
  • 한 번 등록했던 상품을 다시 올리면 중복 상품이 되어 스토어에 좋지 않습니다. 패스합니다.
  • 마진이 되면 리스트에 올리기 전에 공식몰인지 먼저 확인하는 순서도 다시 짚었습니다.
4베스트로 새로 시작하기“손이 알아서 막 해요.”▾
  • 꼬리물기 시트의 샴푸 줄은 10월 6일에 한 것입니다. 3~4주가 지나면 할인이 대부분 끝나 거의 안 나옵니다. 켜 둔 상품까지만 보고 베스트로 넘어갑니다.

베스트 세팅

  1. 화장품 유형 선택
  2. 카테고리: 샴푸였으니 헤어케어
  3. 해외직구 제외, 80개 보기
  4. 위에서부터 차례로 소싱
  • 해외직구 상품은 판매할 수 없으니 나오면 바로 넘깁니다.
  • 신상은 아직 판매처가 많이 안 풀려 있을 수 있습니다. 어느 정도 내려 봤는데 없으면 없다고 보고 넘어갑니다.
5검색이 안 뜰 때: 상품명 짧게 자르기새 방법“한 3단만 남기고 다 없애 봅시다.”▾
  • 기획세트처럼 여러 상품이 묶여 있거나 상품명이 길면 가격비교에서 잘 안 뜹니다.
  1. 맨 앞 회사명(예: 라이온코리아)을 지웁니다. 브랜드명은 남깁니다.
  2. 중간 설명을 지우고 브랜드 + 핵심 단어만 남깁니다(예: 브랜드 + 핸드솝).
  3. 다시 검색하면 뜨는 경우가 많습니다. 다만 비슷한 다른 상품이 섞여 뜨니 같은 상품인지 꼭 확인합니다.
  • 지울 때는 커서를 두고 Delete 키를 누르거나 키보드 화살표로 움직이는 게 가장 빠릅니다. 지금 하시는 방법이 맞습니다.
  • 꼬리물기 키워드(두 단어)는 그 브랜드가 상품명에 계속 쓰는 단어로 잡습니다. 이번 상품은 ‘핸드솝’이 그 단어입니다.
6함께 본 상품과 넘긴 이유“빠르게 패스하셔도 돼요.”▾

짚어 둘 점

  • 6개짜리 같은 큰 구성도 올려 두면 하나씩 팔리긴 합니다. 기획세트까지는 보셔도 됩니다.
  • 11번가는 상세페이지를 내리면 판매자 정보가 바로 보이고, 이번처럼 ‘구매대행 위탁판매 상품’이라고 적힌 경우도 있습니다.
  • 쿠팡 빠른배송이면 보통 본사입니다. 본사면 포인트가 있는지, 모든 옵션 보기로 수량을 늘리면 더 싸지는지 봅니다.
  • 안 되는 상품은 미련 두지 말고 빨리 넘기셔도 됩니다.

  • 검색 안 뜨면 상품명 짧게 잘라 다시 검색 허진구회사명 빼고 브랜드 + 핵심 단어, 같은 상품인지 확인
  • 위탁 주문 들어오면 송장 입력 직접 해 보기 허진구막히면 셀수다 질문하기
