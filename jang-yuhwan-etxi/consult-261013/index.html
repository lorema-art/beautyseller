장유환 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

6월 말 강의 이후 회사 일과 이사로 석 달가량 손을 놓으셨다가, 추석특강을 들으며 다시 시작하려는 단계입니다. 집 PC에서 셀러들의 수다 접속이 막혀 있던 문제를 원격으로 풀었고, 자택 IP 등록·자동등록 프로그램 설치·가격관리 프로그램 가입과 세팅까지 코치가 직접 마쳤습니다. 이제 프로그램 쪽 준비는 끝났으니, 이번 주는 강의 복습과 소싱 실습에 집중하고 주말에 컨설팅을 받으시면 됩니다.

오늘 해결한 것

집 PC 자택 IP 등록, 자동등록 프로그램 설치(크롬), 가격관리 프로그램 가입·API 키·로그인 유지 세팅까지 완료.

이번 주 과제

추석특강·2주차 강의 다시 보기, 금요일까지 하루 1~3시간 소싱 실습.

다음 상담

주말(토·일 중) 컨설팅 신청. 예약 화면에 빈 시간이 없으면 가능한 날짜·시간을 여러 개 카톡으로 보내기.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1지금 상황: 다시 시작하는 단계“추석특강부터 이제 조금씩 듣기 시작하고 있고요.”▾
  • 6월 말 강의를 다 보신 뒤 회사 일·이사로 바빠 석 달 가까이 진행을 못 하셨고, 그사이 내용을 많이 잊으셨다고 하셨습니다.
  • 그동안 프로그램과 강의가 많이 업데이트돼서, 예전 강의를 다시 보기보다 추석특강을 기준으로 맞춰 보는 방향이 맞습니다. 프로그램 부분은 추석특강이 가장 최신입니다.
  • 집 PC와 회사 노트북 두 곳에 프로그램을 깔아 두셨는데, 회사에서는 셀러들의 수다가 열리지만 집 PC에서는 애플리케이션 ID·시크릿 입력 창이 떠서 더 진행하지 못하고 계셨습니다.
  • 여기까지 다시 따라오신 것 자체가 잘하신 겁니다. 한 번에 다 기억하지 못해도 괜찮습니다.

  • 스마트스토어는 스토어에 연결된 계정으로 다시 로그인해야 했습니다.
  • 사업자·스토어는 다른 가족 명의, 강의 신청은 대표님 명의라 이름과 아이디가 서로 다르지만, 같은 경우가 많아 진행에는 문제없습니다.
3IP 등록해결“한 번만 해 놓으면 되는데…”▾
  • 등록된 IP가 사무실 것뿐이고 자택 IP가 빠져 있어 집에서 막혔던 것으로 확인됐습니다. 코치가 자택 IP를 등록했습니다.
  • IP는 접속할 때마다 등록하는 게 아니라 한 번만 해 두면 됩니다. 한번 지정한 IP는 바뀌지 않습니다.
  • 목록에 자택·사무실 외에 정체를 모르는 IP가 하나 더 있습니다. 사무실에 가셨을 때 불필요한 것 하나는 삭제해 주세요.
4자동등록 프로그램 설치와 사용법해결“자동 등록 프로그램은 크롬에서 켜셔야 돼요 무조건.”▾
  • 예전에 깔아 두셨던 자동등록 프로그램이 집 PC에서 보이지 않았고, 현재 구글 계정에 등록돼 있지 않았습니다. 설치 중 안랩 보안 창이 떠서 닫고 진행했고, 코치가 직접 설치했습니다.
  • 자동등록은 셀러들의 수다 창이 아니라 반드시 크롬에서 켜야 합니다.

  • 하루 동안 찾은 상품을 담아 두었다가 주무시기 전에 대량 등록 시작만 누르면 됩니다.
5가격관리 프로그램세팅 완료“지금 당장 켜실 필요는 없지만 차후에는 켜셔야 돼요.”▾
  • 가입이 안 돼 있어 오늘 새로 가입했고, API 키는 한 번만 세팅해 두면 됩니다.
  • 컴퓨터와 이 프로그램이 켜져 있으면, 스토어에서 카탈로그에 매칭된 상품 가격을 1,000원 이내 범위에서 자동으로 계속 조정합니다.
  • 시작 버튼을 누르면 크롬 창이 따로 뜨고, 거기서 스마트스토어에 로그인(로그인 상태 유지)하면 창이 닫히고 백그라운드에서 돌아갑니다. 한번 세팅하면 이후엔 다시 떠 보이지 않아도 정상입니다.
  • 아직 등록한 상품이 없어서 지금은 안 켜도 됩니다. 상품을 올린 뒤부터는 컴퓨터를 켤 때 셀러들의 수다와 함께 기본으로 켜 주세요.
6모르는 전화가 와도 겁먹지 않기중요“전화는 강의 때 얘기 드린 것처럼 안 받으셔도 되고요.”▾
  • 6월에 테스트로 상품 하나를 올렸다가 총판 쪽에서 전화가 많이 와서 놀라셨고, 그 뒤로 소싱을 멈추셨습니다.
  • 이런 전화는 받지 않으셔도 됩니다. 강의에서 알려 드린 대로만 대응하면 문제가 생기지 않습니다.
  • 스토어에는 전화만 되는 공기계 번호를 등록해 두셨습니다. 이 경우 별도 인터넷 전화(아톡)를 따로 만들 필요 없이 그대로 쓰시면 됩니다.
7이번 주 숙제와 컨설팅 잡는 법다음 단계“금요일까지는 소싱을 하루에 1시간에서 2, 3시간 정도는 최대한 해주시고요.”▾
  • 추석특강은 아직 다 못 보셨습니다. 소싱 강의(2주차)부터 다시 보시고 그대로 실습해 보세요.
  • 평일엔 아침부터 저녁 7~8시까지 출퇴근·업무와 겹쳐 컨설팅을 신청하기 어렵다고 하셨습니다. 일요일까지 일정이 열려 있으니 주말에 코치 컨설팅을 신청하세요.
  • 예약 화면에 가능한 시간이 없다면 다른 분들이 먼저 예약한 것입니다. 일주일 중 가능한 날짜·시간을 최대한 많이 카톡으로 보내 주시면 코치가 조정해 드립니다.
  • 컨설팅은 30분 단위로 진행됩니다. 섹션별로 집중해서 보기 때문에 30분이면 충분합니다.
