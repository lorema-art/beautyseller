전혜미 대표님 컨설팅 정리 (2회차)

전혜미 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

원격으로 대표님 화면을 보며, 오늘의 할인 대신 네이버 슈퍼적립 가전제품을 올리는 방법을 처음부터 끝까지 함께 해 봤습니다. 주문이 들어오면 뷰셀 물류로 받아서 발송하는 흐름(재고 요청·입고 등록·배송 요청)과 KC 인증 입력까지 실습했습니다.

지금 상태

프로그램 사용법은 익숙해지셨습니다. 그동안 오늘의 할인 상품을 아침에 돌려 올리셨는데, 다른 수강생과 겹쳐 마진이 빨리 깎이는 구간이었습니다.

오늘 정리한 것

오늘부터 오늘의 할인은 올리지 않고, 슈퍼적립 가전을 올립니다. 매출 규모가 커지면 네이버가 스토어 전체를 더 노출해 줘서 화장품도 덕을 봅니다. 가전은 위탁 직배송 대신 뷰셀 물류를 거쳐 보냅니다.

앞으로

이번 주(토요일 전)까지 슈퍼적립 가전을 쭉 올리고, 토요일 2주차 강의 후에도 하루 1시간·최소 5개는 계속 올립니다. 일요일은 강의 내용을 적용해 보는 날로 쓰고, 다음 주 컨설팅을 신청합니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1오늘의 할인은 이제 그만“오늘부터는 우선 오늘의 할인 제품 올리지 마시고요.”▾
  • 1주차는 상품 등록 연습 구간이었습니다. 오늘의 할인 상품은 동기·다른 기수분들이 함께 올려서 마진이 굉장히 빨리 깎입니다.
  • 2주차가 지나면 대부분 하지 않습니다. 계속하는 건 하루 30분~1시간밖에 못 쓰셔서 2주차 소싱법을 도저히 할 수 없는 분들뿐입니다.
2슈퍼적립 가전 — 스토어를 키우는 치트키핵심“네이버는 수수료 장사 하잖아요.”▾

가전제품 위주로 등록
  • 네이버는 수수료로 돈을 벌기 때문에 주문 건수보다 매출이 큰 스토어를 좋아합니다. 가전으로 매출을 키우면, 순익은 적더라도 화장품 등 어떤 상품을 올려도 노출이 더 잘 됩니다.
  • 어떤 카테고리든 괜찮지만 의류·잡화·향수는 뺍니다. 가장 권장하는 건 가전제품입니다.
  • 가전은 마진 용도가 아니라 전략용입니다. 자세한 원리는 3주차에 설명드리고, 대표님은 1주차에 미리 빠르게 시작하시는 겁니다.
  • 상품을 왼쪽 클릭하면 원래 창이 바뀌어 번거롭습니다. 오른쪽 클릭 → 새 탭에서 링크 열기로 여세요.
3마진 계산 — 셀수다 마진계산기로핵심“판매 페이지에서 보시면 안 돼요. 얘는 허수예요.”▾

택배비 넣고 마진 확인
  • 셀러들의 수다 → 마진계산기를 켜고, 사 오는 가격과 적립 포인트를 넣습니다.
  • 포인트는 판매 페이지 위쪽 숫자가 아니라(리뷰 적립 등이 섞인 허수), 결제창 아래 ‘최대 ○○원’을 기준으로 봅니다.
  • 가전은 보통 모델명이 있어서, 모델명으로 네이버 가격비교를 검색하면 카탈로그가 나옵니다. 등록가는 카탈로그 최저가보다 10원 싸게.
  • 예시(청소기): 구매가 약 64만 원, 포인트 약 7만 7천 원, 판매가 약 63만 5천 원, 택배비 1만 원 가정 → 마진 약 1만 9천 원. 마진은 조금 줄어도 안전한 게 낫습니다.
  • 택배비는 박스 크기·무게에 따라 다릅니다. 대략 5kg 정도면 5천 원, 10kg 넘으면 1만 원. 가늠이 안 되면 우선 1만 원으로 잡습니다.
4가전도 직배송 말고 뷰셀 물류로주의“배송비가 좀 들더라도 … 그냥 안전하게 보내는 게 방법이라서.”▾
  • 가전은 원래 위탁으로 바로 보내도 됐지만, 최근 네이버의 위탁 판매 규제가 심해졌습니다(4주차에 자세히). 뷰셀이 발송하는 건 문제가 없어서, 한 번 뷰셀 물류로 받았다가 보냅니다. 그러면 위탁 위반 사항이 없습니다.
  • 직접 위탁을 아예 하지 말라는 건 아니지만, 필살기처럼 가끔 쓰는 게 좋습니다. 위탁은 주문을 건건이 다 넣어야 해서 품도 더 듭니다.
  • 뷰셀 물류로 보내면 출고 때 뷰셀이 운송장을 입력하고, 셀수다에 넣어 둔 API 키 덕분에 대표님 스토어에 자동으로 발송 처리됩니다.
  • 수익이 잘 나는 분들은 알려 드린 그대로만 하십니다.
5주문이 들어오면 — 재고 요청과 입고 등록핵심“사서함 번호를 주소지 뒤에다 써서 보내주시면 ‘아, 대표님 거구나’.”▾

배송 요청
  • 2주차에 안내할 내용이지만, 오늘부터 올리면 토요일 전에 주문이 들어올 수 있어서 미리 알려 드렸습니다.
  • 재고 요청 화면에 카탈로그명을 복사해 넣고, 옵션(없으면 비움)과 보내는 수량을 넣습니다.
  • 공급가와 구매 사이트는 대표님 재고 관리용입니다. 얼마에·어디서 샀는지 넣고 입고 등록합니다.
  • 구매할 때 받는 주소는 뷰셀 물류 주소로, 주소 뒤에 사서함 번호를 꼭 적어 주세요. 동명이인 수강생이 꽤 있고, 택배 이름 가운데가 별표로 가려져서 못 찾는 경우가 생깁니다.
6배송 요청 — 엑셀 템플릿 한 장“입력만 하면 끝나나요?”▾
  • 배송 요청 → 엑셀로 등록에서 템플릿을 받습니다.
  • 적을 것: 고객 성함 · 연락처 · 주소 · 배송 메시지 · 카탈로그명 · 수량. 저장한 뒤 파일 선택 → 등록하기를 누르면 끝입니다.
  • 대표님 컴퓨터에 엑셀이 없어서(본가의 다른 방 컴퓨터에만 있음) 템플릿이 안 열렸습니다. 뷰셀이 엑셀 설치 파일을 보내 드렸으니, 셋업(setup)을 눌러 설치하시면 됩니다.
7KC 인증 — 자동으로 안 되면 손으로“AI가 이 인증 번호를 못 찾고 있는 거예요.”▾
  • 가전은 KC 인증을 등록해야 합니다. 프로그램이 입력하라고 띄우면, AI가 인증번호를 못 찾은 경우입니다.
  • 본사 판매 페이지를 조금 내려 KC 인증번호를 복사해 넣고, 인증 종류는 전기용품을 선택합니다.
  • 인증번호 확인을 누르면 인증창이 뜹니다. 거기서 인증기관·제조사를 복사해 넣고 등록 → 다 된 건 비우기.
8대량 등록은 자기 전에 돌려 두기“돌아가고 있는 거를 저희가 쳐다보는 건 시간 낭비니까.”▾
  • 밤에 돌린다고 매출이 더 좋은 건 아닙니다. 프로그램은 어차피 최저가로 등록하고, 다른 분이 먼저 또는 나중에 매칭되는 건 통제할 수 없습니다.
  • 돌아가는 동안 컴퓨터를 만지면 안 되니, 하루 종일 찾은 상품을 자기 전에 ‘대량 등록 시작’으로 돌려 두고 주무시라는 뜻입니다.
  • 가격 경쟁은 2주차에 드리는 가격 관리 프로그램을 켜 두면 자동으로 관리됩니다.
9컨설팅은 꾸준히“수익 잘 나오시는 분들은 그냥 컨설팅을 매주 꾸준히 받으세요.”▾
  • 강의가 끝나고 1~2달 차가 되면 대부분 소싱이 잡혀 알아서 잘하십니다. 그 전까지는 지금 뭘 해야 하는지, 뭐가 잘못됐는지 혼자 판단하기 어렵습니다.
  • 대표님도 꾸준히 받는 게 좋겠다고 하셨습니다.
