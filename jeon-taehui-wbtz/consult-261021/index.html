전태희 대표님 1:1 컨설팅 정리

전태희 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

지난주(10-14) 이후 크게 어긋나는 부분 없이 잘 진행하고 계셔서, 이번에는 대표님 질문 위주로 봐 드렸습니다. 역마진 발송지연 페널티 걱정은 덜어도 되고, 스토어 알림(발송제한·CS·수정 요청 상품)만 제때 챙기면 됩니다. 하루 8~9개까지 올라온 소싱은 10개로 올리되, 허리를 생각해 30분 일하고 5분 쉬기를 지킵니다.

오늘 확인한 것

3개월 배송지연은 사실상 페널티 없음. 고객이 직접 취소하게 하는 방식도 괜찮음. 품절 처리만 페널티가 있으니 피하기.

이번 주 과제

하루 10개 소싱 · 토·일 가격관리 · 수정 요청 상품 3건 보완 후 복원 요청 · 시트에서 지마켓 빼거나 색으로 구분.

다음 단계

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1역마진 발송지연·취소 페널티“페널티 비율, 이거 사실 거의 안 봐도 되는 거긴 한데요.”▾
  • 역마진 때문에 발송지연 처리하는 건이 줄고는 있지만 아직 꽤 있어서, 건수·비율이 많아지면 페널티가 있는지 물어보셨습니다.
  • 3개월 배송지연 처리는 사실상 페널티가 없습니다.
  • 페널티는 보통 판매자가 품절로 취소할 때 생깁니다. 우리는 고객이 직접 취소하도록 유도하는 방식이라 괜찮습니다.
  • 점수가 조금 깎일 수는 있지만, 보낼 수 있는 주문이 역마진 주문보다 훨씬 많기 때문에 비율이 문제 될 만큼 쌓이기는 아주 어렵습니다. 크게 신경 쓰지 않으셔도 됩니다.
2꼭 챙길 것: 발송제한 D-1·CS“CS 이런 것만 신경 써주시면 돼요.”▾
  • 스토어 화면의 발송제한 D-1 주문과 고객센터(CS) 알림 건만 신경 쓰시면 됩니다.
  • 당일이나 다음 날 안에 처리하면 괜찮습니다.
3수정 요청 상품 3건: 보완 후 복원 요청바로 적용“이런 거는 보시고 빨리빨리 복원 요청을 하시는 게 좋아요.”▾
  • 스토어에 수정 요청 상품 3건이 떠 있습니다. 들어가서 사유를 읽어 보세요(예: 상품 품질 확인, “제조사명으로 수정 바랍니다”).
  • 대표님 상품이 잘 노출되다 보니 경쟁 판매자가 신고해서 잠깐 안 보이게 만드는 경우가 많습니다. 내용을 보완하고 빨리 복원 요청을 누르세요.
경우처리
마진 남고 판매 가능내용 보완·재고 수정 후 복원 요청
마진 안 남음가격 10,000원 올리고 판매 중지 후 복원 요청
4스토어 그래프 보는 법 (복습)“떨어지면 상품 수가 부족하거나 가격관리를 안 하고 있을 확률이 높거든요.”▾
화면보는 법
데이터 분석 → 요약 → 실시간 현황비교일이 14일이라 지난주 오늘 vs 이번 주 오늘 비교. 어떤 부분이 아쉬운지 확인
판매 분석직접 선택으로 기간 설정 후 주·월 단위로 추세 확인. 업데이트로 최대 2개월만 볼 수 있음(예전엔 3개월·1년도 가능)
  • 월별로 어떻게 운영되고 있는지 점검합니다. 10월은 아직 진행 중이라 더 올라갈 겁니다.
  • 그래프가 떨어지면 상품 수와 가격관리부터 점검해 보완합니다.
5하루 10개 소싱, 30분 + 5분 리듬숙제“30분 일하시고 5분 쉬는 거, 꼭 해서 스트레칭 꼭 해주시고요.”▾
  • 지금 하루 최소 3개, 많으면 8~9개 올리고 계십니다. 아팠던 17일에는 슈퍼적립 상품만 3개 올리셨습니다.
  • 허리만 괜찮으면 하루 10개를 하고 싶지만 버티기 어렵다고 하셨습니다.
  • 꾸준히 하려면 체력이 중요합니다. 뷰셀 대표님이 말씀드린 대로 30분 일하고 5분 쉬며 스트레칭하면 능률이 확실히 오릅니다.
  • 이 리듬을 지키면서 하루 10개 소싱을 숙제로 드립니다.
  • 주말 가격관리는 토·일요일에 한 번씩 해 주세요.
6꼬리물기 시트에서 지마켓 구분“얘는 꼬리 물게 하면 안 되잖아요.”▾
  • 시트에 지마켓에서 찾은 상품이 섞여 있으면 꼬리물기 할 때 헷갈립니다. 정신없이 하다 보면 지마켓 상품으로 꼬리물기를 하게 될 수 있는데, 지마켓 상품은 꼬리물기 대상이 아닙니다.
  • 지마켓을 자주 찾으실 것 같으면 아예 빼거나, 색을 다르게 칠해 구분하세요.
  • 꼬리물기는 지난번 말씀드린 대로 순서대로 끝까지 진행해 주시면 충분합니다.
