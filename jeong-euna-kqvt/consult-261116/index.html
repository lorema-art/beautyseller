하루 7개셀수다 오늘의 할인 찜
정은아 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

쌓여 있던 질문을 원격으로 하나씩 풀었습니다. 상품정보 기재 위반, 반품비 미입금 고객, 직배송 입고 수량, 온라인 사무실 사용법을 정리했습니다. 꼬리물기는 전체적으로 잡혔지만, 하던 키워드를 끝내지 않고 넘어가거나 중복(파란색) 키워드를 다시 보느라 한 달 가까이 같은 상품만 나왔습니다. 이제부터는 꼬리물기에 더해 가전과 셀수다 ‘오늘의 할인’ 상품을 매일 올립니다.

해결한 것

상품정보 기재 위반은 이미 수정을 잘 하셨고, 복원 요청만 누르면 됩니다. 반품비를 안 보내는 고객은 기다리면 됩니다. 구글 이미지 AI 결제 금액은 사용량과 맞습니다.

바꿀 것

꼬리물기는 하던 키워드를 끝까지 보고 넘어갑니다. 파란색(중복) 키워드는 1~3개월 동안 다시 보지 않습니다. 위탁 대신 사무실로 받아 출고합니다.

새로 할 것

슈퍼적립 가전 카탈로그 소싱 하루 3~5개, 셀수다 오늘의 할인 하루 7개 찜 후 동일 상품·마진 확인해서 등록합니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1상품정보 기재 위반: 복원 요청만 누르기해결“수정 요청 상품에서 복원 요청 누르면 네이버에서 3일 정도 안에 확인해 줘요.”▾
  • 카탈로그 상품명(예: 1개)과 첫 번째 옵션(예: 2개)이 달라 네이버에서 기재 위반 메일이 왔습니다. 예전에 프로그램으로 등록할 때 생긴 문제로 보입니다.
  • 대표님이 직접 고친 내용은 맞습니다. 판매중지해 둔 것도 괜찮습니다.
  • 남은 일은 수정 요청 상품 → 복원 요청 하나입니다. 네이버가 3일 안팎으로 확인합니다.
  • 옵션의 ‘제3자 정보제공 동의’, 카탈로그에 묶여 들어간 옵션은 그대로 두면 됩니다.
2반품비를 안 보내는 고객“돈 안 주는데 우리가 마이너스 보면서 해 줄 필요 없잖아요.”▾
  • 발송 기한 안에 정상 발송했으므로, 반품 배송비는 고객이 내야 합니다. 상품은 오늘 수거됐습니다.
  • 고객이 돈을 보낼 때까지 그대로 기다립니다. 고객이 네이버에 신고해도 이런 이유로 처리할 수 없다고 네이버에 설명하면 됩니다.
  • 입금되면 환불 보류 해제 → 반품 완료 처리(초록 버튼)를 누릅니다. 지금 검은 버튼은 눌리지 않는 상태입니다.
3자동등록 새 기능: 판매중지 상품 찾기“상품정보 제공고시가 모자라면 판매상태만 중지가 돼요.”▾
  • 자동등록 프로그램은 이제 다시 받지 않아도 자동으로 업데이트됩니다.
  • 전시는 ‘전시중’인데 판매상태만 ‘중지’인 상품은 상품정보 제공고시가 부족한 상품입니다.
  • 판매중지 상품 찾기로 이런 상품을 모아 보고, 상품정보 제공고시를 채워 주면 됩니다. 각 기능 설명 글을 읽으면 그대로 따라 할 수 있습니다.
4사무실 입고 신청은 무조건 ‘1개’ 기준중요“기준은 무조건 하나인 거예요. 그다음에 수량만 바꿔 주면 돼요.”▾
상품명: 1개짜리 카탈로그명
+
수량: 실제 개수
  • 입고 신청: 6개를 샀다면 상품명은 1개짜리로 적고 수량을 6으로 바꿉니다.
  • 배송 요청: 1개 주문이면 수량 1, 고객이 2개를 샀으면 상품명은 그대로 두고 수량만 2로 바꿉니다.
  • ‘200ml 2개’처럼 상품명에 개수가 들어가면 시스템이 곱해서 2×2로 계산합니다. 그래서 반드시 1개짜리 이름으로 적습니다.
  • 여러 개짜리를 샀을 때 낱개 포장인지는 대부분(90% 이상) 후기에 나와 있습니다. 후기에 없으면 받아 봐야 압니다. 미리 너무 걱정하지 않아도 됩니다.
  • 택배비 충전 사이트 비밀번호는 상담 중에 초기화해 드렸습니다. 로그인 후 바꿔 주세요.
5에누리에서 살 때는 네이버 카탈로그가 기준“카탈로그는 ‘은아’로 올려놓고, 에누리에서 ‘은순’을 찾으면 안 되잖아요.”▾
  • 우리가 파는 상품은 네이버 카탈로그 상품입니다. 에누리에서 사 오는 상품이 같은 상품인지 꼭 확인합니다.
  • 1차로 상품명, 2차로 사진을 봅니다. 사진과 다른 상품이 올 확률은 거의 없습니다.
  • 에누리는 배송비를 넣으면 네이버 공식몰보다 비쌀 때가 많지만, 몇 개 사서 낱개로 팔면 남는 경우가 있습니다. 이때 위의 입고 방식으로 사무실에 보내면 됩니다.
6질문은 쌓아 두지 말고 온라인 사무실에“여기다 남겨 주시면 그나마 좀 빠른 답변을 받을 수 있어요.”▾

카톡
  • 뷰셀은 온라인 사무실 채팅창을 거의 항상 켜 두고 있어, 남기면 실시간으로 보입니다. 보통 30분 안에 답하고, 1시간이 넘으면 외부 일정 중입니다.
  • 질문을 모아 두면 머리가 복잡해지고, 컨설팅 때 진도를 나가기 어렵습니다. 생길 때마다 바로 남겨 주세요.
  • 네이버에서 오는 전화는 담당자 번호로 오는 것이라 070으로 바꿀 수 없습니다. 받지 않아도 이메일로 다시 연락이 옵니다. 고객은 대표님 개인 번호를 모르니 다른 전화는 편하게 받으셔도 됩니다.
7구글 이미지 AI 결제와 세금“제가 돈을 가져가는 게 아니라 AI가 가져가는 거잖아요.”▾

이미지 AI 결제

  • 상품 1개 등록에 100~300원 정도, 상세 페이지가 길거나 가전이면 500원 정도 나갑니다.
  • 8월 말부터 16,000원씩 여러 번 결제됐는데, 등록한 상품 수(약 284개)로 계산하면 사용한 만큼 나간 것이 맞습니다.

세금

  • 세금은 순이익에 붙어서 생각보다 많지 않습니다. 사업용·생활비 카드를 홈택스에 등록해 두신 것 잘하셨습니다.
  • 현금이나 포인트로 살 때는 현금영수증을 사업자로 받으면 절세가 됩니다.
  • 매출이 났는데도 판매량이 아직 적은 편입니다. 원인은 꼬리물기가 틀어졌거나 스토어 활성화가 덜 된 것 둘 중 하나여서, 아래 꼬리물기 점검과 가전 등록으로 이어졌습니다.
8꼬리물기: 끝까지 보고, 파란색은 다시 보지 않기중요“밥 한 숟가락 먹고 뛰어나갔다가 3시간 뒤에 남은 밥 먹는 느낌이거든요.”▾

무엇이 틀어졌나

  • 코스맥스를 하다가 끝내지 않은 채 네이처리퍼블릭(1,000개 넘게 보고 1개 찾음)으로 넘어갔다가, 다시 코스맥스로 돌아오셨습니다.
  • 하던 키워드에서 다른 제조사(예: 서울화장품)가 나올 수 있으므로, 하던 것은 무조건 끝내고 다음으로 넘어갑니다.
  • 코스맥스는 10월 중순에 이미 찾은 파란색(중복) 키워드였습니다. 파란색은 1~3개월 동안 다시 보지 않습니다. 그래서 한 달 가까이 같은 상품만 계속 나왔습니다.

앞으로

  • 가장 최근에 찾은 상품부터 꼬리물기를 합니다. 같은 날짜에 찾은 것이 여러 개여도 상관없습니다. 날짜가 바뀔 때까지 기다리지 않습니다.
  • ‘글루타치온 썬크림’처럼 썬크림의 성분·강도를 나타내는 말은 키워드가 아니므로 검색하지 않습니다.
  • 전반적인 꼬리물기 방법은 이제 잘 잡혔습니다.
9위탁 줄이고 사무실로 받아서 출고중요“서류가 없으면 두 번 적발되면 정지예요.”▾
  • 위탁은 법적으로는 문제가 없지만, 네이버가 공급사와의 공식 계약서를 요구합니다. 본사와 계약하기는 어려워 서류가 없으면 두 번 적발 시 스토어 정지입니다.
  • 최근 경쟁 판매자들의 신고가 많아, 동기·다른 기수분들도 적발되고 있습니다.
  • 그래서 사무실로 받아서 출고합니다. 사무실 배송비 3,000원을 넣고도 1,000원 이상 남으면 등록합니다.
  • 지난 특강(카탈로그 가격 조정·셀수다 설명)에서도 같은 내용을 안내했습니다.
10새 숙제 ①: 슈퍼적립 가전 하루 3~5개“가전이 무서울 것 같지만 의외로 또 그렇지도 않아요.”▾

마진 계산 후 등록
  • 가전을 올려 매출이 오르면 네이버가 스토어를 더 밀어 줍니다(3주차 강의 내용). 전화가 많이 와서 싫으셔도 올려야 합니다.
  • 가전 카테고리는 세 가지(대형·소형 가전 / 휴대폰 / 안마용품)를 하루씩 돌아가며 봅니다.
  • 꼬리물기가 아니라 카탈로그만 찾아 들어가는 방식이라 빠릅니다. 1시간에 20~40개도 찾습니다.
  • 마진 계산 때 리뷰 적립, 특정 카드 발급 적립은 일회성이라 넣지 않습니다. 빨간 할인가와 실제 적립 포인트로 계산합니다.
  • 판매자들이 모두 같은 가격에 머물러 있는데 한 곳만 싸면 그날만 하는 할인일 수 있습니다.
11새 숙제 ②: 셀수다 ‘오늘의 할인’ 하루 7개 찜“꼭 동일한 상품인지 보셔야 돼요. 그거 안 보면 안 돼요.”▾

마진 1,000원 이상이면 등록
  • 매일 7개까지 찜할 수 있습니다. 7개 중 마진 남는 것만 등록하면 됩니다.
  • 동일 상품 확인이 먼저입니다. 모델명(예: NKGN9)을 비교하고, 애매하면 본사 페이지에서 확인합니다.
  • 쿠폰은 대부분 여러 번 발급되니 쿠폰가로 계산하고, 카드 할인 7%, 사무실 배송비 3,000원을 넣습니다.
  • 나이·성별·지역에 따라 보이는 가격이 달라서, 코치가 본 가격과 대표님 화면 가격이 다를 수 있습니다.
  • 네이버 링크로 들어갈 때 ‘서비스 접속이 안 된다’가 뜨는 경우는 뷰셀이 수정해 보기로 했습니다.

체크 표시는 이 브라우저에서만 저장됩니다.

  • 반품비 입금되면 보류 해제 정은아환불 보류 해제 → 반품 완료 처리 · 그전까지는 그대로 두기
  • 판매중지 상품 찾기로 고시 보완 정은아전시중인데 판매만 중지된 상품
  • 택배비 충전 사이트 비밀번호 변경 정은아상담 중 초기화한 비밀번호로 로그인 후 바꾸기
  • 꼬리물기 최근 상품부터, 끝까지 정은아파란색(중복)은 1~3개월 보지 않기 · 성분·강도 표현은 키워드 아님
  • 슈퍼적립 가전 하루 3~5개 등록 정은아대형·소형 / 휴대폰 / 안마용품 하루씩 번갈아 · 모델명으로 카탈로그 찾기
  • 셀수다 오늘의 할인 하루 7개 찜 정은아동일 상품 확인 → 배송비 3,000원 넣고 1,000원 이상 남으면 등록
  • 위탁 대신 사무실 입고 정은아입고·배송 요청은 1개짜리 상품명 + 실제 수량
  • 질문은 생길 때마다 바로 정은아셀수다 질문하기 → 온라인 사무실 → 카톡
