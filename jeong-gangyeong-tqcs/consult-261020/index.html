정강영 대표님 1:1 컨설팅 정리

2026년 10월 20일 · 정강영 대표님, 뿌요 교육실장 · 원격으로 화면 함께 보며 진행

12월 말본격 운영 시작
정강영 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

원래 컨설팅은 소싱한 상품을 함께 점검하는 시간이지만, 상품 등록이 되어야 그다음이 있으니 이번에는 막혀 있던 프로그램 문제부터 풀었습니다. 자동등록은 IP를 다시 넣어 등록 완료까지 확인했고, 가격관리 프로그램과 캡처 도구도 바로 찾을 수 있게 고정해 드렸습니다. 대표님은 11월 중순~12월 초 여행을 다녀온 뒤 12월 말부터 본격적으로 하실 계획입니다.

오늘 해결한 것

자동등록 오류(IP 불일치) → 등록 완료. 가격관리 프로그램 실행·로그인 확인 후 즐겨찾기 고정. 캡처 도구를 작업표시줄에 고정해 1:1 문의에 사진을 붙일 수 있게 됨.

다시 확인한 원칙

쇼핑몰 최저가·브랜드 카탈로그가 있는 상품만 올립니다. 카탈로그 없는 상품을 수동으로 올리거나 묶어서 노출시키는 건 하지 않습니다.

남은 숙제

네이버 가격비교 보안 확인 오류는 네이버에 문의. 가격관리는 매일 아침 PC를 켜면 한 번 실행. 여행 기간엔 판매 중지 대신 판매가를 3만 원 올려 둡니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1자동등록이 안 되던 이유: IP 불일치오늘 해결“IP가 안 맞다는데… 뒷부분이 살짝 바뀌었어요.”▾
  • 프로그램 자체가 잘 안 돌아간다고 하셔서 상품 하나로 직접 돌려 보며 원인을 찾았습니다(카탈로그 담기 → 대량 등록 시작, 소액 비용 발생).
  • 원인은 IP가 다르다는 것이었습니다. 주소가 크게 바뀐 건 아니고 뒷자리가 살짝 바뀌어 있었습니다. 보통은 잘 안 바뀌지만 인터넷 환경에 따라 조금씩 변할 수 있습니다.
  • 바뀐 IP를 추가한 뒤 다시 돌려 등록 완료를 확인했습니다.
  • 스마트스토어 전체 상품에 안 뜨던 상품들은 업로드 자체가 안 됐던 것입니다.

IP는 어디에 넣나요

  • IP는 네이버 커머스 API 센터에서 추가합니다.
  • 등록 프로그램에는 IP를 넣지 않아도 됩니다. 커머스 API의 애플리케이션 ID와 시크릿 키만 넣으면 자동으로 인식됩니다.
  • 평소엔 점검할 필요가 거의 없지만, 다시 등록이 안 되면 IP가 바뀌었는지 먼저 의심해 보세요.
2카탈로그 있는 상품만 올리기중요“카탈로그로 노출시키면 광고비 없이 1위 노출이 가능한 거라서 그렇게 하는 거예요.”▾
  • 네이버 가격비교에서 상품을 고를 때 ‘쇼핑몰 최저가’도 카탈로그입니다. ‘브랜드 카탈로그’만 되는 게 아니라 둘 다 됩니다. (해외직구 제외 필터도 확인)
  • 그 외 일반 상품은 카탈로그가 아니라서, 대표님이 올려 봤을 때 등록이 안 됐던 것입니다.
  • 카탈로그가 없는 상품을 수동으로 올리는 것도 하지 않습니다. 노출이 안 되고, 광고비를 써야 보이기 때문에 사실상 안 팔립니다.
  • 스마트스토어에서 보이는 ‘상품을 묶으면 노출이 쉽다’는 안내는 브랜드를 운영할 때 쓰는 기능입니다. 아직은 준비가 더 필요하니 하지 않으셔도 됩니다.

지금은 손대지 않아도 되는 설정

  • 하한가(가격이 그 아래로 내려가지 않게 막는 기능): 만 원으로 켜져 있었는데, 실장님도 쓰지 않는 기능이라 꺼도 됩니다.
  • 상품번호 추가, 상태 조회 같은 기능은 사입 주문이 들어왔을 때 쓰는 것입니다. 지금은 해당 사항이 없으니 ‘전체 끄기’로 꺼 두세요.
  • 창이 여러 개 떠서 하나씩 끄기 힘든 문제는, 한꺼번에 끄는 방법을 상담 중에 찾지 못했습니다.
4캡처해서 1:1 문의하는 법오늘 해결“캡처 자체가 안 되니까 문의할 수도 없고, 너무 답답했어요.”▾

1:1 문의에 사진 첨부
  • 동영상 모드가 눌려 있으면 영상 녹화가 됩니다. 왼쪽 카메라 모양을 눌러 사진으로 찍으세요.
  • 저장 위치는 바탕화면, 다운로드 등 어디든 괜찮습니다.
  • 문의는 셀수다(세일스타) → 홈 → 1:1 질문하기 → 사진 첨부로 올립니다. 궁금한 건 웬만하면 이 경로로 문의해 주세요.
  • PC에 깔려 있던 정체불명의 캡처 프로그램은 쓰지 않으셔서 삭제했습니다.
5네이버 가격비교 보안 확인 오류네이버 문의“이거는 저희가 할 수 있는 게 아니라서 네이버에 문의해서 해야 돼요.”▾
  • 셀수다에서 네이버 가격비교로 들어갈 때 보안 확인 화면이 뜨고, 정답을 넣어도 계속 틀렸다고 나오는 문제입니다.
  • 실장님도 처음 보는 화면으로, 네이버 쪽에서 막은 것인지 프로그램으로는 해결할 수 없습니다. 네이버 고객센터에 문의해 주세요. 캡처해서 보내면 설명이 쉽습니다.
  • 그 전까지는 크롬 창에서 직접 네이버 가격비교에 들어가서 작업하시면 됩니다.
6엣지에서 크롬으로 바꾼 뒤 혼란“크롬으로 바꿔 놓으니까 컴퓨터가 이상하게 세팅이 돼 가지고…”▾
  • 원래 엣지를 쓰시다가 크롬으로 바꾸면서 설정이 리셋되어 정신이 없으셨다고 합니다. 모니터가 하나라 창이 겹치는 것도 힘드셨습니다.
  • 저희 확장 프로그램은 크롬 위주라 크롬으로 쓰시는 게 맞습니다. 오늘 자주 쓰는 도구(가격관리, 캡처)를 고정해 두었으니 조금씩 익숙해지실 겁니다.
7여행 기간 운영: 판매 중지 대신 가격 인상중요“상품 중지보다는 판매가를 3만 원 인상하시는 게 더 낫다.”▾
  • 대표님은 11월 중순에 떠나 12월 초에 돌아오십니다. 그때까지 준비 과정을 숙달해 두고, 12월 말부터 본격적으로 하실 계획입니다.
  • 지난 오프라인 컨설팅 때는 여행 기간에 상품을 중지하라고 안내했지만, 바꿔서 판매가를 3만 원 올려 두는 것을 권합니다.
  • 가격이 높으니 주문은 거의 안 들어오고, 혹시 팔리면 그만큼 이익입니다. 돌아오면 원래 가격으로 되돌립니다.
8다음 상담부터는 소싱 점검“다음부터는 우리 소싱하는 거 조금 위주로 같이 봐요.”▾
  • 원래 컨설팅은 대표님이 꼬리물기·베스트 소싱한 상품을 같이 점검하는 시간입니다. 이번엔 등록 문제부터 풀었으니, 다음에는 소싱 위주로 봅니다.
  • 대표님은 다른 분들보다 시간이 더 걸리더라도 천천히 해 보겠다고 하셨습니다. 천천히 하되 포기만 하지 않으면 됩니다.

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 매일 아침 가격관리 프로그램 실행 정강영즐겨찾기의 ‘세일스타 가격관리’ → 시작 → 로그인 → 진입 성공 확인
  • 카탈로그 있는 상품만 소싱·등록 정강영쇼핑몰 최저가·브랜드 카탈로그 · 초록색 카메라 아이콘으로 등록 · 수동 등록·묶음 노출 X
  • 네이버 가격비교 보안 확인 오류 문의 정강영네이버 고객센터 · 오류 화면 캡처 첨부 · 그동안은 크롬에서 직접 접속
  • 막히면 캡처해서 1:1 문의 정강영가위 아이콘 → 새 캡처(사진 모드) → 저장 → 셀수다 홈 → 1:1 질문하기 → 사진 첨부
