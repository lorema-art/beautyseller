정종준 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

노트북을 들고 사무실에 오신 날입니다. 강의로 본 내용을 처음으로 직접 손으로 해 봤습니다.

지금 상태

스마트스토어는 열려 있고 세팅도 잘 되어 있습니다. 강의도 여러 번 보셔서 흐름은 알고 계십니다. 다만 직접 해 본 적은 한 번도 없고, 올라간 상품이 0개입니다.

오늘 한 것

① 셀러들의 수다 오늘의 할인에서 상품을 찾아 마진을 계산하고 자동등록 프로그램에 담기 ② 네베소(네이버 베스트)로 직접 소싱하기 ③ 사라졌던 가격관리 프로그램 다시 설치. 세 가지를 했습니다.

앞으로 일주일

오늘의 할인에서 매일 7개씩 찾아 올리고, 네베소로 상품을 최소 1개 찾습니다. 시간이 남으면 2주차 강의를 보면서 꼬리물기를 해 봅니다. 등록은 댁에서 하셔야 합니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1눈으로 본 것과 직접 하는 것은 다릅니다핵심“실제는 하나도 안 해봤죠.” — 정종준 대표님▾
  • 상품명 앞에 수식어를 넣고 뒤의 숫자를 지우는 것까지, 방법은 말로 다 설명하실 수 있었습니다. 강의를 여러 번 보신 덕분입니다.
  • 그런데 막상 해 보니 어느 칸에 어떤 가격을 넣는지, 어느 버튼을 누르는지에서 여러 번 멈추셨습니다. 처음이라 그런 것이고, 한 사이클만 직접 돌려 보면 금방 익숙해집니다.
  • 그래서 오늘은 설명보다 대표님이 직접 마우스를 잡고 해 보는 데 시간을 썼습니다.

1,000원 이상이면 담기
  • 오늘의 할인 탭에서는 하루에 7개까지 찜할 수 있습니다. 뷰셀이 프로그램으로 미리 찾아 둔 상품이라, 마진만 남으면 그대로 올리면 됩니다.
  • 찜하고 상품보기를 누르면 왼쪽은 우리가 사 오는 사이트, 오른쪽은 네이버 카탈로그가 열립니다.
  • 첫 번째 확인: 같은 상품인가. 양쪽의 모델명(코드)을 비교합니다. 가격보다 이게 먼저입니다.
  • 두 번째 확인: 마진이 남는가. 셀러들의 수다 안에 있는 마진계산기를 씁니다.
  • 네이버 쪽 링크가 안 열리면, 상품명을 복사해서 네이버에 직접 검색해 가격을 봅니다.
  • 전자제품도 올려도 됩니다. 하지 말라고 한 적은 없습니다.

왜 이 숙제부터인가

  • 지금 올라간 상품이 없고, 자동등록 프로그램을 거의 안 써 보셔서 아직 헷갈려 하십니다. 매일 조금씩 올리면서 프로그램에 익숙해지는 것이 먼저입니다.
3마진계산기에 넣는 숫자핵심“제가 보는 가격하고 대표님 보는 가격은 다를 수가 있어요.”▾
  • 구매가 — 사 오는 사이트에서 쿠폰·카드 할인까지 적용된 최종 가격을 넣습니다. 포인트·적립금은 그 아래 칸에 따로 넣습니다.
  • 판매가 — 네이버 카탈로그 최저가보다 10원 싼 가격을 넣습니다. (사 오는 곳 가격과 헷갈리기 쉬운 칸입니다.)
  • 택배비 — 사무실로 받았다가 고객에게 보내는 비용입니다.

  • 온라인 가격은 나이·성별·지역에 따라 다르게 보입니다. 그래서 대표님 화면에 보이는 가격으로 계산해야 합니다.

오늘 계산해 본 3개

  • 싱글 사이즈 상품 — 구매가 196,200원, 택배비 3,000원, 마진 약 1,000원 → 올릴 수 있는 상품.
  • TV(설치 제품) — 뷰셀 화면에서는 플러스였는데 대표님 화면에서는 마이너스 → 올리지 않음.
  • 세 번째 상품 — 구매가 75,810원(멤버십 적립 포함), 판매가 89,700원, 택배비 3,000원 → 계산기 기준 약 1만 원 남음 → 자동등록 프로그램에 담아 둠.
4기준은 1,000원 — 1만 원은 다른 이야기“아니요, 천 원 이상 남는 거.”▾
  • 올릴지 말지의 기준은 구매가·택배비·수수료를 다 빼고 1,000원 이상 남는가입니다. 사무실에서 고객에게 다시 보내는 택배비도 이 안에 포함해서 계산합니다.
  • 대표님이 기억하신 ‘1만 원’은 소싱 기준이 아닙니다. 이미 올린 상품이 역마진이 됐을 때 판매가를 1만 원 올려 두라는 이야기였습니다. 손해를 보고 팔 수는 없기 때문입니다.
5자동등록 프로그램 — 담기는 어디서나, 등록은 댁에서핵심“댁의 IP랑 여기랑 달라서 지금 여기서 등록이 안 돼요.”▾
  • 같은 상품이고 마진이 남는 걸 확인했으면, 카탈로그 화면에서 자동등록 프로그램을 켜고 카탈로그 담기를 누릅니다.
  • 담아 둔 상품은 프로그램을 껐다 켜도 없어지지 않습니다.
  • 등록 시작은 사무실에서 누르지 않았습니다. 등록은 IP가 같아야 해서 댁에 가셔서 누르셔야 합니다. 오늘 담아 둔 상품도 댁에서 등록하시면 됩니다.
  • 자동등록은 오늘의 할인 상품만 되는 게 아닙니다. 직접 찾은 상품도 같은 방법으로 담아서 올립니다.
  • 직접 찾은 상품은 맞든 틀리든 우선 올리세요. 주문이 들어오면 구매해서 사무실 주소로 보내고, 사무실에서 고객에게 출고합니다.

카탈로그 상품만
  • 판매자 한 곳만 있는 개별 상품은 할 수 없습니다. 여러 판매처가 묶여 있는 카탈로그만 봅니다.
  • 상품은 Ctrl을 누른 채 클릭해서 새 탭으로 여러 개 띄워 둡니다. 하나씩 들어갔다 나오는 시간을 아끼는 방법입니다.
  • 네이버 창은 왼쪽 위에 맞춰 화면의 3분의 2 정도로 두고, 비교할 사이트는 오른쪽에 둡니다.
  • 첫 페이지에 80개씩 보이게 해 두었습니다. 첫 페이지 80개를 다 보고 다음으로 넘어갑니다.
7강의와 달라진 점 — 에누리 대신 G마켓·쿠팡변경“저희가 에누리를 버릴 거예요.”▾
  • 강의에서는 에누리를 보라고 했지만, 화장품은 에누리에 잘 안 나옵니다. 최근 다른 대표님들과 해 보면서 확인한 내용입니다.
  • 그래서 G마켓과 쿠팡 두 곳을 켜 두고 봅니다.
  • 순서: 카탈로그 상품명을 브랜드명부터 용량까지 복사 → 쿠팡에 검색 → G마켓에 검색 → 검색 결과는 그대로 두고 네이버에서 수량별 가격을 먼저 봅니다.
  • 마스크팩처럼 용량이 아니라 낱개로 포장된 상품은 ‘마스크’까지만 복사하면 됩니다.
8네이버에서 먼저 볼 것 — 팔 수 있는 구성과 암산핵심“먼저 나온 거는 사람들이 많이 찾고 잘 팔리는 거라서 그래요.”▾
  • 카탈로그를 열었을 때 먼저 선택되어 뜨는 구성은 가장 싼 구성이 아니라 가장 잘 팔리는 구성입니다.
  • 우리가 팔 수 있는 건 ① 먼저 뜨는 메인 구성 ② 1개짜리 두 가지뿐입니다. 나머지 구성은 볼 필요가 없습니다.
  • 사 올 때는 반대로 개당 가격이 가장 싼 묶음을 찾습니다. 편의점 1+1처럼 묶음이 개당 더 싸기 때문에, 묶음으로 사서 나눠 파는 구조입니다.
  • 암산으로 먼저 거르기 — 가장 싼 묶음 가격을 수량으로 나눕니다. 백 원 단위는 버리고 계산하면 쉽습니다.
  • 예) 2개 28,000원 → 개당 14,000원. 택배비 3,000원만 더해도 17,000원이라 수수료를 떼면 마이너스 → 바로 패스.
  • 암산으로 애매하면 그때 마진계산기를 씁니다. 수학 시험처럼 어려운 문제는 붙잡지 말고 넘어가는 것이 요령입니다.
9본사 확인 3가지와 사이트별로 보는 범위핵심“남는다고 땡이 아니라, 이게 정품이 맞는지 봐야 돼요.”▾

본사 기준 — 셋 중 하나만 맞으면 됩니다

  • ① 공식·인증 표시 — 사이트가 붙여 주는 딱지가 있는가
  • ② 브랜드명 = 스토어명 — 판매자 이름이 브랜드와 같은가
  • ③ 홈쇼핑 — 홈쇼핑에서 파는 상품인가

네이버 카탈로그

  • 판매처에 ‘G마켓’, ‘옥션’이라고만 나오면 그건 사이트 이름입니다. 눌러서 실제 판매자를 확인합니다. 표시가 없고, 판매자명이 영어이고, 사진이 흐릿하면 본사가 아닙니다.

G마켓

  • 로그인을 해야 가격이 제대로 보입니다.
  • ‘일반 상품’ 위까지만 봅니다. 일반 상품 아래는 관계없는 제품이 섞여 나옵니다.
  • 네이버 카탈로그에 보이는 G마켓 가격과 G마켓에서 직접 검색한 가격은 다를 수 있고, 카탈로그에 없던 본사가 나오기도 합니다. 그래서 따로 검색합니다.

쿠팡

  • 검색 결과 위쪽 8칸만 봅니다. 더 내리지 않습니다.
  • 파란색 로켓배송만 됩니다. 쿠팡이 본사에서 직접 매입한 상품이기 때문입니다. 주황색 판매자로켓은 안 됩니다.
  • 로켓이 있으면 ‘모든 옵션 보기’에서 단위당 가격(10ml당 얼마)으로 가장 싼 묶음을 찾습니다.
  • 8칸 안에 로켓이 없으면 거기서 끝입니다.

오늘 대표님이 직접 본 상품

  • 4개 묶음 상품 — 개당 약 4만 원, 계산기로 1,000원이 남았지만 네이버 판매처 5곳이 모두 본사가 아니었고, G마켓·쿠팡에도 없어서 패스.
  • 마스크팩 — 쿠팡 2개 19,000원 → 개당 약 9,500원에 택배비 3,000원을 더하면 역마진. G마켓에 홈쇼핑이 있었지만 더 비싸서 패스.
  • 네이버에서 안 되는 걸 봤어도 G마켓·쿠팡까지 보는 이유: 네이버에 모든 판매처가 나오는 게 아니라서, 절반 정도는 따로 검색해야 나옵니다.
10찾았을 때와 못 찾았을 때“아무리 못해도 샴푸까지 보면 나와요.”▾

찾았으면

  • 팔 구성(1개짜리 또는 메인 구성)을 누르고 자동등록 프로그램에 먼저 담습니다.
  • 노트북에 넣어 둔 뷰셀 4기 시트의 꼬리물기 양식에 적습니다: 카탈로그명(복사), 찾은 키워드에는 ‘베스트’(또는 네베소), 찾은 날짜.
  • 양식의 나머지 칸은 비워 둡니다. 꼬리물기를 할 때 쓰는 칸입니다. 이 부분은 2주차 강의를 휴대폰으로 옆에 켜 놓고 따라 해 보세요. 오늘 한꺼번에 설명하면 더 복잡해져서 남겨 두었습니다.

못 찾았으면

  • 스킨케어 안의 3차 카테고리를 위에서부터 차례로 다 훑고, 그다음 2차 카테고리(바디케어 등)로 넘어갑니다.
  • 스킨케어에서는 잘 안 나올 수 있습니다. 그렇다고 건너뛰어서 샴푸부터 보시면 안 됩니다. 위에서부터 차근차근 봅니다.
11가격관리 프로그램 — 다시 설치했습니다“얘가 대표님 스토어를 자동으로 가격을 관리해 주는 거예요.”▾
  • 노트북을 켤 때 뜨던 오류는 가격관리 프로그램 폴더가 없어져서 생긴 것이었습니다. 프로그램이 자동으로 켜지려는데 파일을 못 찾고 있었습니다.
  • 회원가입부터 다시 하고, IP를 넣어 세팅한 뒤 스마트스토어 로그인까지 해 두었습니다.
  • 이제 노트북을 켜면 크롬 창이 하나 저절로 열립니다. 화면에 ‘작동중’이라고 나오면 잘 돌아가는 것입니다. 댁에서 매일 켜 두시면 됩니다.
  • 이미 돌아가고 있을 때는 다운로드 폴더의 ‘셀수다 가격관리’를 다시 눌러도 새로 켜지지 않는 것이 정상입니다.
  • 상담 처음에 물어보신 매주 역마진 확인도 이 프로그램과 이어지는 내용입니다. 다만 지금은 올라간 상품이 없어서 관리할 가격도 없습니다. 등록이 먼저입니다.
