조은혜 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

일이 바빠 2주 넘게 소싱을 못 하셨고, 들어오는 주문만 처리하고 계셨습니다. 그래프는 처음보다 우상향이지만 새로 올린 상품이 없어 지난주보다 흐름이 약해졌습니다. 그래서 오늘은 꼬리물기 규칙을 다시 잡고, 실제 소싱 속도를 점검했습니다. 속도(상품당 20~30초)와 찾는 디테일은 문제없고, 꼬리물기 시트를 규칙대로 정리하는 것이 핵심 과제입니다.

오늘 확인한 것

매칭 상품 100개 미만, 그중 최저가 선점 가능한 건 약 50개. 가격관리 프로그램은 컴퓨터가 꺼져 있어 멈춘 상태. 꼬리물기 시트는 순서·표시 규칙이 들쭉날쭉 → 다시 정리 필요.

오늘 해결한 것

셀러들의 수다 업데이트 완료, 자동 소싱 프로그램 설치를 막던 보안 해제. 꼬리물기 시트를 뷰셀에게 공유해, 요청하시면 바로 봐 드릴 수 있게 됐습니다.

이번 주 집중

꼬리물기를 정확하게. 하루 3시간 중 꼬리물기로 6개 이상, 오늘의 할인 3개 등록. 특강 녹화본 뒷부분(꼬리물기)은 꼭 다시 보세요.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1현재 상태 — 상품을 더 밀어 넣을 때주의“이 상태로 두면 매출은 계속 쭉 떨어질 거예요.”▾
  • 매칭된 상품이 100개가 조금 안 되고, 그중 절반 정도부터 1,000원 이상 차이가 나기 시작합니다. 사실상 최저가 선점이 가능한 건 약 50개입니다.
  • 그래프는 시작 때보다 우상향이지만, 금액이 크게 튄 날 때문에 그렇게 보이는 것이고 주문은 10건을 겨우 넘는 수준입니다.
  • 다행히 떨어지는 그래프는 아니지만 지난주보다 약해졌고, 최근 일주일 올린 상품이 없습니다. 지금은 소싱이 문제입니다.
  • 상품을 더 넣고 주말에 가격 관리로 최저가를 선점하면 매출이 늘어날 수 있습니다.
  • 가격관리 프로그램은 평소 켜 두셨지만 오늘은 컴퓨터를 못 켜서 멈춰 있었습니다. 큰 변경은 없으니 지금 버전 그대로 쓰시면 됩니다.
2꼬리물기 규칙 — 최근에 찾은 것부터, 좌→우핵심“꼭 최신에 나오는 것부터 하셔야 돼요.”▾
  • 어떤 상품으로 꼬리물기를 해서 3개를 찾았다면 → 다음은 3번(가장 마지막에 찾은 것)부터. 거기서 7개가 나오면 → 7번부터. 중간에 남은 것들은 나중에.
  • 이유: 온라인 할인은 시시각각 바뀝니다. 10월 2일에 찾은 상품을 10월 9일에 꼬리물기하면 그때 있던 할인은 이미 사라졌을 수 있어 시간 낭비입니다.
  • 시트는 왼쪽에서 오른쪽으로 봅니다. 다 본 키워드는 빨간색, 이미 본 중복 키워드는 파란색(3개월 동안 다시 안 봄).
  • 대표님 시트는 본 키워드에 체크가 안 된 곳이 있고 규칙성이 떨어졌습니다. 4배소로 새 상품 찾기가 어려우니 지금 있는 상품으로 꼬리물기를 다시 하기로 했습니다.
  • 하다가 뭔가 이상하면 “시트 한 번만 봐 주세요”라고 말씀하세요. 시트는 오늘 공유받아 두었습니다.

  • ‘크림 미스트’는 여러 브랜드가 나오니 OK → 첫 페이지 끝까지 최저가 비교, 마진 확인.
4카테고리·제조사·브랜드 보는 법핵심“제조사도 사업자들도 이름이 동일한 데가 분명히 있어요.”▾
  • 카테고리: 상품의 카테고리 이름(예: 미스트)을 검색해서 첫 페이지만 봅니다. 카테고리 안으로 눌러 들어가는 건 4배소싱 때만.
  • 제조사·브랜드: 검색 후 첫 페이지(잘 팔리는 40개)를 먼저 보고 → 끝이 아니라 왼쪽 세부 카테고리 중 1,000개 넘는 것을 하나씩 눌러 각각 첫 페이지를 봅니다. (예: 생활건강 → 출산육아 → 식품 → 화장품, 향수는 제외)
  • 화장품 제조사(코스맥스)인데 강아지 용품·식품이 뜨면 의심하세요 → 제품정보에서 제조사 확인. ‘코스맥스 바이오’처럼 이름만 겹치는 다른 업체면 제외합니다.
  • 잘못 따라가면 꼬리물기가 꼬여서 처음부터 다시 해야 합니다.

  • 판매처가 본사가 아니거나 사진이 합성 같으면 패스. 같은 사이트 중복도 패스.
  • 에누리: 배송비 포함 켜고, 광고 지나 카탈로그에서 파란색(최저) 가격 부분을 꼭 누르기 → 카드 할인 있으면 켜고 비교.
  • 용량당 가격도 보세요. 5개짜리가 제일 싸다고 해도 10ml당 1,248원으로 다른 것보다 비싸면 볼 필요 없습니다.
  • 최저가 구간만 보면 됩니다. 아래로 스크롤해 비싼 것까지 볼 필요 없습니다.
  • 평가: 오랜만인데도 상품당 20~30초로 빠르고, 디테일도 문제없습니다. 오늘 잡아 드린 부분만 챙기면 더 잘 찾아집니다.
6위탁은 줄이고 사입으로주의“지금은 위탁 비중을 좀 줄이는 게 나아요.”▾

  • 단품 위탁은 마진이 너무 적거나 안 남는 경우가 많습니다. 묶음으로 팔아야 마진이 나오는 상품이 많습니다.
  • 웬만하면 사무실로 보내는 사입 방식으로 하세요.

8오늘의 할인·공동구매“마진이 적든 크든 매일 3개씩은 등록하세요.”▾
  • 오늘의 할인은 하루 3개까지 신청할 수 있고, 대부분 가전·디지털입니다. 찜 수도 보입니다.
  • 신청 → 찜 → 상품보기 → 카탈로그·매입가 확인 → 카드 할인까지 넣어 마진 계산 후 등록. 차이가 비정상적으로 크면 뭔가 이상할 수 있으니 적당한 마진인 것을 고르세요. 품절인 건 빼고 진행합니다.
  • 공동구매는 뷰셀이 먼저 사 둔 상품을 나눠 드리는 것입니다. 상품당 1명 선착순, 선불금에서 차감되니 잔액이 있어야 합니다. 올라오면 셀러들의 수다(모바일 앱 포함)에 알림이 뜹니다.
  • 질문은 셀러들의 수다에서 상시 켜 둔 ZOOM으로 들어오시면 됩니다.
9프로그램 업데이트·자동 소싱 설치해결“아까 대표님 컴퓨터에 보안 풀어 놨어요.”▾

  • 자동 등록 프로그램은 뷰셀 것을 쓰세요(거인의 공방 쪽과 운영 방식이 달라 세부가 다릅니다).
  • 자동 소싱 프로그램은 보안 때문에 설치가 막혀 있었는데 오늘 풀어 두었습니다. 거인의 공방에서 다시 다운로드하세요.
