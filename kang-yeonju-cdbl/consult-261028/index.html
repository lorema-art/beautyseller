강연주 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

들어온 주문으로 발주 판단 → 역마진 처리 → 배송 지연까지 함께 처리했고, 프로그램을 금방 익히셔서 슈퍼적립 가전 소싱과 입고·배송 요청까지 진도를 당겼습니다.

지금 상태

예전에 다른 판매 도구를 써 보셔서 발주 확인까지는 이미 하신 상태였습니다. 오늘의 할인 상품에 27·28일 주문이 들어왔는데, 동기분들이 함께 올리는 상품이라 마진이 남지 않는 건이 섞여 있었습니다. 일부 상품은 판매중지해 두셨습니다.

오늘 처리한 것

네이버·에누리 최저가 비교 → 마진 안 남는 상품 1만 원 인상(로션 포함) → 27·28일 주문 발송 지연 처리(사유 ‘상품 준비 중’, 기한 3개월 뒤).

이번 주 할 일

네이버 멤버십 가입 후, 슈퍼적립 가전 상품을 마진계산기로 확인해 주말 강의 전까지 최대한 많이 등록합니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1주문 엑셀 다운 → 판매 장부“주문 건이 많아지면 기존 주문 건하고 섞여서 못 찾아요.”▾
  • 발주 확인을 누르기 전에 엑셀부터 다운로드합니다. 비밀번호는 0 또는 1234처럼 간단하게.
  • 열어서 불필요한 열은 지우고, 보기 쉽게 셀 서식을 맞춘 뒤 필터 → 오름차순으로 정렬합니다. 같은 주문 건이 나란히 모입니다.
  • 필요한 정보만 복사해 판매 장부에 붙입니다. 날짜는 주문일이 아니라 발주한 날짜로 적습니다.
  • 판매 장부는 스프레드시트(클라우드)로 만들기를 권장합니다. 노트북·외부에서도 바로 열 수 있어 USB로 들고 다닐 필요가 없습니다.
  • 필요한 정보만 앞에 보이게 하는 정렬 세팅은 2주차에 해 드립니다. 판매 장부 서식은 오늘 먼저 드렸습니다.
2최저가 비교 — 네이버 카탈로그 vs 에누리핵심“여기서 제일 저렴한 구성은 몇 개짜리일까요?”▾

네이버 카탈로그

  • 상품명에서 브랜드명부터 용량(ml) 앞 숫자까지 복사해 검색하면 등록한 카탈로그가 나옵니다.
  • 아래로 내려 수량별 구성 중 가장 싼 것을 찾습니다. 이번 상품은 2개 구성 21,890원 → 개당 약 11,000원.
  • 여기에 사무실 경유 배송비 3,000원을 더하면 판매가로는 마진이 남지 않았습니다.

에누리

  • 가격 비교 사이트입니다. 로딩이 느리니 먼저 검색해 두고, 배송비 포함을 켠 뒤 광고 아래 에누리 카탈로그를 찾습니다. 가장 싼 곳은 파란색으로 표시됩니다.
  • 가격이 네이버보다 비싸면 금액을 눌러 카드할인을 켜 봅니다. 그래도 변동이 없으면 보이는 가격이 최저가입니다.
  • 이번 상품은 기획세트·2개 구성 모두 네이버보다 비싸 → 지금은 살 수 있는 곳이 없는 상품으로 판단했습니다.
3마진 안 남는 상품 — 중지 대신 1만 원 인상주의“저라면 웬만하면 중지는 안 해요.”▾
  • 마진이 안 남는데 그대로 두면 주문이 계속 들어옵니다. 판매중지가 아니라 가격을 1만 원 올려 주문을 막습니다. 변경할 때 뜨는 경고 문구는 무시해도 됩니다.
  • 오늘 해당 상품과 로션(어제 다른 대표님과 봤을 때도 마진 없음)을 1만 원 인상했습니다.
  • 이미 중지해 둔 상품은 그대로 두셔도 되지만, 다음 주부터는 중지하지 말고 1만 원 인상만 하세요. 가격 관리 방법은 따로 알려 드립니다.
  • 역마진이 자주 나오는 이유: 오늘의 할인 상품은 프로그램이 매일 자동으로 찾아 줘서 동기분들이 다 같이 올리기 때문입니다.
4배송 지연 처리 + 취소 요청 대응핵심“고객분이 취소 요청하시면 승인만 해 주시면 돼요.”▾

안내 문구 붙여넣기
  • 오늘 27일·28일 주문 건을 발송 지연 처리했고, 발송 기한이 3개월 뒤 27일까지 늘어난 것을 확인했습니다.
  • 안내 문구 흐름: 인사 → 사과 → 공급처 사정으로 빠른 출고가 어려움 → 1~2개월 정도 걸릴 수 있음 → 원하시면 취소해 드림 → 계속 신경 쓰겠음. 정식 템플릿은 다음 주에 드리고, 오늘은 메모장에 임시로 적어 드렸습니다.
  • 고객이 취소를 요청하면 취소 승인만 누르면 됩니다.
  • 판매 장부에서는 지우지 말고 ‘배송지연’ 탭을 따로 만들어 옮겨 둡니다. 취소·환불이 끝난 주문만 시트에서 삭제합니다.
5슈퍼적립 소싱 — 이번 주는 가전핵심“주력은 화장품이지만 가전을 전략적으로 병행할 거예요.”▾
  • 2주차 소싱법과는 다른 방법으로, 프로그램을 빨리 익히셔서 진도를 당겨 알려 드렸습니다.
  • 네이버 → 쇼핑 → 슈퍼적립 → 카테고리. 의류·잡화·향수는 빼고, 이번 주는 가전으로 합니다. 가전을 왜 병행하는지는 3주차에 설명합니다.
  • 오늘의 할인은 하루 30분~1시간도 겨우 쓰는 분들이 주로 쓰는 방식입니다. 대표님은 주말 강의 전까지 슈퍼적립 상품을 최대한 많이 올리기로 했습니다.

네이버 멤버십

  • 월 4,900원(연간 결제 가능). 가입하면 가격이 더 할인되고 적립 포인트도 가져갈 수 있어 가입을 권장합니다. 가입하면 멤버십 할인가가 보입니다.
  • 적립 금액은 목록(바깥)에 표시된 금액 기준으로 봅니다. 예: 바깥 89,880원 / 판매 페이지 12만 원 → 판매 페이지 금액은 리뷰 적립 포함이라 무시.
6마진계산기로 등록 여부 판단“카탈로그보다 10원 싸게 등록했을 때 마진이 남는가를 보면 돼요.”▾
  • 셀러들의 수다 마진계산기에 멤버십 할인 후 매입가와 적립 포인트를 넣습니다. (예: 청소기, 다른 대표님 계정으로 62만 원까지 할인)
  • 가전은 대부분 모델명이 있어서, 모델명으로 네이버 카탈로그를 역으로 찾습니다.
  • 카탈로그 최저가보다 10원 싸게 등록한다고 놓고 마진을 봅니다. 예시 청소기는 약 62,000원이 남았습니다.
  • 택배비: 보통 5kg까지 5,000원, 10kg 이상 1만 원. 크고 무거운 가전은 1만 원으로 잡아도 마진이 남으면 자동등록 프로그램으로 바로 담습니다.
7주문 들어오면 — 입고 신청 + 배송 요청“입고 신청을 해야 제가 물건이 오는지를 알 수 있어요.”▾

뷰셀 검수·출고
  • 슈퍼적립 상품도 주문이 오면 네이버·에누리를 다시 봅니다. 보통 본사가 먼저 뜨고, 본사가 제일 싸면 본사에서 삽니다.
  • 배송지는 사무실 주소(재고배송요청 화면에 표시) 뒤에 대표님 고유 사서함 번호를 붙입니다.

입고 신청 (재고배송요청 → 재고관리 → 입고신청)

  • 카탈로그명 복사·붙여넣기, 옵션은 있을 때만, 수량, 공급가, 구매 사이트까지 적고 입고 등록. 대표님 스스로 재고를 관리하는 데도 도움이 됩니다.

배송 요청 (배송요청 → 엑셀로 한 번에 등록)

  • 엑셀 템플릿을 받아 고객 주문 정보 중 필요한 칸만 채웁니다. 상품명은 카탈로그명과 똑같이 — 프로그램으로 등록했다면 그대로라 다를 일이 없습니다.
  • 저장 → 파일 선택 → 등록하기. 물건이 입고되는 대로 뷰셀이 검수해 보냅니다.

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 새 주문은 엑셀 먼저 다운 강연주비번 0/1234 · 불필요 열 삭제 · 필터 오름차순
  • 판매 장부 스프레드시트로 운영 강연주발주일 기준 · ‘배송지연’ 탭 따로 · 환불 끝난 건만 삭제
  • 마진 안 남는 상품은 1만 원 인상 강연주판매중지 대신 가격으로 주문 막기
  • 배송 지연 건 취소 요청 오면 승인 강연주27·28일 주문 건 지연 처리 완료
  • 네이버 멤버십 가입 강연주월 4,900원 · 할인가·포인트를 마진계산기에 반영
  • 슈퍼적립 가전 최대한 많이 등록 강연주주말 강의 전까지 · 모델명으로 카탈로그 확인 · 택배비 최대 1만 원
  • 주문 시 입고 신청 + 배송 요청 강연주사무실 주소 + 사서함 번호 · 카탈로그명 동일
  • 배송 지연 템플릿·판매 장부 정렬 세팅 뷰셀다음 주(2주차)
