2026년 11월 6일 · 김창영 대표님, 뷰셀 · 전화 + 원격 (화면 녹화 포함)

김창영 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

혼자 따라 하는 매뉴얼

김창영 대표님 전용 매뉴얼 — 혼자서 올려 보기 →오늘 원격으로 같이 한 순서 그대로 정리했습니다. 오늘의 할인 3개 찜 → 같은 상품 확인 → 마진 계산 → 담기 → 자기 전 대량등록, KC 인증 넣기, 토끼(자동 소싱)로 찾은 상품 올리기까지. 사모님과 같이 보면서 따라 하세요.

한눈에 보기

처음이라 잘못 누를까 봐 아직 하나도 올려 보지 못하신 상태였습니다. 오늘은 원격으로 뷰셀이 먼저 한 번 보여 드리고, 대표님이 직접 따라 해 보는 방식으로 진행했습니다.

지금 상태

스마트스토어는 몇 년 전에 열어 두셨지만 농산물만 올려야 하는 줄 알고 거의 쓰지 않으셨습니다. 소싱·등록은 아직 해 보지 않으셨고, 강의(월요일 특강 포함)는 보셨지만 막상 하려니 순서가 기억나지 않는다고 하셨습니다.

오늘 한 것

오늘의 할인에서 찜 → 같은 상품 확인 → 마진 계산 → 자동등록 프로그램에 담기 → 대량등록까지 직접 2개를 올렸습니다. 셀러들의 수다·거인의 도구 공방 비밀번호를 초기화했고, 자동 소싱 프로그램(토끼)을 설치해 ‘아모레퍼시픽’ 키워드로 돌려 두었습니다.

앞으로

컴퓨터가 아직 낯서시니 서두르지 않습니다. 이번 주와 다음 주(1~2주)는 프로그램 두 개(자동등록·토끼)가 손에 익는 것이 목표입니다. 익숙해지면 카톡을 주시고, 그다음에 손으로 상품 찾는 연습을 같이 합니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1오늘의 할인 — 매일 3개는 꼭핵심“아무리 바빠도 제가 상품 찾아드리는 거니까 얘는 꼭 진행하세요.”▾
  • 셀러들의 수다 → 오늘의 할인에 뷰셀이 프로그램으로 찾아 둔 상품이 뜹니다. 하루 3개까지 찜할 수 있으니, 한 달이면 90개가 올라갑니다.
  • 목록의 ‘+금액’이 예상 마진입니다. 너무 고르지 말고 5만 원 이하로 표시된 것 중 아무거나 골라도 됩니다.
  • 초보 추천(노란 별표) 상품은 하루 2개까지. 3번째는 초보 추천이 없는 상품으로 골라야 합니다.
  • 찜한 상품이 다른 상품으로 판명돼도 그날 찜 개수는 돌아오지 않습니다. 오늘도 1개가 그렇게 빠져서 2개로 마쳤습니다.
2왼쪽은 사는 곳, 오른쪽은 카탈로그“파란 걸로 기억하지 마시고요, 왼쪽 오른쪽으로 기억하세요.”▾
  • 찜하고 상품 보기를 누르면 왼쪽 버튼은 사는 사이트(SSG·옥션 등), 오른쪽은 네이버 카탈로그(우리가 등록할 곳)입니다. 왼쪽부터 봅니다.
  • 사는 가격이 보이는 나이·지역·성별에 따라 달라서, 실제로 그 가격에 살 수 있는지 꼭 직접 확인해야 합니다.
3같은 상품인지 ‘틀린 그림 찾기’주의“이런 게 오류가 조금씩 있어서 꼭 확인하고 올리세요 라고 하는 거예요.”▾
  • 사진만 보지 말고 영어 모델명과 박스 그림까지 비교합니다. 두 창을 왔다 갔다 하면서 보면 됩니다.
  • 오늘 실습한 가전은 한쪽은 ‘+2’, 다른 쪽은 ‘W…’로 모델명과 박스 그림이 달라 다른 상품 → 올리지 않았습니다.
  • 두 번째로 고른 가습기(7L 복합식)는 같은 상품으로 확인돼 담았습니다.
4마진 계산 — 1,000원 이상이면 등록핵심“10원 싸야 우리가 최저가니까 10원을 빼고요.”▾

  • 시범(밥솥): 최저가 358,770원 → 판매가 358,760원. 사는 곳의 빨간 가격을 넣고, 밥솥은 보통 1개씩 사니 수량 1.
  • 그대로면 역마진이지만, 아래로 내리면 나오는 카드 할인(이 상품은 최대 9%)을 넣으니 마진이 생겼습니다.
  • 택배비는 뷰셀 사무실을 거쳐 보내는 기준: 사람 머리만 하고 5kg 정도면 5,000원, 사람 몸통만 하고 10kg 정도면 10,000원. 밥솥은 5,000원 → 약 22,000원 마진.
  • 해당 카드가 없으면 셀러들의 수다 구매대행에 맡기면 대신 사 드립니다.
5담아 두고, 자기 전에 대량등록핵심“자기 전에 얘를 켜 놓고 주무시면 자고 일어나면 등록이 다 되어 있어요.”▾
  • 마진이 확인되면 카탈로그 화면에서 초록색 카메라 모양(자동등록 프로그램) → 이 카탈로그 담기. 이미 아래에 켜져 있으면 다시 누르지 말고 켜진 창을 씁니다.
  • 하루 동안 담아 두었다가, 주무시기 전이나 농장 나가기 전에 대량등록 시작을 누르고 컴퓨터를 켜 둔 채 자리를 비웁니다.
  • 돌아가는 동안에는 그 컴퓨터를 만지면 안 됩니다. 1개에 1~3분. 사모님이 쓰시는 옆 컴퓨터는 상관없습니다.
  • 대표님은 보통 새벽 2~3시에 주무시니, 그 전에 등록을 걸어 두고 아침에 확인한 뒤 끄시면 됩니다.
  • 종일 켜 둔 컴퓨터는 과부하가 걸리니, 다음 작업 전에 한 번 껐다 켜기.
6가전은 KC 인증번호 넣기“모든 가전제품은 저런 인증번호를 꼭 넣어 줘야 되거든요.”▾
  • 등록 중 KC 인증 입력을 요구하면: 카탈로그의 공식 판매처(본사) → 아래로 내려 인증번호 확인 → 없으면 상세 정보 펼쳐보기 → 맨 아래 영어·숫자 코드. 여러 개면 하나만 적으면 됩니다.
  • 그래도 제조사·인증기관을 못 찾으면 다른 네이버 판매자 상세에서 인증번호 확인을 눌러 그대로 복사합니다.
  • 인증 종류도 그 판매자와 똑같이(오늘은 전기용품이 아니라 방송통신기자재), 제조사 복사, 인증기관(오늘은 국립전파연구원) 입력 → 등록.
  • 오늘 이 상품은 등록이 한 번 실패해서 뷰셀이 따로 확인하기로 했습니다.
7자동 소싱 프로그램(토끼)핵심“이것만 계속 가동해도 한 달에 30에서 80만 원은 벌려요.”▾
  • 크롬 위쪽 토끼 아이콘 → 키워드 적고 엔터 → 컴퓨터를 켜 두는 동안 혼자 계속 찾습니다. 다 찾으면 연관 상품으로 이어 가서 웬만하면 멈추지 않습니다. 오늘은 아모레퍼시픽으로 걸어 두었습니다.
  • 마진 1,000원 이상인 것만 찾습니다. 찾은 건 전부 올려도 됩니다(50개면 50개).
  • 컴퓨터를 껐다 켜면 마지막 키워드를 다시 넣어 돌립니다.
  • 멈추고 엑셀 저장 → ‘소싱 결과 최신’ 파일에서 판정 등록 가능 + 신뢰도 높음만 → 카탈로그 주소를 열어 수량 칸 숫자(예: 7개 구성)에 맞는지 보고 담기 → 대량등록.
  • 키워드는 감으로 정하면 잘 안 팔립니다. 화장품을 잘 아는 것과 잘 파는 것은 다르니 2주차 강의(데이터로 판단)를 다시 보세요. 건강식품은 별도 신고가 필요해 지금은 안 합니다.
  • 설치 초반 프로그램 오류가 있어 뷰셀이 따로 잡아 드리기로 했습니다.
8품목 제한 없음 · 수동 등록은 나중에“이렇게 간단한데 수동으로 할 필요가 있을까요?”▾
  • 농산물로 시작한 스토어라도 다른 품목을 올려도 괜찮습니다.
  • 손으로 올리는 방법도 있지만, 프로그램이 이렇게 간단하니 지금은 필요 없습니다. 1~2주 프로그램에 익숙해진 뒤 손으로 상품 찾는 연습을 같이 합니다.
9로그인 · 주문 처리“주문이 들어오면 저희 사무실로 주문을 해 주셔야 제가 받아서 검수하고 보내죠.”▾
  • 거인의 도구 공방 비밀번호를 초기화해 카톡으로 보내 드렸습니다. 셀러들의 수다 아이디는 휴대폰 번호, 비밀번호도 쉽게 바꿔 두었습니다. 휴대폰 메모장에 적어 두세요.
  • 주문이 들어오면 셀러들의 수다에 주문 내역을 기록해 사무실로 주문 → 사무실에서 검수 후 발송합니다(2주차 강의). 관리·사입은 3주차 강의에서 다룹니다.
10앞으로의 계획“숙달이 완벽히 되면 그 다음 단계, 다음 단계 이렇게 나가면 되겠네.”▾
  • 내년부터 약초 농사(하고초·꿀풀 등)는 꼭 필요한 것만 남기고 줄이실 계획입니다. 직접 기른 상품도 스토어에 하나씩 올리실 생각입니다.
  • 사모님이 곧 일을 마치시면 함께하실 예정이라, 오늘 녹화본과 매뉴얼을 보며 대표님이 시범을 보이고 사모님이 따라 하는 방식으로 연습하시기로 했습니다.
  • 강의는 10번 이상 반복해서 보세요. 용어부터 익숙해져야 합니다.

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 오늘의 할인 매일 3개 찜 → 같은 상품 확인 → 마진 확인 → 담기 김창영초보 추천 2개 + 일반 1개 · 1개 기준 1,000원 이상
  • 자기 전(또는 농장 나가기 전) 대량등록 시작 김창영돌아가는 동안 컴퓨터 만지지 않기 · 아침에 확인 후 끄기
  • 토끼 켜 두고, 엑셀에서 ‘등록 가능 + 높음’ 상품 올리기 김창영껐다 켜면 마지막 키워드 다시
  • 1~2주 연습 후 숙달되면 카톡 주기 김창영사모님과 함께 매뉴얼 보며 연습
  • 2주차 강의 다시 보기 (키워드·주문 기록) 김창영강의는 10번 이상
  • KC 인증 등록 실패 건 · 토끼 오류 확인 뷰셀상담 중 따로 확인하기로 한 것
  • 화면 녹화본 정리해 보내 드리기 뷰셀매뉴얼에 화면 캡처 추가 예정
