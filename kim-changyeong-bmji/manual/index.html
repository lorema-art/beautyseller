하루 흐름

처음 며칠은 느려도 괜찮습니다. 잘못 눌러도 고장 나지 않습니다. 모르면 카톡으로 물어보세요.

오늘의 할인에서 찜 (하루 3개)→ 왼쪽 사는 곳 · 오른쪽 카탈로그→ 같은 상품인지 확인→ 마진 계산

같은 상품 + 1,000원 이상 남는다

초록 카메라(자동등록) → 이 카탈로그 담기 자기 전·농장 나가기 전 대량등록 시작 아침에 확인하고 컴퓨터 끄기

다른 상품이거나 안 남는다

올리지 않는다 찜 개수는 돌아오지 않으니 그날은 거기까지
시간대 정리

낮: 오늘의 할인 3개 찜하고 담아 두기 · 토끼 켜 두기 → 새벽 2~3시 주무시기 전: 대량등록 시작 → 아침: 등록됐는지 확인하고 컴퓨터 한 번 끄기.

매일 하는 일 — 오늘의 할인 3개

01셀러들의 수다 → 오늘의 할인에서 찜하기

  1. 셀러들의 수다를 열고 왼쪽 메뉴에서 오늘의 할인을 누릅니다.
  2. 목록 맨 오른쪽 ‘+금액’이 예상 마진입니다. 5만 원 이하로 표시된 것 중 아무거나 하나 누르세요. 너무 고르지 않아도 됩니다.
  3. 창이 뜨면 찜하고 상품 보기를 누릅니다.
찜 규칙 세 가지

① 하루 3개까지. ② 노란 별표 초보 추천은 그중 2개까지, 나머지 1개는 초보 추천이 없는 상품으로. ③ 찜했는데 다른 상품이었어도 찜 개수는 돌아오지 않습니다. 그날은 남은 것만 올리고 끝.

02왼쪽은 사는 곳, 오른쪽은 카탈로그

  1. ‘이 상품 올려보기’ 창의 왼쪽 버튼(옥션·SSG 등)은 우리가 사는 곳입니다. 먼저 누릅니다.
  2. 오른쪽 버튼 네이버 가격비교 보기는 우리가 등록할 네이버 카탈로그입니다.
  3. 버튼 색이 아니라 왼쪽 = 사는 것, 오른쪽 = 파는 것으로 기억하세요.
창이 사라졌다면

셀러들의 수다 창을 끄지 마세요. 다른 창이 위에 덮인 것뿐입니다. 아래 작업표시줄에서 셀러들의 수다를 다시 누르면 됩니다.

03같은 상품인지 ‘틀린 그림 찾기’

프로그램이 찾아 준 상품도 가끔 틀립니다. 그래서 올리기 전에 꼭 확인합니다.

  1. 왼쪽(사는 곳)과 오른쪽(카탈로그) 창을 왔다 갔다 하며 비교합니다. 두 창을 동시에 띄울 필요는 없습니다.
  2. 사진만 보지 말고 영어 모델명을 한 글자씩 비교합니다.
  3. 박스 그림과 거기 적힌 글자도 봅니다. 용량(예: 7L), 구성(몇 개 묶음)도 같은지 봅니다.
  4. 하나라도 다르면 다른 상품 → 올리지 않습니다.
11월 6일 실습 예

한쪽 박스엔 ‘+2’, 다른 쪽엔 ‘W…’라고 적혀 있고 모델명 끝도 달랐습니다 → 다른 상품이라 올리지 않았습니다. 두 번째 가습기(7L 복합식)는 같은 상품이라 올렸습니다.

04마진 계산 — 1,000원 이상이면 등록

  1. 판매가: 오른쪽 카탈로그의 최저가에서 10원 뺀 값. (최저가 358,770원 → 358,760원)
  2. 사는 가격: 왼쪽 사이트의 빨간 가격.
  3. 수량: 손님이 보통 몇 개 사는지 생각해서. 밥솥·가습기는 1개.
  4. 카드 할인: 사는 곳 화면을 아래로 내리면 나오는 카드 할인 중 가장 큰 %를 적습니다. (예: 9)
  5. 택배비: 아래 표대로. 상품은 뷰셀 사무실을 거쳐 손님께 갑니다.
  6. 결과가 1,000원 이상이면 등록합니다.

그 카드가 없으면

셀러들의 수다 왼쪽 메뉴 구매대행에 맡기면 뷰셀이 대신 사 드립니다.

05초록 카메라 → 이 카탈로그 담기

  1. 등록할 상품의 오른쪽(네이버 카탈로그) 화면을 띄워 둡니다.
  2. 크롬 위쪽 초록색 카메라 모양을 누르면 자동등록 프로그램이 뜹니다. 이미 아래에 켜져 있으면 또 누르지 말고 켜져 있는 창을 씁니다.
  3. 이 카탈로그 담기를 꾹 누릅니다. ‘담긴 목록’ 숫자가 하나 늘면 성공입니다.
  4. ‘대량’이 아니라 담기를 누르는 겁니다. 등록은 밤에 한꺼번에 합니다.

06자기 전(또는 농장 나가기 전) 대량등록

  1. 그날 담아 둔 상품이 다 모였으면 자동등록 프로그램에서 대량등록 시작을 누릅니다.
  2. 컴퓨터를 켜 둔 채 주무시거나 외출하세요. 끄지 않습니다.
  3. 돌아가는 동안 이 컴퓨터는 만지지 않습니다. 마우스를 움직이면 멈출 수 있습니다. 옆 컴퓨터(사모님 컴퓨터)는 써도 됩니다.
  4. 1개에 1~3분 걸립니다. 3개면 넉넉히 1시간이면 끝납니다.
  5. 아침에 다 됐는지 보고 컴퓨터를 한 번 끕니다. 종일 켜 둔 컴퓨터는 느려지니, 다시 일할 때는 새로 켜서 시작하세요.

07가전제품은 KC 인증번호 넣기

등록 중에 ‘KC 인증을 입력하라’는 창이 뜨면 이렇게 합니다. 가전제품은 꼭 넣어야 합니다.

  1. 네이버 카탈로그에서 ‘공식’이라고 적힌 판매처(본사)를 누르고 아래로 내려 인증번호를 찾습니다.
  2. 안 보이면 더 내려서 상세 정보 펼쳐보기 → 맨 아래쪽의 영어·숫자 코드가 인증번호입니다. 여러 개면 하나만 적으면 됩니다.
  3. 제조사·인증기관을 못 찾겠으면 다른 네이버 판매자의 같은 상품 페이지에 들어가 인증번호 확인을 누릅니다.
  4. 거기 나온 대로 복사해 넣습니다.
    • 인증번호: 그대로 복사
    • 인증 종류: 그 판매자가 적은 것과 똑같이 (11월 6일 실습: 전기용품 ✕ → 방송통신기자재)
    • 제조사: 복사
    • 인증기관: 적힌 대로 (실습: 국립전파연구원)
  5. 등록을 누르면 자동으로 이어서 등록됩니다.
실패라고 뜨면

여러 번 다시 누르지 말고 화면을 휴대폰으로 찍어 카톡으로 보내 주세요. 11월 6일 실습 상품도 한 번 실패해서 뷰셀이 확인 중입니다.

토끼 — 자동 소싱 프로그램

08토끼 켜 두기

토끼는 컴퓨터가 켜져 있는 동안 혼자 돌아다니며 마진 1,000원 이상인 상품을 찾아 줍니다. 농사일 나가실 때 켜 두면 됩니다.

  1. 크롬 오른쪽 위 토끼 그림(셀수다 자동 소싱)을 누릅니다. 로그인하라고 하면 아이디는 휴대폰 번호, 비밀번호는 셀러들의 수다 비밀번호.
  2. 키워드 칸에 키워드를 적고 Enter. 지금은 아모레퍼시픽으로 걸어 두었습니다.
  3. 한 키워드를 다 찾으면 연관 상품으로 계속 이어 가서, 웬만해서는 멈추지 않습니다. 그냥 두세요.
  4. 화면의 ‘36개 중 30개’ 같은 숫자는 검토한 개수입니다. 찾은 상품은 아래 목록에 쌓입니다.
  5. 컴퓨터를 껐다 켰다면 토끼를 다시 열고 마지막 키워드를 다시 적어 돌립니다.
키워드는 감으로 정하지 않기

화장품을 잘 아는 것과 잘 파는 것은 다릅니다. 당분간은 뷰셀이 걸어 둔 키워드를 그대로 쓰시고, 키워드 고르는 법은 2주차 강의(데이터로 판단)를 다시 보세요. 건강식품은 별도 신고가 필요해 지금은 하지 않습니다.

09토끼가 찾은 상품 올리기

  1. 토끼에서 중지 → 엑셀 저장을 누릅니다.
  2. 다운로드 폴더에서 ‘소싱 결과 최신’ 엑셀 파일을 엽니다. 칸이 많지만 다른 건 보지 않아도 됩니다.
  3. 판정 칸이 등록 가능이고, 신뢰도 칸이 높음인 줄만 봅니다(색으로 표시돼 있습니다).
  4. 그 줄의 카탈로그 주소를 복사 → 크롬 주소창에 붙여넣고 엔터.
  5. 엑셀 수량 칸 숫자를 봅니다. 7이면 7개짜리 구성을 올리라는 뜻입니다. 카탈로그가 그 구성인지 확인합니다.
  6. 초록 카메라 → 이 카탈로그 담기. 오늘의 할인에서 담은 것과 같은 목록에 같이 쌓입니다.
  7. 밤에 대량등록 시작 (6번과 같음).
몇 개까지 올려도 되나요?

토끼가 찾은 것은 전부 올려도 됩니다. 50개를 찾았으면 50개 다. 오늘의 할인의 ‘하루 3개’ 제한은 토끼에는 해당되지 않습니다.

그 밖에

10주문이 들어오면

  1. 주문 내역을 셀러들의 수다에 기록해 뷰셀 사무실로 주문합니다(2주차 강의에서 보여 드린 방법).
  2. 사무실에서 받아 검수 후 손님께 발송합니다.
  3. 미리 사 두는 것(사입)과 관리 방법은 3주차 강의에서 다룹니다. 그 전까지는 주문 받고 삽니다.
