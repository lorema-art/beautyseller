김동욱 대표님 1:1 컨설팅 정리

2026년 10월 27일 · 김동욱 대표님, 뷰셀 · 사무실 대면
47분상담 시간
하루 10개+슈퍼적립 가전 등록 목표
11월 1일전화 코칭 (예정대로)
김동욱 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

오늘의 할인으로 올린 상품에 주문이 들어왔지만 대부분 역마진이었습니다. 발주 판단과 역마진 처리를 함께 하고, 이해가 빠르셔서 원래 3주차에 알려드리는 슈퍼적립 소싱을 앞당겨 이번 주부터 시작하기로 했습니다.

지금 상태

본업이 있어 퇴근 후 2~3시간 작업. 오늘의 할인 화장품은 대부분 올렸고 식품 1개 등록. 동기분들이 같은 상품을 함께 올려 가격이 빠르게 내려가 주문 2건을 빼고는 발주 불가 상태였습니다.

오늘 처리한 것

엑셀 다운 → 발주 확인 → 네이버·에누리 비교로 발주 불가 판단 → 판매가 +10,000원 인상 + 발송지연(3개월) 처리. 슈퍼적립 가전 2개를 함께 찾아 마진 계산·KC 인증 입력까지 실습했습니다.

이번 주

오늘의 할인은 멈추고 네이버 슈퍼적립 → 디지털/가전에서 고가 상품을 하루 10개 이상 등록합니다. 스토어를 먼저 활성화해 두면 2주차 소싱법으로 올리는 화장품이 잘 팔립니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1주문 확인 — 엑셀 다운 후 발주 확인주의“발주 확인을 꼭 눌러주셔야 돼요.”▾
  • 주문 건을 전체 선택해 엑셀을 먼저 다운로드합니다. 비밀번호는 0 또는 1234처럼 간단하게.
  • 그다음 발주 확인을 꼭 누릅니다. 안 누르면 공급처에 주문을 넣은 뒤 고객이 취소했을 때 자동 환불됩니다. 발주 확인을 해야 우리 승인을 거쳐서 환불됩니다.

주문 정리 시트

  • 집 데스크톱과 밖 노트북을 함께 쓰시니 구글 스프레드시트로 관리하는 게 편합니다.
  • 남길 것: 구매자, 상품명, 옵션 정보, 수량, 매출(가격·주소 확인용). 택배사 같은 나머지 열은 지웁니다.
  • 셀 크기를 맞추고 오름차순 정렬하면 같은 상품이 한데 묶입니다. 이 상태로 발주 파일에 정리합니다. 발주 파일 서식은 뷰셀이 보내드립니다.
  • 세팅은 2주차에 해서 이 과정을 줄입니다.
2발주 가능 판단 — 네이버 먼저, 에누리 다음핵심“에누리는 로딩이 오래 걸리니 미리 검색해 두세요.”▾

에누리 최저가 비교
  • 네이버: 카탈로그 아래 수량별 가격에서 가장 싼 구성을 찾아 개당 가격을 냅니다.
  • 에누리: 배송비 포함을 켜고, 광고 구좌를 지나 카탈로그로 들어갑니다. 파란색이 모든 구성 중 최저, 카드 할인이 있으면 버튼이 뜨고 없으면 보이는 가격이 최저가입니다.
  • 카탈로그를 쉽게 찾는 가격비교 버튼은 주문 처리할 때만 씁니다. 2주차에는 절대 누르지 않습니다.

오늘 본 사례

  • 상품 A: 3개 구성이 가장 싸서 개당 약 12,000원. 주문은 2개 → ×2에 분할 재발송 배송비 3,000원을 더하면 판매가보다 비쌉니다. 에누리도 네이버 37,000원보다 비싼 40,000원 → 발주 불가.
  • 상품 B: 주문 금액 13,990원. 에누리 3개 구성 ÷3 ≈ 7,000원, 2개면 약 14,000원으로 판매가보다 비쌈 → 발주 불가.
  • B는 대표님이 이미 최저가라 마진이 날 수 없었습니다. 1개짜리로 등록해야 할 걸 2개짜리 카탈로그로 담은 것으로 보입니다. 수량을 누르고 담아야 그 수량의 카탈로그 코드로 등록됩니다.
3역마진 처리 — 가격 인상 + 발송지연핵심“강제로 취소를 먼저 해버리면 네이버에서 뭐라 할 때가 있어요.”▾

1. 판매가 10,000원 인상

  • 상품 조회/수정에서 상품을 찾아 10,000원 올립니다. 그래야 새 주문이 더 들어오지 않습니다.

2. 발송지연 처리

  • 주문 선택 → 발송지연처리 → 사유 상품 준비 중 → 발송 기한 주문일로부터 3개월 뒤(최대) → 보내드린 안내 문구 붙여넣기 → 확인.
  • 안내 문구 구성: 인사와 사과 → 공급사 사정으로 출고 지연 → 1~2개월 정도 걸릴 것 같음 → 취소 원하시면 요청 주시면 환불.
  • 고객에게 안내가 자동으로 가고, 주문 상세 맨 아래에서 늘어난 기한을 확인할 수 있습니다.
  • 먼저 강제 취소하면 네이버 패널티 위험이 있고 고객도 기분이 상합니다. 문구로 방어하는 겁니다.

3. 시트에서 따로 관리

  • 시트에 ‘배송지연’ 탭을 따로 만들어 모아 둡니다.
  • 고객이 취소 요청하면 스토어에 뜨는 요청을 취소 승인 → 환불 완료 후 시트에서 행 삭제.
  • 오늘 2건을 뺀 나머지 주문은 모두 발송지연 처리를 마쳤습니다.
4이번 주 소싱 — 슈퍼적립 디지털/가전핵심“매출이 늘어나는 게 첫 번째 과제거든요.”▾
  • 오늘의 할인은 멈춥니다. 동기분들이 같이 올려 마진이 빨리 깎이고 발주 불가가 많이 나옵니다.
  • 네이버 → 쇼핑 → 슈퍼적립 → 카테고리 디지털/가전. 위에서부터 내려가며 봅니다. 순서가 매일 바뀌고 상품이 끝없이 많습니다.
  • 네이버는 매출이 늘면 스토어를 더 노출해 줍니다. 원래 3주차 최대 숙제가 하루 15개인데, 대표님은 지금부터 고가 상품을 하루 10개 이상 올립니다.
  • 스토어가 먼저 활성화되면 2주차 소싱법으로 올리는 화장품이 잘 팔립니다. 전략적으로 쓰는 방법입니다.
  • 2시간이면 꽤 많이 찾으실 겁니다. 오늘 실습에서도 바로 2개를 찾았습니다.

뺄 상품

  • 설치가 필요한 대형 가전(세탁기, 설치형 TV, 인덕션 등)은 뺍니다. 밥솥 같은 소형 가전은 OK.
  • 크고 무거운 건 배송비를 감안해야 합니다. 10kg 정도까지, 애매하면 넘어갑니다.
5마진 계산 — 포인트는 현금처럼“슈퍼적립만큼은 포인트 포함해서 보시면 돼요.”▾

→
네이버 가격비교 검색
→

→

최저가 -10원 등록
  • 카탈로그를 먼저 찾습니다. 카탈로그가 너무 싸면 계산할 필요도 없습니다. 가전은 대부분 모델명으로 바로 찾습니다.
  • 마진 계산기: 매입가 = 멤버십 할인가, 수량 1, 포인트 할인 = 상품 페이지 안쪽에 보이는 포인트(바깥 목록의 포인트는 리뷰 적립금이 섞여 있어 쓰지 않음).
  • 판매가 = 카탈로그 최저가에서 10원 낮게.
  • 배송비 기준: 기본 3,000원, 5kg까지 5,000원, 10kg까지 10,000원.

오늘 찾은 2개

  • 청소기: 최저가 -10원으로 잡으면 약 32,000원 남음 → 배송비 10,000원을 잡아도 남아 등록.
  • 두 번째 상품: 포인트 적용 실구매가 27,200원, 약 5kg으로 배송비 5,000원 → 그래도 남아 등록.

네이버페이 앱

  • 휴대폰에 네이버페이 앱을 깔면 앱 안에 삼성페이 기능이 있습니다. 쌓인 포인트를 카드처럼 쓸 수 있어 포인트를 현금처럼 보시면 됩니다.
6위탁보다 사무실 경유주의“위탁은 필살기라고 보시면 돼요.”▾
  • 법적으론 문제없지만, 네이버·쿠팡은 고객에게 바로 보내는 위탁이면 그 업체와의 계약서를 요구합니다. 오늘 본 청소기 브랜드와 우리는 계약이 없습니다.
  • 지금은 매출이 적어 괜찮지만 늘어나면 동기·경쟁사·본사가 신고할 수 있습니다(4주차에 자세히).
  • 번거롭더라도 사무실로 받아서 다시 보내는 게 안전합니다. 대부분 M배송(내일 배송)이라 1~2일 안에 받고, 3일 안에 거의 무조건 출고합니다.
  • 가전은 주문이 들어오면 하나 사서 하나 보내면 됩니다(소량 사입 개념이 필요 없음).
7KC 인증 입력“가전제품은 KC 인증이 필수 대상이에요.”▾
  • 본사(공식몰) 상품 페이지 아래쪽에서 KC 인증번호를 찾아 복사합니다.
  • 인증 종류는 본사와 똑같이(예: 전기용품 안전인증) → 인증번호 입력 → 인증번호 확인 버튼.
  • 확인 화면에 나온 인증기관과 제조사를 복사해 넣고 등록합니다.
8작업 환경 — IP와 탭 정리“밖에서는 담아 놓고 댁에 가서 등록하세요.”▾
  • 집 IP(와이파이·랜선)를 등록하고 강의장 IP는 뺐습니다. 다르면 바꾸시면 됩니다.
  • 밖에서 작업할 땐 IP 등록이 번거로우니 카탈로그만 담아 두고(껐다 켜도 유지) 집에서 등록합니다.
  • 상품은 우클릭 → 새 탭에서 링크 열기로 열어야 목록을 다시 찾지 않습니다.
  • 끝난 창은 바로 닫습니다: Ctrl+W 닫기, Ctrl+Shift+T 닫은 탭 되살리기. 창이 쌓이면 헷갈립니다.
9셀수다 — 입고 등록과 배송 요청“본사에 주문하고, 셀수다 재고관리에 적어 주셔야 돼요.”▾

입고 등록 (재고관리)

  • ① 본사에 주문 → ② 셀수다 재고관리에 입력: 카탈로그명(상품명 그대로), 옵션(없으면 비움), 수량.
  • 매입가·구매처는 선택이지만, 안 적으면 재고를 따로 관리하셔야 합니다. 적어 두시길 권합니다.
  • 입고 등록을 누르면 뷰셀 쪽에서 실시간으로 들어올 물건을 확인합니다.
  • 주문 배송지는 사무실 주소 뒤에 대표님 사서함 번호를 붙입니다. 지금 번호는 임시라 물량이 늘면 공식 번호(A·B 구역)로 한 번 바뀔 수 있습니다.

배송 요청

  • 주문이 갑자기 몰릴 수 있으니 엑셀로 한 번에 등록을 씁니다. 템플릿에 수취인, 상품명, 옵션(비워도 됨), 수량, 연락처, 주소, 배송 메시지를 넣고 등록하면 끝.
  • 택배비는 미리 충전해 두면 차감되는 방식입니다(해당 주차에 안내).
10동기 간 가격 경쟁과 카탈로그 매칭“처음 한 10개 정도만 겹치고, 거기서부터는 안 겹쳐요.”▾
  • 프로그램은 카탈로그 최저가에서 10원을 내리기 때문에 동기분이 뒤에 올리면 또 10원 내려갑니다. 차이는 매칭이 됐느냐입니다.
  • 매칭은 통상 1주일, 뷰셀 프로그램을 쓰면 1~3일. 네이버 AI 검수라 길면 30일 넘게 안 될 때도 있습니다(반 랜덤).
  • 2주차에 가격 자동 관리 프로그램을 드립니다. 2주차 소싱법을 쓰면 처음 10개 정도만 겹치고, 이후엔 각자 보는 게 달라 상품이 안 겹칩니다.
  • 1주차를 오늘의 할인으로 시작한 건 천천히 따라오셔야 하는 분들 때문이고, 이해가 빠른 분은 먼저 다음 단계로 갑니다.
11오프라인 창고 — 시장조사용으로만주의“절대로 오프라인 창고에서 미리 사지 마세요.”▾
  • 현장에서 휴대폰으로 카탈로그와 가격을 바로 검색 → 온라인보다 확실히 싸면 집에 와서 등록하고 반응을 봅니다.
  • 창고 상품은 이미 온라인 경쟁에서 밀려 싸게 나온 것들이라 선사입은 금지, 등록 후 팔리면 그때 삽니다.
  • 1기 수강생 중 창고를 돌며 약 500개를 올려 하루 50건씩 주문받은 사례가 있지만, 거의 매일 매장을 돌아야 하고 운전이 많습니다.
  • 뷰셀은 온라인 99%, 오프라인 1%(무엇이 잘 팔리는지 보는 시장조사). 가신다면 오프뷰티는 갈매점보다 큰 성수점을 추천합니다.
12의심상품 검수 메일 — 소명은 뷰셀이“얘는 소명만 하면 무사히 넘어가요.”▾
  • 새 스토어가 상품을 올리면 네이버 AI가 ‘진짜 파는 상품·판매자인지’ 확인하는 통상 절차입니다. 몇 번 검수 후 문제 없으면 넘어갑니다.
  • 소명은 뷰셀이 대신 해 드립니다. 대표님은 사업자등록증 일부, 이메일 주소, 현재 스토어 등록 판매가, 판매 여부(미판매)를 캡처나 파일로 보내 주시면 됩니다.
