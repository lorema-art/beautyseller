김은영 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

“강의를 서너 번 봐도 올리는 것 자체를 모르겠다, 주문이 들어오면 그다음을 몰라서 시작을 못 하겠다”는 고민으로 시작해, 프로그램을 하나씩 같이 점검하고 등록 → 주문 → 발주의 큰 흐름과 베스트·꼬리물기 소싱을 처음부터 다시 짚었습니다.

지금 상태

프로그램은 대부분 스스로 깔아 두셨지만, 컴퓨터를 평소 잘 안 쓰셔서 각 프로그램이 무슨 역할인지, 주문이 들어오면 어떻게 하는지를 몰라 상품을 하나도 올리지 못한 상태였습니다. 요즘은 하루 1~2시간 정도 작업 가능하십니다.

오늘 한 것

IP 추가, 사서함(재고관리) 업데이트, 드래그 확장 프로그램 설치, 가격관리 프로그램 가입·로그인까지 세팅했습니다. 오늘의 할인으로 첫 상품을 실제로 등록했고, 주문 처리 화면과 마진 계산기, 베스트·꼬리물기 소싱을 시연했습니다.

앞으로

처음에는 원리보다 정해진 클릭 순서를 외워서 반복하는 게 가장 빠릅니다. 뿌요 교육실장이 오늘 내용을 클릭 순서대로 정리해 카톡으로 보내 드리고, 숙제는 베스트 1개 → 꼬리물기 1개 이상입니다.

각 프로그램이 하는 일

  • 자동등록 프로그램: 카탈로그 링크를 넣으면 AI가 사진·상세 정보를 모아 대표님 스마트스토어에 올려 줍니다. (셀러들의 수다와는 다른 프로그램)
  • 셀러들의 수다(셀수다): 오늘의 할인, 마진 계산기, 재고관리(사서함) 등이 들어 있습니다.
  • 드래그 확장 프로그램: 네이버가 카탈로그 상품명 복사를 막아 둔 것을 풀어 줍니다. 뷰셀 3기 오픈채팅방 파일로 오늘 설치했습니다.
  • 가격관리 프로그램: 올려 둔 상품 가격을 자동으로 맞춰 줍니다. 오늘 회원가입했습니다(아래 9번).

IP 확인

  • 자동등록은 등록된 IP(최대 3개)에서만 작동합니다. 오늘 IP를 하나 추가해 두었습니다.
  • 집에 가셔서 네이버에 ‘IP’를 검색하면 숫자가 나옵니다. 프로그램에 등록된 것과 같은지만 확인하세요.

재고관리(사서함)

  • 예전 버전이라 사서함 번호가 안 보였습니다. 최신 버전으로 업데이트 완료, 번호가 정상으로 뜹니다.

등록 시작
  • 상품 옆 돈 아이콘을 누르면 마진 계산이 나옵니다. 예: 수분 앰플 50ml는 마진 700원 → 1,000원 미만이라 패스.
  • 자동상품등록은 1개씩, 대량등록은 담아 둔 여러 링크를 한 번에 올립니다.
  • 대량등록은 화면이 저절로 움직이므로 식사·취침 등 컴퓨터를 안 쓸 때 돌리세요.
  • 잘못 담았으면 비우기로 지웁니다.
  • AI가 공식 홈페이지 등에서 상세 이미지와 전성분을 가져와 올립니다. 상담 중 1개가 실제로 등록 완료됐습니다.
  • 스토어에 올린 상품은 카탈로그에 묶여 노출되기까지 1~2일 걸립니다. 빠르면 다음 날 주문이 들어올 수 있습니다.
  • 스마트스토어 이름은 크게 상관없습니다. 손님은 카탈로그에서 가격을 보고 들어옵니다.

구매해서 손님께 발송

  • 발주확인을 누르면 ‘발주 후’로 넘어가고, 이후에는 대표님이 승인해야만 취소됩니다. 주문이 오면 먼저 발주확인부터 누르세요.

물건은 미리 사지 않습니다

  • 선사입: 주문 전에 먼저 사 두는 것. 반사입: 주문이 들어온 뒤에 사는 것. 지금 하는 방식은 반사입입니다.
  • 미리 사 두면 재고 부담이 생기고, 가격이 계속 바뀌어 손해가 날 수 있습니다.
  • 손님이 늦게 받거나 못 보내는 상황이 생길 수도 있습니다. 손님은 싸서 사고 우리는 남겨야 하니, 안 맞으면 어쩔 수 없다고 넘기는 마음이 필요합니다.
4마진 계산기 쓰는 법“구매가는 대표님이 사는 가격이에요.”▾
  • 판매가: 카탈로그 최저가보다 10원 싸게 (예: 20,090원이면 20,080원).
  • 구매가: 대표님이 소싱처에서 사 오는 가격. 묶음(예: 2개)으로 사면 수량도 함께 넣습니다.
  • 택배비: 뷰셀 사무실을 거쳐 보내면 3,000원, 소싱처에서 손님께 바로 보내면 입력하지 않습니다.
  • 계산 결과에 초록불이 들어오고 1,000원 이상이면 진행합니다.
  • 여기서 1,000원은 수수료·택배비를 다 뺀 순이익입니다. 판매가와 구매가 차이가 꽤 나 보여도 다 빼면 생각보다 적게 남습니다.
  • 수수료는 네이버 약 6.7%(매출이 늘면 5%까지 내려감), 쿠팡은 약 11%로 네이버가 싼 편입니다.
5베스트 소싱 순서“순서대로 하셔서 꼬리물기 시트에다 하나씩 적어주시면 돼요.”▾

들어가는 곳

  • 스토어 화면에서 보지 말고 가격관리 → 가격비교로 들어갑니다. 다른 곳에서 보면 값이 달라집니다.
  • 화장품 → 2차 카테고리(예: 스킨케어) 안에서만 움직이고, 위에서부터 순서대로 내려옵니다.
  • 조건: 해외직구 제외, 80개씩 보기, 1페이지만. 2~3페이지는 거의 안 팔리는 상품이라 시간만 듭니다.
  • 순서대로 하는 이유는 어디까지 봤는지 잊지 않고, 봤던 걸 또 보지 않기 위해서입니다. 진행한 곳은 꼬리물기 시트에 적어 둡니다.

왜 꼬리를 무나요?

  • 같은 키워드를 쓰는 다른 브랜드도 할인 중일 확률이 높고, 같은 제조사·브랜드는 이번 달 할인 상품이 몰려 있기 때문입니다.
  • 어떤 게 팔릴지 모르니 1,000원 남는 건 여러 개 올려 둬야 그중에서 팔립니다.
  • 꼬리를 계속 물다 보면 다른 대표님들과 키워드가 갈라져 나만의 상품이 생기고, 잘 팔리면 효자 상품이 됩니다. 꼬리물기가 쌓이면 베스트는 덜 해도 됩니다.
  • 참고: 꼬리물기는 보통 1시간에 3~7개, 3개월 차 대표님들은 한 마켓에 약 2,000개 정도 올려 두셨습니다.

  • 집에서 IP 확인 김은영네이버에 ‘IP’ 검색 → 자동등록 프로그램에 등록된 IP와 같은지
  • 숙제: 베스트 1개 찾고 꼬리물기 1개 이상 김은영맞든 틀리든 직접 해 보기 · 마진 1,000원↑ + 공식 판매처 · 하루 1~2시간
  • 주문 들어오면 발주확인부터 김은영신규주문 → 선택 → 발주확인 → 최저가 찾기 → 마진 계산 → 구매·발송 (3일 이내)
  • 대량등록은 컴퓨터 안 쓸 때 김은영실패하면 IP·전성분 확인, 전성분은 직접 입력 후 재등록
  • 오늘 내용 클릭 순서 정리 + 꼬리물기 시트 카톡 전달 뿌요 교육실장해외직구 제외·80개·1페이지 같은 디테일 포함
  • 가격관리 프로그램 재확인 뿌요 교육실장‘1 사이클 시작’ 안 뜸 · 카탈로그 매칭 후 점검, 필요하면 원격
  • 강의 편집본 요청 전달 뿌요 교육실장대표님 피드백: 영상이 길어 집중이 어려움
숙제 해 보시고 막히면 바로 컨설팅 신청혼자 붙잡고 있지 말고, 원격으로 같이 1분 소싱을 연습합니다.
