김혜선 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

“왜 저는 잘 안 나올까요?”라는 질문에서 출발했습니다. 꼬리물기 시트와 소싱 화면을 함께 보니, 확인 자체는 잘하고 계셨지만 키워드를 덜 적고, 필요 없는 설정에 시간을 쓰고, 지칭 단어만 돌고 있었습니다.

지금 상태

카탈로그·에누리·카드 할인 확인 순서는 제대로 하고 계십니다. 다만 소싱 결과가 기준(1시간 평균 약 3개)보다 적게 나오고 있습니다.

바꿀 것

상품명에 있는 단어는 모두 키워드로 적고, 꼬리물기에서는 ‘해외직구 제외·80개씩 보기’를 하지 않습니다. 지칭 단어에 더해 제조사·브랜드 키워드까지 돌립니다.

앞으로

부업으로 하루 2~4시간을 쓰시니, 직접 찾은 상품을 하루 5개씩 등록하고 다음 주 컨설팅에서 점검합니다. AHC 선크림 반품은 월요일 오전에 처리되도록 물류에 전달합니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1꼬리물기 시트: 빠진 키워드 채우기“있는 거를 모조리 다 적어 주셔야 되거든요.”▾
  • 네베소 크림 시트를 함께 보니 ‘크림’까지는 잘 적으셨지만 ‘더 크림’, ‘0.1 크림’ 같은 단어가 빠져 있었습니다. 상품명에 들어 있는 단어는 빠짐없이 키워드로 적습니다.
  • 병풀크림에서 찾은 상품도 같은 방식으로 티트리 크림, 수딩 크림 등을 추가해 두었습니다. 핸드크림처럼 놓친 키워드도 함께 적습니다.
  • 지칭 단어만 보고 계셨는데, 시트는 가로로(지칭 단어 → 카테고리 → 제조사 → 브랜드) 진행합니다.

시트 표시 규칙

  • 빨간색: 다 본 키워드
  • 파란색: 최근에 이미 본 중복 키워드 → 다시 보지 않음
  • 삭선: 검색했는데 한 브랜드 상품만 나오는 키워드 → 그 브랜드가 할인을 안 한다는 뜻이라 볼 필요 없음
2꼬리물기에서는 필터를 걸지 않기시간 절약“지칭 단어랑 네 가지 방향 키워드에서는 따로 해 주시는 건 없어요.”▾
  • ‘해외직구 제외’와 ‘80개씩 보기’는 베스트 소싱에서만 씁니다. 꼬리물기 키워드로 검색할 때는 바로 내려가 카탈로그를 클릭하면 됩니다.
  • 지금까지 꼬리물기에서도 80개씩 보기를 하셔서 시간이 더 걸렸습니다. 해당 부분 강의를 다시 복습해 주세요.
3‘티트리 크림’으로 함께 소싱해 보기실습“카드 할인이 안 되면 더 이상 볼 게 없기 때문에 다음으로.”▾
네이버 카탈로그 클릭
→
수량별 개당 단가 계산
→
에누리 ‘배송비 포함’ 체크
→
카탈로그 최저가(파란색) 클릭
→
카드 할인 확인 · 없으면 패스
  • 묶음 상품은 계산기로 나눠 개당 단가를 봅니다. 예) 3개 59,890원 → 개당 약 19,000원, 배송비 3,000원만 더해도 21,000원이라 이 가격으로는 살 수 없음.
  • 에누리에 카탈로그가 없으면 상품명을 뒤에서부터 두 글자쯤 지우고 다시 검색해 봅니다. 그래도 없으면 패스합니다.
  • 이미 본 상품이 다시 나오면 패스해도 됩니다. 기억이 가물가물하면 한 번 더 보는 것도 방법입니다.
  • 계산기는 작업 표시줄에 고정해 두었습니다.
42개 묶음을 사서 1개씩 팔기“한 상자에 하나만 들어 있어야 되거든요.”▾
  • 잘 팔리는 2개 묶음 카탈로그를 사서 1개짜리로 판매할 수 있습니다. 예) 24,000원 ÷ 2 = 12,000원 + 배송비 3,000원 = 15,000원 → 마진 가능성 있음.
  • 먼저 공식 판매처인지 확인합니다. 무신사처럼 1개짜리로 올라와 있는 경우도 있으니 들어가서 수량까지 확인합니다.
  • 한 상자에 2개가 같이 포장된 상품은 나눠 팔 수 없습니다. 리뷰 사진으로 상자 개수를 확인하고, 확실하지 않으면 받아 봐야 알 수 있습니다.
  • 남은 1개는 물류센터에 보관했다가 주문이 오면 따로 박스 포장해 발송할 수 있습니다. 박스는 물류센터에 구비되어 있습니다.
  • 상담 중 본 롯데홈쇼핑 상품(본사 판매)은 셀수다 마진 계산기로 돌려 보니 마이너스여서 패스했습니다.
5마진 기준과 위탁 판매“저는 1원 이상 플러스면 보내거든요.”▾
  • 첫 만남 20% 쿠폰을 넣은 상품이 몇백 원만 남는 경우를 물으셨습니다. 마이너스면 보내지 않고, 1원이라도 플러스면 보냅니다.
  • 화장품은 사입보다 위탁이 더 많이 나옵니다. 고객에게 바로 보내니 재고 부담이 거의 없습니다.
  • 다이소 상품은 너무 저렴해 소싱하지 않습니다.
6왜 잘 안 나올까: 제조사·브랜드 키워드핵심“보통 1시간에 평균적으로 3개 정도 나와야 되긴 하거든요.”▾

지금까지 지칭 단어만 돌려서 결과가 적었을 가능성이 큽니다. 제조사·브랜드에서도 상품이 많이 나옵니다. ‘코스맥스’로 함께 해 봤습니다.

  • 카테고리 안 상품이 실제 그 제조사 제품인지 제품 정보에서 확인합니다. 예) ‘코스맥스펫’은 다른 회사라 패스.
  • 한 카테고리를 끝까지 보면 뒤로 가기로 돌아가 다음 1,000개 이상 카테고리를 차례로 봅니다.
  • 매일 가장 최근에 찾은 키워드부터 꼬리물기를 이어 갑니다.
7AHC 선크림 반품 건뿌요 처리“월요일에 반품되실 수 있도록 물류 담당자분께 전달해 놓을게요.”▾
  • 반품을 접수해 두셨는데, 물류센터는 토요일 휴무라 월요일에 순차 처리됩니다.
  • CJ대한통운 기사님 수거 시간에 맞춰 준비될 수 있도록 뿌요 교육실장이 대표님 성함과 상품명을 물류 담당자에게 전달합니다.
  • 반품 수거는 보통 11시~2시 사이에 오며, 연휴라 늦을 수도 있습니다. 기사님이 일찍 와서 못 가져가면 물류에서 바로 포장해 보내 드립니다.
8숙제와 다음 일정“하루에 다섯 개씩 찾아서 상품 등록하실 수 있겠죠.”▾

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 상품명 속 단어를 빠짐없이 꼬리물기 시트에 적기 김혜선빨간색=완료 · 파란색=최근 중복 · 삭선=한 브랜드만 나오는 키워드
  • 꼬리물기에서는 해외직구 제외·80개씩 보기 하지 않기 김혜선베스트 소싱에서만 사용
  • 제조사·브랜드 키워드까지 가로로 꼬리물기 김혜선카탈로그 끝까지 → 1,000개 이상 카테고리 → 제품 정보로 제조사 확인
  • 2개 묶음 1개 판매는 공식 판매처·상자 개수 확인 후 진행 김혜선리뷰 사진으로 한 상자에 1개인지 확인 · 마진 1원 이상이면 발송
  • 직접 찾은 상품 하루 5개 등록 김혜선다음 주 컨설팅 전까지 · 1시간 평균 3개가 기준
  • AHC 선크림 반품 건 물류 담당자에게 전달 뿌요 교육실장월요일(10/12) 오전 CJ대한통운 수거 전 준비
  • 월요일 반품 수거 여부 확인 김혜선수거가 안 되면 물류에서 바로 포장 발송
