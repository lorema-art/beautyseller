하루 10개숙제: 소싱·등록
김재명 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

하루 10건 넘게 들어오던 주문이 이틀 전부터 끊긴 상황에서 상담을 시작했습니다. 원인 점검, 정산 지연 해결, 꺼져 있던 가격 관리 프로그램 다시 켜기, 그리고 꼬리물기 소싱을 빠르게 하는 법까지 함께 봤습니다.

주문이 줄어든 이유

잘 팔리던 상품에 계정당 구매 수량 제한이 걸려 있었고, 가격 관리 프로그램이 돌아가지 않아 가격 경쟁이 전혀 안 되고 있었습니다. 프로그램은 상담 중에 내려받았습니다.

가전 소싱

방법은 화장품과 같지만 직접 전달이 많아 정산까지 돈이 오래 묶입니다.

화장품 소싱 (추천)

지금은 화장품으로 위탁과 사입을 섞어서 가는 쪽이 낫습니다.

소싱 방식

오프라인 매장을 도는 것보다 컴퓨터 앞에서 꼬리물기가 시간 대비 효율이 좋습니다. 네이버·에누리에서 볼 곳만 보고 바로 넘기는 연습이 핵심입니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1주문이 끊긴 이유: 구매 수량 제한“가족이나 지인분들한테 좀 대리 구매해달라고 해서 보내드려도 되기는 해요.”▾

상황

  • 하루 10건 이상 들어오던 주문이 이틀 전부터 끊겼습니다.
  • 잘 팔리던 상품에 계정당 구매 수량 제한이 걸려 있었습니다(10개 이상 불가, 어떤 상품은 3개 이상 불가). 리셀러를 막기 위한 장치로 보입니다.
  • 한 상품에 16건이 동시에 들어왔는데 살 수가 없어서, 마진은 남는 상품이지만 역마진처럼 발송지연 처리를 하셨습니다. 이후 해당 상품은 판매중지를 걸어 두셨습니다.

앞으로 이런 상품이 생기면

  • 가족·지인 아이디로 대리 구매해서 보내도 됩니다.
  • 또는 지금처럼 역마진 처리하고 판매가 1만 원 인상, 혹은 판매중지.
  • 뿌요 실장은 제한이 걸리면 팔 수 있는 데까지만 팔고 다른 상품으로 넘어갑니다. 거기에 힘을 쓰기보다 새로 소싱하는 편이 낫다는 판단입니다.
2직접 전달 건 정산이 늦을 때“일주일에 한 번 정도 여기에 구매 확정 요청이 있어요.”▾

상황

  • 9월 28일부터 들어온 주문을 직접 전달로 처리했는데, 송장 번호가 중복됐다는 메시지가 뜨고 구매확정이 하루 한 건꼴로만 넘어와 지출만 계속되는 상태였습니다.
  • 송장 중복은 네이버·지마켓에서 산 판매자도 리셀러나 개인 판매자라서 생기는 일입니다. 문제는 아닙니다.
  • 직접 전달은 자동 구매확정까지 약 28일이 걸려 정산이 원래 늦습니다.

구매확정 요청하는 법

  1. 직접 전달 처리한 다음 날부터 8일이 지나면 구매확정 요청이 가능해집니다.
  2. 해당 목록에서 전체 선택 → 구매확정 요청 클릭 → 고객에게 알림이 갑니다.
  3. 일주일에 한 번 이렇게 눌러 주세요.
  • 더 빨리 정산이 필요하면 고객에게 톡톡으로 “잘 받으셨으면 구매확정 부탁드린다”고 보내는 방법도 있습니다.
  • 전화는 보이스피싱 걱정 때문에 받지 않거나 끊는 고객도 있습니다.
3가격 관리 프로그램 다시 켜기상담 중 다운로드“이러면 지금 가격 경쟁이 하나도 안 되고 있다는 얘기거든요.”▾
  • 지난주엔 잘 올라갔는데, 지금 스토어 상품이 가격 경쟁을 전혀 못 하고 있었습니다. 대표님은 프로그램이 어디 있는지 모르셔서 돌리지 못하고 계셨습니다.
  • 위치: 구글 드라이브 → 공유 문서함 → 프로그램 → 가격 관리 프로그램
  • 상담 중에 같이 내려받았습니다. 설정하고 계속 켜 두세요.
  • 등록 상품은 약 200건입니다.

문의는 어디로

  • 이 전화번호로 남기는 문의는 답변이 어렵습니다. 프로그램의 질문하기로 남기시거나 컨설팅 때 물어봐 주세요.
4소싱 방향: 가전 vs 화장품, 오프라인 vs 온라인“컴퓨터 앞에 앉아서 조금씩 찾아보는 게 조금 더 효율적이라서.”▾

가전

  • 방법은 화장품 4배소와 같습니다. 카테고리에서 가전으로 들어가면 됩니다.
  • 한다면 작은 것(다리미, 포트, 소형 주방가전·음식물 처리기 등) 위주로.
  • 다만 직접 전달일 확률이 높아 정산까지 돈이 묶입니다. 당장 묶여도 괜찮은 여유 자금이 없으시다고 하셔서, 지금은 화장품 위탁+사입 병행을 권해 드렸습니다.

오프라인 소싱

  • 대표님은 내일 인천, 일요일 코스트코를 돌아보실 계획이었습니다. 네이버에선 적립이 없으면 다 역마진이라 찾기 어렵다고 느끼셨습니다.
  • 오프뷰티(홍대점)를 직접 가 보셨는데 인터넷보다 비싼 것도 많았습니다. 오프라인이 쌀 것 같아도 아닌 경우가 많아 시간 대비로는 온라인이 낫습니다. 가셔도 되지만, 추천은 온라인입니다.
  • 도매 사이트 10곳(비밀창고)은 가입했지만 승인이 잘 안 나고 있습니다.

지금 꼬리물기 시트 상태

  • 마지막 기록이 10월 1일·6일입니다. 일주일 넘게 지났으니 그 사이 할인이 풀린 상품이 있을 수 있어 다시 검색해 볼 만합니다.
  • 꼬리물기 도중 대부분 역마진(약 -200원)이 나와 포기하셨는데, 아래 5번 방식으로 다시 해 보시면 됩니다.
5꼬리물기 실습: 그린티 수분크림실습“할인하는 상품을 찾는 거라서.”▾

키워드 뽑기

  • 상품을 한 단어로 정리 → 수분크림. 함께 나온 키워드: 그린티, 시루, 히알루론산, 녹색, 속건조, 80ml.

빠르게 거르는 순서

  1. 상품명을 50자까지 복사해 붙여 넣습니다.
  2. 네이버 카탈로그에서 수량별 단가 중 가장 싼 것만 봅니다. 멤버십 할인가가 없으면 상세로 들어가지 않고 넘어갑니다. (예: 15,900원에 적립 300원 남짓 → 사실상 할인이 없어 패스)
  3. 에누리에서 배송비 포함 체크 → 해당 상품 카탈로그가 있는지 봅니다. 중간쯤까지 내려도 없으면 아래에도 없습니다.
  4. 안 보이면 상품명 뒤쪽 2~3단어를 지우고 다시 검색합니다.
  5. 카탈로그 안에서는 파란 글씨 최저가만 클릭하고 카드 할인이 되는지 확인합니다.
  6. 구성이 이상하거나 본사가 아닌 판매처면 더 볼 것 없이 바로 끄고 다음 상품으로.

상담 중 계산 예시

  • 3개 58,000원 → 개당 약 16,000원 + 택배비 3,000원 = 약 19,000원 → 판매가보다 높아 패스.
  • 다른 상품은 에누리 최저가 28,200원 vs 네이버 26,000원 → 에누리가 비싸서 패스.

짚은 점

  • 대표님은 그동안 공식몰에 들어가 구매하기 화면까지 확인하며 계산하셨습니다. 그건 발주할 때 보면 되고, 소싱 단계에서는 할인 폭이 있는지만 빠르게 봅니다.
  • 마진이 남으면 고객 주소로 바로 보내는 위탁도 괜찮습니다(대표님이 이미 하고 계신 방식).
  • 대표님도 “이렇게 하는 게 더 좋은 것 같다”고 하셨습니다. 처음엔 시간이 걸리지만 반복하면 빨라집니다.
6꼬리물기 시트 사용 팁“ctrl shift v 하면 주변 서식에 맞춰서 복사가 되거든요.”▾
  • 시트 맨 위의 꼬리물기 규칙이 지워져 있어서 다시 복사해 넣어 드렸습니다. 가끔씩 읽어 보세요.
  • 붙여 넣을 때 한 칸 내용이 두 줄로 나뉘며 아래 칸이 지워지는 문제가 있었습니다. Ctrl+Shift+V로 붙여 넣으면 서식 없이 한 칸에 들어갑니다.
