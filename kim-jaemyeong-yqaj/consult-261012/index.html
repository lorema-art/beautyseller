김재명 대표님 1:1 컨설팅 정리

35분상담 시간 (원격, 녹음 2개)
첫 페이지지칭 단어·카테고리는 40개만
10/17(토)저녁 7시 코치 컨설팅
김재명 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

소싱은 꾸준히 하고 계셨지만 주문이 들어오면 대부분 역마진이 나는 상황이었습니다. 꼬리물기 시트를 함께 보니 카탈로그가 아닌 상품이 많고 진행 규칙이 어긋나 있어서, 강사가 시작점을 새로 찍어 드리고 꼬리물기를 처음부터 다시 잡았습니다. 멈춰 있던 가격 관리 프로그램도 로그인 문제를 풀어 다시 돌렸습니다.

역마진이 나는 이유

할인이 없는 상품, 카탈로그가 아닌 상품까지 등록되어 있었습니다. 수량 제한이 걸리면 대량 구매로만 풀려고 하신 것도 원인입니다. 실제로는 여러 판매처에서 소량씩 삽니다.

오프라인 소싱

카탈로그·최저가가 없어 등록이 안 되는 상품이 대부분이고, 판매량도 크지 않습니다.

온라인 꼬리물기 (집중)

카탈로그 기준으로, 지칭 단어 → 카테고리 → 제조사·브랜드 순서대로 다시 시작합니다.

당분간 주 2회 점검

방향은 잘 잡고 가고 계십니다. 가끔 길에서 한 발씩 벗어나는 부분만 잡으면 되니, 이번 주는 목요일 중간 점검 + 토요일 컨설팅으로 두 번 봅니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1주문은 많은데 역마진: 수량 제한과 재판매 금지 문구“실제로 제가 몇 백 개씩 물건을 사는 경우는 흔치 않아요.”▾

상황

  • 한 상품에 10건 넘게 주문이 들어왔는데, 구매처가 3개 이상·10개 이상 구매 불가로 막아 두어 나머지 물량을 모두 역마진 처리하고 판매중지를 거셨습니다.
  • 사입을 하려고 본사 홈페이지에 가 보니 대량 구매 할인은 되지만 재판매는 금지, 적발 시 법적 조치라는 문구가 있어 멈추셨습니다.

정리

  • 상세페이지·본사 사이트의 재판매 금지 문구는 강의 때 말씀드린 대로 신경 쓰지 않으셔도 됩니다. 내려 달라는 요청이 오면 그때 내리면 됩니다.
  • 대량 구매로만 접근하신 게 문제입니다. 리뷰가 몇백 개 쌓인 상품도 한 번에 산 게 아니라 소량씩 여러 번 산 것입니다.
  • 잘 팔리는 상품도 주문은 주에 10개 안팎에서 조금씩 늘어납니다. 갑자기 2~3배로 뛰는 경우는 드뭅니다.
  • 같은 상품을 파는 곳은 한 곳이 아닙니다. 한 판매처가 막히면 다른 판매처를 찾아보면 됩니다.
  • 지금은 할인이 있는 시기이기도 합니다. 대표님은 오늘의 할인은 보지 않고 꼬리물기만 하고 계셨는데, 장기적으로 수익을 키우는 건 꼬리물기가 맞습니다.
2꼬리물기 시트 점검: 처음부터 다시재시작“이미 위에서부터 잘못된 게 너무 많아요.”▾
  • 저장해 두신 링크를 하나씩 눌러 보니 카탈로그가 아닌 상품이 꽤 많았습니다. 주문이 들어와도 구매처를 찾기 어려운 상품들입니다.
  • 진행 규칙도 중간에 바뀌어서(위에서부터 하다가 날짜 기준 뒤에서부터) 어떤 순서로 찾고 계신지가 분명하지 않았습니다.
  • 원래라면 4배소를 다시 해야 하지만, 대신 강사가 시작 상품을 찍어 드리고 거기서 꼬리물기를 새로 시작하기로 했습니다(닥터포헤어 샴푸).
  • 시간이 많지 않으신데도 꽤 많이 찾으셨습니다. 방향은 맞으니 어긋난 부분만 바로잡으면 됩니다.
3지칭하는 단어 만들기실습“얘네가 띄어쓰기 기준으로 한 덩어리로 보는 거예요.”▾

만드는 법 (닥터포헤어 폴리젠 샴푸 예시)

  1. 사람들이 이 제품을 뭐라고 부르는지 → 샴푸. 이게 메인이고 바꾸지 않습니다.
  2. 상품명 앞에서부터 보되 브랜드(닥터포헤어)는 뺍니다.
  3. 띄어쓰기 단위로, 원래 순서대로 메인과 붙입니다. 앞에 있던 단어는 앞에(폴리젠 샴푸, 실크 샴푸), 뒤에 있던 단어는 뒤에(샴푸 손상).
  4. 상품명에 남은 단어가 있으면 끝까지 다 만듭니다.

고유명사는 지우기

  • 지칭 단어로 검색했을 때 그 브랜드 상품만 나오면, 다른 브랜드는 쓰지 않는 이름입니다. 유행이 없는 단어이니 수집하지 않고 취소선을 긋습니다. (폴리젠 샴푸 → 취소선)
  • 실크 샴푸처럼 다른 브랜드도 같이 뜨면 진행합니다.
4어디까지 보나: 지칭 단어·카테고리·제조사·브랜드“여기서 1,000개 넘는 거를 누르셔야 돼요.”▾

지칭 단어·카테고리

  • 첫 페이지 40개만 봅니다. 다음 페이지로 넘어가지 않습니다. 대표님은 이미 잘 하고 계셨습니다.
  • 시트에 카테고리가 헤어 왁스로 적혀 있었는데, 이 상품은 샴푸입니다. 카테고리를 다시 확인해 주세요.

제조사·브랜드 여기가 달라요

대표님은 제조사도 첫 페이지만 보셨는데, 제조사와 브랜드는 세부 카테고리까지 들어가야 합니다. 이걸 안 하셔서 나오는 상품이 적었습니다.

  1. 제조사로 검색 → 첫 페이지 40개를 봅니다(그 제조사에서 가장 잘 팔리는 상품들).
  2. 카테고리 화살표를 눌러 세부 카테고리를 엽니다.
  3. 상품이 1,000개 넘는 카테고리를 적은 순서대로 눌러, 각각 첫 페이지를 봅니다.
  4. 그 안에서 또 1,000개 넘는 하위 카테고리가 있으면 같은 방식으로 들어갑니다. (예: 생활건강 → 욕실용품 → 반려동물, 화장품 → 클렌징)
  5. 제조사가 끝나면 브랜드도 똑같이 봅니다.
  • 다른 카테고리에서 방금 본 상품이 또 나오면, 확실히 기억나면 넘어가고 헷갈리면 한 번 더 봅니다.
  • 중복으로 등록하려 해도 프로그램이 걸러 줍니다(상담 중 확인: 10개 중 중복 5개 제외, 5개 등록).
  • 카탈로그만 봅니다. 카탈로그가 아닌 상품은 보지 않습니다.
5다음 날은 어디서부터 이어가나“가장 최근에 찾은 단어의 키워드부터 꼬리물기 하시라고.”▾
  • 시트에 적힌 규칙대로 매일 가장 최근에 찾은 키워드부터 꼬리물기를 합니다.
  • 예: 8번에서 꼬리물기를 했는데 그 아래 2개가 새로 찾아졌다면, 다음은 7번이 아니라 새로 찾은 아래쪽부터 이어갑니다.
  • 한 번 본 키워드는 빨간색으로 칠해 표시합니다.
  • 좌에서 우로 진행합니다.
6에누리 확인 실습: 샴푸 3개실습“얘를 특정할 수 있는 것 정도는 냅두는 게 좋아요.”▾

순서

  1. 에누리에서 검색합니다. 카탈로그는 맨 위에 뜨므로 아래로 내릴 필요가 없습니다.
  2. G마켓·11번가·롯데온 같은 단일 상품만 뜨면, 상품명에서 불필요한 단어를 지우고 다시 검색합니다.
  3. 지울 때는 용량·향(숲향)·오리지널 같은 단어부터 지우고, 브랜드처럼 제품을 특정하는 단어는 남깁니다. 한 번에 다 지우지 말고 하나씩 지워 봅니다.
  4. 찾은 카탈로그가 같은 제품인지 확인합니다(상담 중 용기 색이 달라 다른 제품이었던 경우가 있었습니다).
  5. 최저가를 누르기 전에 먼저 개당 가격을 나눠서 저렴한지 확인합니다. 저렴할 때만 들어가 카드 할인을 봅니다.
  6. 네이버보다 비싸면 패스.

마진 계산 예시: 꾸뛰르 헤어 녹차질감 샴푸

  • 4개 묶음 52,400원 → 개당 약 13,100원으로 판매가보다는 저렴했습니다.
  • 하지만 고객에게 보내는 택배비 3,000원을 더하면 역마진 → 패스.
  • 살 때는 에누리에서 배송비 포함을 켜서 봅니다. 그리고 사무실로 받은 물건을 고객에게 다시 보낼 때 드는 배송비를 따로 한 번 더 계산해야 합니다.
7오프라인 소싱은 잠시 내려두기“오프라인에 판매하는 것들은 판매량이 크지 않다 보니까.”▾
  • 며칠간 온라인에서 200개 가까이 봤는데 다 역마진이라, 계획을 세워 오프뷰티 매장을 돌며 사진을 많이 찍어 오셨습니다.
  • 등록하려고 보니 카탈로그·최저가가 없어 대부분 등록이 안 됐고, 2개만 등록하셨습니다.
  • 카탈로그가 있는 오프라인 상품도 있지만 판매량이 크지 않습니다. 지금은 온라인 꼬리물기에 집중하시는 게 낫습니다.
8가격 관리 프로그램 로그인 실패 해결상담 중 해결“걔를 로그인 안 하면 프로그램 가동이 안 돼요.”▾
  • 지난주 코치님 안내로 내려받으셨는데, 시작을 누르면 로그인 실패가 계속 떴습니다.
  • 시작을 누르면 크롬 창이 하나 따로 뜹니다. 이 창에서 스마트스토어에 로그인해야 프로그램이 돌아갑니다.
  • 이메일과 비밀번호를 입력해 저장해 두면 다음부터는 로그인 버튼만 누르면 됩니다. 상담 중 로그인해서 정상 가동을 확인했습니다.
  • 업데이트 알림이 떠도 문제없이 쓰고 계시면 굳이 받지 않아도 됩니다. 2주~한 달에 한 번만 새로 받으시면 됩니다.
