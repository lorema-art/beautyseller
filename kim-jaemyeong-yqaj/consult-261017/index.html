김재명 대표님 1:1 컨설팅 정리

2026년 10월 17일 · 김재명 대표님, 뿌요 교육실장
36분상담 시간 (원격)
1건잘못 넘어간 주문 반품·환불 처리
하루 3개숙제: 소싱·등록
김재명 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

지난 10월 12일 상담에서 잡아 둔 토요일 컨설팅입니다. 대표님은 닥터포헤어 샴푸에서 다시 시작한 꼬리물기를 이어 서울화장품을 보고 계셨습니다. 시트 적는 법을 바로잡고, 역마진이던 상품을 다른 구매처에서 찾아 다시 판매로 돌리고, 소싱 실습과 잘못 눌린 주문 1건의 반품·환불까지 함께 처리했습니다.

시트는 왼쪽에 지칭 단어

왼쪽 칸에 판매처 내용을 적으셔서 헷갈리는 상태였습니다. 왼쪽은 지칭 단어, G마켓·옥션 같은 판매처는 오른쪽 브랜드 옆에 적습니다.

소싱 속도

에누리에서 조금만 내려 보고 카탈로그가 없으면 바로 패스. 상담 중 실습에서 한 상품에 30~40초 정도로 빨라졌습니다.

배송중으로 잘못 넘어간 주문

이 상태에선 취소가 안 됩니다. 판매자 직접 반품으로 접수하고 바로 반품 완료 → 환불합니다.

숙제는 무리 없이

평일엔 시간을 내기 어려우셔서, 하루 3개 등록을 목표로 하고 여유 있을 때 더 해 보시기로 했습니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1꼬리물기 시트 적는 법 바로잡기“여기에는 웬만한 지칭 단어로 적어주시는 게 좋고.”▾

상황

  • 왼쪽 칸에 지칭 단어를 안 적고 판매처 내용을 적어 두셔서 보기가 헷갈리는 상태였습니다.

이렇게 적어 주세요

  • 왼쪽은 지칭 단어로 적습니다. 꼬리물기가 핵심이라, 코치가 이 칸을 보고 방향이 틀렸으면 다시 잡아 드립니다.
  • G마켓·옥션 같은 판매처를 적고 싶으시면 오른쪽, 브랜드 옆에 적습니다.
  • 지금 보고 계신 제조사 칸에는 서울화장품이라고 기재해 두기로 했습니다.
  • 판매처를 적는 건 해도 되지만, 하다 보면 시간이 아까워 안 적게 되실 수 있습니다. 일단은 적는 쪽으로 가 봅니다.

어디서부터 이어가나 (지난번 복습)

  • 보고 계시던 게 12일 키워드였습니다. 시트 규칙대로 매일 가장 최근에 찾은 키워드부터 꼬리물기를 합니다.
  • 서울화장품 → 닥터포헤어까지 보신 다음, 그 아래에서 새로 찾은 키워드로 다시 꼬리물기를 이어갑니다.
  • 제조사·브랜드는 1,000개 넘는 세부 카테고리를 눌러서, 지칭 단어·카테고리는 검색해서 바로 봅니다.
2역마진 상품, 다른 구매처 찾았을 때상담 중 조치“그런 제품은 사실 등록을 더 하실 필요는 없고.”▾

상황

  • 원래 구매처에서 수량 제한(10개 이상 구매 불가)이 걸려 역마진이던 상품(부케가르니 퍼퓸 바디로션 화이트머스크)을 무신사를 보다가 29CM에서 찾으셨습니다. 마진이 남아 주문 1건을 그곳에서 사서 보내셨습니다.
  • 무신사·29CM는 대부분 본사 제품입니다. 테무에도 가끔 본사가 조금 저렴하게 들어가 있는 경우가 있습니다.
  • 찾은 구매처를 어디에 등록해야 할지 몰라 막혀 계셨습니다. 스토어에서 가격을 올려 두셨는데, 가격 관리 프로그램을 돌리자 원래 가격으로 되돌아갔다고 하셨습니다(1위를 잡는 프로그램이라 10원·수백 원 단위로 움직입니다).

이렇게 처리합니다

  1. 이미 스토어에 등록된 상품이니 새로 등록하지 않습니다.
  2. 스마트스토어에서 해당 상품을 찾습니다. 판매중지 상태였다면 판매중으로 돌립니다(판매중이 아니면 노출이 안 됩니다).
  3. 판매가를 1위 가격보다 10원 저렴하게 수정합니다. 상담 중 17,760원으로 맞췄습니다.
  4. 주문이 들어오면 29CM에서 구매해 고객에게 보냅니다.
  • 구매처 사이트가 헷갈릴 때는 그 사이트의 구매 내역에서 상품을 확인하면 됩니다. (상담 중 W컨셉과 29CM가 헷갈려 같이 확인했습니다.)
3소싱 실습: 서울화장품실습“이 정도로 하면은 보통 지금 한 30초에서 40초 정도 걸리고 있거든요.”▾

빠르게 거르는 순서

  1. 제조사 안에서 상품 1,000개 넘는 카테고리(예: 크림) 위주로 봅니다.
  2. 에누리에서 배송비 포함을 체크합니다. 금액이 달라질 수 있습니다.
  3. 중간쯤까지만 내려 보고 카탈로그가 있는지 봅니다. 맨 아래나 2~3페이지까지 가지 않아도 됩니다. 위에 없으면 뒤에도 없습니다.
  4. 없으면 상품명 뒤쪽 단어부터 지우고 다시 검색합니다.
  5. 그래도 카탈로그가 없거나, 가격이 표시되지 않는 상품이면 바로 패스합니다.
  6. 카탈로그가 있으면 눌러서 카드 할인이 되는지 봅니다. 목록 가격과 들어가서 본 가격이 다를 때가 많으니(할인이 풀린 경우 등) 꼭 들어가서 확인합니다.
  7. 묶음 상품은 개당 가격으로 나눠 보고, 고객에게 보내는 택배비 3,000원을 더해 판매가와 비교합니다.

상담 중 계산 예시

  • 7,640원 카탈로그(1개) → 카드 할인 없음 → 패스.
  • 4,640원 + 배송비 3,000원 → 마진이 남지 않아 패스.
  • 3개 26,200원 → 개당 약 8,700원 → 패스.
  • 판매가와 1,000원 이상 차이가 나야 마진이 남습니다. 10원 차이는 의미가 없습니다.

짚은 점

  • 대표님 방식이 맞게 가고 있습니다. 바쁜 날에도 두 개씩은 찾아 두고 주무셨다고 하셨는데, 잘하고 계신 겁니다.
  • 구매는 공식(본사) 판매처 위주로 찾습니다. 공식몰도 마진이 안 남을 수 있지만, 할인을 해서 마진이 남는 화장품도 있습니다.
4위탁 위주로 가도 됩니다“위탁이 훨씬 많을 거라서 그렇게 하시면 돼요.”▾
  • 위탁: 뷰셀 사무실을 거치지 않고 구매처에서 고객 주소로 바로 보내는 방식입니다. 사입은 사무실로 받았다가 고객에게 다시 보냅니다.
  • 대표님은 지금 모두 위탁으로 하고 계십니다. 화장품은 사입할 상품이 많지 않아 위탁 위주로 하셔도 됩니다.
5G마켓 로그인 불편 해결상담 중 해결“이거 누르고 나서 비밀번호 한 번 더 눌러서 얘 누르면 바로 들어가지거든요.”▾
  • 비밀번호를 바꿀 때 대문자로 저장되어, 크롬이 자동으로 채워 주는 비밀번호가 틀려 매번 로그인이 안 되는 상태였습니다.

고친 순서

  1. 크롬 주소창 옆 열쇠 아이콘(또는 설정)에서 비밀번호 자동완성으로 들어갑니다.
  2. 목록에서 G마켓을 찾습니다.
  3. 수정을 눌러 현재 비밀번호(대소문자 확인)로 고치고 저장합니다.
  4. 로그인 화면에서 아이디를 누르고 비밀번호 칸을 한 번 더 누른 뒤 자동완성을 고르면 바로 로그인됩니다.
6잘못 ‘직접 전달’로 넘어간 주문: 판매자 직접 반품상담 중 처리“배송 중으로 넘어간 상태에서는 취소가 안 되거든요.”▾

상황

  • 역마진이라 보내지 못한 주문 1건이, 이름이 같은 고객이 있어 헷갈려 잘못 눌리면서 직접 전달(배송중)으로 넘어가 버렸습니다. 물건은 보내지 않았는데 구매확정 단계로 가고 있었습니다.
  • 구매확정 연장을 눌러 11월 1일로 미뤄 두셨지만, 연장을 해도 결국 구매확정으로 넘어갈 뿐입니다. 보낼 수 없는 상황이니 바로 환불해 드리는 게 낫습니다.

취소와 반품의 차이

  • 운송장 입력이나 직접 전달 처리 전까지는 취소로 처리할 수 있습니다.
  • 운송장이 들어갔거나 직접 전달로 넘어간 뒤에는, 실제로 안 보냈어도 네이버 시스템상 반품으로 처리해야 환불됩니다.

처리 순서

  1. 스마트스토어센터에서 해당 주문(배송중)을 선택합니다.
  2. 판매자 직접 반품을 누릅니다.
  3. 반품 사유는 배송 지연, 수량 1개로 둡니다.
  4. 사유 칸에 아래 안내 문구를 붙여 넣습니다. 이 문구가 고객에게 그대로 전달됩니다.
  5. 실제로 보낸 상품이 없으니 수거 요청 안 함을 고르고 반품 접수를 누릅니다.
  6. 반품 목록에서 해당 건을 확인하고, 메모에 “반품 직접 취소함”처럼 적어 두면 나중에 무슨 건인지 기억하기 쉽습니다.
  7. 반품 완료 처리를 하면 바로 환불됩니다.

상담 중 쓴 안내 문구

안녕하세요 고객님, 먼저 배송에 불편을 드려 죄송합니다. 현재 공급사 측 사정으로 출고가 지연되고 있는 것으로 확인됩니다. 가능한 빠른 출고로 배송을 해드리려 했으나 제품 준비로 빠른 출고가 어려운 것으로 확인됩니다. 고객님의 불편함을 최소화하기 위해 우선 환불 및 반품으로 진행 도와드리겠습니다.

  • 처리 후 메뉴에 숫자 1이 남아 보여도 반영이 조금 늦는 것뿐입니다. 들어가 보면 0으로 되어 있고, 반품 완료 목록에 올라와 있습니다.

  • 평일에는 하루 2시간도 내기 어려우시다고 하셨습니다.
  • 그래서 하루 3개 등록을 목표로 합니다. 덜 피곤할 때나 이동 중 틈틈이 할 수 있을 때는 최대한 더 등록해 보세요.
