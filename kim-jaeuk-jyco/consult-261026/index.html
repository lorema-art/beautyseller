김재욱 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

자동등록 프로그램의 API 키 입력 단계에서 막혀 계셨습니다. 원격으로 네이버 API 연동과 제미나이 결제 설정을 마치고, 직접 상품을 하나 올려 입구마켓에 정상 등록되는 것까지 확인했습니다. 이번 주는 매출보다 등록 과정에 손이 익는 것이 목표입니다.

지금 상태

오늘 사업자로 스마트스토어 ‘입구마켓’ 개설. 셀러들의 수다·카탈로그 담기·자동등록 프로그램 세팅 완료, 첫 상품 등록 성공(심사 중).

오늘 정리한 것

‘오늘의 할인’에서 1,000원 이상 남는 상품을 고르고, 네이버 카탈로그의 구성 수량(1개/2개)을 맞춘 뒤 담아서 대량등록하는 흐름을 함께 해 봤습니다.

앞으로

위탁 100%보다 주문 들어올 때 3~6개만 사는 반사입으로 갑니다. 다음 주에는 직접 상품 찾는 법을 배우니, 그 전에 등록은 혼자서도 막힘없이.

제미나이 결제 설정
  • 셀러들의 수다, 카탈로그 담기, 자동등록 프로그램까지 설치는 해 두셨고 API 키 입력에서 멈춰 있었습니다.
  • 스마트스토어 API 센터에서 계정을 만들고 애플리케이션 이름은 ‘뷰셀’, 설명은 점 하나로 입력했습니다.
  • 네이버에서 ‘내 IP’를 검색해 복사·등록하고, 전체 API 그룹 5개를 모두 추가했습니다.
  • AI는 여러 개가 되지만 이 프로그램은 제미나이 기반이 가장 깔끔합니다.
2제미나이 충전 — 월 결제가 아닌 사용한 만큼“상품 하나 등록할 때 한 100원에서 300원 정도 나가요.”▾
  • 기타 금액으로 16,000원 충전, 자동충전을 켜 두었습니다.
  • 매달 나가는 돈이 아니라, 상품 1개 등록에 약 100~300원씩 차감되고 잔액이 다 떨어지면 다시 충전되는 구조입니다. (뷰셀이 가져가는 비용이 아닙니다.)
  • 그래서 신중하게 아껴 올릴 필요는 없고, 연습용으로 충분히 쓰셔도 됩니다.
3첫 상품 등록 실습 — 오늘의 할인 → 카탈로그 → 대량등록핵심“카탈로그를 다 담아 놓고, 원래는 자기 전에 돌리시면 돼요.”▾

대량등록 시작
  • 오늘의 할인에 표시되는 ‘낱개로 팔면 +○○원’이 마진입니다. 예시 상품은 1,296원이었습니다.
  • 마진이 나는 게 1개짜리인지 2개짜리인지 확인하고, 네이버 카탈로그도 같은 구성으로 바꾼 뒤 담습니다.
  • 처음 고른 상품은 카탈로그가 이상해서 프로그램이 제품을 못 찾았고, 닥터오라클 상품으로 다시 해서 입구마켓에 정상 등록을 확인했습니다. 직접 찾아 올리는 상품에서는 이런 경우가 거의 없습니다.
  • 등록 중 멈춘 것처럼 보여도 판매처 정지 등으로 순서가 밀리는 것이니 건드리지 말고 기다리세요. 그래서 담아 두고 자기 전에 돌리는 방식을 권합니다.
  • 등록 확인은 스마트스토어 → 상품 목록에서. 처음엔 심사 중으로 떠도 괜찮습니다.

복습지난주 강의
  • 1주차 상품은 동기분들이 다 같이 올리는 오늘의 할인 상품이라 마진이 빨리 깎입니다. 많이 올리는 것보다 프로그램으로 등록하는 과정에 익숙해지는 게 목표입니다.
  • 다음 주(2주차)에 직접 상품 찾는 법을 배우는데, 등록에서 버벅이면 좋은 상품을 찾아도 올릴 수가 없습니다.
  • 지난주 강의 중 스마트스토어 맥락 설명 부분이 이해가 덜 됐다면 다시보기로 한 번 더 보세요.
5현실적인 기대치 — 천천히, 쌓이는 구조“평일 하루 2시간씩이면 4주차 끝났을 때 많아야 100만 원이에요.”▾
  • 본업(병원 근무)이 있고 퇴근 시간이 일정하지 않아 하루 1~3시간, 평균 2시간(평일 기준)으로 잡았습니다.
  • 이 페이스로 한 달간 상품 50개 정도 올리면 4주차 순수익은 많아야 100만 원 선입니다. 수익이 나면 다음 달 더 올리게 되고, 그렇게 쌓여 수익이 커집니다.
  • 대표님도 한 달 10~20만 원부터 한 걸음씩 가시겠다고 하셨고, 이 마음가짐이 맞습니다.
  • 컴퓨터가 낯선 건 다들 마찬가지입니다. RPG 게임 캐릭터 키우듯 생각하면 훨씬 편하고 재밌습니다.
6플랫폼 정책 걱정 — 네이버는 대응 가능“정책을 바꿔도 카탈로그는 죽지 않습니다.”▾
  • 이전에 쿠팡 위탁판매를 하다 정책 변경과 계정 정지를 겪으셔서, 네이버도 그럴까 가장 걱정하셨습니다. 스마트스토어는 처음이십니다.
  • 모든 플랫폼은 가끔 크게 바뀝니다. 다만 네이버는 뷰셀도 오래 했고 스승님은 10년 가까이 하며 계속 대응해 왔습니다. 로직이 바뀌면 대응법을 찾아 알려 드립니다.
  • 오히려 로직 변경 때 초보 경쟁자들이 빠져나가서, 남아 있는 사람에게는 기회가 됩니다.
7위탁보다 반사입 — 주문 들어올 때 3~6개만방향“사입을 무조건 많이 산다는 생각을 버려야 돼요.”▾

그때 소량(3~6개) 매입
  • 위탁 비중을 크게 가져가고 싶으셨지만 권장하지 않습니다. 위탁은 돈은 되지만 네이버·쿠팡 모두 위수탁 규정상 계약서를 요구하고, 경쟁사 신고가 계속 들어옵니다.
  • 쿠팡은 방어가 불가능하지만, 네이버는 방어 수단이 있어 강의에서 따로 안내합니다.
  • 미리 싸게 사 두는 선사입 대신, 위탁으로 올려 두고 주문이 들어오면 소량씩 사는 반사입으로 하세요.
  • 안 팔리면 뷰셀이 매입해 드리고, 선물하거나 당근마켓으로 처분해도 됩니다. 부담 가질 필요 없습니다.
8자주 물어보신 것들“안 될 때는 셀러들의 수다에 남겨 주시는 게 제일 빨라요.”▾

스토어 이름

  • ‘입구마켓’ 좋습니다. 한글 이름이 더 낫습니다. 판매자명이 영어면 소비자가 가품처럼 느끼기도 합니다.

신용카드

  • 필수는 아니지만 만드는 게 유리합니다. 2주차 강의에서 권장 카드를 보여 드립니다. (현재 2장 보유)

노트북 교체·이사

  • 노트북은 없어도 됩니다. 새 PC에서는 다시 세팅하지만 오늘 만든 키를 그대로 쓰니 훨씬 간단합니다. 이사로 인터넷이 바뀌면 IP 주소만 바꿔 주면 됩니다.

질문은 어디로

  • 프로그램·시스템 문의는 셀러들의 수다에 남기는 게 가장 빠릅니다.
  • 거기서 해결이 안 되거나 개인적인 건은 뷰셀 카톡으로. 하루 3번 정도 확인해서 실시간 답은 어려울 수 있습니다.
  • 셀러들의 수다 모바일 사용: 단톡방 공지의 링크와 설치 방법을 보고 따라 하시면 됩니다(정식 앱은 아님).
9방문 컨설팅·연말 오프라인 모임“아래쪽에서도 저희가 여행 가는 겸 내려가면 되니까.”▾
  • 부산에 계셔서 방문 컨설팅을 원하셨습니다. 컨설팅 신청 시 방문으로 신청하고 일정만 맞추면 언제든 가능합니다. 주말은 강의 끝난 뒤, 뷰셀이 없으면 코치님과도 가능합니다.
  • 연말 전에 오프라인 모임을 수도권 한 번, 부산·남부권 한 번 여는 것을 검토 중입니다. 정해지면 단체방에 공지합니다.
