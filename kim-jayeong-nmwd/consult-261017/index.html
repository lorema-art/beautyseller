김자영 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

지난주보다 주문이 늘어 하루 5건 이상 들어오지만, 퇴근 후 2시간을 발주·가격 확인·기록에 다 쓰느라 소싱을 거의 못 하고 계셨습니다. 이번 상담은 시간을 잡아먹는 일을 덜어 내는 데 집중했습니다. 발주는 시간을 정해 끊고, 계산과 기록은 꼭 필요한 것만 남깁니다.

지금 상태

판매 중지를 풀고 나서 주문이 꾸준히 들어오고 있습니다. 그런데 한 주 내내 발송이 늦어졌고, 상품 정보에 개인 휴대폰 번호가 남아 있던 일, KC 인증 표시, 상표권 메일까지 겹쳤습니다.

바꿀 것

발주는 1건 3분, 5건 15분(최대 20분) 안에 끝냅니다. 안 되면 배송 지연을 걸고 넘깁니다. 실구매가는 확정 할인만 빼서 계산하고, 운송장 안내와 마진 재계산은 하지 않습니다.

앞으로

순서는 1번 발주, 2번 소싱입니다. CS는 맨 뒤에 10분 안팎으로 처리합니다. 주말에는 배송 지연 건 발주, 카탈로그 가격 관리, 소싱을 합니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1발주 시간 정하기핵심“3분에 끊어 버리고 배송 지연으로 그냥 넘겨 버리세요.”▾
  • 평일에 쓸 수 있는 시간은 퇴근 후 최대 2시간입니다. 그 시간을 발주에 다 써서 소싱을 못 하고, 그런데도 발송은 한 주 내내 늦어졌습니다.
  • 위탁이라도 5건은 15분 안에 끝내야 합니다. 1건이 3분 안에 해결되지 않으면 끊고 배송 지연을 건 뒤 다음 건으로 넘어갑니다.
  • 15분이 빠듯하면 최대 20분을 넘기지 않는 것을 기준으로 합니다.
  • 넘긴 건은 소싱을 마치고 남는 시간이나 주말에 다시 찾아 발주합니다.

소싱

할인 행사 알림 소싱은 보조로만

  • 스토어에서 오는 ‘페스티벌·할인 시작’ 알림으로 찾은 상품은 단타입니다. 매출이 잠깐 났다가 끝납니다.
  • 오래 가는 건 4배수와 꼬리물기로 찾은 상품입니다. 소싱 시간이 정말 없을 때만 단타로 보충합니다.
2실구매가는 확정 할인만 빼기“이거는 계산 안 하시고 넘어가면 시간이 압축돼요.”▾
  • 테라바디 상품은 행사가 끝나 매입가가 크게 올라 역마진이 됐습니다. 신세계몰·이마트·G마켓·에누리를 확인했지만 포인트를 반영해도 약 57만 원으로 빠듯했습니다.
  • 그래서 테라바디 2건은 배송 지연(가격 상승)을 걸어 두고, 월초에 할인이 다시 붙는지 봅니다.
  • 계산할 때는 기본 적립과 멤버십 적립만 뺍니다.
  • 삼성월렛 최대 12.5% 같은 카드 적립은 빼지 않습니다. ‘중복 적용 불가’ ‘최대 적립액’ ‘건당·인당 한도’ 같은 조건이 붙어 실제로 얼마가 들어올지 알 수 없기 때문입니다. 결제 화면에서 바로 깎이는 카드 즉시 할인만 넣습니다.
  • 카드 할인이 있는지는 상품 페이지만 봐서는 모릅니다. 구매 직전 화면까지 들어가서 확인합니다.

시트 팁

  • 컴퓨터 파일을 구글 시트로 옮기신 것은 잘하셨습니다. 회사에서도 바로 볼 수 있습니다.
  • 복사해 붙이면 칸 서식이 깨질 때 Ctrl + Shift + V로 붙이면 주변 서식에 맞춰 들어갑니다.
3기록과 고객 안내 줄이기“운송장 번호 일일이 보낼 필요 없어요.”▾
  • 운송장 번호가 오기를 기다렸다가 톡톡으로 하나하나 보내는 일은 그만합니다. 고객이 “언제 와요?”라고 물을 때만 운송장 번호와 택배사를 알려 줍니다.
  • 운송장 번호를 적는 대신, 결제 후 뜨는 주문 상세 링크를 판매 장부(시트)에 붙여 둡니다. 문의가 오면 링크를 눌러 바로 배송 조회를 할 수 있습니다.
  • 링크가 옆 칸을 가리면 텍스트 줄바꿈 → 자르기로 설정합니다.
  • 포인트 적립 내역도 건마다 적을 필요는 없습니다. 주문이 10건, 20건으로 늘면 적을 시간이 없습니다.
  • 네이버 정산 메일을 보고 수수료와 마진을 고치지 않아도 됩니다. 마진계산기는 세금까지 떼고 보수적으로 잡아서, 실제 입금은 보통 몇십 원 더 많습니다.
  • 톡톡 쪽지를 목록으로 띄워 ‘반품’ ‘지연’으로 검색해 처리하는 방법은 대표님이 직접 찾으신 좋은 방법입니다. 그대로 쓰시면 됩니다.
4개인 번호 노출 · KC 인증 표시함께 해결“속이 시원해.”▾
  • 자동등록 프로그램을 쓰기 전에 올린 초기 상품 약 150건의 A/S 특이사항에 개인 휴대폰 번호가 들어가 있어서, 근무 중에 고객 전화가 걸려 왔습니다.
  • 상담 중에 상품 조회를 1,000개씩 보기로 바꾸고, 전체 선택 → 일괄 변경 → A/S 정보에 070 번호를 넣어 한 번에 바꿨습니다.
  • 일부 전자제품은 KC 인증 번호가 들어가 있는데도 상세 화면에 ‘사용 안 함’으로 나왔습니다. 번호가 들어가 있으면 판매에 큰 영향은 없습니다. 다만 자동등록 때 ‘사용함’으로 들어가도록 프로그램 담당(퓨즈)에 업데이트를 요청하기로 했습니다.
5상표권 침해 메일 (마녀공장)“결국 제품 내리면 되는 건데, 약간 겁주는 거라 보시면 돼요.”▾
  • 판매 중지와 손해배상을 언급하는 메일이 왔지만, 실제 소송으로 이어지기보다는 판매자에게 겁을 주려는 성격이 강합니다.
  • 해당 상품은 이미 판매 중지·전시 중지를 해 두셨습니다. 답장은 굳이 하지 않아도 됩니다.
  • 혹시 답변이 필요한지 확인하기 위해, 메일 화면을 캡처해 보내 주시면 뿌요 교육실장이 뷰셀 대표님께 공유합니다.
6CS와 알림 확인“CS는 맨 뒤로 빼서 10분 내외로 빠르게.”▾
  • 고객 문의는 네이버 홈페이지 알림, 문의·리뷰 관리 등 여러 곳에 뜹니다. 스마트스토어의 톡톡만 보면 놓치는 건이 없습니다.
  • CS는 돈을 벌어 오는 일이 아니므로 맨 뒤로 빼고, 10분 안팎으로 처리하고 넘깁니다.
  • 예전에 응답이 늦어 제재를 받았을 때 소명 메일은 네이트로 왔습니다. 불안하면 아침 9시, 밤 10시에 메일 확인 알람을 맞춥니다.
  • 더 나은 방법은 스토어 메일 주소를 네이버 메일로 바꾸는 것입니다. ‘내 정보’에서 수정하고, 2단계 인증을 한 번 더 받으면 됩니다. 인증 메일이 스팸함으로 갈 수 있으니 스팸함도 확인합니다.

체크 표시는 이 브라우저에서만 저장됩니다.

  • 발주는 1건 3분, 5건 15분(최대 20분) 김자영넘기는 건은 배송 지연 걸고 소싱 먼저
  • 매일 발주 다음 소싱 김자영4배수·꼬리물기 위주, 할인 알림 단타는 보조로만
  • 실구매가는 기본·멤버십 적립과 카드 즉시 할인만 반영 김자영카드 적립·한도 있는 혜택은 계산하지 않기 · 구매 직전 화면에서 확인
  • 운송장은 문의 올 때만 안내, 시트에는 주문 상세 링크 저장 김자영포인트 적립 기록과 정산 메일 보고 마진 고치기는 그만
  • 스토어 메일을 네이버 메일로 변경 김자영내 정보 → 수정 → 2단계 인증 · 그전까지는 9시·22시 메일 확인 알람
