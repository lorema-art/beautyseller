김지영 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

“자동등록이 일주일째 안 돼서 상품을 하나도 못 올렸다”는 고민으로 시작해, 원격으로 대표님 화면에 들어가 프로그램 상태를 점검하고 베스트 소싱과 오늘의 할인 등록까지 한 바퀴 같이 돌려 봤습니다.

지금 상태

셀수다 자동등록(가운데 초록불)이 일주일 넘게 안 되어 강의 실습을 미뤄 오셨습니다. 원격으로 들어가 보니 상담 중에는 정상 작동했고, 정확한 원인은 확인되지 않았습니다. 강의는 전체 흐름은 알겠는데 직접 해 보지 못해 연결이 잘 안 되는 상태입니다.

오늘 한 것

다시 안 될 때 쓰는 네이버 커머스 API 재입력 방법을 안내했고, 스킨케어 베스트 소싱을 시연한 뒤 대표님이 직접 한 상품을 따라 해 봤습니다. 이어서 오늘의 할인 → 카탈로그 담기 → 대량등록 흐름을 실제로 돌렸습니다.

앞으로

강의 영상을 옆에 틀어 놓고 클릭을 그대로 따라 하며 손에 익히는 게 우선입니다. 막히면 혼자 미루지 말고 컨설팅을 바로 예약해서 진도를 빼세요.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1자동등록(셀수다)이 안 될 때핵심“이거를 복사해서 이 창에다가 하나씩 넣어주시면 되는데.”▾
네이버에서 ‘네이버 커머스 API’ 검색
→
로그인 → 내 스토어 애플리케이션
→
ID·Secret 복사
→
프로그램 환경설정에 붙여넣고 저장
  • 처음 점검 때는 세 개 모두 초록불이었는데, 이후 가운데(자동등록)가 계속 꺼져 있었습니다.
  • 원격으로 들어간 시점에는 다시 정상으로 떠서, 바로 소싱·등록 실습으로 넘어갔습니다.
  • 입력창에 바로 안 들어가면 환경설정을 눌러 거기에 붙여넣고 저장합니다.
  • 그래도 안 되면 IP(작업 장소)가 바뀌었는지 봅니다. 대표님은 계속 집에서 작업하셔서 이번엔 원인이 아닌 것으로 보입니다.
  • 다시 안 되면 혼자 일주일씩 붙잡지 말고 컨설팅을 예약해서 원격으로 같이 보는 게 빠릅니다.
2프로그램이 안 돼도 소싱 연습은 가능“프로그램이 안 돼도 소싱하는 거는 한번 연습해 보셔도 되긴 하거든요.”▾
  • 자동등록이 멈춰도 상품 찾기(소싱)는 따로 연습할 수 있습니다. 찾은 상품은 꼬리물기 시트에 모아 두면 됩니다.
  • 급하면 수동 등록도 가능합니다. 방법은 강의(1강 뒷부분)에 있습니다.
  • 강의를 흘려듣기만 하면 연결이 안 됩니다. 영상을 옆에 틀어 놓고 클릭을 하나씩 따라 해 보시면 훨씬 빨리 이해됩니다.
3베스트 소싱 한 바퀴 (시연)“수량을 먼저 보세요.”▾

준비

  • 네이버 가격비교와 에누리 두 창을 나란히 띄워 크기를 맞춰 둡니다.
  • 베스트 › 1차·2차·3차 카테고리 중 하나를 잡고(오늘은 스킨케어), 해외직구 제외, 80개, 카탈로그 기준으로 위에서부터 차례로 내려갑니다.

한 상품 보는 순서

상품명 복사 → 에누리 검색
→
네이버 ‘수량’에서 가장 싼 묶음
→
개당 가격 + 배송비 3,000원
→
본사(공식 판매처)인지
→
안 되면 에누리 확인 후 패스
  • 예: 2개 18,000원 → 개당 9,000원 + 3,000원 = 12,000원. 1개 카탈로그 가격과 차이가 없어 패스.
  • 예: 마스크팩 50매 49,500원 → 10매 기준 약 1만 원. 역시 비싸서 패스.
  • 예: 4개 묶음이 가장 싸서 계산상 가능해 보였지만, 판매처가 모두 본사가 아니라 패스.

본사(공식 판매처) 확인 세 가지

  • 마켓명 옆 공식 표시가 있는지
  • 상세페이지에 ‘○○ 공식 판매처’ 문구가 있는지
  • 판매처 이름이 브랜드와 맞는지. ‘검증된 정품 판매’ 같은 문구에 속으면 안 됩니다. 본사가 아닙니다.

에누리에서는

  • 항상 배송비 포함을 먼저 체크합니다. 안 누르면 숫자가 달라져서 다시 해야 합니다.
  • 카탈로그가 안 보이면 상품명 뒤쪽 단어를 지워 짧게 검색합니다.
  • 카탈로그에서 파란 글자(가장 저렴한 쪽) 숫자를 눌러 들어가 확인합니다.
4대표님 직접 실습에서 나온 포인트연습“제가요? 한 번도 안 해봤는데.” “해봐야죠.”▾
  • 상품명은 앞부분만 드래그해서 복사합니다. 다른 상품명과 겹치면(예: 세포랩) 검색창을 싹 지우고 다시 복사합니다.
  • 에누리 검색이 로딩되는 동안 네이버 쪽 수량을 먼저 보면 시간을 아낍니다.
  • 실습 상품: 3개 58,000원 → 개당 약 2만 원이라 패스.
  • 2개·3개 가격이 거의 같으면 헷갈릴 수 있는데, 크게 싼 게 없으면 바로 넘어가면 됩니다.
  • 다 본 상품은 네이버 카탈로그 창만 닫고 다음 상품으로 넘어갑니다. (전체 창을 닫는 게 아닙니다)
  • 대표님은 카드가 없으셔서 카드 할인은 계산에서 빼고 봅니다.

  • 베스트에서 마진 1,000원 이상 남는 상품을 찾으면 꼬리물기 시트에 정리합니다.
  • 상품명에서 지칭 단어를 뽑고, 카테고리·제조사·브랜드로 각각 검색해 비슷한 상품을 이어서 찾습니다.
6오늘의 할인으로 바로 등록하기“첫 번째는 마진 1,000원 이상 남는지, 두 번째는 판매처가 공식 판매처인지.”▾
① 마진 1,000원 이상
+
② 공식 판매처
  • 말 그대로 그날 할인이라 내일 바로 풀릴 수 있습니다.
  • 먼저 묶음인지 낱개인지 보고, 상품 옆 돈 아이콘을 누르면 예상 마진 계산이 나옵니다.
  • 대표님은 건기식 판매가 안 되시므로 건기식은 패스합니다.

예시: 닥터올가 (화장품)

  • 낱개 9,900원에 구매 → 카탈로그보다 10원 싸게(약 15,050원) 올려도 약 4,000원 남는 계산.
  • 제목 클릭 → 가격비교로 넘어가 상세페이지를 끝까지 내려 공식몰(본사)인지 확인했습니다.
7카탈로그 담기 → 자기 전 대량등록주의“자기 전에 이거 돌려주시면 돼요.”▾
마진 확인된 카탈로그 창
→
자동등록 창 ‘카탈로그 담기’
→
하나씩 모아 두기
→
자기 전 ‘대량등록 시작’
  • 카탈로그 화면을 켠 상태에서 담기를 누르면 링크가 바로 들어옵니다. 오늘의 할인뿐 아니라 직접 소싱한 상품도 같은 방식으로 올립니다.
  • 등록 1건당 비용은 약 200원입니다.
  • 시연 중 창이 두 개 열려 있어서 의도하지 않은 상품(토리든)이 함께 등록되기 시작했습니다. 등록할 때는 창을 하나만 열어 두세요.
  • 이 상품은 마진 계산 없이 들어간 것이라 판매되면 안 됩니다 → 판매중지.
8비용 확인과 등록 결과 보기“토큰이 없어서 안 된다고 써지거든요.”▾
  • 남은 금액은 구글 AI 스튜디오에서 대략 확인할 수 있습니다.
  • 대표님은 설치할 때 안내대로 자동 충전을 해 두셨을 것으로 보입니다. 한 번 들어가서 확인해 보세요.
  • 잔액이 없으면 등록 시 토큰 부족 메시지가 뜹니다. 그때 충전하면 됩니다.
  • 등록 결과는 자동등록 창 ‘담김’에서 봅니다. 진행 중(예: 상세 이미지 텍스트 추출 중) → 등록 완료 또는 실패 사유가 표시됩니다.
