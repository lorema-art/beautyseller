김미진 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

본업과 병행하느라 요즘 소싱을 많이 못 하셨고, 목표는 상품 100개 등록입니다. 이번 상담은 꼬리물기 시트를 정리하고, 함께 소싱을 돌려 보며 검색어 줄이기와 판매처 판단 기준을 맞췄습니다.

정리한 것

바탕화면에 흩어진 꼬리물기 파일을 하나로 정리(261018로 저장, 나머지 삭제). 휴대폰 특가 알림으로 올린 상품(마스크, AHC 리얼 아이크림, 바디워시)은 시트에 ‘특가’로 따로 표시했습니다.

함께 본 것

레티놀 세럼 줄에서 이어 프리메라·라네즈·리프트 세럼 등을 봤고, 대부분 카탈로그가 없거나 마진이 안 맞아 넘겼습니다. 이지듀는 셀러허브 판매처 기준 약 7,000원 마진으로 위탁 가능 후보가 나왔습니다.

다음

지금 등록 상품 수가 적어서 등록이 우선입니다. 다음 주 수요일(10/28)까지 기존 꼬리물기 줄로 해 보고, 그래도 안 나오면 베스트부터 새로 소싱합니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1꼬리물기 시트 정리“헷갈리니까 나머지는 삭제하시는 게 나을 것 같아요.”▾
  • 바탕화면에 꼬리물기 파일이 두 개 있었고, 둘 다 수정 날짜가 9월이라 10월 작업분이 어디 있는지 헷갈렸습니다.
  • 지금 쓰는 파일을 바탕화면에 261018(날짜) 이름으로 다시 저장하고, 나머지 파일과 바로가기는 삭제했습니다.
  • 앞으로는 이 파일 하나만 열어서 이어 갑니다.
2특가로 올린 상품은 따로 표시시트에 ‘특가’“특가들은 특가가 바뀌잖아요.”▾
  • 마스크, AHC 리얼 아이크림, 바디워시는 꼬리물기가 아니라 휴대폰에 뜬 특가 알림을 보고 올린 상품입니다. 시트에 ‘특가’로 적어 꼬리물기 줄과 구분했습니다.
  • 이렇게 등록해도 되지만, 특가(단기 할인)는 할인이 빨리 풀려서 다시 사기 어려울 수 있습니다.
  • 특가로 사 둔 상품은 사무실로 보내 재고가 있지만 아직 판매 전입니다.
  • 꼬리물기의 출발점은 레티놀 세럼(레티놀 앰플에서 들어간 줄)입니다. 9월 30일 기록이라 2~3주가 지나 할인이 많이 풀렸을 수 있지만, 일단 여기서 이어 갑니다(비타티놀 등).
3카탈로그 가격관리 한 번 물갈이“에누리 검색해서 최저가 되면 10원 저렴하게, 안 되면 만 원 올려 주시고요.”▾
  • 가격관리 프로그램이 자동으로 돌고 있어 오늘은 괜찮았습니다. 다만 스마트스토어에서 카탈로그 가격관리로 직접 들어가 보는 건 아직 안 하셨습니다.

등록된 상품 하나씩

  1. 에누리에서 검색해 실제 최저가 확인
  2. 맞출 수 있으면 최저가보다 10원 싸게
  3. 단가가 안 맞으면(손해) 1만 원 올려 두기
  • 한 번 싹 정리해 두되, 지금은 이것보다 상품 등록이 더 중요합니다. 등록 상품이 적으면 그 상품이 안 팔릴 때 매출이 그대로 0입니다.
4함께 소싱하며 맞춘 기준“3, 4 단어만 놔두고 지우시면 되거든요.”▾

키워드 고르기

  • 검색했는데 한 브랜드(예: 프리메라)만 나오는 키워드는 의미가 없습니다. 파란색으로 표시하고 넘어갑니다. 다 본 줄은 빨간색으로 표시합니다.
  • 리뷰가 10개 이하인 상품은 보지 않고 넘어갑니다.

에누리에서 찾는 순서

  1. 상품명 복사 → 에누리에 붙여 검색, 배송비 포함 체크
  2. 카탈로그가 있는지 확인. 카탈로그가 나오면 다른 판매처를 하나하나 볼 필요 없습니다.
  3. 없으면 상품명 뒤쪽(용량·세부 이름)을 지우고 다시 검색. 브랜드는 남겨 두고, 3~4단어만 남깁니다. 다 지우면 너무 많이 떠서 오히려 못 찾습니다.
  4. 그래도 없으면 바로 패스
  5. 파란 글자 최저가를 눌러 카드 할인이 붙는지 확인. 카드 할인이 없어 단가가 안 맞으면 패스

5이지듀: 셀러허브에서 사도 되나등록 후보“셀러허브는 유명한 곳이라 여기서 구매하셔도 되기는 해요.”▾
  • 에누리 최저가를 따라가 보니 쿠폰 적용으로 저렴하게 파는 곳이 공식 본사가 아니라 백화점 몰에 입점한 셀러허브(대형 리셀러)였습니다. 홈쇼핑이 아니면 개인·법인 사업자도 입점할 수 있습니다.
  • 뷰셀이 ‘공식 판매처에서만’ 기준을 빡빡하게 잡은 건, 기준이 느슨하면 아무 데서나 사는 분들이 생겨서입니다. 강사님 기준은 조금 더 유연합니다.

공식몰이 아닐 때 사도 되는 조건

  • 판매자 정보 확인 → 리뷰가 있고, 한국인(한국 사업자)이 판매
  • 셀러허브처럼 큰 리셀러는 대량으로 사 두고 파는 곳이라 구매해도 됩니다. 화장품은 유통기한이 보통 3년 안팎이라 크게 걱정하지 않아도 됩니다.

보내는 방법

  • 마진이 약 7,000원 남아 위탁이 가능합니다. 주문이 들어오면 거기서 고객 주소로 바로 보내면 됩니다.
  • 마진이 넉넉하니 택배비 3,000원을 더 들여 사무실로 받아 보내도 괜찮습니다.
6등록 방법과 가격 메모“너무 품 들이지 말고 하시는 게 나을 것 같아요.”▾
  • 프로그램의 카탈로그 담기로 담아 두면 등록이 더 편합니다.
  • 대표님은 얼마에 올렸는지 잊지 않으려고 시트에 따로 적어 두는 방식을 쓰고 계십니다. 적으셔도 되지만, 가격관리가 돌면 판매가는 계속 바뀌고 주문이 오면 어차피 다시 찾으니 여기에 너무 힘을 쓰지 않아도 됩니다.
7반품, 원격 접속“물류 담당자분께 요청하시면 돼요.”▾
  • 반품이 생기면 물류 담당자에게 요청하면 됩니다. 아직 반품이 많지는 않습니다.
  • 원격 접속이 4~5분마다 끊겼습니다. 대표님 화면에 코드가 5분 뒤 만료된다고 뜨고, 지난번에도 같았습니다. 다음 상담 때도 끊기면 새 코드를 불러 주시면 됩니다.
8100개까지 가는 법“너무 안 나온다 싶으면 베스트부터 다시 해 보시는 것도 방법이에요.”▾
