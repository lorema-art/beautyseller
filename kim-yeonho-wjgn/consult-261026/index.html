김연호 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

들어온 첫 주문 1건으로 주문 확인부터 고객 배송까지 전체 흐름을 원격으로 함께 처리했습니다. 정렬·세팅은 2주차에 자세히 다루고, 그 전까지 들어오는 주문은 오늘 순서대로 처리하시면 됩니다.

지금 상태

오늘의 할인 상품으로 올린 상품에 주문 1건이 들어와 발주 전 상태였습니다. 동기분들이 같이 올리는 상품이라 가격이 바뀌었을 수 있어 최저가부터 다시 확인했습니다.

오늘 처리한 것

엑셀 다운 → 발주 확인 → 네이버·에누리 최저가 비교 → 4개 묶음(21,300원) 쿠팡 구매, 사무실로 배송 → 셀수다에 입고 신청 + 배송 요청 등록까지 마쳤습니다.

앞으로

내일 오전 사무실 도착 후 당일 출고되고, 운송장은 스마트스토어에 자동 입력됩니다. 남은 3개는 재고로 두고 다음 주문 때 바로 보냅니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

운송장 자동 입력
  • 배송 요청까지 등록하면 그 뒤로는 따로 만질 일이 없습니다. 출고되면 운송장이 스마트스토어에 자동으로 들어가 발송 처리됩니다.
2주문 확인 — 발주 확인은 꼭주의“물건은 보냈는데 환불이 자동으로 돼요.”▾
  • 신규 주문(발주 전)을 선택해 엑셀을 먼저 다운로드합니다. 비밀번호는 0 또는 1234처럼 간단하게 둡니다.
  • 그다음 발주 확인을 꼭 누릅니다. 안 누르면 물건을 보낸 사이 고객이 취소했을 때 환불이 자동으로 처리돼, 물건은 나가고 돈은 날아갑니다.
3엑셀 정리 → 판매 장부“초기에 세팅을 안 해 놓으면 다 지워야 되는 번거로움이 있어요.”▾
  • 엑셀을 열고(비밀번호 0) 편집 사용 → 첫 줄 삭제 → 배송에 필요한 정보만 남깁니다. 아직 발송 전이라 운송장 같은 열은 모두 지웁니다.
  • 남길 것: 수취인명(구매자명보다 중요), 상품명, 옵션, 수량, 상품 총 주문금액, 주소지.
  • 정리한 내용을 복사해 판매 장부에 붙여 둡니다. 판매 장부 서식은 뷰셀이 보내드립니다.
  • 지금은 정렬이 안 되어 있어 손으로 지우지만, 2주차에 정렬 세팅을 하면 이 과정이 없어집니다.
4최저가 비교 — 네이버 vs 에누리핵심“세 개의 구성 중에 제일 저렴한 게 몇 개짜리일까요?”▾

네이버

  • 상품명에서 브랜드명부터 용량 앞 숫자까지만 복사해 검색하면, 등록할 때 본 카탈로그가 나옵니다.
  • 수량 구성 3개 중 4개 구성이 가장 저렴: 21,300원 ÷ 4 = 개당 5,325원.

에누리

  • 가격 비교 사이트로, 네이버처럼 카탈로그가 있고 싼 곳부터 보여줍니다. 배송비 포함을 먼저 켜고 봅니다.
  • 같은 4개 구성이 34,000원 → 네이버가 더 쌉니다. 네이버(쿠팡 판매처)에서 구매하기로 했습니다.
5마진 계산과 남는 재고“안 팔리면 제가 매입해 드릴 거니까요.”▾
  • 개당 5,325원에 분할 재발송 배송비 3,000원을 더해 마진을 봅니다. 이번 상품은 마진이 간당간당하게 남습니다.
  • 소싱할 때는 1,000원 이상 남는 상품을 찾지만, 판매 단계에서는 매출 3,000만 원까지 마진에 크게 구애받지 않고 회전시킵니다.
  • 고객은 1개 주문 → 4개를 사서 1개만 보내고, 남은 3개는 재고로 두었다가 다음 주문이 들어오면 바로 보냅니다.
  • 끝까지 안 팔리면 뷰셀이 매입해 드립니다.
6사무실 주소로 구매하기“사서함 번호를 주소 뒤에 붙여 주시는 거예요.”▾
  • 쿠팡에 로그인(QR 로그인)하고 쿠폰을 받은 뒤 주문합니다. 배송지는 새로 하나 만듭니다.
  • 사무실 주소는 셀수다 재고 입고 요청 화면에 있습니다. 주소 뒤에 대표님 사서함 번호(다041)를 꼭 붙입니다. 그래야 들어온 물건이 누구 것인지 구분됩니다.
  • 받는 사람은 대표님 성함·연락처로 적고, 출입은 문 앞 / 언제든 출입 가능(새벽 포함)으로 설정합니다.
  • 오전 9시까지 사무실에 도착한 상품은 당일 출고합니다. 이번 건은 내일 새벽 도착 예정입니다.
7셀수다 — 입고 신청 + 배송 요청핵심“웬만하면 건수가 별로 없더라도 엑셀로 진행을 하세요.”▾

입고 신청 (재고관리 → 입고 신청)

  • 카탈로그명(상품명) 기준으로 입력, 옵션은 있을 때만.
  • 수량 4개, 개당 매입가 5,325원, 구매처 쿠팡 → 입고 등록. 뷰셀이 실시간으로 보고, 입고되면 검수일자를 적어 드립니다. 이 화면으로 재고를 관리하시면 됩니다.

배송 요청 (배송요청 → 엑셀로 한 번에 등록)

  • 엑셀 템플릿은 처음 한 번만 받으면 됩니다.
  • 고객 정보 입력: 받는 사람, 카탈로그명, 옵션(없으면 비움), 수량(1개), 연락처, 주소, 배송 메시지는 있을 때만.
  • 저장 → 파일 선택 → “1건 읽음” 확인 → 등록하기 → 확인. 건수가 적어도 엑셀로 등록하는 습관을 들입니다.

  • 2주차 전까지 들어오는 주문 처리 김연호엑셀 다운 → 발주 확인 → 최저가 비교 → 사무실로 구매 → 입고 신청 → 배송 요청
