권정은 대표님 1:1 컨설팅 정리

2026년 10월 15일 · 권정은 대표님, 뿌요 교육실장 · 원격으로 화면 함께 보며 진행

하루 5개꼬리물기 등록 숙제
권정은 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

베스트 소싱으로 올린 상품에서 주문은 들어오는데(도브·일리윤 등) 막상 남는 돈이 적어 “제가 잘하고 있는 건지” 고민이 많으셨습니다. 이번에는 질문이 많아 질문 위주로 진행했고, 역마진·의심 주소 처리 기준, 포인트 마진 계산, 꼬리물기 시작 방법을 함께 정리했습니다. 베스트는 충분히 하셨으니 이제 꼬리물기로 하루 5개를 등록합니다.

잘하고 있는 것

10월 10일부터 베스트 소싱을 많이 해 두셨고, 올린 상품 중 4~5개에 주문이 들어왔습니다. 주문 들어올 때 카탈로그·에누리를 다시 확인하고 계시고, 일리윤 리뉴얼(564ml) 대체 발송도 잘 처리하셨습니다.

바로잡을 것

소싱할 때는 마진 1,000원 이상만. 주문이 들어왔을 때는 1원이라도 플러스면 발송, 역마진이면 취소하지 말고 배송지연 후 세일 때 다시 봅니다. 베스트 1페이지 전체를 AI로 긁는 건 시간 대비 효과가 적으니 꼬리물기로 넘어갑니다.

마음가짐

처음엔 1~2천 원씩 남는 게 정상입니다. 멘토들도 똑같이 천 원, 2천 원, 3천 원 하다가 가끔 1만 원 넘게 남는 상품을 만납니다. 계속 보다 보면 시야가 조금씩 트입니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1마진 기준: 소싱 1,000원↑, 주문 시 플러스면 발송중요“저는 주문 들어왔을 때 마진이 플러스 1원이면 보내거든요.”▾
  • 도브 바디워시·일리윤 세라마이드처럼 주문은 많이 들어오는데 남는 게 거의 없고, 소싱 당시 찾아 둔 구매처가 주문 시점엔 없어서 2,000원 남길 걸 1,000원 남기는 일이 많았습니다.
  • 상품 가격은 고정이 아니라 계속 바뀝니다. 그래서 구매 링크를 적어 둬도 주문이 들어오면 카탈로그·에누리 기준으로 한 번 더 확인합니다.
  • 소싱할 때는 무조건 마진 1,000원 이상만 올립니다. 처음부터 적게 남는 상품은 주문 들어올 때 더 줄어듭니다. 1,000원 이하도 올렸던 교육실장도 나중에 더 힘들었다고 합니다.
  • 주문이 들어왔을 때는 조금이라도 플러스면 발송합니다. 예: 도브는 소싱 때 1,430원으로 계산했지만 주문 시 약 480원 → 보냅니다. 이렇게 조금씩 벌다 보면 더 큰 마진 상품이 보입니다.
2역마진은 취소 말고 배송지연“발송 취소 말고 뒤로 미뤄 놨다가 다시 한번 들어가서 찾아보면…”▾
주문 시 역마진
→
배송지연 처리
→
주말·월초·월말 세일 때 재확인
→
마진 나면 발송
  • 바로 취소하지 않습니다. 월말에 세일이 많으니 그때 다시 찾아보고 보냅니다.
  • 포인트로 마진을 맞추는 경우 포인트 한도까지 쓰고, 그 이상 포인트가 안 되면 그때부터 역마진으로 처리합니다(4번 참고).
3창고·본사처럼 보이는 주소“검색했는데 딱히 안 나오는데 의심스럽다 싶으시면 배송지연 하시면 돼요.”▾
  • 창고 주소에 박스에 ‘LA’라고 적어 달라며 5개를 주문한 건이 있었습니다. 마진도 안 남아 배송지연 처리해 두셨습니다.
  • 창고나 본사처럼 보이는 주소는 간혹 들어옵니다. 먼저 주소를 검색해 봅니다.
  • 의심스러운데 마진이 남으면 뷰셀 사무실로 받았다가 고객에게 보내는 방식으로 진행하고, 그래도 마진이 남으면 발송, 안 남으면 배송지연합니다.
4포인트로 남는 마진 계산법중요“천 원은 안 커 보이는데 쌓이게 되면 몇십만 원씩 쌓이거든요.”▾
  • 찾은 상품 대부분이 옥션·11번가 등의 멤버십 적립 포인트로 마진이 남고, 카드 즉시할인은 많지 않습니다(카드 적립은 7만 원·5만 원 같은 한도가 있음). 이렇게 보셔도 됩니다.
  • 기준: 네이버·G마켓 둘 다 로그인한 상태에서 보이는 포인트 결제 금액으로 계산합니다.
  • 소싱할 때는 포인트가 무한하다고 보고 찾습니다. 올린 상품이 다 팔리진 않으니, 주문이 오면 포인트 한도까지 쓰고 넘으면 역마진 처리합니다.
  • 마진 계산에서 빼는 것: 리뷰 적립, 머니 결제 적립(카드로 결제하니까), 카드 적립(일회성).
  • 네이버 멤버십 포인트는 구매 확정 후 쌓이고, 마이쇼핑의 멤버십 게이지에서 확인합니다. 화면의 5만 5천 원은 3개월 누적 표시이고, 지금 쓸 수 있는 건 약 5,300원이었습니다. 적립 예정액을 따로 보는 곳은 없고, 결제 전 화면에 보이는 금액으로 봅니다.
  • 결제할 때: 다른 결제 보기 → 카드 간편결제 → 네이버 현대카드, 포인트를 쓰려면 금액 입력하기에서 넣습니다.
  • 브랜드가 한 번씩 10% 슈퍼적립 같은 포인트를 크게 줄 때 판매가 확 뛰기도 합니다.
5베스트 시트와 AI 수집“이렇게 하면 대표님 시간이 너무 많이 들 텐데요.”▾
  • 바디케어(해외직구 제외) 베스트 1페이지를 통째로 GPT·클로드에 붙여 브랜드 카탈로그·쇼핑몰 최저가를 뽑고, 에누리에서 같은 이름(안 나오면 짧게)으로 찾게 해 두셨습니다. 아직 검수는 못 하셨습니다.
  • 마진 남는 것만이 아니라 전체를 붙인 거라 시간이 많이 듭니다. 베스트는 충분히 하셨으니 이제 꼬리물기로 넘어갑니다.
  • 시트의 노란색은 업로드한 상품, 그중 주문이 들어온 건 4~5개입니다.
6꼬리물기 시작하기: 지칭 단어부터새 숙제“이 상품이 어떤 키워드로 나왔는지를 저희가 확인을 해야 돼요.”▾
  • 기존 꼬리물기 틀(4가지 방향 키워드)에 날짜와 키워드를 꼭 적습니다. 시트에 추가해도, 꼬리물기 시트에 따로 써도 됩니다.
  • 마진 1,000원 이상으로 업로드한 상품을 기준으로 시작합니다. 예: 일리윤 → 한 단어로 ‘로션’.
  • 지칭 단어는 브랜드·대표 수식어를 빼고 로션을 기준으로: 세라마이드 로션, 아토 로션, 무향 로션, 건성 로션, 민감성 로션, 그리고 용량까지.

검색하는 순서

네이버 쇼핑 + 에누리 창 나란히
→
80개씩 보기, 3개쯤 열어 비교
→
개당가로 마진 계산
→
안 되면 에누리 확인
  • 개당가 예: 3개 35,000원 → 개당 약 11,000원 + 마진 3,000원이면 14,000원 → 역마진이라 패스.
  • 에누리에서는 배송비 포함 체크, 카탈로그가 있는지 보고, 없으면 단어를 지워 짧게 만들어 다시 검색합니다(검색 결과가 더 많이 나옴). 그래도 없으면 패스.
  • 공식몰로 보이는 곳 가격(예: 17,810원)이 판매가보다 300원 비싸면 패스.
7카테고리·제조사·브랜드 보는 방법“1,000개 기준으로 만약에 1,000개가 없으면 그 자체만 보면 돼요.”▾
  • 지칭 단어 검색이 끝나면 뒤의 카테고리(예: 바디로션)로 검색해 1페이지 끝까지, 그다음 제조사·브랜드입니다.
  • 제조사·브랜드는 방식이 살짝 다릅니다. 검색해서 1페이지(40개 기준)를 끝까지 본 뒤, 카테고리 화살표를 눌러 뒤에서부터 1,000개 기준으로 들어가 각각 1페이지씩 봅니다.
  • 하위 카테고리가 있으면 4~5단계까지 순서대로 끝까지 들어갑니다. 초록색이 뜨면 더 들어갈 곳이 없다는 뜻입니다.
  • 카탈로그가 없거나 리뷰 10개 미만이면 패스합니다.
  • 검색한 제조사와 실제 제조사가 같은지 상품 정보에서 확인합니다. 예: ‘아모레퍼시픽’으로 찾았는데 ‘아모레’만 적혀 있으면 다른 곳이니 바로 패스.
8베스트는 언제 다시 보나“기업에서 계속 신제품을 내잖아요. 끝이 날 수가 없죠.”▾
  • 원하는 카테고리를 레벨 3까지 다 했어도 끝이 아닙니다. 신제품·리뉴얼이 계속 나옵니다.
  • 꼬리물기를 위로든 아래로든 다 했는데 더 이상 나오는 상품이 없을 때 = 지금 할인 중인 상품을 못 찾고 있다는 뜻 → 그때 다시 베스트로 돌아갑니다.
9일리윤 용량 리뉴얼(568 → 564ml)“잘하셨어요 대표님.”▾
  • 568ml가 더 이상 나오지 않고 564ml로 리뉴얼돼, 주문 건을 564ml로 보내셨습니다. 이렇게 대체해 보내셔도 됩니다.
  • 리뉴얼 전후로 판매가가 크게 바뀌니, 대체 발송할 때 마진을 다시 확인합니다.
10오늘의 할인은 참고만“시간이 너무 부족해서 당장 상품 올려야 되는 분들이 빠르게 올리도록 만든 거예요.”▾
  • 오늘의 할인으로 샤넬 향수를 올렸다가 정지를 당했고, 들어가 보면 금액이 다른 경우도 많아 지금은 잘 안 쓰고 계십니다. 도브 등 주문 들어온 일부는 오늘의 할인에서 올린 상품입니다.
  • 하루 2~3시간 쓰실 수 있으니 베스트·꼬리물기 중심으로 갑니다.
11발주 주소 입력“그 방법 말고는 사실 없긴 해요.”▾
  • 네이버든 다른 사이트든 주소는 하나씩 입력해야 합니다. 이름·전화번호·주소 복사 붙여넣기가 제일 빠릅니다.
  • 목표 속도는 15분에 5건 정도. 주문이 몰리면 최신 주문부터 처리하고, 이전 건은 배송지연합니다.
  • 엑셀로 정리해 더 빠르게 입력하는 방법은 하시다 보면 차차 알려드립니다. 교육실장은 유료 대량 주문 프로그램은 쓰지 않고, 아침 1시간·오후 1시간처럼 시간을 나눠 처리합니다.
12사입 vs 온라인 위탁, 도매창고 목록“손가락만 까딱까딱 하면 되는 거라서 이게 훨씬 더 편한 것 같아요.”▾
  • 사입한 레몬 허니가 처음엔 비싸게 팔리다 시장 가격이 떨어져 팔지 못하고 있습니다. 가격이 계속 바뀌니 사입은 위험할 수 있습니다.
  • 교육실장도 처음엔 오프라인 창고를 다녔지만 시간이 많이 들어, 지금은 사입·위탁을 같이 보되 에누리 등 온라인에서 주로 찾습니다.
  • 도매창고(비밀창고) 목록은 받는 곳을 모르셨는데, 라이브 끝나고 드리는 것으로 압니다 → 카톡으로 따로 문의해 받으세요.

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 꼬리물기로 하루 5개 찾아 등록 권정은하루 2~3시간 · 업로드한 베스트 상품 기준 · 날짜·키워드 기록
  • 소싱은 마진 1,000원 이상만 권정은주문 시엔 카탈로그·에누리 재확인 → 플러스면 발송
  • 역마진 주문은 배송지연 후 세일 때 재확인 권정은바로 취소하지 않기 · 주말·월초·월말
  • 의심 주소는 검색 먼저 권정은마진 남으면 뷰셀 사무실 경유 발송, 아니면 배송지연

  • 질문은 셀수다 프로그램 ‘질문하기’에 권정은코치님들이 빠르게 답변
