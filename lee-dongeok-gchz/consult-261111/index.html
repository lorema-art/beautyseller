이동억 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

주문 이후 단계를 한 번도 해 보지 않아 막막해하셨고, 택배비 충전 창도 잘 안 된다고 하셨습니다. 이번에는 택배비 충전부터 자동 소싱 프로그램 설치, 그리고 실제 주문 1건을 발주 확인 → 본사 구매 → 입고 등록 → 배송 요청까지 직접 해 보셨습니다. “해 보니까 괜찮네요”라고 하셨습니다. 세팅은 끝났으니 이제 할 일은 소싱량을 늘리는 것입니다.

꼭 지킬 순서

주문이 오면 엑셀 다운 → 발주 확인을 먼저 하고 구매합니다. 발주 확인을 안 누르면 고객이 취소할 때 자동 환불되어 물건만 남습니다.

새로 세팅한 것

자동 소싱 프로그램을 설치했습니다. 시간이 없을 때 돌려 두는 보조 수단이고, 꼬리물기는 계속 직접 합니다.

지금 필요한 것

상품 수를 늘리면 주문이 크게 늘어납니다. 시간이 많지 않으셔도 소싱을 더 해 주세요.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1지금 상황“주문 들어왔을 때 다음 단계를 한 번도 안 해 봐서요.”▾
  • 오랜만에 다시 하던 중 주문 하나가 취소되었고, 발주를 정확히 어떻게 하는지 모르셨습니다.
  • 어제 택배비 결제 창이 잘 안 됐고, 특강에서 들은 자동 소싱 프로그램 설치법도 궁금하셨습니다.
2택배비 충전하기“보통은 저녁 10시에 한꺼번에 입금 처리를 해요.”▾

  • 설치 파일은 단톡방에 안내한 드라이브에서 받습니다. 사이트의 ‘무료자료 → 프로그램 받기’에 있는 것은 다른 버전입니다.

  • 컴퓨터를 켜 두면 계속 돌아갑니다. 중간에 멈추면 껐다 켜서 다시 돌립니다.
  • 결과에서 ‘등록 가능’·‘신뢰도 높음’으로 뜬 상품만 등록하고, 그 아래는 등록 불가입니다. 수량 칸에 적힌 숫자가 카탈로그 수량입니다.
4프로그램이 있어도 꼬리물기는 계속중요“사람이 하는 게 좋아요.”▾
  • 프로그램은 네이버만 보고 에누리는 보지 않습니다.
  • 강의에서는 잘 팔리는 메인 구성과 1개짜리만 올리라고 했지만, 프로그램은 마진이 남으면 그 이상 구성(예: 4개짜리)까지 다 올립니다. 이런 구성은 많이 찾지 않아 메인 대비 10~20% 정도의 주문이 들어온다고 보시면 됩니다.
  • 그래서 판매가 원활하려면 꼬리물기는 꼬리물기대로 하고, 프로그램은 시간이 없을 때 돌려 두는 양방향으로 갑니다. 프로그램만 돌렸을 때 월 수익은 수십만 원(약 30~80만 원) 수준으로 말씀드렸습니다.
  • 마진 구조 예: 4개 구성 네이버 판매가 약 12만 원, 본사에서 2개 약 4만 원이면 4개 약 8만 원에 사서 보내는 식입니다.

①② 엑셀 다운 → 발주 확인 (먼저!)

  • 구매 전에 반드시 엑셀을 받고 발주 확인을 누릅니다. 안 누르면 고객이 취소할 때 자동으로 환불되어, 이미 산 물건만 남습니다.
  • 발주 확인을 누르면 주문이 ‘발주 후’로 넘어가니, 엑셀을 먼저 받아 둡니다.

③ 본사에서 구매

  • 배송지는 재고관리에 있는 주소로 넣고, 상세주소까지 넣은 뒤 주소 맨 뒤에 사서함 번호를 붙입니다(이름은 별표로 가려져서, 이름이 같은 수강생과 구분하려고 개인 사서함 번호를 드린 것).
  • 결제는 카드가 좋습니다(카드 할인). 발급받은 카드가 오면 등록해 두세요.
  • 현금영수증은 꼭 사업자로, 그중에서도 스토어 매출이 나오는 사업자로 받습니다. 아니면 세금 문제가 생길 수 있습니다.

④ 재고관리 → 입고 등록

  • 카탈로그명, 산 수량(이번엔 3개), 공급가(배송비 포함 산 금액), 구매 사이트(네이버 등 대표님이 알아볼 수 있게) 입력 → 입고등록. 옵션·메모는 없으면 비워 둡니다.

⑤ 배송요청 → 엑셀로 등록

  • 가급적 엑셀로 한 번에. 템플릿 받기 → 예시 지우고 수령인·상품명(카탈로그명)·수량·연락처·주소·배송 메시지 입력 → 저장 → 파일 선택 → 등록하기.
  • 주소가 두 칸으로 잘리면 한 칸으로 올려 줍니다. 칸 너비는 상관없습니다.
6그다음은 자동으로“운송장 입력하면 스토어에 자동으로 들어갈 거예요.”▾
  • 물건이 도착하면 매일 아침 9시에 검수하고, 그 전에 입고된 제품은 당일 발송합니다.
  • 운송장을 등록하면 연동된 스토어에 자동으로 발송 처리됩니다.
  • 택배비가 충전돼 있지 않아도 등록은 되지만, 택배비는 충전해 두셔야 합니다.
  • 회원 정보는 별표(*) 항목만 필수입니다.

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 택배비 충전하기 이동억배송요청 → 충전하기 · 무통장 입금 후 결제 버튼까지 · 반영은 보통 밤 10시
  • 주문 오면 엑셀 다운 → 발주 확인 먼저 이동억안 하면 고객 취소 시 자동 환불
  • 본사 구매 시 주소 뒤에 사서함 번호 이동억상세주소까지 · 카드 결제 · 현금영수증은 매출 나는 사업자로
  • 재고관리 입고 등록 + 배송요청 엑셀 등록 이동억카탈로그명·수량·공급가(배송비 포함)·구매 사이트 · 템플릿으로 한 번에
  • 발급받은 카드 등록 이동억카드 할인으로 매입가 낮추기
  • 자동 소싱 프로그램 돌려 두기 이동억키워드 콤마 구분 · ‘등록 가능·신뢰도 높음’만 등록
  • 꼬리물기로 소싱량 늘리기 이동억프로그램과 별개로 계속 · 상품 수가 늘면 주문이 늘어남
