이수영 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

강의를 아직 거의 보지 못한 상태에서 오신 첫 실습 컨설팅이었습니다. 네이버 가격비교 스킨케어 베스트를 함께 보며 소싱의 처음부터 끝까지(구성 고르기 → 가격 비교 → 마진 계산 → 본사 확인 → 자동등록)를 한 번 따라가 봤습니다. 오늘 본 상품은 모두 패스였지만, 처음보다 확실히 빨라지셨습니다. 이제 강의를 보고 혼자 실습해 본 뒤 다시 컨설팅을 잡습니다.

오늘 이해하신 것

판매할 수 있는 구성은 메인 구성과 1개짜리뿐이라는 기준을 여러 상품으로 연습해 잡으셨습니다. 네이버와 에누리를 함께 봐야 하는 이유(어느 쪽이 쌀지는 그때그때 다름)도 직접 확인하셨습니다.

판단 순서

싼 것부터 → 그다음 본사 확인. 저렴하지 않으면 본사인지 볼 필요가 없습니다. 마진은 네이버 수수료를 빼고 최소 1,000원, 판매가는 최저가보다 10원만 싸게.

다음 할 일

인베이더스쿨에서 강의 보기(특히 2주차) → 혼자 최소 2~3시간 실습 → 꼬리물기 시트 링크 공유 → 컨설팅 신청. 컨설팅은 웬만하면 사무실로 오셔서 진행합니다.

  • 카탈로그 아래 수량 구성 중 가장 먼저 나온 것이 메인입니다. 사람들이 가장 많이 사고 많이 찾는 구성이라 먼저 뜹니다.
  • 사람이 안 들어오는 구성은 100번 등록해도 팔리지 않습니다. 그래서 잘 팔리는 메인이 첫 번째 기준입니다.
  • 두 번째는 1개짜리. 조금 비싸도 1개만 원하는 사람이 있습니다(크림 100ml 두 개까지는 필요 없는 경우). 쿠팡에서 1개를 사면 조금 더 비싼 것과 같은 이치입니다.
  • 지금은 마진을 따지기 전에 “마진이 남는다는 가정하에 어느 구성을 팔 수 있나”부터 바로 보이도록 연습했습니다.

시작 세팅

  • 네이버 가격비교 → 카테고리 1차·2차·3차를 위에서 아래로(오늘은 스킨케어부터) → 해외직구 제외, 80개씩 보기.
  • 화면이 하나라 네이버는 왼쪽, 에누리는 오른쪽에 각각 화면의 2/3 정도로 겹쳐 놓습니다.

검색어 복사

  • 상품명에서 브랜드명부터 숫자까지, 단위(ml 등) 앞까지만 복사해 에누리에 붙여 넣습니다. 숫자 뒤 영어는 뺍니다. 예: 30ml면 ‘30’까지.
  • 에누리 로딩이 느리니 붙여 넣고 기다리지 말고, 그동안 네이버에서 가격을 봅니다.

네이버

  • 카탈로그 아래 가격 중 가장 싼 구성을 찾습니다. 아래 적힌 10ml당 가격을 보면 찾기 쉽습니다.
  • 메인만 보지 말고, 더 많이 샀을 때 더 싼 구성이 있으면 그 구성 기준으로 개당 가격을 구합니다(편의점 1+1·2+1처럼 대량으로 사면 보통 싸집니다).

에누리

  • 아래로 내려 ‘배송비 포함’을 먼저 켭니다. 같은 제품(사진 동일)인지 확인합니다.
  • 파란색으로 표시된 가격이 최저가입니다. 파란 게 안 보이면 아래 다른 수량 옵션을 눌러 보세요. 수량이 많으면 숨어 있습니다.
  • 파란 가격을 누르면 옆에 탭이 뜹니다. 카드 할인 버튼이 있으면 켜고, 눌러도 최저가가 그대로면 카드 할인이 없는 사이트입니다.
  • 네이버보다 비싸면 더 볼 필요 없이 패스합니다. 모든 판매처를 들어가 볼 필요는 없고, 저렴한 곳만 들어가 봅니다.
4마진 계산: 위탁과 사입, 그리고 판매가중요“10원 더도 말고 10원만 싸면 돼요.”▾

두 가지 출고 방식

  • 위탁: 주문이 들어오면 대표님이 바로 주문해서 고객 댁으로 보냅니다. 사는 곳이 무료배송이면 배송비가 따로 들지 않습니다.
  • 사입: 여러 개를 사서 사무실로 보내면 코치 쪽에서 나눠 출고합니다. 이때는 개당 가격에 배송비 3,000원을 더해서 계산합니다.
  • 둘 중 어느 쪽이든 마진만 남으면 됩니다. 양쪽으로 다 계산해 봅니다.

빠른 암산

  • 백 원 단위는 잘라내고(또는 짝수로 반올림) 나눕니다. 예: 18,800원 2개 → 18,000 ÷ 2 = 9,000원, 사입이면 + 3,000 = 12,000원. 네이버 1개 가격보다 비싸면 안 됩니다.
  • 나누기가 어려우면 바로 계산기를 켭니다.

마진계산기 (셀러드레스)

  • 사오는 가격, 수량, 포인트(없으면 비움), 판매가를 넣습니다. 네이버 수수료(약 6.3~6.7%)와 배송비가 반영됩니다.
  • 네이버 수수료를 빼고 최소 1,000원은 남아야 등록합니다.
  • 판매가는 최저가보다 10원만 싸게 잡습니다.
  • 예시로 4개짜리 192,500원 상품을 1개짜리로 판매한다고 넣었을 때, 택배비 3,000원을 포함해도 약 5,000원 남는 것으로 나왔습니다(이 상품은 본사 기준에서 탈락).

  • 요즘 국내에 가품 유통이 많아서, 마진이 남는 걸 찾았다고 바로 사지 않고 본사인지 확인합니다.

② 브랜드명 = 스토어명
③ 홈쇼핑 판매처
  • 세 가지 중 하나만 맞아도 됩니다.
  • ② 예: 브랜드가 세포랩이면 스토어명도 세포랩. 상품명(예: ‘사쿠라’)과 스토어명(예: ‘벤세마 스토어’)을 헷갈리지 않습니다.
  • ③ 홈쇼핑은 네이버에는 거의 없고, 다른 사이트에서 판매자명으로 보입니다. 홈쇼핑도 자기 사이트만으로는 잘 안 팔려서 이런 플랫폼에 입점합니다.
  • 스토어명이 안 보이는 플랫폼은 최저가 사이트에 직접 들어가 확인합니다. 사진이 흐릿하거나 글씨가 깨져 있으면 본사가 아닐 가능성이 높습니다.
  • 기준이 잡히기 전까지는 조금 빡빡해도 이 기준대로 갑니다. 그래도 찾아집니다. 정확한 판별법은 기준이 잡힌 뒤 따로 알려 드립니다.
