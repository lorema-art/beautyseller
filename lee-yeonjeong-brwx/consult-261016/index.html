하루 10개등록 숙제 (유지)
30~40초상품 하나 보는 속도
이연정 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

원격으로 대표님 화면에서 리프팅 마스크 꼬리물기를 같이 돌려 보며 마진 남는 상품 두 개를 찾았고, 멤버십 적립으로 위탁 마진을 계산하는 법과 가격관리 프로그램 점검법까지 정리했습니다.

지금 상태

지난주 숙제(하루 10개 등록)는 되는 날도, 아쉬운 날도 있었습니다. 꼬리물기에서 대략 1시간에 1개 정도 나오고, 한국콜마 쪽은 같은 상품만 반복돼 거의 안 나왔습니다. 그래도 지난주보다 확실히 빨라졌습니다.

이번에 찾은 것

닥터지 1개짜리 카탈로그(쿠폰가 기준 약 1,400원 마진), 톤28 공식몰 멤버십 적립을 반영한 위탁(약 2,000원 마진).

앞으로

숙제는 그대로 하루 10개 등록. 10개가 되면 20개로 올립니다. 2~3개월 바짝 상품을 밀어 넣는 시기라, 인내심을 갖고 꾸준히 가시면 됩니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1에누리에서 볼 때 기준핵심“파란색 기준으로 해서 저렴한 것만 클릭해서 보세요.”▾
‘배송비 포함’ 체크
→
파란색 최저가 중 수량 맞는 것만 클릭
→
카드 할인 실제로 되는지 확인
→
안 되면 바로 패스
  • 배송비 포함을 체크해야 합니다. 체크 여부에 따라 나오는 순서와 개수가 달라질 수 있습니다.
  • 카탈로그가 12개짜리면 1개짜리는 누르지 말고 12개짜리만 눌러 할인되는지 봅니다.
  • 묶음 연결은 프로그램이 자동으로 하는 거라 가끔 수량이 엉뚱하게 이어져 있습니다. 직접 들어가서 구성이 맞는지 확인합니다.
  • 네이버 메인 카탈로그가 몇 개(몇 매)짜리인지 먼저 확인합니다. 10매인 줄 알았는데 20개짜리면 계산이 완전히 달라집니다.
  • 묶음은 나눠서 볼 수 있습니다. 예: 5개짜리를 1매씩 나눠 파는 건 가능합니다.
  • 가격 차이가 조금밖에 안 나면 배송비 3,000원을 넣으면 남지 않습니다. 어느 정도 차이가 있어야 합니다.
2카탈로그가 안 뜰 때: 과감하게 지우기“애매하게 지우는 것보다 그냥 확 지워서 세 단어만 남기세요.”▾
  • 에누리에서 카탈로그가 안 나온다고 한 단어씩 지우면 시간이 오래 걸립니다. 뒤쪽부터 확 지워서 세 단어 정도만 남기세요.
  • 그렇게 해도 카탈로그가 없거나 해당 상품이 안 나오면 그냥 넘어갑니다.
  • 마스크팩은 원래 찾기 쉽지 않은 카테고리입니다(“마스크 지옥”). 안 나와도 대표님 탓이 아닙니다.
3찾은 상품: 닥터지 1개짜리“쿠폰 받고 19,000원이 뜰 거예요. 그걸로 계산해 보시면 돼요.”▾

이미 등록했는지 먼저 확인

  • 등록한 것 같다면 네이버 카탈로그를 눌러 내 마켓이 올라와 있는지 봅니다.
  • 시트에서는 Ctrl+F → 상품명 붙여넣기 → ‘모두 찾기’로 확인합니다. 비슷한 마스크가 많아 헷갈리기 쉽습니다. 확인해 보니 이번 건은 미등록이었습니다.

마진 계산

  • 판매가는 카탈로그 최저가보다 10원 저렴하게 잡습니다.
  • 구매처의 ‘최저 할인가’는 쿠폰을 받아야(경우에 따라 앱에서) 뜹니다. 그 쿠폰가 약 19,000원 기준으로 계산하니 약 1,400원이 남아 소싱 가능.
  • 찾은 상품은 꼬리물기 시트에 바로 복사해 둡니다.
4멤버십 적립으로 위탁 마진 보기 (톤28)새 방법“기본 적립이랑 멤버십 추가 적립까지만 하시면 되거든요.”▾
네이버 카탈로그에 ‘공식’ + 멤버십 적립 표시 확인
→
보라색 버튼으로 적립 내역 열기
→
기본 + 멤버십 추가 적립만 빼기
→
위탁이라 택배비 제외하고 마진 계산
  • 공식몰이라고 무조건 들어가는 게 아닙니다. 카탈로그 바깥에 멤버십 적립 금액이 표시된 것만 들어가 봅니다.
  • 리뷰 적립, 네이버페이 머니, 신용카드 적립은 빼지 않습니다. 일회성이라 저희는 거의 계산에 넣지 않습니다.
  • 예: 톤28 약 29,920원 → 기본 적립과 멤버십 적립을 빼면 약 25,000원대에 산 셈이 됩니다. 위탁으로 고객에게 바로 보내면 택배비가 따로 안 들어 약 2,000원이 남습니다.
  • 적립금은 현금처럼 쓸 수 있지만 인출은 안 됩니다. 다른 상품 살 때 포인트로 결제하거나 역마진을 메우는 데 씁니다. 결제할 때는 역마진처럼 보여도 적립을 빼면 남는 구조입니다.
  • 이런 상품은 자주 나오진 않고 띄엄띄엄 할인합니다. 이제 소싱하다 보면 눈에 들어오실 겁니다.

+
② 공식몰 멤버십 적립 빼고 계산
5꼬리물기 시트 진행 순서“가장 최근에 찾은 상품부터 꼬리물기를 하라고 되어 있거든요.”▾
  • 시트 위쪽의 규칙 안내가 지워져 있었습니다. 규칙은 가장 최근에 찾은 상품부터 꼬리물기하는 것입니다.
  • 오늘은 지금 하던 줄(닥터지까지)을 끝까지 하고, 내일은 맨 아래 새로 쌓인 상품부터 위로 올라가며 합니다.
  • 위로 올라가는 동안 아래에 또 새 상품이 쌓이니, 다음 날 다시 아래부터 시작하면 됩니다.
6가격관리 프로그램 점검주의“1사이클 시작, 진입 성공 이렇게 돼야 정상적으로 돌아가는 거예요.”▾

자동 프로그램이 잘 도는지 확인

‘자세한 기록 보기’ 열기
→
‘1사이클 시작 · 진입 성공’ 있는지
→
없으면 중지 → 다시 시작 → 크롬 창에서 네이버 로그인
  • 상담 때 열어 보니 로그인이 안 된 상태였습니다. 다시 로그인하니 정상으로 돌아왔습니다.
  • 네이버가 보안 때문에 로그인을 자주 묻습니다. 가끔 기록을 열어 확인하는 습관을 들이세요.

수동으로 볼 것

  • ‘최저가 같음’은 대표님 가격이 최저가라는 뜻이니 그대로 둡니다.
  • ± 표시는 네이버 전산 오류로 뜨기도 합니다. 가끔 들어가서 실제로 최저가인지 확인하고, 아니면 최저가보다 10원 싸게 맞추거나, 역마진이면 1만 원 올려 둡니다.
  • +1,000원 이상 벌어진 상품도 같은 방식으로 정리합니다. 이건 평일 말고 주말에 몰아서 하시면 됩니다.
7스토어 현황과 페이스“애매하게 쌓이면 애매하게 매출이 나와서 더 힘들거든요.”▾

3개월바짝 하는 기간
  • 스토어 ‘실시간 현황’은 매일 볼 필요 없이 일주일에 한두 번만 봅니다. 지금은 상품을 많이 밀어 넣을 때입니다.
  • 지금 속도는 절대 느리지 않습니다. 꼬리물기를 하다 보면 할인이 몰려 있는 구간이 나오니, 그때까지 인내심을 갖고 찾으면 분명히 나옵니다.
  • 3개월 정도 바짝 해서 매출 궤도에 올라가면 잘 떨어지지 않습니다. 그 궤도까지만 힘내시면 됩니다.
  • 롯데온은 묶음이 엉뚱하게 연결되어 있거나 본사가 아닌 곳이 섞인 경우가 많습니다. 꼭 들어가서 확인합니다.
