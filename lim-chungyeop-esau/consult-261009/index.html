임충엽 대표님 1:1 컨설팅 정리

2026년 10월 9일 오후 6시 7분 · 임충엽 대표님, 뿌요 교육실장
41분상담 시간
4건취소 승인 처리
5개숙제: 소싱 상품
임충엽 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

해외 출장으로 자리를 비운 사이 주문·취소 건이 쌓였고 네이버 경고도 들어왔습니다. 상담 중에 밀린 건을 함께 정리했고, 남은 시간은 소싱 복습에 썼습니다.

오늘 정리한 것

취소요청 4건을 승인해 환불까지 마쳤습니다. 역마진 상품(더바디샵 브리티시 로즈)은 발송지연 처리하고 판매가를 1만 원 올려 더 팔리지 않게 막았습니다.

마진이 남으면

바로 발주해서 보냅니다.

역마진이면

발송지연 처리 + 안내 멘트, 그리고 같은 상품 판매가 1만 원 인상.

앞으로의 루틴

주문 알림은 끄고 매일 아침 9~10시에 한 번만 주문을 처리합니다. 나머지 시간은 소싱과 강의 복습에 씁니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다. 배송지연 안내 멘트는 바탕화면에 ‘배송지연 멘트’ 파일로 저장돼 있습니다.

1출장 후 현황“어제 본 거하고 오늘하고 또 다르고.”▾
  • 9월 말 해외 출장 중 주문이 들어왔고, 그동안 강사님이 대신 처리해 주셨습니다(10월 1일 배송지연 멘트 발송).
  • 네이버에서 ‘처리가 제대로 안 됐다’는 경고가 들어왔습니다.
  • 대표님은 주문·발주 절차를 거의 잊은 상태여서, 처음부터 다시 짚었습니다. 소싱은 어느 정도 하실 수 있는 단계입니다.
2주문이 들어오면: 발주 확인“저희가 확인을 하면 고객이 취소하려면 저희 승인이 있어야 하거든요.”▾

순서

  1. 신규주문 목록에서 전체 선택
  2. 엑셀 다운로드 (비밀번호는 1234나 0 등 편한 것으로)
  3. 발주확인 클릭 → 주문이 ‘발주 전’에서 ‘발주 후’로 넘어갑니다.

발주 전과 발주 후의 차이

  • 발주 전: 고객이 마음대로 취소할 수 있습니다.
  • 발주 후: 판매자가 보내겠다고 확인한 상태라, 고객이 취소하려면 판매자 승인이 필요합니다.

엑셀

  • 엑셀은 판매장부를 쉽게 정리하려고 받는 것입니다.
  • 대표님 PC는 MS 제품 키가 없어 엑셀이 열리지 않습니다. 정품 인증부터 해결해 주세요.
3역마진 판단: 더바디샵 브리티시 로즈실습“마진 남으면 보내주고 아니면 배송 지연.”▾

계산

  • 대표님 스토어 판매가: 27,330원
  • 네이버: 단품 27,000원대, 2개 묶음은 오히려 더 비쌌습니다.
  • 에누리(배송비 포함, 카드할인 적용): 2개 49,000원 → 개당 24,500원
  • 여기에 택배비 3,000원이 붙으면 27,500원 → 판매가보다 높아 역마진입니다.

확인 순서

  1. 주문번호(파란 글씨)를 눌러 상품명 확인 후 복사
  2. 네이버 가격비교와 에누리에서 실제로 살 수 있는지, 묶음이 더 싼지 확인
  3. 마진이 남으면 발주, 안 남으면 발송지연
4역마진 처리: 발송지연 + 가격 인상“배송지연 했다고 끝이 아니라, 이 상품이 더 이상 판매가 되면 안 되잖아요.”▾

발송지연 처리

  1. 해당 주문 건을 먼저 선택 → 발송지연처리
  2. 발송 기한 날짜 지정 (최대 90일까지 가능)
  3. 바탕화면 ‘배송지연 멘트’ 파일에서 문구를 드래그 → Ctrl+C → 붙여 넣기
  4. 확인을 두 번 누르면 완료
  • 멘트는 “공급자 측 사정으로 출고가 지연되고 있다”는 취지로 작성해 두었습니다.
  • 같은 상품 추가 주문 2건은 대표님이 직접 발송지연 처리를 해 보셨습니다.

판매가 1만 원 인상

  1. 상품관리 → 상품조회/수정
  2. 상품명 칸에 상품명을 넣고 검색
  3. 상품 선택 → 판매가 변경 → 1만 원 인상(자동 설정)
  • 같은 상품이면 인상은 한 번만 하면 됩니다.
5취소요청과 배송준비 건“놔두면 고객님들이 취소하실 거예요. 그때 승인만 해주시면 돼요.”▾

취소 승인

  1. 스토어센터 → 취소/반품/교환 → 취소요청
  2. 건을 선택 → 취소 승인 처리 → 확인 → 자동 환불
  • 한 번에 여러 건은 안 되고 한 건씩 처리해야 합니다.
  • 오늘 4건 처리 완료(1건 뿌요 실장, 3건 대표님). 어제 네이버페이에서 온 전화도 이 건이었습니다.

배송준비 5건

  • 이미 결제하고 기다리는 고객들입니다. 발송지연 안내가 나가 있으니 미리 정리할 필요 없이 두고, 취소요청이 들어오면 승인만 합니다.
  • 반품·교환은 화장품 특성상 거의 없습니다. 들어오면 그때 처리합니다.

상태 확인하는 법

  • 대시보드의 ‘발송기간 초과’ 표시는 발송지연이나 발주를 하면 자연스럽게 사라집니다.
  • 발송지연을 했는지 헷갈리면 주문번호를 눌러 아래 이력을 보세요. 발송 기한이 먼 날짜로 잡혀 있으면 지연 처리된 건입니다.
6소싱 복습: 가격 비교 기준“한 개만 나오는 건 나눌 수가 없으니까 무조건 쭉쭉 넘어가면 돼요.”▾

순서

  1. 화장품 1차 → 3차 카테고리까지 → 카탈로그 → 해외직구 제외 → 80개 보기
  2. 상품명 복사 → 네이버 가격비교에 붙여 넣고 수량 기준 최저 단가 확인
  3. 에누리: 배송비 포함 체크 → 카탈로그 확인 → 파란색 최저가 → 카드할인 되는지 확인
  4. 단위를 맞춰 비교 (예: 10매×2 = 20매, 50매 5만 원 = 10매당 1만 원)

빠르게 거르는 기준

  • 옵션이 여러 개 나오는 상품만 검토합니다. 단가가 하나뿐인 상품은 바로 패스.
  • 마진 1,000원 이상이면 선택합니다.
  • 판매처가 본사 기준인지 봅니다(현대몰 등). 홈쇼핑이어도 본사가 아닌 곳이 있으니, 많이 보면서 감을 익혀야 합니다.
  • 하나를 고르면 꼬리물기로 연관 상품을 이어서 찾습니다.

대표님이 헷갈리신 부분

  • MUV 쪽으로 넘어가는 흐름이 아직 헷갈리고, 처음엔 시간이 오래 걸립니다. 실습량으로 익숙해지는 부분입니다.
7공부법과 하루 루틴“그게 맞든 틀리든 계속 해보세요.”▾

강의

  • 인베이더 스쿨 강의를 2주차(발주)부터 다시 봅니다. 1주차는 아시니까 생략해도 됩니다.
  • 강의 화면에서 마우스가 어디를 누르는지 보고, 똑같이 따라 눌러 보세요.
  • 공용판 소싱 영상도 알짜배기입니다. 반복해서 보세요.
  • 강의 사이트는 카톡 인증을 마쳤고 북마크바에 등록해 두었습니다. 수강 기간은 180일 정도 남아 있을 것으로 봅니다.

하루 루틴

  • 대표님은 하루 3~4시간 실습할 수 있다고 하셨습니다.
  • 주문 알림은 켜 두면 자꾸 들여다보게 되니 쓰지 않습니다. 아침 9~10시에 1시간만 주문을 처리하고, 그 뒤엔 보지 않습니다.
  • 주문은 약간 시간차가 있어도 화면에 뜹니다. 지금은 주문이 많지 않아 하루 한 번이면 충분합니다.

막힐 때

  • 셀수다 프로그램 ‘질문하기’에 남겨 주세요.
