나선영 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

처음엔 자동등록이 재미있어 많이 올렸지만, 주문이 들어와도 정품 소싱처를 못 찾아 취소·배송 지연이 반복되면서 기운이 빠진 상태였습니다. 이번 상담은 들어온 주문 처리부터 베스트 소싱(네베소)까지 화면을 같이 보며 실습했고, 공식 판매처 구분 기준과 프로그램 재설치를 정리했습니다.

잘하고 있는 것

주문이 들어오면 네이버 가격비교 + 에누리 검색 → 본사 확인 → 본사면 주문, 안 되면 발송 지연 처리. 지금 하고 계신 방법이 맞습니다. 4주차 실시간 강의까지 모두 들으셨습니다.

바로잡을 것

최저가 판단은 메인 카탈로그 가격이 기준. 묶음을 개당가로 나누고 배송비 3,000원을 더해 기준보다 싸야 합니다. 공식 판매처는 “100% 정품” 문구가 아니라 공식 딱지·브랜드사 표기로 봅니다.

마음가짐

강의로 볼 땐 쉬워 보여도 실제는 다릅니다. 베스트는 숙련자도 3시간에 1개 나올까 말까 할 때가 있습니다. 안 나오는 시기를 견뎌야 성과가 나오니, 매일 조금씩이라도 이어갑니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1근황과 학습 진도“첫 주 했을 때는 재밌는 거예요.”▾
  • 실시간 강의는 4주차까지 모두 들으셨고, 복습은 2주차까지 하셨습니다. 본업 때문에 늦게 귀가하다 보니 3·4주차 복습은 못 하셨습니다.
  • 첫 주에 자동등록 프로그램으로 상품을 많이 올렸다가 한꺼번에 올라가서 네이버에서 막히기도 했습니다.
  • 이후 주문은 한두 건씩 계속 들어오는데, 정품 소싱처를 못 찾아 1:1 질문으로 확인 → 정품 아니면 안 된다는 답 → 취소·배송 지연으로 넘기는 일이 반복되며 기운이 빠지셨습니다.
  • 네베소·꼬리물기는 아직 감이 오지 않는 상태 → 오늘은 실습 위주로 진행했습니다.
2들어온 주문: 크리스마 화장솜오늘 처리“역마진이라서 배송 지연 3개월 처리해 주시면 될 것 같아요.”▾
  • 어제 들어온 크리스마 3분의 1 화장솜(4매 1개)은 발주 확인만 해 두고 상담에서 같이 보기로 남겨 두셨습니다. 판매가는 14,550원입니다.
  • 네이버 가격비교: 4매 1개 약 14,000원이 가장 저렴하고, 그보다 싸게 살 수 있는 묶음이 없음 → 에누리로 넘어갑니다.
  • 에누리: 배송비 포함 체크 후 카탈로그에서 약 12,000원대 확인 → 판매처 세인아이앤씨 상세를 보니 마즈·문구·부케가르니 등 여러 브랜드를 같이 파는 곳 → 본사 아님.
  • 게다가 3만 원 미만 주문은 배송비 3,000원이 붙어 마진도 남지 않습니다.

5실습 사례: 알페신 카페인 샴푸 외“베스트는 3시간에 한 개 나올까 말까 할 때도 있거든요.”▾
  • 알페신 카페인 샴푸: 네이버에선 3개 묶음 개당 약 15,000원 + 3,000원 = 18,000원으로 안 됨 → 에누리에서 롯데홈쇼핑 3개 44,570원(최대 할인 시 42,920원), 공식 딱지 확인 → 카탈로그 18,130원보다 10원 싸게 들어간다고 계산해도 택배비를 넣으면 역마진.
  • 홈쇼핑 최대 할인가는 로그인해야 실제 금액이 나옵니다 → 주요 홈쇼핑에 회원가입해 두기.
  • 6개 묶음 상품: 네이버는 개당 약 12,000원 + 3,000원으로 안 됨 → 에누리 6개 약 7만 원, 개당 1만 1천 원대로 가능해 보였지만 판매처가 패션플러스로 공식 표시가 없어 애매 → 보류.
  • 300g 상품: 에누리 약 18,000원으로 오히려 더 비쌈 → 패스. 1L 상품: 2개 16,000원으로 카탈로그와 비슷 → 패스.
  • 오늘 본 베스트 상품은 모두 패스 — 베스트는 원래 잘 안 나옵니다. 꼬리물기 때가 상품도 더 많이 나오고 공식몰 찾기도 수월합니다.
6공식 판매처(본사) 구분 기준중요“100% 정품입니다, 이거는 공식이 아니에요.”▾

공식으로 보는 것

  • 공식 판매처 딱지가 붙어 있거나 홈쇼핑 판매.
  • 상품명 앞에 브랜드사 이름이 오고(예: 바이브랩), 상세페이지에 “○○ 공식 판매처입니다”라고 적혀 있음.
  • 본사 상세페이지는 성분·시험 성적표·포인트 1번 2번처럼 설명이 아주 많습니다. 본사인데 표시를 안 해 둔 경우도 있어 디자인으로 감을 잡습니다.

공식이 아닐 가능성이 높은 것

  • 브랜드 이름 없이 “100% 정품” 문구만 있는 곳.
  • 신세계몰 등에서 판매자 앞에 셀러허브라고 붙은 곳 — 상세페이지도 본사 것과 완전히 다르게 상품 정보만 바로 나옵니다.
  • 패션플러스: 개인사업자가 많아, 상세가 본사 것 같아도 공식 딱지가 없으면 애매합니다.
  • 여러 브랜드를 섞어 파는 판매처.
  • 많이 보다 보면 ‘느낌적으로 아니다’가 보이기 시작합니다. 그 느낌을 살려 계속 봅니다.
  • 참고: 본사 상세페이지를 그대로 퍼오면 지적재산권에 걸리지만, 우리는 쓰지 않으니 걸릴 일이 거의 없습니다.
7작업할 때 짚은 것“이거 지금 검색 이렇게 하시면 안 돼요.”▾
  • 미리 열어 둔 카탈로그 위에서부터 순서대로 진행합니다. 네이버에서 따로 검색하지 말고, 상품명을 복사해 에누리에 붙여넣습니다.
  • 실수로 탭을 닫았으면 Ctrl + Shift + T로 다시 불러옵니다.
  • 계산은 컴퓨터 계산기를 계속 켜 두고 쓰는 게 익숙해지면 편합니다.
8매일 루틴과 숙제새 숙제“30분이라도 괜찮으니까 일단 컴퓨터 켜시고 네이버만 켜보세요.”▾
  • 마음먹으면 하루 1~2시간은 되지만, 하다가 안 나오면 포기하게 된다고 하셨습니다.
  • 하루 1시간, 어렵다면 30분이라도 컴퓨터를 켜고 네이버만 켜 둡니다. 그러면 자연스럽게 카탈로그를 보게 됩니다.

9새 PC 설치와 프로그램 점검오늘 처리“1주차랑 그대로 해서 깔면 돼요.”▾
  • 새로 장만한 PC에도 1주차 안내대로 똑같이 설치하면 되고, 노트북과 PC 둘 다 쓸 수 있습니다.

10가격이 안 맞을 때: 주말 수동 가격관리“천 원 이상인 거는 토요일, 일요일에 하나하나 들어가서.”▾
  • 올려도 가격이 안 맞아서 등록을 멈추고 계셨습니다.
  • 가격관리 프로그램은 1,000원 이하 차이만 자동으로 맞춰 줍니다. 1,000원 넘는 상품은 토·일에 직접 하나씩 들어가 가격을 관리해야 합니다.
  • 방법은 3주차 강의에 있으니 복습하고 그대로 따라 합니다.
11사무실 방문“아마도 있을 것 같아요.”▾

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 크리스마 화장솜 주문 발송 지연 3개월 처리 나선영본사 아님 + 배송비 포함 역마진
  • 매일 30분~1시간 네이버 카탈로그 켜기 나선영컴퓨터 켜고 네이버부터
  • 숙제: 베스트 1개 → 꼬리물기 3개 나선영메인 카탈로그 기준 · 개당가 + 배송비 3,000원 · 공식 판매처 확인 · 다음 주 컨설팅까지
  • 주요 홈쇼핑 회원가입 나선영로그인해야 최대 할인 실제 금액 확인 가능
  • 자동등록 프로그램 새 버전 설치 나선영노트북 재부팅 후 재시도 → 안 되면 새 PC에 1주차대로 처음부터
  • 가격관리 프로그램 켜져 있는지 확인 나선영셀사 가격관리 → 스토어 로그인 → 시작

  • 설치가 계속 안 되면 컨설팅 재신청 나선영원격으로 다시 봐 드림
  • 숙제 검사·사무실 방문 일정 맞추기 뿌요 교육실장다음 주 컨설팅
