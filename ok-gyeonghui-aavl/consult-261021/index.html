옥경희 대표님 1:1 컨설팅 정리

2026년 10월 21일 · 옥경희 대표님(2기), 뿌요 교육실장 · 원격으로 화면 함께 보며 진행

18건배송지연 처리한 주문
+3~4만 원판매가 인상
옥경희 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

오프라인 강의 때 연습으로 올렸다가 지운 줄 알았던 상품 1개가 남아 있어, 할인이 풀린 뒤 1~2만 원씩 손해 보는 주문이 총 18건 들어와 있었습니다. 원격으로 함께 들어가 전부 3개월 배송지연을 걸고, 더 들어와도 손해가 나지 않게 판매가를 3~4만 원 올렸습니다. 이어서 취소 요청 처리법, 판매 장부, 셀수다 업데이트, 주문 엑셀 다운로드까지 한 번씩 보여 드렸습니다.

오늘 해결한 것

역마진 주문 18건 배송지연(발송기한 3개월 뒤) · 판매가 인상 · 셀수다 최신 버전 업데이트 후 작업표시줄 고정 · 판매 장부와 꼬리물기 시트 북마크 추가.

꼭 기억할 것

배송지연 건에서 들어오는 취소 요청은 바로 취소 승인해 주세요. 단, 이미 발송한 주문은 승인하면 물건만 가고 돈은 환불되니, 판매 장부로 먼저 확인합니다.

남은 숙제

4강·추석 특강 마저 듣기, 2주차(발주·배송지연) 복습, 조회 항목(그리드) 순서 정리, 반품 자동수거 해지는 강의 보며 직접.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1남아 있던 상품 1개로 역마진 주문 18건오늘 해결“한 만 원, 2만 원 손해 보는 것 같은데…”▾
  • 오프라인 강의 날 도움을 받아 연습용 상품을 여러 개 올렸고, 주문이 들어올까 걱정되어 다 지워 달라고 하셨습니다. 그런데 한 개가 남아 있었고, 며칠 전 스마트스토어를 처음 열어 보고 주문이 들어온 걸 아셨습니다.
  • 할인이 풀리면서 원가가 올라 지금은 건당 1~2만 원 손해입니다. 같은 상품을 더 싸게 살 곳도 찾지 못하셨습니다.
  • 처음엔 3건으로 알고 계셨는데, 확인해 보니 총 18건이었습니다. 상담 막바지에 따로 보이던 10월 16일 주문까지 마저 배송지연을 걸었습니다.
  • 네이버에서 판매를 못 하게 막지 않을까 걱정하셨는데, 그런 일은 없습니다. 배송지연은 정상적인 처리 방법입니다.

  • 이 내용은 2주차 강의에 나옵니다. 오늘 함께 해 봤으니 강의를 다시 보면 더 잘 이해되실 겁니다.
2더 팔려도 손해 없게 판매가 인상오늘 해결“팔려도 대표님 마진이 남아야 되니까.”▾
  • 대표님 스토어에 올라가 있는 상품은 이 1개뿐입니다. 그대로 두면 계속 손해 나는 주문이 들어오므로 판매가를 3만 원 이상, 넉넉히 4만 원 올렸습니다.
  • 이렇게 하면 거의 팔리지 않고, 혹시 팔려도 마진이 남습니다.
  • 처음 하시는 분들은 버튼 누르는 걸 무서워하시는데, 실제로 해 보면 큰일 날 게 없습니다. 하나씩 눌러 보시면 됩니다.
3취소 요청 들어오면 승인하는 법매일 확인“취소 승인 누르고, 확인 확인 두 번 누르면 끝이에요.”▾
  • 배송지연을 보내면 고객들이 취소 요청을 많이 합니다. 그냥 두면 CS 문의가 들어와 번거로워지니 확인하는 대로 승인해 주세요.

이것만은 조심하세요

  • 지금은 전부 배송지연 건이라 취소 요청은 바로 승인해도 됩니다.
  • 나중에 정상 주문을 넣기 시작하면, 이미 발송해 배송 중인 주문에도 취소 요청이 들어올 수 있습니다. 이걸 승인하면 물건은 가고 돈은 환불됩니다. 반드시 확인 후 처리하세요.
4판매 장부와 꼬리물기 시트“판매 장부 기준으로 취소가 가능한지 확인한 뒤에 취소해 주시는 게 좋아요.”▾
  • 판매 장부는 아직 한 번도 안 써 보셨습니다. 이미 PC에 있어서, 크롬 위쪽 북마크에 바로가기를 추가해 드렸습니다.
  • 꼬리물기 시트도 복사해서 함께 넣어 드렸습니다.

6조회 항목(그리드) 설정과 주문 엑셀 다운로드직접 마무리“이거는 한 번만 하면 돼요.”▾

조회 항목 설정

  • 위치: 판매관리 → 발주확인/주문관리, 또는 홈의 신규 주문 클릭 → 아래로 내려 ‘조회 항목 설정’.
  • 엑셀로 받았을 때 보기 편하도록, 필요한 항목을 하나씩 클릭해 위로 올려 순서를 맞춥니다: 수취인명 → 택배사 → 송장번호 → 배송방법 → 결제·발송기한 등.
  • 상담 중에 실장님이 순서를 맞추다가 저장 전에 초기화되어 끝까지 마치지 못했습니다. 강의를 보며 직접 해 보시고, 안 되면 다음 컨설팅에서 다시 해 드립니다. 다 맞춘 뒤 꼭 저장을 누르세요.

주문자 이름 보는 법

  • 스마트스토어 센터 홈에서 배송준비 숫자를 누르면 아래쪽 목록에 주문자 이름이 나옵니다.
7하나씩 눌러 보며 익숙해지기“조금씩 하다 보면 자신감이 붙으실 거예요.”▾
  • 대표님은 이 일을 시작하며 처음으로 매일 컴퓨터를 켜게 되셨고, 지금은 매일 출근 전 오전에 강의를 듣고 계십니다. 4강과 추석 특강을 듣는 중이고 4강을 마저 들으면 정규 강의는 다 듣게 됩니다.
  • 소싱은 강의를 마저 듣고 시작하실 계획입니다.
  • 반품 자동수거 해지, 나머지 설정은 시간이 걸리는 작업이라 2주차 강의를 보며 대표님이 직접 하시기로 했습니다. 어렵지 않은 작업입니다.
  • 막히는 게 있으면 1:1 문의를 남기거나 컨설팅을 신청해 주세요.
