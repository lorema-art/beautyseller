박정음 대표님 1:1 컨설팅 정리

2026년 10월 10일 · 박정음 대표님, 뿌요 교육실장 · 원격 화면 공유

박정음 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

대량 등록을 누르자 컴퓨터가 혼자 움직여 놀라셨던 것은 정상적인 크롤링이었습니다. 원격으로 함께 확인한 결과 API 키와 프로그램 설정은 모두 제대로 되어 있고, 상담 중 상품 등록과 판매 중지 상품 복구까지 직접 해 봤습니다.

지금 상태

서울 첫 오프라인 강의에서 셀수다와 자동등록 프로그램을 설치하셨고, 설정은 잘 되어 있습니다. 상담 중 케라시스 상품이 스토어에 정상 등록되는 것까지 확인했습니다.

바꿀 것

실수로 올라간 의류(런닝 나시)는 판매 중지했습니다. 크롤링 중에는 컴퓨터를 쓰지 말고, 하루 일을 마친 뒤 자기 전에 돌립니다. 전성분이 빠져 판매 중지된 상품은 직접 채워 넣어 다시 판매 중으로 돌립니다.

앞으로

강의를 복습하며 배운 대로 꾸준히 등록하고, 매주 컨설팅으로 방향을 점검받습니다. 구리 오프라인 상담은 거리가 멀어(편도 약 4시간) 온라인 위주로 진행합니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1자동등록 프로그램 작동 확인정상“막 쭉쭉 알아서 스크롤 되죠? 그렇게 하면 잘 하신 거예요.”▾
  • 대량 등록 버튼을 누른 뒤 화면이 저절로 스크롤된 것은 프로그램이 네이버 상품 페이지를 크롤링하는 정상 동작입니다. 크롤링이 끝나면 스크롤이 멈춥니다.
  • 원격으로 확인해 보니 API 키가 정상 등록되어 있었습니다. 애플리케이션 ID는 바뀌는 값이 아니며, 혹시 몰라 한 번 더 입력해 두었습니다.
  • 약관 동의 화면이 보이지 않았던 것은 이미 동의를 마쳤기 때문입니다. 동의하지 않았다면 상품 등록 자체가 되지 않습니다.
  • 등록이 끝나면 프로그램에 완료 또는 실패가 표시됩니다. 실패하면 오류 메시지가 뜹니다.
  • 크롤링 중 컴퓨터를 쓰면 다른 정보가 섞여 들어갈 수 있습니다. 끝날 때까지 두는 것이 좋습니다.
2잘못 올라간 상품 정리함께 해결“판매 중지는 당하는 게 아니고 하는 거죠.”▾
  • 스토어에 상품 2개가 올라가 있었고, 그중 하나가 의도하지 않은 의류(런닝 나시)였습니다.
  • 강의에서 다루지 않는 상품군이라 상담 중에 판매 중지 처리했습니다. 판매 중지는 판매자가 직접 걸고 풀 수 있습니다.
  • 등록된 상품이 있다는 것 자체가 프로그램이 정상 작동했다는 증거입니다.
3자동등록 방법 다시 보기“일 다 하시고 주무시기 전에 돌리시는 게 좋거든요.”▾

‘카탈로그 담기’ 클릭 (주소 자동 입력)

‘대량 등록 시작’
  • 대량 등록을 시작하면 순서 목록에 ‘크롤 중’이 표시되고, 프로그램이 상세 페이지를 훑으며 필요한 정보를 모읍니다.
  • 상담 중 함께 돌려 케라시스 상품이 스토어에 등록 완료되는 것을 확인했습니다.
  • 컴퓨터로 할 일을 모두 마친 뒤, 자기 전에 돌려 두는 것을 권합니다.
4판매 중지된 상품 살리기 (전성분 채우기)함께 해결“화장품 같은 경우에는 전성분이 반드시 들어가야 되거든요.”▾

유니레버 시그니처 향 상품은 전성분이 없어 프로그램이 정보 부족으로 판단하고 자동 판매 중지했습니다. 이런 상품은 직접 채워 넣어야 합니다.

‘판매중’으로 변경
  • 챗GPT가 성분을 중간에 생략할 때가 있습니다. 그러면 “전체 성분이니까 다 보여줘”라고 다시 요청합니다.
  • 프로그램으로 올린 상품은 상세가 ‘상세 설명 참조’로만 되어 있어, 그 자리에 전성분을 넣어야 합니다.
  • 저장한 뒤에도 판매 중지 상태이니, 마지막에 판매중으로 바꾸고 확인까지 눌러야 합니다.
  • 캡처 도구는 자주 쓰게 되어 작업 표시줄에 고정해 두었습니다.
5가게와 집에서 돌리기: IP 추가“IP가 다를 수 있거든요. 다르면 추가만 해 주시면 돼요.”▾
  • 대표님은 가게와 약 4km 떨어진 집 두 곳에서 컴퓨터를 쓰십니다. 어디서 대량 등록을 돌려도 상관없습니다.
  • 다만 장소마다 IP가 다를 수 있으니 확인하고, 다르면 네이버 API 센터에서 IP를 추가합니다. 최대 3개까지 넣을 수 있습니다.
6그 밖의 질문“매번 할 필요는 없어요.”▾

API 애플리케이션 이름

  • 1주차에 ‘뷰셀’로 적으라고 한 것은 구분하기 쉽게 통일하려는 것일 뿐입니다. 스토어 이름을 넣어도 상관없고, 지금 설정은 그대로 두면 됩니다.

스마트스토어 여러 개 운영

  • 한 사업자 기준으로 보통 3개까지 운영할 수 있습니다. 단, 일정 매출 구간에 들어서야 추가 개설이 가능하므로 지금은 해당되지 않습니다.

가족이 함께 쓰는 경우

  • 같은 집이라 IP가 겹쳐도 스토어가 다르면 문제없습니다. 같은 스토어라면 중복으로 잡힐 수 있지만 프로그램이 중복을 걸러 냅니다.
  • 강의를 듣는 것이 가장 좋지만, 강의에는 컨설팅이 포함되어 있어 따로 방법이 있을 수 있습니다(컨설팅만 별도 결제 등). 대표님 스토어가 자리를 잡은 뒤 뷰셀 대표님께 상담받기로 했습니다.

셀수다 업데이트 알림

  • 알림이 뜰 때마다 할 필요는 없습니다. 버전 차이가 크거나 쓰기 불편할 때 업데이트하면 됩니다.
7앞으로의 진행“한 끗 어긋나면 헛수고가 돼 버리는 거죠.”▾
  • 이전에 유튜브 쪽을 시도했다가 접고, 꼭 써야 하는 화장품·생활용품 판매에 집중하기로 하셨습니다. 이 일을 꾸준히 이어 갈 생각이십니다.
  • 빠르게 매출을 낸 분들은 강의를 많이 복습하고 배운 대로만 한 분들이었습니다. 이것저것 새로 시도하기보다 배운 방식을 지킵니다.
  • 판매되지 않는 상품만 올리면 노력이 헛수고가 될 수 있습니다. 매주 한 번 컨설팅으로 방향을 점검받습니다.
  • 고창에서 구리까지 편도 약 4시간이라, 실행하면서 상담은 최대한 온라인으로 받습니다.
  • 막히는 부분은 셀수다 ‘질문하기’에 남기면 빠르게 답변받을 수 있습니다.
