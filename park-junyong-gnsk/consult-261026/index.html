박준용 대표님 사전상담 정리

2026년 10월 26일 · 박준용 대표님, 뷰셀 · 전화 + 원격 상담
54분상담 시간
6건+첫 주 들어온 주문
3,000원↑이번 주 등록 마진 기준
박준용 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

올리신 상품 16개에서 벌써 주문이 6건 넘게 들어왔습니다. 원격으로 함께 보며 주문 처리 → 마진 확인 → 역마진 처리를 처음부터 끝까지 실습했습니다. 들어온 주문은 대부분 역마진이라 가격 인상 + 발송 지연으로 처리했고, 이번 주는 실제 판매보다 도구에 익숙해지는 연습이 목표입니다.

지금 상태

노트북은 프로그램 설치 완료, 스마트스토어에 상품 16개 등록. 사무실 PC는 셀수다는 깔렸지만 2·3번째 프로그램 설치가 아직입니다.

오늘 정리한 것

주문이 오면 엑셀 → 판매장부 → 네이버·에누리 카탈로그로 마진 확인. 안 남으면 판매가 +10,000원 인상, 주문은 발송 지연(최대 3개월). 취소가 오면 승인하고 장부에서 지웁니다.

이번 주

하루 1~2개만, 3,000~5,000원 이상 남는 상품만 올리세요. 마진 남는 1개 주문은 고객 집으로 바로 보내고, 여러 개 사야 하면 먼저 연락 주세요.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1원격 연결 — 단톡방 공지 먼저 확인하기“다음부터는 단톡방은 하루에 한두 번 정도 봐 주세요.”▾
  • 1:1 원격 준비 방법을 어제와 오늘 단톡방에 올려 두었는데 못 보셔서 시작이 늦어졌습니다. 전화로만 하면 대표님 화면을 볼 수 없어서 원격으로 진행합니다.
  • 안내 글을 읽기보다 순서대로 따라 하시면 됩니다: 링크 접속 → 화면 공유 다운로드 → 크롬에 추가 → 설치 파일 더블 클릭 → 코드 생성 → 코드 불러 주기.
  • 단톡방의 다른 분 대화는 넘겨도 되지만, 대표·코치가 올리는 글은 대부분 공지입니다. 하루 1~2번은 꼭 확인해 주세요.
  • 노트북은 잘 됐고, 사무실 PC는 셀수다만 설치되고 2·3번째 프로그램이 안 되는 상태입니다. PC마다 깔린 프로그램이 달라 경우의 수가 많으니 따로 다시 보겠습니다.
  • 통화 중에는 대표님 쪽 녹화가 안 돼서, 오늘 화면은 뷰셀이 녹화해 드렸습니다(복습용).
2주문이 들어오면 — 엑셀 정리와 판매장부순서“주문도 안 했는데 택배사가 필요할까요?”▾

엑셀 정리 → 판매장부에 붙여넣기
  • 엑셀에서 택배사·운송장 등 불필요한 열은 삭제합니다. 아직 물건을 사지 않았으니 필요 없습니다.
  • 왼쪽 위 삼각형으로 전체 선택 → 열 경계 화살표를 더블 클릭하면 글자 크기대로 열 너비가 맞춰집니다.
  • 필터 → 오름차순: 상품명 가나다순 정렬입니다. 어렵게 생각하지 않으셔도 됩니다.
  • 필요한 정보만 복사해 뷰셀이 드린 판매장부에 붙여 넣고, 추가 배송비(오늘은 제주 주문 1건)도 함께 적습니다.
  • 지금은 서식이 정돈 안 돼 조금 번거롭습니다. 2주차 강의에서 한 번에 정돈하는 방법을 알려 드립니다.
3마진이 남는지 확인 — 네이버 → 에누리핵심“카탈로그 모르시면 안 돼요.”▾

주문가와 비교
  • 네이버에서 주문 들어온 상품의 카탈로그를 열고 배송비 포함을 켠 뒤, 구성(수량)별 최저가에서 1개 단가를 계산합니다.
  • 대표님께 보내실 때는 배송비 3,000원이 더 듭니다. 이걸 더해도 주문가보다 싸야 마진이 남습니다.
  • 네이버에서 안 남으면 에누리에서 같은 방법으로 찾습니다. 1위가 아니라 파란색으로 표시된 구성(가장 저렴한 구성)만 보세요. 가격을 눌렀을 때 카드 할인 표시가 있으면 반영합니다.
  • 세타필 예시: 주문가 25,480원. 네이버는 배송비까지 더하면 27,000원대, 에누리 최저가는 26,150원 → 역마진.
  • 프리메라 마스크(5매): 1개 최저가가 18,680원보다 싼 곳이 없음 → 역마진.
  • 에누리에서 카탈로그가 안 나올 때는 불필요한 단어를 빼고 검색합니다. 키워드 다듬는 법은 2주차에 배웁니다.
  • 지금 이미 더 비싸면 카드 할인은 볼 필요가 없습니다. 어떤 카드를 쓰면 좋은지는 2주차에 안내합니다.
4역마진일 때 — 가격 인상 + 발송 지연핵심“마이너스 보고 물건을 보낼 순 없잖아요.”▾

  • ‘50% 초과 인상’ 경고가 뜨면 무시 → 확인으로 진행했습니다.
  • 오늘 세타필·프리메라·헤라 세 상품 모두 인상했습니다.

발송기한 +3개월 · 확인
  • 사유 문구는 뷰셀이 한글 파일에 적어 드린 것을 복사해 씁니다. 사유 항목(상품 준비)은 건드리지 않습니다.
  • 발송기한은 원래 평일 3일인데, 주문일로부터 최대 3개월까지 미룰 수 있습니다. (오늘 건은 내년 1월 26일 전후)
  • 주문 고객을 찾을 때는 검색 기준을 수취인명으로 바꾸고 판매장부의 이름으로 찾습니다.
  • 판매장부에서도 역마진 주문 행은 잘라내기(Ctrl+X)로 아래로 빼 두어 구분합니다.
5취소 요청이 오면 — 승인하고 장부에서 삭제“지연 처리하셨으니까 취소 요청이 왔으면 승인해 주시면 돼요.”▾
  • 오늘 지연 처리한 주문 중 1건이 바로 발송 전 취소 요청으로 들어왔습니다.
  • 판매관리 → 취소관리 → 파란색 상품주문번호를 눌러 지연 처리한 그 고객이 맞는지 확인 → 취소 승인.
  • 판매장부에서 해당 주문 행을 삭제합니다. 장부는 자동 저장입니다.
6오늘의 할인은 연습용이에요“2주차에 내가 내 제품 찾는 게 사실 더 중요해요.”▾
  • 상품을 잘 올리셔서 주문이 들어온 건 맞습니다. 다만 오늘의 할인 상품은 동기분들이 다 같이 올려서 가격이 금방 바뀌고, 발주가 안 될 수 있습니다.
  • 지금은 주문 처리 흐름을 연습하는 시간입니다. 발주가 안 돼도 낙담하실 필요 없습니다.
  • 진짜 중요한 건 2주차에 ‘내 제품’ 찾는 법입니다.
7마진이 남는 주문 — 1개면 고객 집으로 바로“한 개짜리가 마진이 남아요, 그러면 고객분 댁으로 바로 보내 주세요.”▾
  • 주문 방법은 인터넷에서 물건 사는 것과 같습니다. 1개 주문 + 마진 확인이면, 살 때 배송지를 고객 주소로 입력해 바로 보냅니다.
  • 택배사는 판매처마다 다르니 신경 쓰지 않으셔도 됩니다.
  • 여러 개를 사야 하는 주문은 사기 전에 뷰셀에 카톡 또는 질문하기로 연락 주세요. 그 전에 마진이 남는지 먼저 확인합니다.
  • 어떤 경우에도 마이너스로 발송하지 않습니다.
8이번 주 등록 — 하루 1~2개, 3,000원 이상만숙제“지금은 이걸 어렵지 않게 하는 게 이번 주의 목표예요.”▾
  • 프로그램 사용은 어렵지 않다고 하셨습니다. 하나씩 올릴 땐 문제없고, 여러 개를 한꺼번에 올릴 때 ‘상점이 없어졌다’ 같은 메시지가 가끔 뜹니다.
  • 등록할 때마다 비용이 드니 불필요하게 많이 올리지 마세요. 하루 1~2개, 연습 삼아 올리면 됩니다.
  • 올린다면 3,000~5,000원 이상 남는 상품만 찾아서 올립니다.
  • 프로그램이 돌아가는 동안 화면을 지켜보지 마시고 다른 작업을 하세요.
9마케팅 업체 전화는 모두 사기주의단톡방 공지에 안내되어 있습니다.▾
  • 상품을 올리자마자 ‘좋은 자리에 올려 주겠다’는 업체 전화가 많이 왔다고 하셨습니다. 모두 사기입니다.
  • 본 번호 노출을 줄이도록 070 번호 개통을 권장합니다. 방법은 단톡방 공지를 확인해 주세요.
10천천히, 끝까지 듣고, 먼저 생각하기“마우스 너무 빨리 움직이지 마시고 눈으로 먼저 보세요.”▾
  • 오늘 여러 번 막힌 이유는 대부분 마음이 급해서였습니다. 혼자 하실 때도 메뉴를 눈으로 먼저 보고 한 건씩 처리하세요.
  • 설명을 끝까지 들은 뒤 질문하셔도 늦지 않습니다. 질문을 드리면 먼저 차분히 생각해 보세요.
  • 처리 후에는 신규주문·취소관리 탭에서 상태를 다시 확인합니다.
  • 그래도 생각보다 잘 따라오고 계십니다.

실행 항목

체크 표시는 이 브라우저에서만 저장됩니다.

  • 세타필·프리메라·헤라 판매가 +10,000원 인상, 발송 지연 처리 박준용 · 뷰셀상담 중 완료 · 취소 1건 승인 및 장부 삭제 완료
  • 단톡방 공지 하루 1~2번 확인 박준용대표·코치 글은 대부분 공지
  • 주문 처리 순서대로 연습 박준용엑셀 → 판매장부 → 네이버·에누리 마진 확인 → 역마진이면 인상 + 지연
  • 하루 1~2개, 3,000~5,000원↑ 상품만 등록 박준용등록 비용 아끼기 · 프로그램 실행 중엔 다른 작업
  • 마진 남는 1개 주문은 고객 집으로 바로 발송 박준용여러 개 사야 하면 카톡·질문하기로 먼저 연락
  • 지연 처리한 주문 상태 지켜보기 박준용취소 요청 오면 고객 확인 → 승인 → 장부 삭제
  • 070 번호 개통 박준용마케팅 업체 전화는 응대 X
  • 사무실 PC 2·3번째 프로그램 설치 다시 보기 박준용 · 뷰셀노트북은 완료
