류운선 대표님 개인 상담 자료입니다. 외부 공유는 삼가 주세요.

한눈에 보기

“프로그램 설치는 된 것 같은데 잘 됐는지 모르겠다”며 오셨습니다. 원격 프로그램부터 설치해 화면을 연결했고, 자동등록 프로그램과 셀러들의 수다를 새 버전으로 바꿔 드렸습니다. 남은 시간에는 네배소로 찾은 마리브 후코테놀 해초 크림 70ml에서 이어지는 꼬리물기를 처음부터 같이 짚었습니다. 오늘은 프로그램 확인에 시간을 써서 실제 소싱은 다음 컨설팅에서 봅니다.

프로그램

설치는 전반적으로 잘 되어 있었습니다. 쓰다가 안 되면 먼저 업데이트, 그래도 안 되면 연락.

꼬리물기

지칭 단어 → 카테고리 → 제조사 → 브랜드, 왼쪽부터 검색해서 첫 페이지만. 다 본 칸은 빨간 글씨.

다음

꼬리물기로 3개 찾으면 카톡 → 시트 첨삭. 다음 컨설팅에서 소싱 과정을 같이 봅니다.

교육자료: 프로그램 업데이트 · 꼬리물기 따라하기 →

오늘 원격 화면을 단계별 사진·영상으로 정리했습니다.

주제별 정리

항목을 누르면 세부 내용이 열립니다.

1원격 프로그램(크롬 원격 데스크톱) 설치“걔가 설치가 되어야 제가 확인을 할 수 있습니다.”▾
  • 단톡방 공지를 못 보셔서 원격 프로그램이 설치돼 있지 않았습니다. 카톡으로 받은 링크에서 1번부터 순서대로 따라 했습니다.
  • 다운로드 버튼을 눌러도 반응이 없는 것처럼 보였는데, 원격 데스크톱 앱 설치 창이 따로 떠 있었습니다 → 허용 → 확장 추가 → 처음 링크로 돌아가 동의 및 설치 → 다운로드 허용 → 코드 생성.
  • 코드를 불러 주시면 연결됩니다. 상담 중 원격이 한 번 끊겼을 때도 코드를 새로 생성해 다시 알려 주시면 됩니다. 연결 중에는 원격 창을 끄지 않습니다.
2자동등록 프로그램 새 버전“안 되는 게 있으면 우선 업데이트를 한번 해 보고, 그래도 안 되면 얘기해 주세요.”▾
  • 새 버전을 아직 설치하지 않으셨습니다. 쓰면서 불편한 게 없으면 매번 받을 필요는 없습니다. 수강생마다 컴퓨터 환경이 달라 프로그램을 계속 수정하고 있습니다.

3셀러들의 수다 새 버전과 새 기능“위탁은 약간 필살기 느낌으로 가져가야 된다고 얘기 드렸잖아요.”▾
  • 셀러들의 수다는 덮어씌워지는 방식이라 기존 버전을 지울 필요가 없습니다.
  • 온라인 사무실: 특강 때 말씀드린 온라인 사무실에 여기서 입장할 수 있습니다.
  • 공동구매: 올라오는 상품마다 내가 판매했을 때 남는 마진이 함께 표시됩니다.
  • 주소 확인(어제 추가된 기능): 위탁으로 보낼 때 주소지가 의심되면 검색해 보세요. 그 주소에 사업자로 신고된 내역이 있으면 나옵니다.
4꼬리물기 시트 정리“되게 잘하셨어요.”▾
  • 시트를 어디서 여는지 헷갈려 사본을 여러 개 만드셨습니다. 구글 점 9개 → 스프레드시트로 들어가 꼬리물기 양식을 열고, 빈 사본·잘못 만든 사본은 지웠습니다.
  • 강의 때 보여 드린 대로 잘 만드셨고, 네배소로 찾은 상품도 나올 만한 제품입니다.
  • 아쉬운 점 하나: 다른 칸은 다 띄어쓰기를 하셨는데 지칭 단어에도 띄어쓰기까지 맞추면 완벽합니다.
  • 시트는 공유를 열어 링크를 받아 두었습니다.
5지칭 단어: 한 브랜드만 나오면 취소선기준“이 브랜드에서만 쓰는 고유명사면 저희가 할 필요가 없겠죠.”▾
  • 네배소는 1페이지 80개를 보다가 이 상품을 찾으셨고, 그 뒤로는 안 보셨습니다. 네배소는 하나만 찾으면 거기서부터 꼬리물기입니다.
  • 시트를 왼쪽에서 오른쪽으로 순서대로 봅니다. 지칭 단어도 맨 앞 단어부터 검색합니다.
  • 여러 브랜드가 쓰는 말이어야 사람들이 많이 찾고 타고 들어옵니다. 검색했을 때 그 브랜드 제품만 나오면 그 단어는 드래그 → 취소선. “이 키워드는 검색하지 않는다, 중복만 뜬다”는 뜻입니다.
  • 이 판단은 지칭 단어 칸에서만 합니다.

6꼬리물기 보는 법과 기록하는 법중요“사람들은 이 페이지까지 잘 안 넘어가요.”▾
  • 4배수 때 만졌던 세팅(해외직구 제외·80개 보기)은 꼬리물기 때 건드리지 않습니다. 검색한 그대로 첫 페이지 40개만, 4배수 하듯 에누리로 마진을 봅니다.
  • 찾으면 카탈로그명을 바로 아래 줄에 붙여 넣고, 오늘 날짜, 찾은 키워드에는 실제 검색한 단어(예: 크림 70ml)를 적습니다. 그래야 시트만 보고 잘하신 부분과 어려우셨던 부분을 판단할 수 있습니다.
  • 다 본 키워드는 툴바 A(텍스트 색상) → 빨간색.

1,000개 넘는 세부 카테고리마다 첫 페이지
  • 4배수 때는 카테고리 메뉴로 들어갔지만 꼬리물기는 무조건 검색입니다.
  • 제조사·브랜드는 첫 페이지 후 화살표로 세부 카테고리를 펼쳐 1,000개 넘는 곳만 차례로 봅니다(예: 화장품/미용 → 헤어케어 → 탈모케어, 이어서 스킨케어, 마스크/팩). 방금 본 제품이 또 나오고 확실히 기억나면 넘어가도 됩니다.
7다음 꼬리물기는 마지막에 찾은 상품에서“7개를 찾았다고 하면, 이번에는 7번째 거.”▾
  • 여기까지 보면 높은 확률로 2~10개쯤 찾아집니다.
  • 2개 찾았으면 2번째 상품, 그 상품에서 7개 찾았으면 7번째 상품에서 다음 꼬리물기. 가장 최신에서 이어 갑니다.
  • 중간에 붕 뜬 상품들은 나중에 다시 보니 걱정하지 않으셔도 됩니다. 순서를 바로 답하실 만큼 강의 내용을 잘 기억하고 계셨습니다.
8찾은 상품 올리기“이 카탈로그 담기 누르면 여기 쏙 들어가지죠?”▾
  • 셀러들의 수다 말고 직접 싼 상품을 찾아 올렸는데 잘 안 올라가는 것도 있었다고 하셨습니다.
  • 올리는 법: 카탈로그 검색 → 카탈로그가 켜진 화면에서 자동등록 프로그램 → 이 카탈로그 담기 → 자기 전에 대량등록 시작. 스마트스토어 로그인이 꼭 되어 있어야 합니다.
  • 상담 중 1개를 담아 가동해 두었습니다.
  • 등록되면 체크 표시, 안 되면 그 자리에 사유가 나옵니다. 사유를 알려 주시면 됩니다. 숫자 아래 빨간 표시가 무엇인지 헷갈리시면 화면을 캡처해 보내 주세요.
9속도는 걱정하지 않기“1시간에 초보자 기준으로 3개에서 7개 정도가 평균이에요.”▾
  • 최근 하루 6~7시간을 쓰는데도 막혀서 진도가 안 나간다고 하셨습니다. 강의는 3번 정도 틀어 놓고 반복해 들으셨습니다.
  • 처음이라 그런 것이고, 초보 기준 1시간에 3~7개가 평균입니다. 아직 컨설팅을 한 번도 안 받으신 상태였으니 마음 편히 가지세요.
  • 컴퓨터를 예상보다 훨씬 잘 다루십니다. 오늘 배운 순서대로 꼬리물기를 이어 가시면 됩니다.
